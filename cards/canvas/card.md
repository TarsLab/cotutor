# canvas — 画板

## 是什么

孩子自己在上面画的一块板:笔、橡皮、黑红蓝三色、撤销、清空。可以给一幅底图(课包的终帧、几个骨架元素,或孩子刚拍的作业照片)让孩子在上面标画,也可以空白只给题目。「给老师看」会导出一张 png 给你。

## 什么时候用 / 别用

- 用:「画一画」「标出来」「圈出来」这类要孩子动手的题:画高、标直角、圈出错的那步。
- 用:一节末尾,末句讲稿就是这个要求。
- 用:上下文包里有 photos 时,把那张照片做底图,让孩子在自己的作业上圈出错的那道、把答案写上去。
- 别用:答案是一个数或一个词 → 讲稿里问,孩子开口说;能选的 → `choice`。
- 别用:一节里放两张画板。

## 写法

- 第一行是底,后面的行是题目。标签后面的词也可以当题目。
- 底有四种:
  - 课包 id:那幅图的终帧做底,孩子在上面标画。
  - 一张图的路径:照 `photos:` 里那样的 `captures/…` 相对路径写,照片做底。
  - 一段行内骨架 JSON:`{"skeletons":[…]}`,drawtell 的元素写法,不超过 40 个。
  - 什么底都没有:只写题目,就是空白画板。

## 孩子看到什么

紫色卡:题目 + 「点开画一画」(照片做底的,卡上先是那张照片的小图)。点开铺满整屏:顶栏是题目一行和「给老师看」;左边一列七个大钮(笔 / 橡皮 / 黑红蓝 / 撤销 / 清空),最底下是你的小头像;你给的底图是灰的。

他画的时候可以按住你的小头像说话,嘴看着画接一句,不交给你。嘴有时也会主动看着画说一句、问一句。轻点「给老师看」是交画;按住它说话,是画和这句话一起交给你。

交过之后卡上就是孩子画的那张图,锁住了,只能看、不能再画;要他再画,出一张新卡。

## 你会收回什么

`<job>/<n> canvas「题目」 画了 12 笔(红 8、蓝 4),画了约 3 分钟,清空重画过 1 次,清掉的那几版:/…/captures/2026-09-10/1621-2.jpg(用 Read 看),图:/…/conversations/math-tutor/2026-09-10.1620-1.cards/3.png(用 Read 看)`。没清空过就没有那一段。

图是绝对路径,交了画的那轮有 Read,先看图再回;看不了图就靠笔数。他画的时候说过的话在上下文包 `live:` 的 `draw:` 里。

## 状态的形状

`{"ink": [...], "image": "conversations/…/3.png", "cleared": [{"at": …, "from": …, "strokes": 12, "image": "captures/…jpg"}]}` —— 孩子画的元素(drawtell 的 ink 层)、导出的 png 路径(服务端写)、清空过的几版(清空的时刻、那一版第一笔的时刻、几笔、清空前存的图)。
