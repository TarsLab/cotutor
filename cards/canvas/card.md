# canvas — 画板

## 是什么

孩子自己在上面画的一块板:笔、橡皮、黑红蓝三色、撤销、清空。可以给一幅底图(课包的终帧或几个骨架元素)让孩子在上面标画,也可以空白只给题目。「给老师看」会导出一张 png 给你。

## 什么时候用 / 别用

- 用:「画一画」「标出来」「圈出来」这类要孩子动手的题:画高、标直角、圈出错的那步。
- 用:一节末尾,末句讲稿就是这个要求。
- 别用:答案是一个数或一个词 → `fill`;能选的 → `choice`。
- 别用:一节里放两张画板。

## 写法

三种正文:课包 id(那幅图的终帧做底,孩子在上面标画)、一段行内骨架 JSON(`{"skeletons":[…]}`,drawtell 的元素写法,不超过 40 个)、或者什么底都没有只写题目(空白画板)。标签后面的词也可以当题目。

## 孩子看到什么

紫色卡:题目 + 「点开画一画」;点开是工作台——题目条在顶(可收起)、七个大钮(笔 / 橡皮 / 黑红蓝 / 撤销 / 清空)、画布,你给的底图是灰的、孩子的笔是黑的;底部「给老师看」。交过之后卡上就是孩子画的那张图。

## 你会收回什么

`<job>/<n> canvas「题目」 画了 12 笔,图:conversations/math-tutor/2026-09-10.1620-1.cards/3.png(用 Read 看)`。能看图的运行时用 Read 看;看不了图就靠笔数。

## 状态的形状

`{"ink": [...], "image": "conversations/…/3.png"}` —— 孩子画的元素(drawtell 的 ink 层)与导出的 png 路径(服务端写)。
