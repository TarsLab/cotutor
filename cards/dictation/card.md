# dictation — 听写

## 是什么

听写卡:首页上一张,写着「听写 · 6 个词」。孩子点开,老师一个词一个词念,孩子用 Apple Pencil 在田字格里写。全部写完,书上的字淡淡叠在孩子写的上面,孩子自己对。只用在首页。

## 什么时候用 / 别用

- 用:孩子今天要听写生字词,家长把词表给你。
- 用:上次听写没写全的词,排进下一次。
- 别用:教一个字怎么写 → `tianzige`。
- 用:英语单词听写:一张卡里都写英文单词,孩子在四线三格里写整个单词。
- 别用:板书里 → 只能用在首页。

## 写法

围栏标签 `dictation <老师的键>`。老师的键可以不写,不写就用语文老师的声音。

正文一行一个词:

- 词是一到四个汉字,不带拼音和标点。
- 要说明怎么念,在词后面空一格接着写。例如 `鼓励 鼓励,老师鼓励我的鼓励`。
- 同音的、单个字的词,都写上念法。例如 `叶 树叶的叶`。
- 念法是孩子听到的全部。它会被念两遍。
- 最多 20 个词。
- 英文单词前面可以配一个 emoji,如 `🚌 bus a red bus`。能画出来的东西才配,抽象的词(like、the)不配。孩子写完对答案时才看到。

## 反例

词里夹了拼音,解析不成,整张卡退成一段文字:

<!-- expect {"kind":"text","warning":true} -->
```dictation
鼓励gǔlì
```

汉字的词和英文单词写在一张卡里,解析不成:

<!-- expect {"kind":"text","warning":true} -->
```dictation
春天
red
```

一个词超过四个字,解析不成:

<!-- expect {"kind":"text","warning":true} -->
```dictation
画蛇添足画
```

## 孩子看到什么

首页上一张卡,写着「听写」和几个词,看不到字。点开后:

1. 老师念第一个词,念两遍。孩子听不清可以点「再念」。
2. 左边是听写本,一个词一行;右边一个大田字格,一次写一个字,写好点「这个字写好了」。
3. 不会写可以点「不会写,给答案」:书上的字一笔一笔写给他看,再照着灰色描红写一遍。
4. 全部写完,书上的字淡淡叠在孩子写的字上。孩子点一个字,书上的字就在他写的字上一笔一笔写一遍。
5. 少写了笔、多写了笔、空着的词,卡上问一句「这个再写一遍?」,不画叉,不打分。看过答案的词不再问。
6. 孩子可以对任何一个词说「我想再写」。

英文单词:一个单词一个四线三格,写整个单词;写完正确的单词淡淡叠在上面,配了 emoji 的放在旁边,孩子自己对,不逐个字母比,也不问「再写一遍?」,想再写自己点。

## 你会收回什么

孩子写的每一笔都会记下来,连同时刻。应用逐字对照书上的笔画,记下少了哪一笔、多了几笔、笔顺对不对、写得偏不偏、哪个字看了答案。家长在 `/dictation/parent` 看结果,在 `/dictation/reel` 看录像。卡上没有状态。

## 状态的形状

没有。
