# fill — 填空

## 是什么

句子里留空让孩子填;答案只有你知道。孩子在舞台里逐空打字(或按住说),「交给老师」就到你下一轮的上下文包里。

## 什么时候用 / 别用

- 用:答案是一个词、一个数,不适合给选项(给了选项就是猜)。
- 用:放在一节末尾,末句讲稿就是这道题。
- 别用:答案是一句话、写法很多种 → 讲稿里问,孩子说话答。
- 别用:一句里超过三个空。

## 写法

句子里用 `___`(三个下划线)留空,下一行 `= 答案`;多个空按顺序各一行 `= 答案`。答案孩子看不到。

## 例子

<!-- expect {"kind":"fill","props":{"text":"三角形的面积等于底乘高再除以___。","blanks":1,"answers":["2"]}} -->
```fill
三角形的面积等于底乘高再除以___。
= 2
```

<!-- expect {"kind":"fill","props":{"blanks":2,"answers":["3","5"]}} -->
```fill
3、4、___ 和 5、12、13 都是勾股数组;一个直角三角形两条直角边是 3 和 4,斜边是 ___。
= 3
= 5
```

## 反例

没有 `___` 就不是填空,解析不成,退成一段文字:

<!-- expect {"kind":"text","warning":true} -->
```fill
这句里没有空。
= 2
```

## 孩子看到什么

紫色卡,空是一条下划线(至少四个字宽),填了的字紫色。点卡开舞台:句子里逐空是输入框,填了就存,底部「交给老师」。卡上不画对错。

## 你会收回什么

`<job>/<n> fill「三角形的面积等于底乘高再除以___。」 第 1 空填「2」(答案「2」)`——每个空一句。对错由你口头说。

## 状态的形状

`{"answers": ["2"]}` —— 按空的顺序;没填的空是空串。
