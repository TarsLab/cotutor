# paint — 画图

## 是什么

孩子说清楚的一个故事,分好幅交给画家,应用画成一张连环画(四幅时 2×2,像练习册)。出题时带上题干和词语宝库,就是一道看图说话题。

## 什么时候用 / 别用

- 用:「你说我画」里,孩子把整段连着说过一遍、和你分好幅以后。
- 用:「我来出题」里,词都落到了幅上、题干也定了。
- 别用:故事还没说清楚。先接着问,画是奖励。
- 别用:现成的图 → `image`;要孩子自己画 → `canvas`。

## 写法

- `题:` 题干,出题才写。
- `词:` 词语宝库,用顿号隔开,出题才写。画不出来的词(突然、终于)也放这里。
- `角色:` 一行一个,写成「名字:样子、颜色、衣服」。每幅都照这个样子画。孩子说的颜色就用孩子的。
- `1.` 起一幅一行,一到四幅。每幅只写看得见的:时间和天气、地方、谁、动作、表情、东西。
- 每幅都写出角色的名字,不用「他」。
- 不写心里想的、说的话,也不写「羞愧」这种看不见的词:写成「低着头,脸红红的」。
- 一幅最多三个角色,一幅只画一件事。

## 反例

没有分幅,解析不成,会退成一段文字:

<!-- expect {"kind":"text","warning":true} -->
```paint
小熊和小猴种西瓜,小猴很懒,最后很羞愧。
```

五幅太多,解析不成:

<!-- expect {"kind":"text","warning":true} -->
```paint
1. 早上
2. 中午
3. 下午
4. 晚上
5. 第二天
```

## 孩子看到什么

题干一行;画好前是分好的几幅(孩子说的话)和「画家在画」;画好了图淡入,每格左上角一个圆圈数字;下面是词语宝库。点开铺满,能双指放大。`角色:` 不显示。没画成就一直是分好的几幅,孩子端不说没画成。

## 你会收回什么

孩子下一条消息的 `cards:` 里有一行:画好了,或没画成。你看不到图:想知道画得怎样,问孩子「哪里和你想的一样?哪里不一样?」。

## 状态的形状

没有。
