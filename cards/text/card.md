# text — 一段字

## 是什么

板上的一段字:定义、结论、公式、一句要记住的话、题面。一张卡一个意思,能独立被指着讲三句。

## 什么时候用 / 别用

- 用:给一个概念下定义、放一个公式、写一句要记住的话、写题面(没有选项、不用孩子填)。
- 用:小节标题——只写一行 `# 标题`,板上出一行无底的字,不算卡。
- 别用:原文、古诗、单词表(超过两行的要念的东西)→ 用 `read`,孩子能点哪段听哪段。
- 别用:要孩子选、填、画的 → `choice` / `fill` / `canvas`;`text` 卡上什么都做不了。
- 别用:把讲稿写进卡。「第一步:13 的平方是多少」这种是你说的话,写在围栏外面,一行一句。

## 写法

围栏标签只写 `text`。正文第一行以 `# ` 开头就是这张卡的标题,下面是正文;只有一行 `# 标题` 没有正文 = 小节标题。样子(底色、字号、并不并排)不用管,后期定。
算式写 `text formula`(衬线居中,单独一行)。老写法 `text cover`(封面:第一行标题、第二行副标题)、`text note`(一句要记住的话)、`text quote`(引一句原文)、`text step`(第一行是这步的名字)仍然认,但不用再写。

## 反例

方括号是讲稿的标注语法,不写在卡里;写了会被剥掉,家长视图多一行提醒:

<!-- expect {"kind":"text","props":{"text":"两条短边叫直角边"},"warning":true} -->
```text
两条短边叫[直角边]
```

## 孩子看到什么

一张带底色的卡:标题一行小字、正文一段;封面是深底大字;公式衬线居中。讲稿念到 `[词]` 时,词在卡上被标注(标题位画圈、正文里的词术语底、公式荧光)。点开只是看清,没有交互。

## 你会收回什么

没有——这种卡没有状态。

## 状态的形状

没有。
