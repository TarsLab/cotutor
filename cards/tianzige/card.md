# tianzige — 田字格

## 是什么

田字格:孩子问「这个字怎么写」时用的卡,一到四个汉字,每个字一个格,讲到这张卡时逐笔写一遍,之后孩子点哪个字,哪个字再写一遍。笔顺是现成的数据,不是你写的。

## 什么时候用 / 别用

- 用:孩子问「X 怎么写」「X 的笔顺」;讲生字、讲词语时要孩子看清怎么落笔。
- 用:一个词就写一张,`鼓励` 两个字放一张,孩子看得到它们是一个词。
- 别用:给孩子读的整句、古诗 → `read`。
- 别用:解释字义、讲来历 → `text`;田字格里只有字,没有别的。
- 别用:拼音、部首、笔画数写进卡里 → 说在讲稿里;笔画数卡上会自己显示,你不用数,也别在讲稿里数。

## 写法

正文就是要写的字,一到四个汉字,不要空格、标点、拼音。同音的词先给再确认:先出这张卡,讲稿里问一句「你说的是加油打气的那个鼓励吧」,不是再换。

## 反例

夹了拼音或标点解析不成,会退成一段文字:

<!-- expect {"kind":"text","warning":true} -->
```tianzige
鼓励 gǔ lì
```

超过四个字也解析不成,拆成两张:

<!-- expect {"kind":"text","warning":true} -->
```tianzige
画蛇添足画蛇
```

## 孩子看到什么

白底卡,每个字一个田字格,格里先是淡淡的字形;讲到这张卡时一笔一笔写出来,鼓写完再写励,右下角标着几画。之后孩子点哪个格,哪个字再写一遍。没有舞台、没有按钮。数据里没有的字(生僻字)只显示字形、不动。讲稿的 `[词]` 落不到这张卡上,要标注写在别的卡里。

## 你会收回什么

没有——田字格不记状态(点了几遍不告诉你)。

## 状态的形状

没有。
