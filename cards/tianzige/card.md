# tianzige — 田字格

## 是什么

田字格:孩子问「这个字怎么写」时用的卡,一到四个汉字,每个字一个格,讲到这张卡时逐笔写一遍,之后孩子点哪个字,哪个字再写一遍。笔顺是现成的数据,不是你写的。

## 什么时候用 / 别用

- 用:孩子问「X 怎么写」「X 的笔顺」;讲生字、讲词语时要孩子看清怎么落笔。
- 用:一个词就写一张,`鼓励` 两个字放一张,孩子看得到它们是一个词。
- 别用:给孩子读的整句、古诗 → `read`。
- 别用:解释字义、讲来历 → `text`;田字格里只有字,没有别的。
- 别用:部首、笔画数写进卡里 → 说在讲稿里;笔画数卡上会自己显示,你不用数,也别在讲稿里数。

## 写法

- 第一行是要写的字:一到四个汉字,不要空格、标点。
- 第二行写拼音:一字一个音节,空格隔开,带声调(`gǔ lì` 或 `gu3 li4`)。
- 多音字写这句话里的读法,如「长大」写 `zhǎng dà`。
- 拼音和字数对不上,卡上就只有字,不显示拼音。
- 同音的词先给:先出这张卡,讲稿里说一句是哪个意思,如「鼓励,就是给人加油打气」。
- 不先问,也不在末尾问「你说的是……吧」。写错了,孩子会说。

## 反例

拼音和字写在同一行,或夹了标点,解析不成,会退成一段文字:

<!-- expect {"kind":"text","warning":true} -->
```tianzige
鼓励 gǔ lì
```

拼音和字数对不上,卡照常,只是不显示拼音:

<!-- expect {"kind":"tianzige","props":{"chars":"鼓励"},"warning":true} -->
```tianzige
鼓励
gǔlì
```

超过四个字也解析不成,拆成两张:

<!-- expect {"kind":"text","warning":true} -->
```tianzige
画蛇添足画蛇
```

## 孩子看到什么

白底卡,每个字一个田字格,写了拼音的标在格子上方(像课本);格里先是淡淡的字形;讲到这张卡时一笔一笔写出来,鼓写完再写励,右下角标着几画。之后孩子点哪个格,哪个字再写一遍。没有舞台、没有按钮。数据里没有的字(生僻字)只显示字形、不动。讲稿的 `[词]` 落不到这张卡上,要标注写在别的卡里。

## 你会收回什么

没有——田字格不记状态(点了几遍不告诉你)。

## 状态的形状

没有。
