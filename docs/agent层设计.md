# cotutor agent 层设计

> 2026-09-08。范围:agent 层的概念,即目录、上下文、记忆、子代理、跨 agent 的知识流动;**不涉及 drawtell**。前提来自《产品规划.md》:老师 = 可直接对话的老师文件 + 自己的对话;两个 CLI 并行支持(claude 2.1.220 / qwen 0.21.13)。本文先把「记忆」这个词拆干净,因为它在 CLI 里对应三个不同的东西,混用会把设计做歪。带 ✓ 的是本机实测,其余标「文档」。
> 同日修订:**不设记忆的写入纪律**。孩子的这些数据都是学习数据、都是本地文件,不做隐私与评判方面的约束(拍板);本文只讲东西放哪、怎么流,不讲不许写什么。
> 同日三次修订:**一个 workspace 一个孩子**(拍板)。`~/cotutor/<slug>/` 一孩一 workspace 一 vault 一服务进程;老师的记忆、账本、计划天然按孩子分,不再有孩子维度;跨孩子共享靠拷贝技能。

## 0. 事实盘点(2026-09-08)

**Claude Code(本机实测 + 文档)**

- ✓ 根目录的 `.claude/agents/` 与 `.claude/skills/` 从子目录 cwd 都找得到(向上查找到 git 根);`claude --agent <name> -p ...` 可从子目录启动
- ✓ `--agent` 主会话认 frontmatter 的 `memory: project`,记忆目录落在 **cwd** 下:`<cwd>/.claude/agent-memory/<name>/`,不是 git 根;老师被指示后会自己写 `MEMORY.md` 索引 + 主题文件(带 frontmatter,`type: project`)
- ✓ 会话按 cwd 归档:`~/.claude/projects/<cwd 路径>/<session>.jsonl`
- 文档:通用「自动记忆」按 **git 仓**归档(`~/.claude/projects/<仓>/memory/`),同仓子目录共用一份;`autoMemoryDirectory` 可从任何 settings 作用域(含 `--settings <文件>`)改位置;关掉自动记忆则 `memory` 字段也失效
- 文档:`MEMORY.md` 只常驻头 200 行或 25KB,主题文件按需读;超限写入成功但下次加载截断并报错要求重写
- 文档:命名子代理**不继承**主会话记忆与对话;fork 继承对话、系统提示与记忆;子代理各有自己的记忆目录
- 文档:`CLAUDE.md` 从 cwd 向上每层都加载并按根到 cwd 顺序拼接,子目录里的在读到该目录文件时加载

**Qwen Code(文档)**

- 自动记忆按 checkout:`~/.qwen/projects/<project>/memory/`;`pinned/` 放手工固定的文档;`/dream` 定期去重清理
- `.qwen/team-memory/` 可开,进 git 共享,**单一目录,不分 agent**;写入前扫密钥
- 子代理 `memory` 字段、`--agent` 旗、`skills` 字段均未落地(文档写明待后续 PR)
- fork 子代理继承父对话并共享缓存前缀(文档称省 80%+ token);fork 不能再起子代理;顶级命名子代理默认后台跑

**结论**:老师的私有记忆只在 Claude 有原生机制;Qwen 下没有。所以设计上**私有记忆只能是缓存**,真正要传承的知识必须在workspace文件里,与 CLI 无关。

## 1. 三种「记忆」,三个归属(核心)

| 名 | 装什么 | 谁写 | 谁读 | 真相在哪 | CLI 机制 |
|---|---|---|---|---|---|
| **长期记忆(vault)** | 关于孩子与这个家的**事实**:档案、课程表、日记(孩子问的话、打分够的摘要、观察)、教材目录与口径、计划 | 家长手写;机器只按封闭清单新建或追加(日记、计划),且老师不直接写——记账时回「## 记账」段,应用渲染(2026-09-14,《obsidian仓库设计.md》) | 所有老师(上下文包机械抽 profile / plan / recent;讲解前 Read 教材那一节、Grep 日记)、规划老师、家长 | 文件形状由 lib/diary.ts 保证 | **无**,是普通文件 |
| **产物账本(ledger)** | 课包等产物的索引与费用 | scene-maker 与应用(追加式) | 应用、家长端 | artifacts.jsonl 契约 | 无 |
| **私有工作记忆** | 老师**自己怎么干活**:讲法偏好、踩坑、工具用法、上次做到哪 | 该老师 | 只有它自己 | 缓存,丢了不坏事 | Claude `memory: project` → `agents/<name>/.claude/agent-memory/<name>/`;Qwen 无,退化为 `agents/<name>/NOTES.md` 由指令维护 |
| **会话记忆** | 当天这一段对话 | CLI | 该会话 `--resume` | 转录 NDJSON 落 `conversations/` | `--resume <id>`;按天切,跨天不 resume |

三条约定(讲归属,不讲禁令):

1. **要给别的老师看的,进日记(记账段的 observations)。** 日记是所有 agent 都读的地方(上下文包的 recent 从它抽),也是 Qwen 下唯一存在的跨会话记忆;私有记忆里的东西只有写它的老师下次会看到。
2. **私有记忆是缓存,不是契约。** 别的 agent 想读可以读(都是本地文件),但不要依赖它;删了重建成本为零。
3. **谁写谁是真相**(《obsidian仓库设计.md》):vault 是长期记忆(档案、课程表、日记、教材、计划、参考),workspace 是运行记录(对话、课包、照片、产物账本、私有记忆);机器写 vault 只新建或追加、永不改家长的字。2026-09-14 改掉的旧拍板:观察不再走「账本 + 投影」两处一份,真相就在日记。

**cwd 取老师目录,不取根**(2026-09-08 拍板)。理由:`CLAUDE.md` 向上叠加,家规在前、老师专属在后 ✓;agents / skills 向上都找得到 ✓;`memory: project` 自然落进老师的家 ✓;会话按老师归档 ✓;老师产的文件落自己目录不串门。唯一的坑:通用自动记忆按 git 仓共用一份,老师作为 `--agent` 主会话时是否还会往那里写未验(实测只见它写 agent-memory);若会,每老师一份 `--settings` 把 `autoMemoryDirectory` 指到 `agents/<name>/memory/`。此项暂不决策,以后再说(2026-09-08)。

**多孩子 = 多套 workspace**(2026-09-08 拍板):每套一个服务进程、一个端口;孩子设备各指各的,家长设备切实例;老师文件与家规从技能仓各链一次,共享的是定义,不共享记忆与账本;跨孩子共享(老二到了老大的年级复用内容)做成一个拷贝技能,拷贝不链接,同存量原则「缓存与拷贝是两件事」。课程表与素材集里已有的孩子字段保留为可选。

**老师与帮手同住 `.claude/agents/`,靠 `cotutor.json` 区分**:有人设条目的是老师(家长孩子能找),没有的是帮手子代理(只有老师能调)。不靠子目录区分,Qwen 是否递归扫描未核;名字用前缀(`helper-*`)保险。

## 3. 上下文:一条消息进来时老师看到什么

| 层 | 内容 | 谁给 | 每条消息付费? |
|---|---|---|---|
| 常驻 | agent 正文(系统提示)+ `CLAUDE.md` 链(家规 → 老师)+ 预载 skill + `MEMORY.md` 头部 + 当天会话历史 | CLI | 是 |
| 注入 | **上下文包**:时段、当前对象(正在看的东西、圈了什么)、本周计划中与本老师相关的行、最近 N 条本学科观察(孩子由 workspace 决定,不进包) | 应用拼成固定格式(YAML 块)放在消息前 | 是,但可控 |
| 按需 | 账本全量、vault 日记、产物、别的老师的汇总 | 老师自己 Read | 用到才付 |

原则:**常驻小、注入准、按需大**。对话按天切是给「会话历史」一个上界;`--resume` 每次重放整段(缓存命中便宜但仍计),所以上下文包只放这条消息用得着的。N 与计划行数是政策旋钮。

## 4. 子代理:什么时候用

子代理不是老师:老师有会话、有人设、能被家长孩子找到;子代理是老师的工具,孩子看不见,家长在家长视图里看得到它们的报告。适用场景对照 Claude Code 文档的三种模式(隔离高噪声、并行、链式)加 fork:

| 场景 | 形态 | 为什么用子代理 | 两 CLI |
|---|---|---|---|
| **并行变体**:同一题两种讲法,给家长 / 孩子选 | 命名子代理 × 2 并行 | 各自独立上下文互不污染;**选择本身是观察**,记账本 | 都有 |
| **独立评审**:产物出来后另一个上下文审 | 命名子代理 | 不受生成者偏见;只回结论 | 都有 |
| **高噪声隔离**:长循环(校验 / 重试 / 批量) | 命名子代理 | 老师主线转录干净 | 都有 |
| **记账员**:学习结束后由家长触发,抽当天观察写账本、投影到日记 | **fork**(或老师自己写) | 需要整段对话上下文;fork 两边都继承对话,Qwen 还共享缓存前缀 | 都有;Qwen fork 不能再起子代理 |
| **规划老师扇出**:按学科并行读账本切片做摘要 | 命名子代理 × N | 并行 | 都有 |

两边共有的约束:子代理不能向人提问 → 报告里带「待裁量」段由老师落盘;命名子代理不继承对话与老师记忆,要上下文就 fork;子代理各有自己的记忆目录(Claude);并发有上限;Qwen 的 `--max-tool-calls` 不算子代理内部调用,预算用 `--max-wall-time`。

## 5. 记忆的维护

**不设写入纪律**(2026-09-08 拍板)但有**写入前三问**(2026-09-14,《obsidian仓库设计.md》§0):一年后家长还想翻到它吗、老师下次讲同类东西需要吗、能不能机械取出来——过不了的留在 workspace,不进 vault。下面是让记忆长期可用的机制:

- **记账段格式**:老师回「## 记账」(thread / name / textbook / summary / steps / observations),应用渲染成日记的一段:H2 = 学科 · 话题名,孩子问的话是 callout,`- 观察:` 一行一条。形状由代码保证,老师写错了应用报 warning、不落。
- **索引上限**:`MEMORY.md` 一行一条,细节进主题文件;Claude 超限会报错要求重写,Qwen 用 `/dream` 自动整理。
- **时间与纠错**:日记按天,观察行在哪天的哪个话题下就是日期与学科;错了家长在 Obsidian 里改一句、删一行,下一轮上下文包就变;Claude 私有记忆文件自动带 `modified`。
- **触发**(2026-09-08 拍板,2026-09-14 落地):记账在**学习结束后由家长触发**,不自动跑。家长先给话题打星,再点「记账」(或 `cotutor bookkeep`):这天每个还没记过、有孩子的话或打了分的话题,各 resume 那位老师一轮,消息是「给刚才这个话题记账」;老师只回「## 记账」段。打分 ≥ `vault.keepScore` 的话题才沉淀摘要与讲解骨架,孩子问的话与观察总是记。
- **周汇总**:不另设周记;规划老师做计划时从最近两周的日记读,写进计划文件的「## 上周」。
- **家长入口**:日记与档案在 Obsidian 里直接改;老师团页能看、能改任何老师的私有记忆,全是文本。

## 6. 规划老师:跨老师的知识怎么流

「学习规划 agent 需要了解其他 agent 的记忆」:它需要的是其他老师**记下的关于孩子的事实**,日记就是为此存在的,所有老师的记账都落在同一处,它一处读。

- **读**:最近两周的日记、档案、课程表、上周计划、`artifacts.jsonl`。别的老师的 `agent-memory/` 也是本地文件,想读可以读,只是不当契约:Qwen 下不存在,内容也偏「怎么干活」。
- **写**:计划草稿 → vault `计划/<周>.md`;家长改过或确认后成为真相。
- **回流**:应用把计划里「与本老师相关的行」放进每条消息的上下文包,各老师不用自己读全文。
- **触发**:定时(周日晚)`claude --agent planner -p "做下周计划"`,或家长在对话里叫它。
- **扇出**:学科多时起子代理各读一片账本再汇总。
- **走不通的路**:让老师之间互发消息传记忆,两 CLI 的子代理消息都在会话内,不跨会话;跨老师只能走文件。

可见性矩阵:

| 角色 | 账本 | 私有记忆 | 会话 | vault |
|---|---|---|---|---|
| 老师 | 读全量,写观察 | 自己的 | 自己的 | 读 |
| 帮手子代理 | 读 | 各自的 | 无(命名)/ 继承(fork) | 读 |
| 记账员(fork) | 写观察与汇总 | 继承老师的 | 继承 | 写日记投影段 |
| 规划老师 | 读全量 | 自己的 | 自己的 | 写计划草稿 |
| 家长 | 全部可看可改 | 全部可看可改 | 家长视图 | 主人 |
| 孩子 | 无 | 无 | 孩子视图 | 无 |

## 7. 两 CLI 记忆机制对照

| 能力 | Claude Code | Qwen Code | 本文怎么用 |
|---|---|---|---|
| agent 文件当主会话 | `--agent` ✓ | 未落地 | Qwen 暂用 `--system-prompt` 塞正文 |
| 每 agent 私有记忆 | `memory: user/project/local` ✓,主会话也认 ✓ | 未落地 | 私有记忆只当缓存;Qwen 用 NOTES.md |
| 记忆位置可改 | `autoMemoryDirectory`(含 `--settings`) | 按 checkout 固定 | Claude 每老师一份 settings(若需要) |
| 共享记忆 | 无(靠文件) | `.qwen/team-memory/` 单一目录 | 都不用,账本是文件契约 |
| fork 继承 | 对话 + 系统提示 + 记忆 | 对话 + 系统提示 + 缓存前缀 | 记账员走 fork |
| 记忆自动整理 | 指令驱动 | `/dream` | 记账员周 rollup 与 CLI 无关 |

`user` / `project` / `local` 三选一:**project**(2026-09-08 拍板)。`user` 落在 `~/.claude/` 跨所有项目,会把老师的记忆和你写代码的记忆混在一起,也不随workspace备份;`local` 不进 git,丢了 diff 与回溯;`project` 落老师目录、进私有 git 仓,能 diff、能删、能迁移。前提是workspace像 drawtell-workspace 一样是私有仓。

## 8. 草案

家规 `CLAUDE.md`(workspace根,所有老师常驻,故意短):

```markdown
# 家规
- 关于孩子的观察,写一条到 ledger/observations.jsonl(一句 claim + evidence + 你的名字和日期),别的老师和规划老师从那里读。
- 你自己的经验记进你的记忆目录(MEMORY.md 一行索引 + 主题文件)。
- 需要家长拍板的事写「待裁量」段,不要停下来等。
- 会话按天,明天从账本和你的记忆接着来,不要指望今天的对话还在。
```
