书架

每位老师一个书架:课本在上面,家长另放的科普书、百科也在上面。家长把书放进来(PDF、EPUB、手机拍的照片),服务端转成同一种样子;孩子在首页点一本就读,老师陪着。这份写书怎么存、怎么预处理、孩子和老师怎么用,家长端的样子在样稿上。

学科写「科学」科学老师 science-tutor,对得上课程表、课本文件名、观察。显示名「科学老师」。
科学老师只有一个 activity陪孩子读书:他自己读、自己翻,不懂了问。不考、不出题。
科学课本能铺了广东版科学二上:Unicode 拼音、带页码的单元、栏目下面分段(layout: science),见 docs/dev/课本.md。
多种格式PDF(有字的、扫描的)、EPUB、手机拍的照片都收。预处理在家长端点,服务端做。

S一本书

不管家长放进来的是什么,转完都是同一种样子:一个 PDF 加一份说明。孩子端、舞台、老师只认这两样,课本那条线(pdf.js 画页、文字层建索引、窗图给老师)整条照用。

规则

编号规则状态
S1一本一个文件夹:vault 的 书架/<学科>/<书名>/,同练习册。里面三样:书.pdf(孩子看的,只读它)、书.json(说明)、原件/(家长放进来的,原样留着,转法改了能重做)。提议
S2书.json 记:书名、学科、原件是什么格式、封面是哪一页、不给孩子看的页、目录(章名 + 从哪一页起)、每页的字从哪来(PDF 文字层 / 认字)、认出来的行与字框(同 BookPage.lines)、处理到哪一步。家长端写,孩子端和舞台只读。形状进 src/schema/shelf.ts。提议
S3索引照课本建:BookIndex 一样;有文字层的页照 readPdfPages,认字的页用书.json 里的行;目录用书.json 里家长核过的,不再猜。缓存照旧在 .cotutor/textbooks/。科普书按段分(layout: prose)。提议
S4课本不搬:还在 教材/,目录照现在自动认。书架上排第一,标「课本」;家长不能在家长端改它的目录、不能删(换课本就是换文件)。提议
S5一本书在一位老师的书架上,照学科(文件夹)。不分年级、学期。提议
S6书只在家里。放在家长的 vault 里,不进仓库、不进 npm 包、不进年级包。认字要把那一页的图发给百炼(家长那把 key),家长端点认字前说一句。提议

P预处理

家长在家长端放一本书、点几下;转换、认字在服务端跑,家长端关了也接着做,回来看进度。一次处理一本,别的排队。

几种格式

放进来的转成书.pdf字从哪来目录从哪来状态
PDF 有字不转,拷一份文字层PDF 书签 → 目录页(parseToc)提议
PDF 扫描的不转,拷一份认字(P4)PDF 书签 → 认字以后的目录页提议
EPUB(流式)本机 Chrome 排成平板的页(3:4,字照低年级的大小),打印成 PDF文字层(Chrome 印出来的自带)EPUB 自己的目录(nav)提议
EPUB(固定版式,绘本)一页一张,照它的页面大小文字层;图里的字不认EPUB 自己的目录提议
手机拍的照片照文件名或拍摄时间排,家长能拖着换、转 90°;一张一页拼成 PDF(本机 Chrome)认字(P4)没有,家长定(P7)提议
Kindle(MOBI、AZW3)等不收。说一句:先用 Calibre 转成 EPUB(多半带 DRM,我们也打不开)提议

规则

编号规则状态
P1收下:家长端「加一本」选文件:电脑上拖进来,手机上从相册、文件里选。一次一本:一个 PDF、一个 EPUB,或一组照片。边收边写进 原件/,单本 500 MB 封顶。提议
P2认格式看文件头,不看扩展名;PDF 再看文字层有多少字(同课本自检的「几乎没有文字」)分有字、扫描。提议
P3转 PDF 用本机 Chrome(同小课堂烤画面那个;Windows 上用 Edge)。没有的话,EPUB 和照片这两种说一句做不了,PDF 照收。提议
P4认字:没有文字层的页用百炼识图认,回每行的字和框,存进书.json。先报一共几页要认、大概多少钱,家长点了才认。一页一页认,能停、能接着;认完的页马上能用。不认也能上架:没字的页只能翻、看,老师靠窗图,不点读。提议
P5封面缺省第 1 页(横着的取右半边,同课本封面),家长能换成别的页。提议
P6不给孩子看的页:版权页、广告、空白页,家长在缩略图上点掉。只是不铺,书.pdf 不改。提议
P7目录:先自动认(上表最后一列);都没有就按 Q2。家长能改章名、删一章、在某一页「从这里起一章」。还能「让老师起个草稿」:把每页头几行字给脑,回章名和起始页,家长看过再定。提议
P8上架:有书.pdf、有封面就能上架;目录、认字可以以后补。上架了孩子首页出这本书的卡;改了目录、认完字,索引重做。下架不删文件。提议
P9出错:哪一步没成,家长端说一句、能重来,原件留着。孩子端看不到半截的书。提议

K孩子与老师

书架上的书和课本走同一条线。孩子首页的卡怎么画,另出孩子首页的设计稿。

编号规则状态
K1一本书一张卡:在那位老师牌的左页上,竖版封面,框下写书名。课本那张还叫「课本」,排第一。提议
K2一位老师一个读书的 activity:头上 base: book,参数「书」说哪一本;卡就是挂了「书」的按钮(同练习册)。课本是书架上的一本。科学老师现在的 课本.md 改名(Q1)。语文、数学的「课本」不动。提议
K3进门照「册与开场」:铺上次那一章那一页,第一次铺目录;孩子先开口。位置记在 .cotutor/book-last.json,键 书架#<学科>/<书名>。提议
K4老师看到的同课本:哪本书、哪一章、这一章的字(认过字的页也有)、窗图。书架上的书都收窗图(图比字要紧)。没字的页,全文 那一页写「这一页没有字,看图」。提议
K5点读有字、分得出段的页才有;认字的页照认出的行分段。提议

Q待讨论

Q1读书的 activity 叫什么

  • 推荐:「读书」。书架上有课本也有别的书,孩子看到的是卡上的书名,不是 activity 名。
  • 还叫「课本」:不用改名,但读科普书时也叫课本,对不上。

Q2没有目录的书一章算多少

  • 推荐 A:两页一章(一个跨页)。百科多是一个跨页一个话题;家长能改。
  • B:整本一章,超过 13 页只铺前 13 页(BOOK_MAX_PAGES),后面的到不了。
  • C:家长不定目录不能上架。最准,最麻烦。

Q3跨页的版式

  • 推荐 A:照现在一页一页竖着排。先看孩子怎么用。
  • B:左右两页并成一张横的(平板横屏刚好),一个话题不切开;舞台、窗图、找位置都要跟着改。

Q4照片要不要自动裁边、拉正

  • 推荐:先不做。只给转 90°。拍歪的书先看认字认不认得出。
  • 做:用识图模型找纸的四个角,拉正、裁掉桌面。每张多花一次钱。

Q5老师能不能翻到别的书上找图

  • 推荐:以后再做。先只读孩子打开的那一本。
  • 做:孩子在课本上问「为什么有四季」,老师在书架上搜到百科那一页,[[翻 《星空与宇宙》 四季]]。要跨书搜、跨书翻,上下文包要带书架的目录。

Q6认字用哪个模型、一本大概多少钱

  • 拿一本真的扫描书量过再定。家长端的报价照量出来的写,不估。
