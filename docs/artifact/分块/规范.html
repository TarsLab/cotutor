Q讨论

Q13工作台能不能改练习册 已定

  • 定了 A:只看不改(2026-11-26)。看块、当孩子点、听念法、看检查;要改的复制一句给编程助手(同课本页顶上那句,如「练习册《表内乘法一》第 8 题的念法改成……」),它改脚本重跑。和技能的铁律一致,不会丢;做起来是课本那页去掉改的部分。
  • B:能改叫法、念法、给老师的(不动框),直接写 workbook.json,记下是工作台改的;编程助手重跑脚本前 cotutor workbook check 报「工作台改过 n 处,重跑会盖掉」,它把改的抄进脚本。省一来一回,但要多一份「谁改过」的记账,编程助手也得记得抄。
  • C:工作台的改动另存一份(workbook.edits.json,照块的 id 盖上去),应用读的时候叠上;脚本重跑不丢。最省心,但块的 id 一变就对不上,还多一套叠加的逻辑。
