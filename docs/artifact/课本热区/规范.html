课本热区

课本页上哪一块是一道题、题里套着哪几个小题、哪一格让孩子写、点了念什么、老师怎么叫它:现在靠规则从 PDF 的文字层猜(src/chalk/kit/book.ts 的 lessonBlocks、mathBlocks、scienceBlocks),表格认不出、课后题不点读,换一本书就要再调。这份提议改成预处理:技能带脚本,家长的编程助手照学科的规范把每页标成一份热区文件,应用读它。这份写文件长什么样、怎么出、孩子怎么点、老师怎么用、怎么预览和调整。

F热区文件

一页一份,和练习册用同一套作答区、物件、答案的写法(src/schema/workbook.ts)。孩子端只拿框和能做什么,答案、给老师的话只进上下文包。

示意,不是截图。原型是人教数学二上第 73 页(PDF 第 78 页)。

Q待讨论

Q1热区文件放哪

  • 推荐 A:vault 的 教材/<册名>.热区/。挨着课本,家长看得见、备份得到;标一次要几个小时,丢了心疼。
  • B:.cotutor/ 下面,同索引的缓存。不占 vault,但不进备份,换电脑要重标。
  • C:等书架(S1)做了放进那本书的 书.json。书架还停着。

Q2标好的热区能不能给别的家庭用

  • 推荐:先不共享。热区里有课文原话和题面,仓库和 npm 包不放教材。
  • 共享:同一个 PDF 指纹的热区放进年级包,别家装上就有。省下每家几小时,要先想清版权。

Q3没标的书,运行时的规则留不留

  • 推荐 A:先留着,当没标时的退路。家长不一定有编程助手的额度去标整本。
  • B:标完就删(删掉的功能删干净)。没标的课只能翻、看,老师只看窗图,不点读、不认格。

Q4题目里空着的地方怎么念

  • 推荐 A:念「几」或「什么」(「二七,几」「一(什么)鱼塘」)。孩子听得出这里要填。
  • B:停一下不念。像课本录音,但孩子不一定听得出。
  • C:念「括号」。照字面,难听。

Q5一排算式、一组口诀分多细

  • 推荐:一组一块,一句一个小块。老师会说「看 7 的乘法口诀」,也会说「二七是多少」;小块不占地方,孩子点一句念一句。
  • 只到组:块少、文件小,但点读一点念一整组。

Q6打勾的格,点一下要不要直接落一个勾

  • 推荐:不落。照旧用笔画勾;手指点只回应(铺色)。和别的格一个规矩。
  • 落:手指点一下画一个勾,再点去掉。快,但和写字格的「点开一张卡」不一样。

Q7练习册要不要换成同一个格式

  • 推荐:先抽出共用的作答区、物件、答案,题照旧。课本热区跑顺了再把 workbook.json 的 questions 换成 zones,一套预览、一套 check。
  • 现在就合:改动大,练习册已经在用。

Q8家长从哪发起标注

  • 推荐 A:编程助手里说一句(同练习册)。家长装 cotutor 时已经有编程助手。
  • B:家长端一个按钮,服务端起 codex exec 在后台标,家长端看进度。省事,但服务端要管 Codex 的登录和额度。
