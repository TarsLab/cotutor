P四条原则

下面每一条规则都从这四条推出来。规则对不上原则的,改规则。

P1

记号不盖字

除了故意盖住的(盖、遮),所有记号都在字的「后面」:字永远是页上最黑、最清楚的那一层。

P2

记号跟着话走

老师的记号属于说它的那一句。话过去了,记号跟着退下去。页上同时最多 3 处是新的。

P3

谁画的一眼分得出

老师的线是朱橙,孩子的记号是蓝,孩子写的字是铅笔灰,荧光笔是黄。颜色只表示谁画的,不表示对错。

P4

页上印着什么就能做什么

目录能点,空格能写,生字能看笔顺。不闪、不贴标签提醒;孩子按下去,页面接得住。

M画法

老师的动作写在讲稿句子后面(cards/动作怎么写.md),孩子的用笔。每种一个样张,样张里的字是真实课本的排法:字上带拼音。

S分学科:什么时候用哪种

一句话一样记号。同一句里既刷又圈,孩子不知道看哪儿。下面是给老师的写法建议,将来进 cards/动作怎么写.md 和各科的 activity。

语文数学英语
刷 荧光笔
[[看 …]]		领读一段、一句:刷到哪读到哪。诗一句一刷。读题:题干一行一行刷,读到问题那句停。领读句子、对话的一行。
圈
[[圈 …]]		要认的生字、这一句讲的那个词。一句最多 3 处。关键的数和单位、「一共」「还剩」「多几个」这种决定算法的词。这句里要会的那个单词。
划 横线
[[划 …]]		中心句、写得好的句子(课本「画出…的句子」)。问题那一句,和要用到的条件(划两处,不圈)。句型:I like … 整句划。
加点
[[加点 …]]		多音字、形近字、加点词里要体会的那个字(课本本来就有加点)。不用。不用(用圈)。
遮 / 盖
[[遮 …]] [[盖 …]]		遮拼音,让他自己读。盖课后词语的答案。盖住算式的得数、例题的答案,让他先算。盖住中文意思,让他先说。
白纸条
[[摆]] [[写]]		少用:写一个例句、组词。主要用它:点阵、方向盘、竖式。写一个词的变化(cat → cats)。
孩子写格子
R3 · R4		生字田字格、拼音四线格、括号填字。□ 和 ( ) 里填数、竖式的空位。四线格里抄单词、横线上填词。

L层级

课本页是 pdf.js 画出来的一张图,字没法真的放到记号上面。所以「字在记号上面」靠正片叠底(multiply):颜色只会让纸变深,黑字叠上任何颜色还是黑的。只有存心挡住的东西用正常混合、不透明。

左:现在的圈,不透明、3px、正常混合,压到的笔画断开。右:提议,2.5px、85% 不透明、正片叠底,线从字下面穿过去。

每层放什么

C记号什么时候退下

老师的记号有三个样子:新(实色)、旧(淡到 30%)、收(没了)。按一句一句往前走算,不按秒算——孩子在看的时候东西不会自己消失。

结果结论
V1语文二上:37 页、1056 个田字格,全书一个样。每格是 pdf.js 操作表里一条描边的闭合四点路径(边长都是 39pt,蓝 #27c9f5,线宽 0.71),加横竖两条虚线中线(线宽 0.34,虚线 1.72)。格里的字:深灰 #2c2e35 262 个(范字)、红 #ff8281 262 个(描红)、空格 532 个。按「正方形 + 两条中线」认,没有误认,也没有漏认。R3 能做。
V2排法:写字的一组都是「范字、描红、空、空」,两组一排(第 16 页「转(转)□□ 夹(夹)□□」)。例外只有两种:第 40 页「比一比,填一填」是单独的空田字格,让孩子选「园 / 圆」填进去;第 41 页标点用的是没有中线的小方框,不算田字格。单独的空田字格也照 R3 走,范字就空着;标点小方框归 R5c。
V3范字和描红都在文字层里(一课的字里有「转转夹夹」)。现在建索引只读 getTextContent,它不带颜色。要分范字和描红,得再走一遍 getOperatorList,跟踪坐标变换和填充色。整本语文扫一遍 5.8 秒。在建索引时做一次,格子存进 .cotutor/textbooks/<指纹>.json 的页里;舞台不用再算。
V4数学二上:空括号「( )」在文字层里有 240 处。矢量的空方框去掉重复的有 805 个,其中 286 个挨着运算符,在样页上看全是算式里的空(第 73、77 页的 7×□=□、□×7=□ 链全中)。166 个连成表格(第 87 页口诀表,其实也要填),353 个分不清:数轴下的框是要写的,价签、七巧板上的框不是;第 99 页还有一大片斜排的小框,是假的。R5a、R5b 能做;R5c 先不做,要做得用别的办法(比如老师 [[请 写]] 时指着那一块)。
V5四线格:语文二上、数学二上都没有。外研社英语三上有 31 组(12 页:字母表、Read and write 里描的词、写卡片的横线),但整本 PDF 没有文字层(0 段字,字都画成轮廓):格里有没有字、是不是描的只能看画的路径;而且英语老师的 activity 不铺课本(base 不是 textbook)。R4 不做:现在没有一节课用得上。哪天英语、一年级语文铺课本了再拿真书做。
V6R5c 试了「一排三个以上一样大、等距的空框」:数学二上 184 个,口诀表的补全格、「在□里画✓」中了,第 79 页鱼形装饰、第 87 页有字的口诀表格也中了。光看形状分不开,不做。

脚本在同目录的 核实/,换一本课本照样跑(课本 PDF 不进仓库,从 vault 的 教材/ 拿):walk.mjs 打出一页的路径和带颜色的字,grids.mjs 扫全书的田字格,blanks.mjs 扫数学的方框和括号(给第二个参数会把认出的框写成 json,拿去和页面截图叠着看)。

Q待讨论

拿不准的放这里。有想法就说编号和你选哪个、为什么。Q1–Q6 先照推荐的做了(2026-11-22),用起来不对照样提。

Q1老师的颜色:红还是朱橙?

红圈在孩子眼里多半是「错了」(作业本上的红圈),和「孩子端没有对错」相冲。学科色也不行:数学的学科色和孩子的蓝笔是同一个颜色。

朱橙 #E8590C(推荐)保留红 #E03131学科色,数学另配

Q2交过的孩子的笔要不要退淡?

收笔交给老师、老师讲完以后,那几笔还要不要实色?退淡能让下一次写的跳出来,但那是孩子的东西。

不退,孩子自己擦(推荐)老师讲完退到 50%

Q3旧的那一层要不要进窗图?

窗图交给脑,淡掉的圈画进去会让老师以为还圈着。

只画新的 + 孩子的(推荐)照屏幕上的样子画

Q4「划」要不要分横线和波浪线?

语文课本习惯:横线画句子,波浪线画好句。分开就多一个写法,老师容易写乱。

先只有横线(推荐)[[划 … 波浪]]

Q5圈的形状

一两个字用椭圆,三个字以上用圆角框?还是都用贴着字块的圆角(本页样张的画法)?

都贴字块,手画感(推荐)短椭圆、长圆角框

Q6R3.1 在 2 倍窗里直接写格子

省一步,但格子只有一指宽,笔画会挤。等写字格用上一阵再看。

先不做(推荐)2 倍窗里直接写
