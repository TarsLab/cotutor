# 一节课、讲稿里的动作与白纸条

给开发本仓库的 agent。总的规矩在仓库根的 `AGENTS.md`;这里是这一块的细节,行为以实现和测试为准。

## 一节课铺哪种页

- 一节课铺哪种页:activity 头上 `base: textbook | photo | lecture`(`src/schema/activity.ts` 的 `ACTIVITY_BASES`;不写当 `photo`,`src/runtime/activity.ts` 的 `activityBase`)。以前头上的 `board: page`、`cards:` 读进来就丢,activity check 提一句。话题第一条记 `base`(以前记录里的 `board: 'page'` 读进来就丢,那些话题不再当一节课)。方砖和 activity 按钮都带 `base`、`listen`(`src/runtime/home/` 的 `activityLook`),孩子端照它走:textbook 直接开话题铺目录,photo 先到拍照屏(拍照、相册、选课本页、不拍用白纸;kid-page 的 `BP`、`bpStartBoard`、`bpPhotos`、`bpWhite`、`bpOpenLesson`)

## 讲稿里的动作与一节课的状态

- 一节课与讲稿里的动作(出厂的 activity 都是;计划在本机草稿 `docs/wip/多模态教学harness-开发计划.md`):老师不写卡,对页做什么写在讲稿的句子后面——`[[翻 6的乘法口诀]]` `[[看 例 4]]` `[[圈 …]]` `[[划 …]]` `[[加点 …]]` `[[遮 …]]` `[[盖 3×5=15]]` `[[摆 点阵 6 行 6 个]]` `[[写 …]]` `[[擦]]` `[[请 圈]]`,写法给老师的那页是 `cards/动作怎么写.md`(系统提示里跟在 activity 后面,`actsGuide`)。
- 解析在 `src/board/acts.ts`(讲稿里所有 `[[ ]]` 都在这里读;以前的 `[[play]]` `[[echo]]` 不认了,丢掉记一行),动作记在句子上(`BoardLine.acts`,第一句前面的在 `BoardSection.acts`);落到页上(照页的文字层找框,`LineAct.do`;页的文字层从哪来是 `LessonSource`:课本、照片认出的字)在 `src/board/lesson-fit.ts`,落不了的给家长记一句。
- 一节课的状态(页集:课本的一课、作业照片、白纸;窗、每页老师的一层 / 孩子的一层 / 开放的、白纸条)形状在 `src/schema/lesson.ts`,怎么变是纯函数 `lessonStep`(`src/board/lesson.ts`,只引类型、内联进孩子端),落盘 `<date>.<话题>.lesson.json`(`src/runtime/journal/lesson-store.ts`,改动排成一条链)。
- 服务端一轮定稿把这一节的动作落进状态(`lesson.jobs` 记落过的那几轮;`lessonSection`);孩子端(kid-page 的 `LS`)第一句前面的马上落、每一句的等它念完(下一句开始放或嘴放完)才落,孩子打断、开了下一轮就一下子落完(声音被掐了的那几句没念到:圈、划、加点不画,别的照落、句数照记;服务端定稿不知道在哪一句打断,照样全落,下一轮的 `round` 一起收掉);回到这节课照 `/api/kid/lesson`。两边照同一个先后:新的一轮先 `{t:'round'}`,一句的动作落完 `{t:'said'}`(`Lesson.said` 加一;只在带动作的那几轮里数)。
- 页上记号的四条原则(改记号的画法、什么时候退下都照它推):记号不盖字(除了故意挡住的遮、盖,都正片叠底画在字后面);记号跟着话走(老师的记号属于说它的那一句,同时新的最多 3 处);谁画的一眼分得出(老师朱橙、孩子的笔蓝、孩子写进格子的字铅笔灰、荧光笔黄,颜色只表示谁画的,不表示对错);页上印着什么就能做什么(目录能点、空格能写,平时不画提示,按下去接得住)。样张和还在议的在 `docs/artifact/页上记号/规范.html`,规则以这里和 `docs/dev/课本.md` 为准。
- 记号什么时候退下:圈、划、加点是「指着字的」(`LINE_MARKS`),记下画它时念完了几句(`TeacherMark.at`),画它那一句和下一句是新的、再往后旧的(淡),同时新的最多 3 处(`markFresh`,舞台画和窗图都照它;窗图只画新的);新的一轮、看别处、翻走都收掉。遮、盖留到揭开。一句里圈、划、加点写多了只做前 3 处,给家长记一句。圈的框连着字头上的拼音(`bookSpot` 的 `py`);划一句跨行一行一截。
- 孩子在课本的田字格、填空里写的字是孩子那一层的 `kid.cells`(键 `<PDF 页>.<第几格>`,笔画是格里的坐标,长边 0–`CELL_UNIT`),事是 `{t:'cell'}`(整格换掉,空的 = 擦干净);「擦掉」不擦它。格子从哪来、写字格见 `docs/dev/课本.md`。
- 孩子在页上的点字、揭开、挪窗、落笔(`{k:'stroke'}`、`wipe`、白纸条里方向盘的 `turn`)经实时那条线报给服务端,也走 `lessonStep`;call.ts 里板的事排成一条,交给脑之前等它记完(「给老师看」先交窗图)。
- 上下文包分两层(`src/runtime/context/board-pack.ts`,runner 的 `lessonSlate`):`board:` 每轮只说会变的(底、页集、你画的、开放、孩子做的、最近点的、孩子在看;`lessonSlateBits`),页上印的字一页一条 `<page>`(`pageNotes`;课本一课一条、照片一张一条),第一次看到时给、之后不重给(板的日志 `turn.told`),压缩以后重给现在这一页;压缩的前情加一段「讲到哪了」(`thread-digest.ts` 的 `lessonProgress`)。
- 附给脑的图一条路:这一轮新拍的照片附整张(`images`),窗里那一块附这一轮(`boards`,过后换占位)。
- 收笔(`src/runtime/live/pen.ts` 的 `turnStep`,秒数 `live.pen`):舞台落笔报 `{k:'pen'}`、抬笔是收下的那一笔,停一会儿没再写 call.ts 替他交一轮(`live.app: pen`,嘴先说「我看看你写的」,`cues.ts` 的 `pen`)。只有老师请着用笔(`PEN_ASKS`)时落的才等着交(`boardEvent` 回 `asked`);课本页上没请他自己画的收下不交,随下一轮走。
- 白纸条(`src/board/strip.ts` 排、舞台画):`看` 着一道题时 `摆`、`写` 落进它下面的一条白纸,页宽、跟着页滚,一道题一条、看别处收起来、回来原样在;题目太高时白纸条从窗口中间偏上开始;孩子写在白纸条上的笔跟着它(`kid.stripInk`)。
- 录像照孩子端记的一节课的样子放(play 的 `lesson`)。
- 没有课本卡(以前记录里的不再显示)

## 讲稿怎么解析

老师的回复(剥掉「## 记账」这类固定段以后)由 `src/board/parse.ts` 的 `parseBoard` 读成一节 `BoardSection`:

- 普通行 = 讲稿一句(`BoardLine`:`text`、`ask` 末尾是不是问号)。标题号、列表号、粗体号、整行注释先清掉(`cleanSpeech`);方括号念的时候去掉。
- `[[名 参数]]` 是动作,在 `src/board/acts.ts` 读:记在那一句的 `acts` 上,念完才落到页上;只有动作的一行跟着上一句;第一句前面的记在节上(`BoardSection.acts`),一开口就落。`[[请 说 词]]` 另记成这句的 `echo`(念完等孩子说,`src/board/echo.ts` 比他说没说)。写错的、不认得的丢掉,给家长记一行。
- 动作落到页上(照页的文字层找框)在 `src/board/lesson-fit.ts`;一节课的状态怎么变是 `src/board/lesson.ts` 的 `lessonStep`。写法给老师的那页是 `cards/动作怎么写.md`(注释剥掉、跟在 activity 后面进系统提示,`src/board/cards/docs.ts` 的 `actsGuide`)。
- 围栏(```)课里不上页、不念,给家长记一行「课里没有卡」。以前的回复里满是卡(`tests/fixtures/board/`),照样读得下,讲稿照念。
- 第一个 H2 起是给家长的尾巴,孩子看不到。写成正文的工具调用整块不念、记一行。
- 流式时(`{partial: true}`)没闭合的围栏、没换行结束的最后一行压着,下次整段重解析自然补上。解析器永不抛错。
- 家长端「看原文」(`annotateSource`)照同一次解析把原文每一行标上它被读成了什么。
