# 实时通话:嘴、请他说、嘴先答

给开发本仓库的 agent。总的规矩在仓库根的 `AGENTS.md`;这里是这一块的细节,行为以实现和测试为准。

## realtime 那条线

- realtime 那条线:老师都走它。
- 嘴在 `src/realtime/`(百炼 realtime 客户端 `bailian.ts`、开口指令 `cues.ts`、一直听时这句收不收 `listen.ts`);实时老师的一次通话在 `src/runtime/live/call.ts`(孩子端的协议、嘴的连接、一直听、请他说、嘴先答),交给脑在 `turns.ts`;交付在 `src/runtime/delivery/`(`delivery.ts`:嘴的声音排到哪、第几句开始放、打断听到第几句;照念排队 `queue.ts`);录像记录 `CallRecorder`、嘴这一道的事件与字幕重放的声音在 `src/runtime/journal/`(`recorder.ts`、`mouth.ts`);孩子端采音放音的内联源 `src/ui/kid/audio-client.ts`;WS `/api/live/<老师>/ws` 在 `src/app/ws/`(零依赖 WebSocket 服务端 `ws.ts`),serve.ts 的 refresh 接一行;孩子端发一条只走这条连接(没有 HTTP 的发),验与拼在 `runner.accept`(`src/runtime/kid-input.ts`);测试照这条路发用 `tests/_kid-send.ts`(经 `Turns`,少的只有嘴),探针用 `scripts/_live-send.mjs`;`cotutor send`、工作台、`replay`、`activity eval` 发的孩子的话也照实时写(`live: {}`,没有嘴),只有系统发的(`--from system`、记账)不是;板上只有实时一种画法(以前的话题也这样画)。
- 百炼(按量 key + 业务空间 id)是机器级的 `~/.config/cotutor/bailian.json`,家长端「首页」里填(`src/app/machine/bailian.ts`);没配孩子端只出「老师们还没到」

## 孩子说当一种作答

- 孩子说当一种作答:讲稿里 `[[请 说 duck]]` 哪个 activity 都能写:还是开放「说」的动作,另外记成这句的 `echo`,念完停下等孩子说;他说的是不是那一句照转写比(`src/board/echo.ts`,英文按词、中文按字),说了接着念下一拍、说的是别的交脑、两拍没开口交脑(`app: quiet`),那句是这一轮最后一句时他说了、没开口都交脑;每拍一行交给脑(上下文包 `live.echo`)。
- 孩子先说:话题只进了门、还没开口时,页上的事(点字、挪窗、翻页)都只记下,`Runner.boardEvent` 回 `still: false`,通话不替他叫老师;目录上点一课任何时候都不起一轮(下一轮「孩子做的」带上)。
- activity 头上 `listen: open` 一直听(`ACTIVITY_LISTENS`;话题第一条记 `listen`,回到这节课照它换);`reply: mouth` 嘴先答(`ACTIVITY_REPLIES`;runner 起一轮时经 `SendStarted.reply` 告诉 call.ts):最后那句请他说的,他答了嘴先在那个范围里接——说中了嘴接一句当接住、交脑;没说中嘴提示一下接着等他,连着两次第三次交脑(`REPLY_MISSES`);嘴提示过的下一轮带给脑(`live.mouth`)。
- 嘴先答时舞台交的窗图(shot)跟着孩子那段声音进嘴的对话(`giveShot`),一条连接里给够 `MOUTH_IMAGES_SWAP` 张安静时换连接(起点,没量过)

## 一次通话里的规矩

实现在 `src/runtime/live/call.ts`;孩子端与这里之间的消息在它的头注释里。

- 嘴的会话断了(百炼 300 秒没输入就关):电话不挂、孩子端不知道;下次按下或发来时现连,
  - 连上之前来的照序攒着补(录像里记一条 {t:'lost'},只记不发)。平时孩子没按着就 30 秒一次心跳,最后一次动静 15 分钟后停跳。
- 换连接:嘴的历史越长每次回答越贵,输入过了 SWAP_TOKENS 就在安静时换一条新的(录像里记 {t:'swap'},只记不发)。
- 一直听(孩子端只在 activity 头上写了 listen: open、或 live.listen 是 open 时连接带 ?listen=open,中途发 {t:'listen', open} 也能换):孩子端一直推声音(录音、小课堂、关麦时不推,{t:'gate', on} 告诉这里),
  - 嘴的会话开 VAD(live.vad 缺省 server_vad、live.silenceMs),create_response / interrupt_response 关着:开口(speech_started)先暂停照念、嘴在放就让孩子端压低({t:'duck'}),
  - 转写回来 src/realtime/listen.ts 判收下 / 放过——收下才算按下 + 松手(打断、接住、交给脑;交给脑之前孩子停一下又开口的并成一句),放过的恢复音量接着念({t:'skip', why} / {t:'unduck'})。
  - 孩子那一句的上下文(话题、设备)孩子端开口时报一次 {t:'ctx', body}。换模式 = 安静时换一条连接(silence 只有新连接能给)。
  - commit 了不回答 300 秒百炼就关(response_idle_timeout,探针 probe-live-vad):放过的多了,离上次回答 IDLE_SWAP_MS 就在安静时换连接。
- 请孩子说(讲稿的 [[请 说 词]],哪个 activity 都能写):那句念完关闸(src/runtime/delivery/queue.ts),
  - 孩子说完(像说了那句,src/board/echo.ts)开闸下一拍,不接住、不交脑;对老师说的照收下办(打断、接住、交脑);ECHO_WAIT_MS 没开口接着走,连着两拍没开口停下交脑(app: quiet)。
  - 请他说的是这一轮最后一句(脑写完了、后面没排着),他说了也交脑,没开口也交脑(app: quiet)。每拍记一笔(录像 {t:'echo'},只记不发),交脑时带上(live.echo)。
- 嘴先答(这节课的 activity 头上 reply: mouth,runner 起这一轮时告诉这里):
  - 最后一句请他说的,他答了嘴先在那个范围里接(src/realtime/cues.ts 的 replyCue;范围 = 那句话 + 要他说出的那一句)——说中了嘴接一句、当这一轮的接住,接着交脑;
  - 没说中嘴提示一下、接着等他,连着 REPLY_MISSES 次没说中交脑;说的是别的照旧交脑。孩子眼前那块图(舞台交的窗图 {k:'shot'})跟着他那段声音交给嘴,
  - 一条连接里给了 MOUTH_IMAGES_SWAP 张就在安静时换连接;嘴替脑接的那几句(孩子说的、嘴说的)下一轮交脑时带上(live.mouth)。
- 录像:进出的消息、两边的声音都记(CallRecorder),落在 conversations/<老师>/<日期>.live/<时分秒>.reel.json / .wav(时分秒 = 这一段开始的时刻)。
  - 按段落:两轮之间安静着(心跳时看),这一段 IDLE_CUT_MS 没动静、或录了 MAX_TAKE_MS,就收下这一段落盘、接着录新的一段;挂了落最后一段。
  - 一段一轮都不会切开(录像按轮在一段里找按下、松手、turn、read);没动静的一段不落。
- 字幕重放:嘴照念的声音按轮另留一份,出了的都留(孩子按下时清掉、没放出来的也在),
  - 一段出完(或被掐、断了)就落 <日期>.<job>.mouth.wav 与每句的起点 .mouth.json(src/runtime/journal/mouth-index.ts);接住那句不在里面。孩子端从 /api/kid/conversations/<老师>/mouth/<日期>/<job> 取。
- 事件:嘴这一道(mouth:按下、松手 / 发了、接住开始放、第几句开始放、打断)补进那一轮的 events.jsonl(Runner.noteEvent),工作台的时间线上看;
- 按下、松手、接住在脑起来之前,先攒着,等那一轮的老师进程起来(main:start)再按它的起点换成相对毫秒(负的)。
