# 照片页与认字

给开发本仓库的 agent。总的规矩在仓库根的 `AGENTS.md`;这里是这一块的细节,行为以实现和测试为准。

## 照片页

- 照片页:孩子拍的作业像课本一样页宽铺、上下滚,几张从上往下连着(`PageSource` 的 `photo`,最多 `PAGE_PHOTOS_MAX` 张;id 是「作业」)。
- 上传回宽高(`src/shared/jpeg.ts` 的 `imageSize` 读文件头),孩子端照它马上铺(`lessonStep` 的 `{t:'photo'}`),服务端收到那一条照同样的规矩铺(runner 的 `lessonOn`);没拍就铺一张白纸页(`[[翻 白纸]]` 也加它,id「白纸」,整页就是一条白纸条)。
- 文字层:runner 一收到照片就在后台照 activity 的「认字收到什么」认(`startPhotoWords`,规则 `src/scenes/photo-words/recognize.ts`,要了行框和题框 `FORMAT_BOXED`;结果流式落在照片旁边 `<照片>.words.json`),`src/chalk/kit/photo.ts` 的 `photoBookPage` 把认出的行、题、字词换成课本的样子(BookPage + 带题框 `area` 的 problem 块),看、圈、遮、盖、点字和课本用同一份(`bookTarget`、`bookFind`、`bookPick`、`bookView`);照片页还认「第 2 张」「第 2 张第 3 题」(`lesson-fit.ts` 的 `photoTarget`)。
- 手拍的歪照片题框还行、行框偏(结论在 `scripts/probe-photo-boxes.mjs` 末尾)。
- 舞台照片画进画布,点字照 `/api/kid/photo-words` 认出的(认完以前隔一会儿再拉)。
- 数学的照片、课本上不弹田字格(页的 `pick`)。
- 英文单词也能点(`bookPick` 点中字母取整个词)
