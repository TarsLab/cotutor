# 照片页与认字

给开发本仓库的 agent。总的规矩在仓库根的 `AGENTS.md`;这里是这一块的细节,行为以实现和测试为准。

## 照片页

- 照片页:孩子拍的作业像课本一样页宽铺、上下滚,几张从上往下连着(`PageSource` 的 `photo`,张数不限;id 是「作业」)。
- 上传回宽高(`src/shared/jpeg.ts` 的 `imageSize` 读文件头),孩子端照它马上铺(`lessonStep` 的 `{t:'photo'}`),服务端收到那一条照同样的规矩铺(runner 的 `lessonOn`);没拍就铺一张白纸页(`[[翻 白纸]]` 也加它,id「白纸」,整页就是一条白纸条)。
- 文字层:runner 一收到照片就在后台照 activity 的「认字收到什么」认(`startPhotoWords`,规则 `src/scenes/photo-words/recognize.ts`,要了行框和题框 `FORMAT_BOXED`;结果流式落在照片旁边 `<照片>.words.json`),`src/chalk/kit/photo.ts` 的 `photoBookPage` 把认出的行、题、字词换成课本的样子(BookPage + 带题框 `area` 的 problem 块),看、圈、遮、盖、点字和课本用同一份(`bookTarget`、`bookFind`、`bookPick`、`bookView`);照片页还认「第 2 张」「第 2 张第 3 题」(`lesson-fit.ts` 的 `photoTarget`)。
- 手拍的歪照片题框还行、行框偏(结论在 `scripts/probe-photo-boxes.mjs` 末尾)。
- 舞台照片画进画布,点字照 `/api/kid/photo-words` 认出的(认完以前隔一会儿再拉)。
- 数学的照片、课本上不弹田字格(页的 `pick`)。
- 英文单词也能点(`bookPick` 点中字母取整个词)

## 作业本

- 检查作业(activity 头上 `base: homework`,出厂三科都是)拍的照片按学科、按天攒成一本,跨话题;孩子端是一整本连着往下滚(老的在上,新拍的接在后面,最后一张白纸)。vault 那一侧在 `src/memory/homework.ts`(路径角色 `homework`,缺省 `作业本/<学科>/<YYYY-MM-DD>/`;学科是 `canonicalSubject`,没写学科用老师名),接一节课在 `src/runtime/homework.ts`。设计稿 https://claude.ai/artifact/UMg75RSteV9b9JqXfADj7U
- 照片照旧先落 `captures/<日期>/<HHMM>-<n>.jpg`(认字的 words.json、取图、附给脑都认那里);检查作业的话题收到就照原名另抄一份进 vault(`keepPhotos`,runner 的 `lessonOn`)。作业本有哪几天、一天几张照 vault 列,家长删了的不再铺;captures 里没有的(sandbox、家长自己放进去的)铺页时从 vault 抄回去。
- 作业本是一张照片页(`homeworkBookPage`):id「作业」、title「作业本」、`day` = 这节课的今天;最近 `HOMEWORK_BOOK_DAYS` 个拍过的天从早到晚,每张照片记着哪天拍的(`PagePhoto.day`)。一张都没拍过也铺(photos 空)。拍来的(`{t:'photo', day}`)接在后面、记着今天,窗移到它(look 是今天的「第几张」)。不再有拍照屏、「用白纸」「选课本页」:点检查作业就进门(同课本),服务端铺整本。
- 坐标:照片之间空多少照 `src/board/lesson.ts` 的 `photoGaps`(同一天 30,换天 100,换周 190,第一张上面也留一周的),`photoSheetBox`、`bookSheets(…, gaps)`、舞台、以前的记号都照它;不带 day 的照片页照旧(贴顶、中间 30)。
- 舞台(`book.tsx` 的 `hwGeo`):天与天之间一行「星期一」(今天写「今天」),周与周之间一道宽条「11月23日 – 29日」(`.bk-div`);最后一张白纸(`.bk-blank`,拍照、从相册选,点中报 `capture`,页面开相机 / 相册)。一进来窗停在白纸的顶上;以前那天的照片上落不了笔(`inkHere`);照片只画窗附近的(`drawNear`,远了放掉),以前那天的字到了附近才拉。窗停在哪一天报 `day`,顶栏照它写(今天「今天」,以前「星期五 11月20日」),没有前后天的箭头,右上角没有拍照、相册。
- 目录(kid-page 的 `#hwk`,`hwToc`):一张纸,一周一排(老的在上,进来停在最下),周的那一行写日子;一天一张竖的小卡(那天第一张的缩图,多张的叠一张),卡下写星期几,今天还没拍是虚线框;窗停在的那一天描学科色。点一天:页面发 `go`,舞台滚到那一天的分割线,停下来照挪窗报(`view`,服务端说成「11月20日第1张:第3题」,`photoView`)。滚到以前那天不另记翻到哪。
- 以前的记号(`homeworkPast`,`GET /api/kid/homework/past?tutor&date&thread`,一整本一次):作业本上每张照片,同一科的老师别的话题(在这个话题之前的)画的圈、划、加点和孩子的笔,照那个话题最后的样子(淡了的照淡),换成这张照片自己的坐标。孩子端有了话题才要(不然会把这一节自己的算进去),舞台垫在这一节老师那层下面画(`.bk-past`),只看:擦不掉、不变旧、不收;窗图里也画(淡了的不画)。遮、盖、白纸条不带:它们盖着页上的字,只看的页上孩子揭不开、收不起来。
- 给老师:`board:` 的底说这是作业本、今天拍了几张、往前列最近 14 天(`HOMEWORK_TURN_DAYS`)、以前的照片上留着记号;页的文字层只给今天的和孩子眼前那几张。「第 2 张」是今天的第 2 张,以前的写 `[[看 11月20日第1张]]`;`[[翻 11月20日]]`(或 `2026-11-20`、`今天`)在作业本上落成「看」那一天(`src/board/lesson-fit.ts` 的 `homeworkTarget`),在别的页上是翻回作业本。作业本里以前拍的照片没认过字就是没认,不说「还在认」。
- 导出(`homeworkPdf`,`GET /api/parent/homework/pdf?tutor&days=`):家长端首页那位老师「每天都在」里的「作业本」点开,一天一行勾几天;一张照片一页,A4 竖着(`src/shared/pdf.ts`,jpeg 原样嵌进去,不加依赖;不是 jpeg 的跳过)。
