# 照片页与认字

给开发本仓库的 agent。总的规矩在仓库根的 `AGENTS.md`;这里是这一块的细节,行为以实现和测试为准。

## 照片页

- 照片页:孩子拍的作业像课本一样页宽铺、上下滚,几张从上往下连着(`PageSource` 的 `photo`,张数不限;id 是「作业」)。
- 上传回宽高(`src/shared/jpeg.ts` 的 `imageSize` 读文件头),孩子端照它马上铺(`lessonStep` 的 `{t:'photo'}`),服务端收到那一条照同样的规矩铺(runner 的 `lessonOn`);没拍就铺一张白纸页(`[[翻 白纸]]` 也加它,id「白纸」,整页就是一条白纸条)。
- 文字层:runner 一收到照片就在后台照 activity 的「认字收到什么」认(`startPhotoWords`,规则 `src/scenes/photo-words/recognize.ts`,要了行框和题框 `FORMAT_BOXED`;结果流式落在照片旁边 `<照片>.words.json`),`src/chalk/kit/photo.ts` 的 `photoBookPage` 把认出的行、题、字词换成课本的样子(BookPage + 带题框 `area` 的 problem 块),看、圈、遮、盖、点字和课本用同一份(`bookTarget`、`bookFind`、`bookPick`、`bookView`);照片页还认「第 2 张」「第 2 张第 3 题」(`lesson-fit.ts` 的 `photoTarget`)。
- 手拍的歪照片题框还行、行框偏(结论在 `scripts/probe-photo-boxes.mjs` 末尾)。
- 舞台照片画进画布,点字照 `/api/kid/photo-words` 认出的(认完以前隔一会儿再拉)。
- 数学的照片、课本上不弹田字格(页的 `pick`)。
- 英文单词也能点(`bookPick` 点中字母取整个词)

## 作业本

- 检查作业(activity 头上 `base: homework`,出厂三科都是)拍的照片按学科、按天攒成一本:一天一章,跨话题。vault 那一侧在 `src/memory/homework.ts`(路径角色 `homework`,缺省 `作业本/<学科>/<YYYY-MM-DD>/`;学科是 `canonicalSubject`,没写学科用老师名),接一节课在 `src/runtime/homework.ts`。
- 照片照旧先落 `captures/<日期>/<HHMM>-<n>.jpg`(认字的 words.json、取图、附给脑都认那里);检查作业的话题收到就照原名另抄一份进 vault(`keepPhotos`,runner 的 `lessonOn`)。作业本有哪几天、一天几张照 vault 列,家长删了的不再出;captures 里没有的(sandbox、家长自己放进去的)铺页时从 vault 抄回去。
- 一天铺成一张带 `day` 的照片页(`homeworkPage`):今天那一章就是照片页「作业」(拍来的接在后面,`{t:'photo', day}` 新开的那一页带 day、章名「11月23日」,`dayTitle`),以前的是「作业#<日期>」。新开的检查作业:今天拍过(`/api/kid/homework/base` 的 `page`)就直接进门铺今天这一章(窗摆回上次停的地方),没拍过先到拍照屏,作业本里有以前几天就多一颗「翻作业本」(进门 body 带 `day`,铺最近那一天)。还没铺页或这一条带了照片时,服务端先铺今天这一章再接上新拍的;孩子端照同一份先落(kid-page 的 `bpPhotos`)。
- 顶栏同课本(设计稿 B):章名、两边前一天 / 后一天(`hwNeighbors`,服务端列的几天加上这节课里今天那一章)、「目录」是一天一行的那一页(kid-page 的 `#hwk`,新的在上,星期、几张);一天最后一页下面一行「后一天 …」(舞台的 `.bk-next`,`next.k`)。孩子翻一天:页面先要 `/api/kid/homework/day`(铺过的翻回去),落在自己那一份上,报 `{k:'day', day}`;服务端照同一份翻、记进板的日志(下一轮「孩子做的」说「自己翻到了作业本的《11月20日》」)、记下翻到哪(`book-last.json` 的「作业本#<学科>」),不叫老师。窗停下也记。
- 以前的记号(`homeworkPast`,`/api/kid/homework/past`):一张照片上,同一科的老师别的话题(在这个话题之前的)画的圈、划、加点和孩子的笔,照那个话题最后的样子(淡了的照淡),换成这张照片自己的坐标。孩子端有了话题才要(不然会把这一节自己的算进去),舞台垫在这一节老师那层下面画(`.bk-past`),只看:擦不掉、不变旧、不收;窗图里也画(淡了的不画)。遮、盖、白纸条不带:它们盖着页上的字,只看的页上孩子揭不开、收不起来。
- 给老师:`board:` 的底说这是作业本今天这一章 / 以前那天、前面查过的照片上留着记号,还列能翻到的最近 14 天(`HOMEWORK_TURN_DAYS`,`LessonSource.homework`);老师写 `[[翻 11月20日]]`(或 `2026-11-20`;`[[翻 作业]]`、`[[翻 今天]]` 回今天)。作业本里以前拍的照片没认过字就是没认,不说「还在认」。
- 导出(`homeworkPdf`,`GET /api/parent/homework/pdf?tutor&days=`):家长端首页那位老师「每天都在」里的「作业本」点开,一天一行勾几天;一张照片一页,A4 竖着(`src/shared/pdf.ts`,jpeg 原样嵌进去,不加依赖;不是 jpeg 的跳过)。
