# 练习册

给开发本仓库的 agent。总的规矩在仓库根的 `AGENTS.md`;这里是这一块的细节,行为以实现和测试为准。

## 是什么

- 照教材一个单元编的几页习题,孩子在 iPad 上用笔直接在页上做。家长放在 vault 的 `练习册/<名>/`(路径角色 `workbooks`,缺省 `练习册`;sandbox 里同教材只读、不拷):`workbook.json` + 每页的 PNG,打印版 PDF 可有可无(应用不读)。
- 形状在 `src/schema/workbook.ts`(zod,`version: 2`):一页 = 页图、文字层 `lines`、能点的字词 `terms`、块 `zones`。块和课本的分块是同一种写法(`src/schema/zones.ts`:一道题一块 `problem`、label「第 3 题」,小题 `sub`、一组 `group` 套在里面;作答区、物件、给老师的在 `src/schema/regions.ts`),只是不写 `rows`(行就是这一页的 `lines`,归框住它的最里面那块),作答区不带课本格子的 `cell`、`src`。
- `workbookProblems` 每页照课本的 `zonePageProblems` 查(id 一页里不重、框、小块在大块里、作答区和物件、答案的引用),再查叫法一册里不重名(小题只在同一道题里不重名,同课本)、题写了 `teacher.goal`。读一册在 `src/memory/workbook.ts`(名字只认一层文件夹,读不出来回给家长的一句)。以前一页写 `questions` 的(`version: 1`)形状不过,照技能重出。
- 坐标是每页图的千分比 `[左, 上, 右, 下]`,横按宽、竖按高。题框、文字层、能写的格子都是排版时记下的,不认字;这就是它和照片页的区别。

## 出一册

- 家长的编程助手照技能 `skills/cotutor-workbook/` 出:一个排版脚本同时画页图、记框、写 workbook.json(框不事后量),放进 vault 的 `练习册/<名>/`。`references/格式.md` 是给它的字段说明和一份完整的例子(手写;例子过形状与检查、schema 的每个字段名都在文里,`tests/workbook.test.ts` 盯着,加字段要补这篇),`references/命令.md` 由 `src/app/skills/workbook-doc.ts` 生成。
- `cotutor workbook check [<名>]`(`src/app/cli/workbook.ts`)一次列全要改的:形状的每一条、`workbookProblems`、页图在不在、PNG 的宽高和 sha256 与 json 对不对得上、页图重了;一块都没写 `say` 提醒一句。应用读一册(`readWorkbook`)只回第一条给家长,check 给助手一轮改完。
- `cotutor workbook glyph <字母>` 打印 `src/chalk/glyphs/` 的笔顺(x 高 = 1、向下为正),描写区的 `model.strokes` 照它换到页上。应用现在只用 `model.glyph`(写字格照着哪个字母),`strokes` 留给以后读描写。
- 练习册不分章:一册就是一个单元的几页,要多单元就出几册。

## 一节课里

- activity 头上 `base: workbook`,「家长填的」里要有一个类型是 `练习册` 的参数(`activity check` 查)。出厂的是二年级数学「做练习册」。
- 首页 activity 按钮填 `练习册: <名>`:首页检查读一遍(`buttonWorkbook`,读不出来报 fix),孩子端读不出来的按钮不出;出来的按钮带 `workbook` 名字,孩子端点了先要 `/api/kid/workbook/base` 铺上,不等老师(同课本的目录)。
- runner 照话题第一条记的参数铺页(`lessonOn`):页是 `kind: 'workbook'`,id `练习册#<名>`,每页宽 1000、高照图的高宽比(`workbookPage`);读不出来铺白纸,给家长记一句。`[[翻 练习册]]` 或册名翻回来。
- 几页换成课本的样子(`src/chalk/kit/workbook.ts` 的 `workbookLayer`):行与字(挑出的字词也当一行放在前面,不归给块)、每页的分块(页号就是第几页)、读回来的块(`zoneBlocks`,每块都带自己的框 `area`:「看 第 3 题」框住题里的图和格)。往下和课本走同一套 `src/chalk/kit/book.ts`:找框(`[[看 第 3 题]]`,练习册还认「第 2 页」「第 2 页第 3 题」)、能写的格(`bookCellsOf`:`write` 作答区,田字格是 `empty`、带 `model` 的照着那个字母写,别的是 `blank`;id 是 `<页>.<作答区 id>`)、点读一块(写了 `say` 的块,`/api/kid/workbook/say`)。写字格、放好、收笔替他交都走课本那一套(`docs/dev/课本.md`)。
- 记住翻到哪:孩子挪窗停下,窗记在 `.cotutor/book-last.json` 的「练习册#<名>」(同课本,`docs/dev/课本.md`);下一次铺这一册时窗摆回那里。练习册不分章:一册就是一个单元的几页,整册从上往下连着。
- 舞台(`book.tsx`):图走 `/api/kid/workbook/image`,行和分块走 `/api/kid/workbook/lines`(分块是 `zonesKidPage` 剥过的);同课本随时能落笔,请着用笔时收笔替他交;写了 `say` 的块单击念(同课本的点读一块,kid-page 的 `hearOk`、`hearUrl`)。
- 给老师:`board:` 的底说练习册几页;每页一条 `<page>`(`workbookText`):一块一行,叫法和印着的字,小题缩进。练什么、卡住怎么引、答案在 `board:` 的「给老师的」(`bookTeacherLines`,照孩子停下的窗和老师「看」的那一块现算;孩子还没挪过窗就当他在看第一页)。上一轮以后落过笔,「孩子做的」多几句(`bookZoneInk`,同课本):圈的一圈围住几个、画的框里几个合拢的形状、哪一格写了几笔,只是大概,以图为准;作答区的名字接上它在哪道题(`bookRegions`)。
- 答案、作答区的名字、物件只进上下文包;孩子端的接口只给页图、行、剥过的分块(`tests/workbook-page.test.ts` 盯着没漏)。

## 坑

- 存盘的一节课过 `LessonSchema`:加一种页要同时进 `PageSourceSchema` 和 `LessonPageSchema`,漏了读回来就当没铺过(刷新、下一轮都丢)。
- 连线、画线、描写的笔还没读成句子(`bookZoneInk` 只数笔),老师看图;英语、语文的册子用到时再做。
- 工作台的「分块」页只认课本;练习册的块由出它的排版脚本写(改了重跑脚本),工作台还不能看和改。怎么认(只看不改,还是能改又不和脚本打架)提议在 `docs/artifact/分块/`。
- 例子(`做练习册.例子.md`)挂的那一册要在跑例子的 workspace 的 vault 里,不在 `activity eval` 直接报。
