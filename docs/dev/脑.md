# 脑

给开发本仓库的 agent。总的规矩在仓库根的 `AGENTS.md`;这里是这一块的细节,行为以实现和测试为准。

## 脑执行

- `src/brain/` 脑执行(`BrainExecutor`:定这一轮怎么跑、请老师、读输出,收尾给整轮转录),runner 只经它请老师;运行时只有 `{api: "bailian", model}` 一种,应用直连百炼(`api.ts`,AI SDK;只读工具在 `api-tools.ts`,话题的模型历史在 `<日期>.<话题>.brain.jsonl`,拼回去时结束的轮瘦身(不带思考、工具往返成一句、照片只附最近那组),上一轮上下文过 32k 就整段压缩(前情 `src/runtime/context/thread-digest.ts` 照索引拼,不调模型);`.log` 落一行一条统一事件(`types.ts`)。不起 Qwen Code:旧 cotutor.json 里的 `{run, resume}` 读得进来、用不了(`runtime.ts`),那时的 `.log` 是 stream-json,`log.ts` 两种行都读)
