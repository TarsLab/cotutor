给开发本仓库的 agent。总的规矩在仓库根的 `AGENTS.md`;这里是这一块的细节,行为以实现和测试为准。

## 课本

- 课本做底:activity 头上 `base: textbook`(语文、数学的「课本」,家里加的科学老师也是;没有课本这块不出,见 `docs/dev/首页与听写.md`)不拍照,页上铺 vault `教材/` 下这一科这学期的课本 PDF(家长从教育网站下载,个人学习用;仓库和 npm 包里都不放教材)。
- 服务端只读 PDF 的文字层,不认图:`src/memory/textbook-index.ts` 拆字、分行、解拼音(人教的拼音是自造编码的字体,一个大写字母 = 带调的韵母,表在 `PINYIN_TONES`;广东版科学是标准 Unicode,一个音节一段,只是 g 印成 ɡ、轻声的 a 印成 ɑ)、读目录与页脚页码,字体记真名(pdf.js 开 `fontExtraProperties`、先读画图的指令才载得进字体,去掉六个字母的子集前缀:FZKTRJK--GBK1-0 整册一样;读不到时是 pdf.js 一页一页起的编号 g_d0_f17),着重号(字体 KentenGeneric,3.5 号的「3」)不成行、记到正上方那个字上(`dot`),一行里空开一个字宽以上的记在后一个字上(`sp`,空着的括号不算;`spacedText` 拼字时留空格、念的时候换顿号),`textbook-pdf.ts` 挑册子、做索引存 `.cotutor/textbooks/<指纹>.json`(不进备份)。
- 分块(zones):课本一页上的块(课题、段、习题、栏目、例题、小题、泡泡、注释……,能套小块)、块里能写的格(作答区),一页一份 JSON(协议版本 3,形状 `src/schema/zones.ts`,作答区、物件、答案和练习册共用 `src/schema/regions.ts`;设计稿 `docs/artifact/分块初始化/`)。文件名照页名:印的页码补成三位(`004.json`;印重了的第二页叫 `4之2`),没印页码的照页的种类(`封面`、`扉页`、`版权`、`目录-1`、`后记`、`封底`、`空白`、`无页码-3`);页码没印但目录上有一项从这一页起、或前后两页正好隔一的照着推(科学的单元页),这些在 `src/memory/textbook-page-names.ts`,规则、prep、工作台都照它,编程助手不改。每页写着 `v`、`page`(PDF 第几页,运行时照它挑)、`name`、`kind`(只有正文、单元页、附录分块);`book.json` 记每页是 PDF 第几页、谁写的、样式表(编程助手写的 `styles.json`)。id 整册不重:块 `<页名>-<第几>`(一页最外一层从上往下)、小块 `<外面那块>.<第几>`、作答区 `<页名>-格<这一页第几个候选的格>`(一节课状态里 `kid.cells` 的键还是 `<PDF 页>.<作答区 id>`,换协议前写过的字对不上就不显示);跨页的同一块,下一页那一截写 `cont`(上一页那块的 id),读回来连成一块。旧版的(`p078.json`,没写 v)读进来就丢,vault 里有的家长端、doctor 报一行。规则出的在 `.cotutor/textbooks/zones/<指纹>/`(`src/memory/textbook-zones-rules.ts`,不用大模型;第一次用到这一册时整册出,三本真课本 3–18 毫秒;`book.json` 记规则与索引的版本,`ZONES_RULES_VERSION` 或 `BOOK_INDEX_VERSION` 变了整个目录删了重出),编程助手、工作台写的在 vault 的 `教材/.zones/<指纹>/`(进备份;`src/memory/textbook-zones.ts`)。一课挑一份(`pickZones`):这一课的页 vault 里都有用 vault 的,不然用规则出的,一课里不混;铺开的几页照目录上最里一层的课分开挑(`pickBookZones`:数学一个单元铺开,改好的那一课用 vault 的,别的课照规则);vault 里读不过形状的那一页当没有,给家长端报一行。运行时只读分块:看、上下文包、点读、能写的格都照这一课挑好的分块(`book.ts` 的 `zoneBlocks` 读回成块,`bookCellsOf` 给格);字、拼音、点字照旧读索引。
  块记着它那几行字的框(`rows`,千分比),读回来照框对上索引里重合最多的那行(不存行号:取字的规则一改号就错位);没写 rows 的,框里没被占的行归框住它中心的最里面那块。块记着它字最多的样式(`style`,字体简称 × 字号「宋 16」,`styleOf`;规则和 push 时算)。栏目下面的题、段是它的小块,读回来记着栏目名(`head`);题号、段号、例几从叫法(`label`:「第 3 段」「例 2」「练一练第 3 题」)读;字照行重拼(段的行直接连,别的空格隔开,一行里隔开的词留空格,语文的栏目、别的字带读音,例题去掉开头的号)。
  规则按课出(`ruleZones`):数学一个单元一组(正文字号、跨页接着的栏目要整个单元一起看,人教数学二上第 26 页单看会把「做一做」下面的 1、2 认成例题),语文、科学目录上最里一层一组(一课下面的诗一首一组,各自分段、点读),目录页一组,剩下连着的页一组;一页只属于一组,套着的课读外面分好的;最后照页名起 id、写 cont(`renameZones`),封面、目录这些不是正文的页不分块。页上画的格(索引的 `cells`)成作答区,挂在框住格子中心的最里面那块上(块的框撑大包住它),没有就挂在页上。「① 本文选自……」这种页下注、题注是 `note`(叫「注①:本文选自」,注号接开头几个字,不念;正文里单独一个「②」是标号,不算)。
  语文正文后面的块(认字栏、课后题、语文园地栏目里的字)规则写上点了念什么(`say`,照印的念:认字栏一个字一个字顿开,隔开的词顿开;写字栏、页下的注、句前的 ◇ 不念),孩子点了念(下面「点读一块」)。
