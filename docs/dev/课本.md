# 课本做底

给开发本仓库的 agent。总的规矩在仓库根的 `AGENTS.md`;这里是这一块的细节,行为以实现和测试为准。

## 课本

- 课本做底:activity 头上 `base: textbook`(语文、数学的「预习」)不拍照,页上铺 vault `教材/` 下这一科这学期的课本 PDF(家长从教育网站下载,个人学习用;仓库和 npm 包里都不放教材)。
- 服务端只读 PDF 的文字层,不认图:`src/memory/textbook-index.ts` 拆字、分行、解拼音(人教的拼音是自造编码的字体,一个大写字母 = 带调的韵母,表在 `PINYIN_TONES`)、读目录与页脚页码,`textbook-pdf.ts` 挑册子、做索引存 `.cotutor/textbooks/<指纹>.json`(不进备份)。
- 目录不认出版社(`parseToc`):一行末尾是 1–3 位页码、前面是课名,中间有点线或空开一个半字号以上就是一项;页的中间三分之一有一道竖着的空就试分两栏(哪样认出的项多用哪样);序号是 ◎、隔开的编号或单独印在左边的大号一、二;三项以上、页码不往回走的第一页是目录,紧跟着接得上的页也是。每一项记下印在目录哪一行(`BookLesson.toc`,从序号到页码)。改目录的规矩先拿两本真课本比一遍改前改后的 `lessons`(不该有一处不同)。
- 同名的课(统编语文两个「古诗二首」):页上、板的日志里带编号(`lessonName`:「18 古诗二首」),`findLesson` 写了编号照编号找。
- 数学课本(文件名带「数学」,索引的 `layout: math`,照人教版数学二上定的):目录没有点线(序号、单元名、页码各一段),单元下面的小节、课题从页里的标题读出来(`mathRows`;标题怎么认在 `src/schema/textbook.ts` 的 `mathHeading`);一课分成标题、例题、栏目(做一做、练一练)和栏目下面的题(`book.ts` 的 `mathBlocks`),老师写 `[[看 例 2]]`、`[[看 练一练第 3 题]]`;一课最多铺 `BOOK_MAX_PAGES` 页;测试的书是 `tests/_math-book.ts`。
- 数学课本不开点字(页的 `pick`)。
- 页上能写的格(`BookPage.cells`,索引版本 5 起):建索引时读每页画图的指令(`src/memory/textbook-cells.ts`,文字层不带颜色),田字格 = 描边的近似正方形 + 横竖两条虚线中线,格里的字红的是描红、黑的是范字、没字是空格,空格照同一排左边最近的范字(`textbook-index.ts` 的 `bookCells`);填空(`blankCells`)= 算式里挨着运算符的空方框、文字层里「(」收尾和「)」起头两段中间空着的括号(编号「(1)」不算,表格里连着的格、数轴下的框分不清不做:试过「一排三个以上一样大的空框」,口诀表补全、勾选框中了,装饰的图案、有字的表格也中了)。四线格(拼音、英文)不认:二上语文没有,外研社英语三上的 PDF 没有文字层,英语老师也不铺课本。核实过人教统编语文二上(1056 格一格不差)和人教数学二上,脚本在 `docs/artifact/页上记号/核实/`。场景里的格是 `bookCellsOf`(id = `<PDF 页>.<第几格>`)。
- 能写的格平时不画;鼠标、悬着的笔移上去浅浅铺一层学科色,手指按住 80ms 还没滚深一点(同目录,`.bk-cell-hint`)。
- 写字格(`src/ui/stage/cell-pad.tsx`):点空格、描红格、填空(写过的格也行;范字格照常点字)开一张卡,点卡上的范字大格里照笔顺写一遍(`/api/kid/tianzige/<字>`,孩子落笔就淡下去留着描),贴着那一格(下面放不下放上面,页挪了跟着走);左上角范字、描红格红字淡铺在底下、填空没有田字格的线、卡照格的宽高比;手指、笔、鼠标都能写;「放好」报 `{type:'cell'}` → 页面 `{t:'cell'}` + `{k:'cell', id, strokes, text: 范字, blank?}`,字缩进那一格(铅笔色 `WRITE_INK`,`.bk-cells`),卡挪到同一排下一个同类的空格;写了没放好时点页上别处、落笔不收,× 丢掉。请着用笔时同落笔一样收笔替他交;板的日志记 `cell`,老师的「孩子做的」说写了几个、照着哪个字。
- 老师看不见图,所以窗停下来以后(刚铺好、老师「看」移完、孩子挪完、落笔)舞台把窗里那块导成 jpeg(`book.tsx` 的 `shoot`,画上老师的圈、盖住的块、白纸条和孩子的笔),经实时那条线 `{t:'board', body:{k:'shot'}}` 交给服务端,只留最新一张 `<date>.<话题>.shot.jpg`;下一轮挪成 `<date>.<job>.shot.jpg` 附给脑(`BrainRequest.boards`),`board:` 的「孩子在看」注一句。
- 窗图:数学课本、照片、白纸收,语文课本和目录不收(字都在文字层里;`boardEvent`);语文课本上孩子在格子里写了字的也收(写成什么样只有图上有)。
- `[[盖 3×5=15]]` 整个字框盖住(拼音的 `遮` 只盖字头上一条),孩子点开报 `reveal`,下一轮「孩子做的」里有「揭开了盖住的」。
- 读 PDF 的坐标要经视口(`convertToViewportPoint`):人教的页面框原点是 (8.5, 8.5),只用页高翻 y 时字框整体偏右上 8.5pt。
- 课本的几何在 `src/chalk/kit/book.ts`:一课几页竖排(页宽 1000),分自然段 / 栏目 / 诗一句一段,`看` 认段、页、栏目、原话。
- 分自然段(`lessonBlocks`)的正文是字最多的那种(字体, 字号);一页上压根没有那种字体名,认这一页同字号里字最多的那种(统编语文二上同一课里字体名每页可以不一样,《寒号鸟》第一页 f31、后面 f17);认字栏那一排(没标点、全是汉字、字距是字号的 1.4 倍以上)不算正文;下一页顶上是插图、正文从页中间起,上面没有别的字也算接着;同一页里空出 1.3 倍行距以上另起一段(诗分节,《植物妈妈有办法》行距 40、节间 60),分节的诗跨页那一段页前或页后正好是一节常见的行数就在翻页处分开。改这里先拿真课本逐课比改前改后的段(统编语文二上核过:《寒号鸟》《葡萄沟》《朱德的扁担》《雪孩子》《去外婆家》以前丢了后半篇)。
- 点读(语文课文,不是目录、不是数学):`bookReadTexts` 把一课分成标题(no 0;读课名,古诗再读标题下面同一页、字不太小的诗题和作者)和一段一块,一段切成句(`readSentences`,句末标点收一句、引号跟着,长句在逗号处切);一行一段的诗按节并成一块。舞台照同一份行算钮(`bookReadParts`:能点的就是段首缩进的那两格:宽两个字(照这一行的字距)、到第一个字为止,高是这一行字连着头上的拼音;钮在那两格正中,标题的在课号左边两个字宽里)。没有自然段(语文园地)不点读。
  孩子端(kid-page 的 `RD`):实时老师页、这位老师有点读的声音(`hasVoice` = `cardVoice`)才给舞台 `read`;舞台点中报 `{type:'read', k, parts, nos}`,页面用共享的 Audio 一句一句放 `/api/kid/textbook/say?tutor&b&p&k&s`(服务端照课本现取第 k 块第 s 句,点读的声音合成、有缓存;孩子端只给号),一块读完停 `READ_GAP_MS`、钮挪到下一块转一圈接着读,读到最后停;再点在读的那块 = 暂停(停在那一秒,再点接着读),停下 `READ_FADE_MS` 钮淡掉。舞台照 `read.k / mode` 画钮(playing 实心暂停、loading 转圈、between 转一圈、paused 描边播放;悬着只出一个淡淡的描边钮,按住钮深一点,能点的范围不画出来),页上不刷不画;读到窗外的一块,孩子 `READ_IDLE_MS` 没动手才挪窗。
  谁出声在 `liveStep` 的 `reading`:孩子点的,嘴(告诉服务端 hush)、小课堂、重放都让它;孩子开口、交东西、嘴又出声就停。读到哪停的报 `{t:'board', body:{k:'read', from, to, done?}}`,记进板的日志,不叫老师;下一轮「孩子做的」说「自己点了课文听(点读的配音):从标题读到第 2 段,在第 2 段停了」。
- 舞台 `src/ui/stage/book.tsx` 照一节课的状态画(页面发 `{type:'lesson'}`):pdf.js 现画(先一张中等清晰度、停下再把窗里那块按屏幕像素重画);窗只有页宽、两倍两种大小,双击切,不两指缩放,页宽时手指只上下滚、松手带惯性,老师的「看」只滚过去、块里的字一行一行刷上荧光黄再淡掉(字行是 `bookTarget` 找那一块时一起给的 `rows`,随 `look.rows` 存进一节课的状态,跨页的段不会把中间的脚注带进来;没带的照框用 `bookRows` 在文字层里挑,白纸、照片没认出字的整块铺一层;只读的录像照记录的窗摆,`camFor`,不刷);Apple Pencil(pointerType pen)写画,手指永远不落笔;课本页上随时能落笔(预习时自己圈生字、标段),照片、白纸页上请了写、圈…才能;请没请只管抬笔后替不替他交(收笔,见 `docs/dev/一节课.md`),没请画的随下一轮走、能按「给老师看」;试用(sandbox、mock)里能落笔时鼠标当笔(`mousePen`,课本页上鼠标拖不动页、用滚轮),电脑上不用笔也能试;轻点报 pick(带那个字的屏幕框,页面的点字卡贴着它;页挪了报 `pickAt` 跟着走,字出了窗、点了页上别处、落笔报 `pickAt null` 收卡,页面自己收了发 `unpick`;老师看别处、翻页页面也收,不按时间收),挪完报 view(板的日志说成「第 55 页:第 7 段」,上下文包 `board:` 的「孩子在看」)。老师的圈、划、加点朱橙、孩子的笔蓝,都正片叠底(记号不盖字);遮、盖不透明。
- 课本页的样子:课本铺满屏宽、没有工具栏;老师是贴着屏幕边的一张签(`#stage.bp.bk #cv-hold`,落在课本的页边里),「擦掉」在舞台里贴在它正下方(`.bk-wipe`,画了才出现);「给老师看」这一轮以后落了笔才能按(`#stage.bp #st-go:disabled`),能交了是实心的学科色;顶栏写课名、不垫渐隐;老师说的话是底下一条字幕。
- 平台盖的水印不铺:页顶的社标是 PDF 的水印批注,舞台渲染时不画批注(`annotationMode: 0`);页底那行「仅供个人学习使用」不在文字层,照整册印得最低的那行字(页码)以下裁掉(`bookCut`,一册一个数,记在页的 `cut`),裁了的页直接连着、不留缝;vault 里的 PDF 不改。
- pdf.js 不是运行时依赖:`pdfjs-dist` 在 devDependencies,`build:stage` 把压缩件拷进 `dist/stage/pdf/`,服务端和舞台用同一份。
- 孩子端:方砖带 `base`,点了直接开话题,舞台先铺上(不露空的老师页),再铺 `/api/kid/textbook/base` 给的目录(一节课的样子;没有课本就收起舞台),顶栏没有拍照(kid-page 的 `bpOpenLesson`;照片页才有 `#stage.ph`)
- 目录能点:`/api/kid/textbook/base` 同时给目录上能点的几项(`lesson-fit.ts` 的 `tocEntries`:课名、场景坐标的那一行、点了铺哪一页;回到一节课也要,存在 kid-page 的 `BP.toc`)。目录页上舞台只滚和点一项(不点字、不落笔、不双击,笔和鼠标当手指;`book.tsx` 的 `tocAreas`、`tocTap`):平时不画范围,手指按住 80ms 还没滚、鼠标或悬着的笔移上去才铺一层学科色,松手停 250ms 再报 `{type:'open'}`。不加闪、不加「上次」标签:孩子凭直觉点那一行,只要点得中、有回应。
  页面自己先翻(`lsKid`),报 `{k:'open', title}`;服务端(`Runner.boardEvent`)照样翻、记进板的日志、记下这本书翻到哪了,通话替他起一轮(消息带 `open`,字是「(在目录上点了《…》)」,老师看到 `孩子做的` 里「自己在目录上点了《…》」)。一课里顶栏有「目录」(`#st-toc`):翻回目录、窗停在这一课那一行,不叫老师。
- 上次翻到哪一课:`.cotutor/book-last.json`(`src/runtime/journal/book-last.ts`;孩子点的、老师 `[[翻]]` 的都算,目录不算)。新开一节课的目录窗停在它那一行(`lessonOpen` 的 `last` 记成 `view`;舞台没有「看」时照 `view` 摆窗),给老师的目录那一句说「上次翻到《…》」。
