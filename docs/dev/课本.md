# 课本做底

给开发本仓库的 agent。总的规矩在仓库根的 `AGENTS.md`;这里是这一块的细节,行为以实现和测试为准。

## 课本

- 课本做底:activity 头上 `base: textbook`(语文、数学的「预习」)不拍照,页上铺 vault `教材/` 下这一科这学期的课本 PDF(家长从教育网站下载,个人学习用;仓库和 npm 包里都不放教材)。
- 服务端只读 PDF 的文字层,不认图:`src/memory/textbook-index.ts` 拆字、分行、解拼音(人教的拼音是自造编码的字体,一个大写字母 = 带调的韵母,表在 `PINYIN_TONES`)、读目录与页脚页码,`textbook-pdf.ts` 挑册子、做索引存 `.cotutor/textbooks/<指纹>.json`(不进备份)。
- 数学课本(文件名带「数学」,索引的 `layout: math`,照人教版数学二上定的):目录没有点线(序号、单元名、页码各一段),单元下面的小节、课题从页里的标题读出来(`mathRows`;标题怎么认在 `src/schema/textbook.ts` 的 `mathHeading`);一课分成标题、例题、栏目(做一做、练一练)和栏目下面的题(`book.ts` 的 `mathBlocks`),老师写 `[[看 例 2]]`、`[[看 练一练第 3 题]]`;一课最多铺 `BOOK_MAX_PAGES` 页;测试的书是 `tests/_math-book.ts`。
- 数学课本不开点字(页的 `pick`)。
- 老师看不见图,所以窗停下来以后(刚铺好、老师「看」移完、孩子挪完、落笔)舞台把窗里那块导成 jpeg(`book.tsx` 的 `shoot`,画上老师的圈、盖住的块、白纸条和孩子的笔),经实时那条线 `{t:'board', body:{k:'shot'}}` 交给服务端,只留最新一张 `<date>.<话题>.shot.jpg`;下一轮挪成 `<date>.<job>.shot.jpg` 附给脑(`BrainRequest.boards`),`board:` 的「孩子在看」注一句。
- 窗图:数学课本、照片、白纸收,语文课本和目录不收(字都在文字层里;`boardEvent`)。
- `[[盖 3×5=15]]` 整个字框盖住(拼音的 `遮` 只盖字头上一条),孩子点开报 `reveal`,下一轮「孩子做的」里有「揭开了盖住的」。
- 读 PDF 的坐标要经视口(`convertToViewportPoint`):人教的页面框原点是 (8.5, 8.5),只用页高翻 y 时字框整体偏右上 8.5pt。
- 课本的几何在 `src/chalk/kit/book.ts`:一课几页竖排(页宽 1000),分自然段 / 栏目 / 诗一句一段,`看` 认段、页、栏目、原话。
- 舞台 `src/ui/stage/book.tsx` 照一节课的状态画(页面发 `{type:'lesson'}`):pdf.js 现画(先一张中等清晰度、停下再把窗里那块按屏幕像素重画);窗只有页宽、两倍两种大小,双击切,不两指缩放,页宽时手指只上下滚、松手带惯性,老师的「看」只滚过去、块里的字一行一行刷上荧光黄再淡掉(字行是 `bookTarget` 找那一块时一起给的 `rows`,随 `look.rows` 存进一节课的状态,跨页的段不会把中间的脚注带进来;没带的照框用 `bookRows` 在文字层里挑,白纸、照片没认出字的整块铺一层;只读的录像照记录的窗摆,`camFor`,不刷);Apple Pencil(pointerType pen)写画(请了写、圈…才能落笔),手指永远不落笔;试用(sandbox、mock)里能落笔时鼠标当笔(`mousePen`),电脑上不用笔也能试;轻点报 pick,挪完报 view(板的日志说成「第 55 页:第 7 段」,上下文包 `board:` 的「孩子在看」)。
- 课本页的样子:课本铺满屏宽、没有工具栏;老师是贴着屏幕边的一张签(`#stage.bp.bk #cv-hold`,落在课本的页边里),「擦掉」在舞台里贴在它正下方(`.bk-wipe`,画了才出现);「给老师看」这一轮以后落了笔才能按(`#stage.bp #st-go:disabled`),能交了是实心的学科色;顶栏写课名、不垫渐隐;老师说的话是底下一条字幕。
- 平台盖的水印不铺:页顶的社标是 PDF 的水印批注,舞台渲染时不画批注(`annotationMode: 0`);页底那行「仅供个人学习使用」不在文字层,照整册印得最低的那行字(页码)以下裁掉(`bookCut`,一册一个数,记在页的 `cut`),裁了的页直接连着、不留缝;vault 里的 PDF 不改。
- pdf.js 不是运行时依赖:`pdfjs-dist` 在 devDependencies,`build:stage` 把压缩件拷进 `dist/stage/pdf/`,服务端和舞台用同一份。
- 孩子端:方砖带 `base`,点了直接开话题,舞台先铺上(不露空的老师页),再铺 `/api/kid/textbook/base` 给的目录(一节课的样子;没有课本就收起舞台),顶栏没有拍照(kid-page 的 `bpOpenLesson`;照片页才有 `#stage.ph`)
