# 页面:地址、工作台、流水、录像、探针

给开发本仓库的 agent。总的规矩在仓库根的 `AGENTS.md`;这里是这一块的细节,行为以实现和测试为准。

## 舞台包与地址

- `src/ui/stage/` 舞台包(React,esbuild 打到 `dist/stage/`);路由在 `src/app/http/app.ts`,页面在 `src/ui/<端>/`,地址按端分:孩子端 `/`、`/dictation`(没有口语课页 `/talk`,口语课是方砖);家长端都在 `/parent` 下(记录 `/parent`、设首页 `/parent/home`、设置 `/parent/settings`、打印二维码 `/parent/qr`、听写 `/parent/dictation`;扫码打开、头像与声音在家长端首页,工作台不重复;`cotutor serve` 只打印家长端首页的地址);工作台都在 `/dev` 下。
- 录像里孩子的屏幕(`/reel`、`/dictation?reel=`)与家长「首页」里的预览(`/preview`)是孩子端页面本身,只开在家长端的 iframe 里;孩子端页面的源码里不出现 `/parent`;家长端「记录」是自己的一页(`src/ui/parent/parent-page.ts`,录像开 `/reel` 的 iframe),几页共用的 `$` / `h` / `toast` / `api` 在 `src/ui/shared/page-dom.ts`;家长端与工作台的锁在 `src/app/http/access.ts`(机器级 PIN,`cotutor pin`;没设就全开;孩子端新加的路径要在那里的白名单登记,`tests/access.test.ts` 盯着)

## 工作台

- 改工作台(`src/app/http/dev-*.ts`、`src/ui/dev/`)先过 `tests/dev-overview.test.ts`、`tests/dev-activities.test.ts` 与 `tests/dev-zones.test.ts`,颜色只用 `dev-theme.ts` 的变量;页面走 `scripts/probe-dev.mjs`(只看不改);「分块」那一页(课本的分块,细节在 `docs/dev/课本.md`)走 `scripts/probe-dev-zones.mjs`(会写 vault,拿试用 workspace)

## 全屏课页的老师签

课本、练习册、作业本、照片页和小课堂共用舞台外的老师签。进页 5 秒或第一次按过后，头像淡到三成。老师讲解时头像静止，字幕留在页底。口语课的签保留麦克风开关标记，请孩子说话时 C 环亮两次。

按住老师签上的任意位置，谷底都固定在头像中心，纸面沿长坡升到页宽中线的峰顶。变形按页高向上、向下展开，再逐渐变浅。按住「给老师看」时，谷底位于该按钮中心。图、文字和笔迹一起变形。按下用 120 毫秒，松手用 200 毫秒，上滑取消时也回平。减少动态效果时直接切换。发送后立即显示「老师在想」或带眼睛的「正在看图」，持续等待 2 秒才让 C 环顺时针转，每圈 2.4 秒。老师一开口就收，减少动态效果时保持静止。

状态由 `src/ui/kid/voice-view.ts` 判定，老师签由 `voice-button.ts` 和 `voice-ui.ts` 绘制，`paper-press.ts` 处理课页的位移与光影。课本长按时由同目录的 `paper-raster.ts` 取窗内已经绘好的页、高清局部和笔迹，在临时画布上按纸面坡度重绘；松手撤下画布。activity 沿用各自的通话配置。工作台 `/dev/voice` 用相同组件，可按住头像试手势或选状态对照。改压纸时跑 `scripts/probe-paper-webkit.mjs`，它从 iPad 横竖屏样张的截图量出头像上、中、下三条标线的位移。真实 PDF 用 `scripts/probe-book-page.mjs --pdf <语文二上课本>`，它比较按住和上滑取消前后的课文笔画像素。Safari 还要看浏览器窗口或 iPad 屏幕实显，WebKit 自动化快照和实显可能不同。

## 孩子端流水

- 点读课文的声音提前读完、进度不动,孩子端记一行 `k: 'read'`(哪一课哪一截、播放器报的进度,字段见 `KidLogRow`);查「底色不跟着走」先翻 `.cotutor/kid-log/`
- 改孩子端流水(页面脚本 `src/ui/kid/kid-log.ts`、收与存 `src/runtime/journal/kid-log.ts`、`src/schema/kid-device.ts`)先过 `tests/kid-log.test.ts` 与 `tests/dev-overview.test.ts`;新加孩子端页面要带 `KID_LOG_JS`(kid-log.test 的 PAGES 里登记);页面走 `scripts/probe-kid-log.mjs`(会写流水与设备表,拿试用 workspace)

## 分析一段录像

- 分析一段录像(家长给的链接,录像顶上「复制链接」拷的):`cotutor reel '<链接>' --shots <目录>`(`src/app/cli/reel.ts`)——先读时间线(孩子开口、老师第一声等几秒、念的每句、课本翻到哪、点字、没成的原因),再看截图;截图是按现在的画法重放的(录像栏写「画法已更新」的那种),样子不对先想是不是画法改过。拿孩子真的 workspace 跑只读,截图写到 workspace 外面。改了先过 `tests/reel-cmd.test.ts` 与 `tests/reel.test.ts`

## 探针

- 页面里的 JS 有两个 CDP 探针进了 `pnpm test`(`tests/probe.test.ts` 起 `probe-layout`、`probe-play`,走 mock;要本机 Chrome,没有就跳过;`COTUTOR_SKIP_PROBES=1` 跳过),改 `kid-page.ts` 先看它们红不红;其余手动验收走 `scripts/probe-*.mjs`(CDP);舞台里的东西用 CDP 驱动;截图也走 CDP(`Page.captureScreenshot`),孩子端、工作台在轮询,无头 Chrome 的 `--screenshot` 会挂;手机尺寸要 `--force-device-scale-factor=2 --window-size=780,1688`;探针不出声:起 Chrome 加 `QUIET_ARGS`(`scripts/_quiet.mjs`,`--mute-audio`;页面不用浏览器合成声,mock 里的配音也是静音),要听加 `COTUTOR_PROBE_SOUND=1`

## 坑

- 舞台页(`/stage/`)也装孩子端的 `theme.css`:舞台里自己的类名要带前缀(`lc-` 这种),撞上 `.pen` `.c` 之类会被那边的样式改掉(`.pen` 关着 pointer-events,圈不上)
- 探针模拟手指用 CDP `Input.dispatchMouseEvent`,别用 `dispatchEvent`:后者直接派到元素上,不走命中判定,盖住了、pointer-events 关了都照样过
