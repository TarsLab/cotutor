# 卡片协议(给改代码的人)

2026-11-17(《多模态教学harness-开发计划》阶段 5)起课里没有卡了:老师对页做什么写在讲稿的句子后面(动作),一节课的页铺在舞台上。卡只剩首页的两种牌——老师牌(`tutor`)和听写牌(`dictation`)。这篇讲这两种牌怎么定义、讲稿怎么解析、加一种牌怎么做。

## 讲稿怎么解析

老师的回复(剥掉「## 记账」这类固定段以后)由 `src/board/parse.ts` 的 `parseBoard` 读成一节 `BoardSection`:

- 普通行 = 讲稿一句(`BoardLine`:`text`、`ask` 末尾是不是问号)。标题号、列表号、粗体号、整行注释先清掉(`cleanSpeech`);方括号念的时候去掉。
- `[[名 参数]]` 是动作,在 `src/board/acts.ts` 读:记在那一句的 `acts` 上,念完才落到页上;只有动作的一行跟着上一句;第一句前面的记在节上(`BoardSection.acts`),一开口就落。`[[请 说 词]]` 另记成这句的 `echo`(念完等孩子说,`src/board/echo.ts` 比他说没说)。写错的、不认得的丢掉,给家长记一行。
- 动作落到页上(照页的文字层找框)在 `src/board/lesson-fit.ts`;一节课的状态怎么变是 `src/board/lesson.ts` 的 `lessonStep`。写法给老师的那页是 `cards/动作怎么写.md`(注释剥掉、跟在 activity 后面进系统提示,`src/board/cards/docs.ts` 的 `actsGuide`)。
- 围栏(```)课里不上页、不念,给家长记一行「课里没有卡」。以前的回复里满是卡(`tests/fixtures/board/`),照样读得下,讲稿照念。
- 第一个 H2 起是给家长的尾巴,孩子看不到。写成正文的工具调用整块不念、记一行。
- 流式时(`{partial: true}`)没闭合的围栏、没换行结束的最后一行压着,下次整段重解析自然补上。解析器永不抛错。
- 家长端「看原文」(`annotateSource`)照同一次解析把原文每一行标上它被读成了什么。

## 一种牌有哪几个文件

| 文件 | 管什么 | 谁读 |
|---|---|---|
| `src/board/cards/<kind>.ts` | 服务端定义 `CardKind`(接口在 `kind.ts`):`props` 契约(zod)、`parse(body, mods)` 围栏正文 → props(抛错 = 没解析成,退成文字 + warning)、`strip` 剥掉不下发孩子端的字段、`note` 解析成了但有一部分没用上时给家长的一句 | 首页解析(`parseHomeBody`)、`/api/kid/home` |
| `cards/<kind>/card.md` | 协议文档,八个固定栏目(下面);**例子即测试** | 家长的编程助手(`pnpm run gen:skills` 生成进 `skills/cotutor-home/references/`)、`tests/cards-doc.test.ts` |
| `cards/<kind>/card.css` | 这种牌的结构样式,只用主题变量(`--tint-*` `--line` …);服务把它们拼在主题 css 前面 `/kid/theme.css`,主题写同名选择器能盖 | 孩子端页面 |
| `src/ui/kid/kid-page.ts` | 首页怎么画:老师牌在 `renderDeck`(按钮、方砖、常驻的听写与拍照听写),公共的听写牌在 `homeCard` | 孩子端 |

`src/board/cards/index.ts` 是登记表(`CARD_KINDS`)、首页围栏 → 牌(`parseCard`)、下发前剥字段(`stripCard`)、首页检查与一句话里用的标题(`cardLabel`)。首页写了别的标签(以前课里的卡、不认识的)退成文字显示原文,首页检查报「要改」。

## card.md 的八个栏目

1. **是什么**(一句)
2. **什么时候用 / 别用**(`- 用:` / `- 别用:` 各至少一条,别用要给替代)
3. **写法**(围栏标签、正文规则)
4. **例子**(≥ 1 个,每个围栏前一行 `<!-- expect {"kind":"…","props":{…}} -->`:测试把围栏喂 `parseCard`,kind 要对、列出的 props 逐个深比、`warning: true` 才允许有 warning)
5. **反例**(常见错法 + 解析器怎么退化;同样带 expect)
6. **孩子看到什么**
7. **你会收回什么**(首页的牌都写「没有」)
8. **状态的形状**(首页的牌都写「没有」)

改了 md 跑 `pnpm run gen:skills`(`tests/skills.test.ts` 断言入库的和生成的一致),workspace 里的由 `cotutor init` / `cotutor refresh` 换新。

## 加一种首页的牌

1. `src/board/cards/<kind>.ts`:照 `dictation.ts` 写 `CardKind`;不下发孩子端的字段在 `strip` 里剥。
2. `src/board/cards/index.ts`:import + `CARD_KINDS` 加一项。
3. `cards/<kind>/card.md` 八个栏目(例子带 expect)、`cards/<kind>/card.css`;`pnpm run gen:skills`。
4. `src/ui/kid/kid-page.ts`:首页上怎么画(公共的在 `homeCard`,归某位老师的在 `renderDeck` 那位老师的牌里)。
5. `src/app/mock/mock.ts` 的样例首页(`mockHomeMd`)放一张;`tests/mock.test.ts` 加一条。
6. 验:`pnpm test`(`cards-doc.test.ts` 会跑你的例子),`cotutor mock` 看首页。

## 不变的原则

- **页面只认 JSON**:首页发布时存 `{kind, props}`,不存原文;不认识的 kind 退成文字显示原文。
- **不下发的不下发**:`strip` 在 `/api/kid/home` 里机械执行(听写牌的字、老师牌按钮的讲法与参数)。
- **不设版本号**:props 新字段一律可选;删种类时同步删除注册、文档和页面分支。
- **坏了 = 没有**:解析失败退成文字、主题坏了退出厂件;孩子端永远没有错误文案。
