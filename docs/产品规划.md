## 一句话

**cotutor = 家里的 AI 老师团,和家长一起教。** 一起教,不替家长教(co-);孩子找哪个老师就和哪个老师说话,老师用一句话、一个弹窗或一个课包回应;家长看全部过程,孩子看精简后的对话与产物。开源(拟 `github.com/tarslab/cotutor`;npm 裸名 `cotutor` 2026-09-07 查为空,GitHub 同名 15 个无关小仓,商标未查)。

## 定位与边界

- **是**:一组可直接对话的老师(老师团)+ 两端两种视图(家长看原始,孩子看精简)+ 孩子侧的「今天」课件与画布。
- **不是**:智能体商店(第一期只自家用,「广场」是家长的管理页);在家上学工具。
- **差异点三条**:孩子侧的笔与画布(圈、写、课件,《交互重新设计.md》底层事实 1),聊天窗是标配不是差异点;数据在自家 vault(《obsidian仓库设计.md》双根);老师与家长同侧,家长永远是观众和最终裁判(《费曼学习法.md》提醒)。
- **品牌层级**:cotutor 是应用品牌;drawtell / voxtell 是开源底层工具,独立仓、独立名不动;drawtell-skills 是老师的技能库。2026-08-22「只有 drawtell 一个品牌」的拍板修订为:**子产品仍不起花名**(homework / reading / canvas 照旧是前缀约定),cotutor 是子产品之上的应用名。理由:应用要开源发布,需要一个搜得到的名字,drawtell 已经是工具名。孩子端标题仍读 `drawtell.json` 的 `title`。
- **借鉴 AionUI 的只有一个概念**:agent 后端可换 + 预设,现有 `gen.agents` 已是(cotutor 里叫 `runtimes`)。不借它的 Electron、多 IM 通道(104 个运行时依赖,是给成人的办公助手壳)。

## 五个概念

| 概念 | 定义 | 落在哪 |
|---|---|---|
| 老师 | **一个可直接对话的 agent** = 预设(人设:名字、音色、头像;技能:加载哪些 skill;政策:评判是否可见、每日次数、可用的回复形式)+ 自己的会话。语文老师、数学老师、朗读老师、作业老师都是老师 | cotutor 包 `agents/<名>.md` 是出厂件(frontmatter + 正文即系统提示);init **拷贝**进workspace `.claude/agents/`(2026-09-09 拍板,原「链」作废:拷进来就是家长的,想改就改;`.qwen/agents/` 是相对链;出厂 hash 记 `.cotutor/shipped.json`,`cotutor upgrade` 没改过的换新、改过的只报 diff);人设与政策在 `cotutor.json`。目录、上下文、记忆、子代理、跨老师知识流见《agent层设计.md》(2026-09-08) |
| 对话 | **一老师一天一段**,家长与孩子进的是同一段;每条消息 `--resume` 同会话,不设常驻进程 | 无头会话 id + NDJSON 转录,机器面 |
| 视图 | **家长视图 = 原始**(说话、思考摘要、工具行、子任务、待裁量全在);**孩子视图 = 精简**(只有老师说的话与产物卡,思考 / 工具 / 转录 / 报错一律不进) | apps/web,`gen-transcript` 已有的过滤是孩子视图的雏形 |
| 媒介 | 画布(纸色 `#f6f4ee`,kid-canvas / excalidraw)、播放器(`drawtell/player`)、语音(voxtell)、聊天窗。**机制,与老师正交**;子产品表里的 canvas 是媒介不是老师 | apps/web + 工具仓 |
| 回复形式 | 老师的一次回复按贵贱分级,老师自己选,孩子不选 | 下节 |

## 回复形式(阶梯)

同《架构重新设计.md》反馈阶梯的思路:在最便宜的层级把事消耗掉。

| 级 | 回复形式 | 谁出 | 时延 | 适合 |
|---|---|---|---|---|
| L0 | 确定性资源:点词即读、笔顺弹窗、再听一遍 | 不经 LLM | 即时 | 怎么读、怎么写 |
| L1 | 聊天窗里一两句话,自动 TTS 播出 | 老师直接答 | 秒级 | 什么意思、为什么 |
| L2 | 快卡:一行板书 + 配音,确定性模板排版 | 老师出内容,模板出场景 | 十秒级 | 答案要看得见(数轴、拼写)。**先不做** |
| L3 | 补讲子场景,挂在孩子圈的那一步 | 老师触发的生成任务 | 分钟级 | 这一步没懂 |
| L4 | 整包课包(新出或重生) | 老师触发的生成任务 | 十分钟级 | 一道题、一页书 |

**实测约束(2026-09-07,workspace 4 次整页作业无头生成)**:1.9 / 7.8 / 11.4 / 14.6 分钟,$1.44 / 3.38 / 4.66 / 4.93,10–73 轮,90–474 事件。孩子问一句等十分钟不叫「继续提问」,所以 **L3 必须是另一种任务**:只补一个子场景,跳过大部分阶梯,目标两分钟内;能不能做到是 R0 实测的第一个结论。L3 / L4 出来之前老师在聊天窗先给一句话(L1),做好了产物卡出现在同一段对话里,孩子首页的叠也同步出现。

## 两个端(重写版,2026-09-08)

新仓从零写,**不搬 apps/web 的结构**;现有纯函数(课程表解析、markdown 子集、待裁量解析、转录过滤)按需抄,不整体搬。旧 apps/web 继续给孩子用,到新孩子端真机试用通过再退役(同一期 M5 的切换惯例)。

### 孩子端(`/`)

- **首页 = 今天 + 老师们**:课程表的今天(一周小路的思路照用,产物卡按学科分叠,没产物也画今天);一排开着的老师头像,点头像进聊天窗。没有广场,没有选孩子(一孩一 workspace)。
- **聊天窗**:语音优先,按住说话,回复自动 TTS;打字可用。孩子视图按《契约草案.md》§4 的机械规则:只看每次运行的最终文本(剥掉待裁量与转交段,按 replyMaxChars 截断)+ 产物卡;没有思考、工具、转录、报错、评判。
- **上下文自动带**:从产物页进聊天窗带当前对象;播放页留「问」直达该学科老师(产物页与播放页是 drawtell 范围,待其回到视野)。
- **后端不通**:老师头像灰掉,聊天窗不开,已有产物照看。
- 验收开关缺省「直接给孩子」。

### 家长端(`/parent`)

- **对话**:按老师列会话,家长视图(主线 + 子代理折叠),随时发消息;孩子的消息与老师给孩子的回复也在这里。**这是家长端第一屏**,不再是「今晚」。
- **老师团**:老师卡片,开关、显示名、头像、音色、政策旋钮;只读写 cotutor.json。
- **记账**:一个按钮,学习结束后点,应用 resume 当天有对话的每位老师写账本与日记段;周末再点一次出周汇总。
- **作业线**(拍照 → 作业老师认学科 → 转交学科老师 → 生成 → 产物卡):拍完确认、裁剪、待裁量回答这些动线按契约在新仓重写,drawtell 回到视野时做。
- **计划**:规划老师出草稿到 vault,家长在 Obsidian 改;家长端只展示与提醒。

## 对话与实现选项

agent 层的概念(workspace目录、cwd、三种记忆的归属、子代理适用场景、规划老师怎么读别的老师的知识)已单独成文《agent层设计.md》,本节只留与产品面直接相关的部分。

- **老师 = 对话**。一个老师一天一段,家长与孩子共用;系统提示 = 老师文件正文,技能 = 正文里点名的 skill,人设与政策从 `drawtell.json` 注入模板。每条消息 `--resume <session>` 一次,异步天性照旧(《架构重新设计.md》两个入口)。首版「一孩一天一段、主 agent 路由」作废:孩子自己选老师,就不需要机器路由。
- **老师出产物,三条路,按需选,不是前提**:
  1. **路由路**:老师会话里用工具触发应用的生成路由(detach 一个无头任务;新仓按现有 detach 模式重写),结果落盘后老师在对话里给产物卡。老师转录干净(生成噪声在另一份日志);
  2. **同会话路**:老师会话内直接跑工作流。最简单,但一次 440+ 事件全进这段对话,家长视图靠 foldRuns 折叠;
  3. **子 agent 路**:老师会话内起子 agent 出产物,主线只剩报告,多题可并行。代价是绑两个 CLI 的子 agent 机制。
  缺省走 1,模式就是今天在用的;3 只在转录吵到碍事或需要并行时再上,见 R8 的可选项。
- **若走子 agent 路(备查,2026-09-07 按 claude 2.1.220 / qwen 0.21.13 文档对照)**:两边都不让子 agent 向人提问 → 子 agent 在报告末尾返回「问题 + 选项」,老师落 `待裁量.md`(`HoldupAskV0` 不变);agent 文件写**最小公共子集**(`name` / `description` / `maxTurns` / `permissionMode` + 正文),不写 `tools`(工具名两边不同)、`model`(值域不同)、`skills`(Qwen 未落地);stream-json 两边都有 `parent_tool_use_id`,家长视图可按它分栏;claude 子 agent 文本进父流要 `--forward-subagent-text`(2.1.211+),qwen 待实测;预算 claude `--max-budget-usd`,qwen `--max-wall-time`(其 `--max-tool-calls` 不算子 agent 内部调用)。
- **老师文件是什么(2026-09-07 核对官方文档与本机)**:两个 CLI 都有「agent 文件」这种东西:一个 Markdown 文件,YAML frontmatter 写 `name` / `description` 等,**正文就是系统提示**;放项目目录 `.claude/agents/`(Claude Code)或 `.qwen/agents/`(Qwen Code)即被发现,用户级放 `~/.claude/agents/` / `~/.qwen/agents/`。它原本是给「子 agent」用的定义格式,但 **Claude Code 还能用 `claude --agent <name>` 让这个文件当主会话的人设跑**,与 `-p` / `--resume` 可组合(本机 2.1.220 实测:`claude --agent x -p ...` 会校验名字并列出可用 agent),所以「老师 = 会话」在 Claude Code 下就是 `claude --agent math-tutor -p "<消息>" --resume <会话id>`。**Qwen Code 0.21.13 本机没有 `--agent`**(其文档写明 `--agent` 是待落地项),老师文件在 Qwen 下暂时只能作为子 agent 被调用;要当主会话,等 `--agent` 落地,或用其在线文档列出的 `--system-prompt` 把正文塞进去(本机 help 未见此旗,升级后再核)。frontmatter 取公共子集,运行时差异留 `gen.agents` 模板。官方文档:
  - Claude Code 子 agent(文件格式、目录、frontmatter 字段表):<https://code.claude.com/docs/zh-CN/sub-agents>(英文 <https://code.claude.com/docs/en/sub-agents>)
  - Claude Code CLI 参考(`--agent`、`--agents`、`-p`、`--resume`):<https://code.claude.com/docs/en/cli-reference>
  - Claude Code 无头模式(stream-json、`parent_tool_use_id`、`--forward-subagent-text`):<https://code.claude.com/docs/zh-CN/headless>
  - Qwen Code 子代理(文件格式、目录、Claude Code 兼容字段):<https://qwenlm.github.io/qwen-code-docs/zh/users/features/sub-agents/>
  - Qwen Code 无头模式(`--resume`、`--system-prompt`、预算旗):<https://qwenlm.github.io/qwen-code-docs/zh/users/features/headless/>
  - Qwen Code 技能(`.qwen/skills/` 目录,老师正文里点名的 skill 从这里找):<https://qwenlm.github.io/qwen-code-docs/zh/users/features/skills/>

## 里程碑(重写版,单位周末,不排日期)

总原则:**旧 apps/web 不动,继续给孩子用**;新仓每一步做完都能单独跑给家长看;孩子端切换只在真机试用通过后。R0 是实测,R1 起写代码。原 C0–C6 作废。

### R0 定生死实测(1 个周末),不写产品代码

1. 拿一道已生成的题,手工跑一次「圈第 N 步 + 一句话」形态的补讲任务(只出一个子场景),记时长与费用。两分钟内 → R6 按本文;超了 → 先改阶梯再谈;
