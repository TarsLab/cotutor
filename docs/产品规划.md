## 一句话

**cotutor = 家里的 AI 老师团,和家长一起教。** 一起教,不替家长教(co-);孩子找哪个老师就和哪个老师说话,老师用一句话、一个弹窗或一个课包回应;家长看全部过程,孩子看精简后的对话与产物。开源(拟 `github.com/tarslab/cotutor`;npm 裸名 `cotutor` 2026-09-07 查为空,GitHub 同名 15 个无关小仓,商标未查)。

## 定位与边界

- **是**:一组可直接对话的老师(老师团)+ 两端两种视图(家长看原始,孩子看精简)+ 孩子侧的「今天」课件与画布。
- **不是**:智能体商店(第一期只自家用,「广场」是家长的管理页);在家上学工具。
- **差异点三条**:孩子侧的笔与画布(圈、写、课件,《交互重新设计.md》底层事实 1),聊天窗是标配不是差异点;数据在自家 vault(《obsidian仓库设计.md》双根);老师与家长同侧,家长永远是观众和最终裁判(《费曼学习法.md》提醒)。
- **品牌层级**:cotutor 是应用品牌;drawtell / voxtell 是开源底层工具,独立仓、独立名不动;老师的技能分两处:和 drawtell 绑定的领域 skill 随 drawtell 包发(2026-09-15 起,drawtell-skills 仓退役),cotutor 自家的在本仓 `skills/`。2026-08-22「只有 drawtell 一个品牌」的拍板修订为:**子产品仍不起花名**(homework / reading / canvas 照旧是前缀约定),cotutor 是子产品之上的应用名。理由:应用要开源发布,需要一个搜得到的名字,drawtell 已经是工具名。孩子端标题仍读 `drawtell.json` 的 `title`。
- **借鉴 AionUI 的只有一个概念**:agent 后端可换 + 预设,现有 `gen.agents` 已是(cotutor 里叫 `runtimes`)。不借它的 Electron、多 IM 通道(104 个运行时依赖,是给成人的办公助手壳)。

## 五个概念

| 概念 | 定义 | 落在哪 |
|---|---|---|
| 老师 | **一个可直接对话的 agent** = 预设(人设:名字、音色、头像;技能:加载哪些 skill;政策:评判是否可见、每日次数、可用的回复形式)+ 自己的会话。语文老师、数学老师、朗读老师都是老师 | cotutor 包 `agents/<名>.md` 是出厂件(frontmatter + 正文即系统提示);init **拷贝**进workspace `.claude/agents/`(2026-09-09 拍板,原「链」作废:拷进来就是家长的,想改就改;`.qwen/agents/` 是相对链;出厂 hash 记 `.cotutor/shipped.json`,`cotutor upgrade` 没改过的换新、改过的只报 diff);人设与政策在 `cotutor.json`。目录、上下文、记忆、子代理、跨老师知识流见《agent层设计.md》(2026-09-08) |
| 对话 | **一老师一天一段**,家长与孩子进的是同一段;每条消息 `--resume` 同会话,不设常驻进程 | 无头会话 id + NDJSON 转录,机器面 |
| 视图 | **家长视图 = 原始**(说话、思考摘要、工具行、子任务全在);**孩子视图 = 精简**(只有老师说的话与产物卡,思考 / 工具 / 转录 / 报错一律不进) | 服务端过滤(`src/server/`),孩子端只拿过滤后的 |
| 媒介 | 画布(纸色 `#f6f4ee`,kid-canvas / excalidraw)、播放器(`drawtell/player`)、语音(voxtell)、聊天窗。**机制,与老师正交**;子产品表里的 canvas 是媒介不是老师 | 舞台包 `src/stage/` + 工具仓 |
| 回复形式 | 老师的一次回复按贵贱分级,老师自己选,孩子不选 | 下节 |

## 回复形式(阶梯)

同《架构重新设计.md》反馈阶梯的思路:在最便宜的层级把事消耗掉。

| 级 | 回复形式 | 谁出 | 时延 | 适合 |
|---|---|---|---|---|
| L0 | 确定性资源:点词即读、笔顺弹窗、再听一遍 | 不经 LLM | 即时 | 怎么读、怎么写 |
| L1 | 聊天窗里一两句话,自动 TTS 播出 | 老师直接答 | 秒级 | 什么意思、为什么 |
| L2 | 快卡:一行板书 + 配音,确定性模板排版 | 老师出内容,模板出场景 | 十秒级 | 答案要看得见(数轴、拼写)。**先不做** |
| L3 | 补讲子场景,挂在孩子圈的那一步 | 老师触发的生成任务 | 分钟级 | 这一步没懂 |
| L4 | 整包课包(新出或重生) | 老师触发的生成任务 | 十分钟级 | 一道题、一页书 |

**实测约束(2026-09-07,workspace 4 次整页作业无头生成)**:1.9 / 7.8 / 11.4 / 14.6 分钟,$1.44 / 3.38 / 4.66 / 4.93,10–73 轮,90–474 事件。孩子问一句等十分钟不叫「继续提问」,所以 **L3 必须是另一种任务**:只补一个子场景,跳过大部分阶梯,目标两分钟内;能不能做到是 R0 实测的第一个结论。L3 / L4 出来之前老师在聊天窗先给一句话(L1),做好了产物卡出现在同一段对话里,孩子首页的叠也同步出现。

## 两个端(重写版,2026-09-08)

新仓从零写;现有纯函数(课程表解析、markdown 子集、转录过滤)按需抄,不整体搬。

### 孩子端(`/`)

- **首页 = 今天 + 老师们**:课程表的今天(一周小路的思路照用,产物卡按学科分叠,没产物也画今天);一排开着的老师头像,点头像进聊天窗。没有广场,没有选孩子(一孩一 workspace)。
- **聊天窗**:语音优先,按住说话,回复自动 TTS;打字可用。孩子视图按《契约草案.md》§4 的机械规则:只看每次运行的最终文本(剥掉固定段与第一个 H2 起的尾巴,按 replyMaxChars 截断)+ 产物卡;没有思考、工具、转录、报错、评判。
- **上下文自动带**:从产物页进聊天窗带当前对象;播放页留「问」直达该学科老师(产物页与播放页是 drawtell 范围,待其回到视野)。
- **后端不通**:老师头像灰掉,聊天窗不开,已有产物照看。

### 家长端(`/parent`)

- **对话**:按老师列会话,家长视图(主线 + 子代理折叠),随时发消息;孩子的消息与老师给孩子的回复也在这里。**这是家长端第一屏**,不再是「今晚」。
- **老师团**:老师卡片,开关、显示名、头像、音色、政策旋钮;只读写 cotutor.json。
- **记账**:一个按钮,学习结束后点;每个话题先打星(1–5),应用对这天每个还没记过的话题 resume 那位老师一次,老师回「## 记账」段,应用写进 vault 的日记(孩子问的话总记,打分够的才有摘要与骨架;《obsidian仓库设计.md》)。
- **作业照片**(2026-09-14 重定):在学科老师的页上直接拍,照片落 workspace `captures/`,老师自己看图认题;不落 vault。家长端同一接口也能发照片,消息下显示缩略图(R5)。
- **计划**:家长在 vault `计划/<周>.md` 自己写;家长端只展示与提醒。

## 政策(家长人工确认,写本仓库,工具仓不硬编码)

| 政策 | 缺省(建议) | 机制兜底 |
