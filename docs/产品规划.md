# cotutor 产品规划

> 政策与机制分离,政策由家长人工确认。已定项在「拍板记录」,未定项在「待拍板」;活过多轮的约定收进根目录 CLAUDE.md,带日期的决定都可推翻。

## 一句话

**cotutor = 家里的 AI 老师团,和家长一起教。** 一起教,不替家长教(co-);孩子找哪个老师就和哪个老师说话,老师回一页板书;家长看全部过程,孩子看精简后的板书与卡。源码公开 `github.com/tarslab/cotutor`(Apache-2.0 加附加条件,见第 22 条),npm 裸名 `cotutor`。

## 定位与边界

- **是**:一组可直接对话的老师(老师团)+ 两端两种视图(家长看原始,孩子看精简)+ 孩子侧的板书、卡与舞台。
- **不是**:智能体商店(第一期只自家用);在家上学工具。
- **差异点三条**:孩子侧的笔与卡(标注、点读、田字格、画板、讲解动画);数据在自家 vault(家长面)与 workspace(机器面);老师与家长同侧,家长永远是观众和最终裁判。
- **品牌层级**:cotutor 是应用品牌;drawtell / voxtell 是开源底层工具,独立仓、独立名不动;和 drawtell 绑定的领域 skill 随 drawtell 包发,cotutor 自家的在本仓 `skills/`。
- **只借一个概念**:agent 后端可换 + 预设(cotutor 里叫 `runtimes`)。不做 Electron、不接 IM 通道。

## 四个概念

| 概念 | 定义 | 落在哪 |
|---|---|---|
| 老师 | **一个可直接对话的 agent** = 预设(人设:名字、音色、头像;政策:每日次数、每句字数、板书开关)+ 自己的会话 | cotutor 包 `agents/<名>.md` 是出厂件(frontmatter + 正文即系统提示);init **拷贝**进 workspace `.claude/agents/`,出厂 hash 记 `.cotutor/shipped.json`;人设与政策在 `cotutor.json`。目录、上下文、记忆见《agent层设计.md》 |
| 对话 | **一老师一天一段**,家长与孩子进的是同一段;段内按**话题**分会话,每条消息 `--resume` 那个话题的会话,不设常驻进程 | 无头会话 id + NDJSON 转录,机器面 |
| 视图 | **家长视图 = 原始**(说话、思考摘要、工具行全在);**孩子视图 = 精简**(只有板书:讲稿与卡;思考 / 工具 / 转录 / 报错一律不进) | 服务端过滤(`src/server/`),孩子端只拿过滤后的 |
| 媒介 | 板书、卡、舞台(drawtell 播放器、excalidraw 画板)、语音(voxtell)。**机制,与老师正交** | 舞台包 `src/stage/` + 工具仓 |

## 两个端

### 孩子端(`/`)

- **首页 = 家长批准的一页卡**(《首页设计.md》):最上面每位老师一张老师卡,卡上的按钮决定进老师页之后是新话题、接着哪个话题、还是带着家长备好的讲法开场;下面是家长排的几张卡。首页由家长在 workspace 根开 Claude Code(技能 `cotutor-home`)商量、`cotutor home publish` 发布;没发布过就是每位老师一张只有「新话题」的卡。没有广场,没有选孩子(一孩一 workspace)。
- **板书页**:按住说话或打字,回复是一页板书:卡先铺开、讲稿一句句念、笔跟着声音标注,末句问句停下等孩子;点一张卡进舞台做题,做完「交给老师」。没有顶栏:左上角「‹ logo 语」胶囊(回首页,整颗填这位老师的颜色、带他的首字,拍板 24、26),右上角喇叭与「更多」(「新话题」「以前的」)。板是平的纸色(拍板 28),语文、数学、英语老师的板右边竖着一个很淡的学科名,照课本封面的字(拍板 27)。孩子视图按《契约草案.md》§4 的机械规则;没有思考、工具、转录、报错、评判。
- **后端不通**:老师卡灰掉,板书页不开。
- **孩子设备上没有通往家长端的入口**;家长设了 PIN(`cotutor pin`,拍板 21)孩子手输 `/parent`、`/dev` 也进不去,没设就是全开,靠家长在旁边。

### 家长端(`/parent`)

家长日常进的那页,不懂技术也用得顺;iPad 扫码进的就是它(《家长板书页设计.md》拍板 13)。一层那天的清单(跨老师、跨话题,能打星、记账、删话题),点一个话题或一次听写就是它的录像(《家长录像设计.md》拍板 16);另有设孩子首页的 `/parent/home`。家长用的页都在 `/parent` 下(听写 `/parent/dictation`、口语课 `/parent/talk`、小老师 `/parent/xlaoshi`),孩子端页面里永远没有 `/parent`。改了老师文件或 vault 想看效果,家长到孩子端当一回孩子聊,回来把那个话题删掉:它写进记忆、日记的一起撤,每日条数退回(《家长板书页设计.md》拍板 18、19)。`/qr?to=parent` 是它的码。孩子端 UI 里没有通往它的入口。要锁的话一个机器级 PIN(拍板 21):iPad 上输一次,这台电脑免密。

### 工作台(`/dev`)

给有技术背景的家长与开发者:装完调一次、出了问题查原因;非技术家长可以不开。

样子见《工作台设计.md》(2026-10-16:「纸面控制台」,左边侧栏,缺省进概览)。

- **概览**:今天几轮、近 7 天、用量(按运行时)、画图张数、各老师今天、要看一眼的轮次(慢 / 出错 / 带提醒,点进去直达看原文)、体检(doctor 不带 `--live`)。
- **对话**:按老师列会话,家长视图,随时发消息(能带照片);孩子的消息与老师给孩子的板书也在这里。「看原文」把一轮拆成六站。话题打星(1–5)与「记账」也在这里(家长端清单上也有):应用对这天每个还没记过的话题 resume 那位老师一次,老师回「## 记账」段,应用写进 vault 的日记(《obsidian仓库设计.md》)。
- **activity**:看、改每位老师的 activity 文件,边改边查、看老师实际收到什么、和出厂比、恢复出厂(《工作台设计.md》第四节)。
- **老师团**:一位老师一行,开关、显示名、头像、音色、政策旋钮、老师文件正文;只读写 cotutor.json 与老师文件。
- **音色**:列出配音引擎的全部音色,先试听再挑,挑中的写进 cotutor.json 那位老师的 `voice`。
- **设置**:路径、端口、证书、配音命令。

作业照片不在工作台:孩子在学科老师的页上直接拍,拍完先到发照片屏(裁剪、圈画、转 90°,《作业照片设计.md》)再发;照片落 workspace `captures/`,老师自己看图认题;不落 vault。计划由家长在 vault `计划/<周>.md` 自己写,没有展示页。

## 政策(家长人工确认,写 cotutor.json,工具仓不硬编码)

| 政策 | 缺省 | 机制兜底 |
|---|---|---|
| 老师说给孩子听的每一句的字数上限 | 60 | 代码在句末截断 |
| 孩子视图过滤 | 只留板书 | 过滤在服务端做,不靠前端隐藏 |
| 模型 | 可换 | `runtimes` |
| 人设(名字、音色、头像) | 每老师一套 | 注入模板与 TTS,不进内容 |
| 是否开放社区贡献老师 | 第一期不开 | 待拍板 2 |

## 数据(双根)

- **一个 workspace 一个孩子**:`~/cotutor/<slug>/` 对一个 vault、一个孩子、一个服务进程;多孩子 = 多套;跨孩子共享靠拷贝,不链接。
- 家长面 vault、机器面 workspace,角色映射 `paths`。
- 机器面:对话索引与转录 `conversations/<老师>/<日期>.*`、课包 `bundles/`、照片 `captures/`、产物账本 `ledger/artifacts.jsonl`。
- 长期记忆在 vault:档案、入口文件、教材、记忆、日记、计划(《obsidian仓库设计.md》)。
