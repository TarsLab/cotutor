# 你说我画:孩子说清楚一个故事,画家照着画,画出来就是一道看图说话题

> 2026-10-11 起。语文老师的一个 activity(`agents/chinese-tutor/activities/你说我画.md`):孩子编故事,老师用「画家」的口吻问到说清楚,写一张画图卡(`paint`,`src/cards/paint.ts`、`cards/paint/`),应用在后台交给百炼文生图画成一张连环画(`src/paint/`);按钮上填了参数「词」就是「我来出题」。还没做的见 §八。正文 2026-10-22 收成现状;10-10 的设想稿、草稿、分期与进度,原文在 git 历史 facdd86。
> 样子照二年级练习册那道「小白兔和小灰兔种萝卜」(四幅图 + 题干 + 词语宝库)。原型:https://claude.ai/artifact/6GYUpbuT6EFSZVSsbqKFAN

**结论先行**:看图说话是**从图到话**,你说我画把它倒过来,**从话到图**。孩子编故事,老师用「画家」的口吻一问一答,把故事问到**画家画得出来**:前后对得上、合常理、每一幅有看得见的动作和表情。整段连着说过一遍,和孩子一起**分幅**(一幅一句画什么);出题时题目要用的词**每个落到一幅、变成图上看得见的线索**,再定题干。最后老师写一张 `paint` 卡,应用画成**一张连环画**(四幅时 2×2),孩子端排成练习册的样子:题干、图、词语宝库。图是奖励,也是孩子出的一道题,能拿去考爸爸妈妈。

## 一、教什么

### 1.1 一个读者:画家

二年级的孩子说不清楚,多半不是不会说,是**不知道听的人缺什么**。家长说「说清楚点」,孩子不知道哪里不清楚。

你说我画里有一个具体的读者:**画家**。画家只知道孩子说出来的话,没说的就画不出来;说得前后不一样,画家就不知道画哪个。于是:

- 老师追问有了一个不评判的理由:「画家想知道小熊穿什么颜色的衣服」,而不是「你没说清楚」。
- 矛盾不是「错了」,是「画家糊涂了,画哪个?」——孩子会自己去改。
- 图一出来,孩子立刻看到自己的话被理解成了什么。说漏的,图上就没有。这是最直接的反馈,不用谁来判。

### 1.2 「说清楚」的七件事(画家的清单)

老师心里有这张清单,问够了才画。孩子不看清单,只听到「画家还想知道一件事」。

| # | 画家要知道 | 二年级要做到的 |
|---|---|---|
| 1 | 谁、在哪里、什么时候 | 开头一句交代清楚 |
| 2 | 先、接着、最后发生了什么 | 三到四件事,按先后排 |
| 3 | 每一幅画什么 | 一幅一件事,有动作 |
| 4 | 看得出来 | 笼统的词换成看得见的样子 |
| 5 | 前后对得上 | 人数、衣服、季节、时间、东西从哪来,前后一样 |
| 6 | 说得通 | 合常理;童话的设定可以,但要先交代 |
| 7 | 结果和心情 | 最后一幅有结果、有人物的心情或想法 |

出题时再加一件:**题目要的词都用上,而且图上看得出来**(四)。1、2、7 就是看图说话的顺口溜,孩子已经会,换个方向用;3、4 是这个功能独有的**画面感**(「很开心」「很多」要变成样子);5 查记性(自己的话对不上),6 查常识(和世界对不上)。

### 1.3 「脱离常理」怎么判

童话的设定(兔子会说话、穿裙子)不问,照画。违背常理又没交代(早上种下,中午拔出大萝卜),好奇地问中间过了多久,孩子说「过了一个夏天」就收下。孩子说是魔法,算数,请孩子在开头交代一句——**设定要先说,后面才说得通**。

规矩只有一条:**孩子给出了说法就算,老师只问不改**。教的不是「什么是对的」,是「听的人会在哪里卡住」。

## 三、老师怎么引导

老师照 activity 文件「老师怎么带」一节带(人设、第一句、七步、我来出题、怎么问、画好以后、收、一段好的回复),那一节就是这个话题的系统提示。

### 3.1 沿用看图说话的规矩

一节只问一个问题,问句是末句;每节一张 `read` 卡,只放孩子这次说的;说不出就给两个让孩子挑;提示只指方向,不替孩子说答案。

### 3.2 五种问法

| 问法 | 什么时候 | 老师这样问 |
|---|---|---|
| ① 画家想知道 | 缺信息 | 「画家拿起笔,又停下来了:小熊穿什么衣服呢?」 |
| ② 画家画哪个 | 前后对不上 | 两句原话并排放一张 `read` 卡,不说哪句错:「画家画小猴,是画他睡觉,还是画他浇水呢?」 |
| ③ 中间过了什么 | 不合常理 | 「早上种下种子,第二幅就抱着大西瓜啦。中间过了多久?」 |
| ④ 画家怎么画出来 | 笼统词 | 「『羞愧』看不见呀。一个人羞愧的时候,脸上、手上是什么样子的?」 |
| ⑤ 这一幅画哪件 | 一句里好几件事 | 「一幅画只画一件事。这一幅画哪件?别的放到下一幅。」 |

②孩子说「他先睡觉,醒了才浇水」更好,收下,多一幅;「画家糊涂了」只用在前后对不上。④孩子答「低着头,脸红红的」,`read` 卡写「小猴低着头,脸红红的,觉得很羞愧。」——**词和样子一起留下**,这也是出题时「词变成线索」的那个动作。

### 3.3 什么时候算说清楚

- 七件事缺哪件问哪件,一节一件;孩子说「快画吧」,「画家还想知道一件事」,**不跳过**。
- 「说没说清楚」只靠老师;「整段放出来、孩子连着说过一遍」应用也拦(activity「应用拦的」的 `连说过一遍`:话题里有一张三行以上的 `read` 卡、孩子在它后面开过口)。没过就不画,下一条的 `缺` 告诉老师。

### 3.4 图出来以后

- 老师看不到图,下一条的 `cards:` 里只有一行「画好了 / 还在画 / 没画成」(`painter.ts` 的 `paintLines`)。不描述图,直接问「哪里和你想的一样?哪里不一样?」;孩子想改,改那一句,再写一张 `paint` 卡。**不一样不是谁错了**,是练「说清楚」的机会。
- 一个话题画几张:按钮上写了参数「最多画」才有上限,应用算好 `还能画` 给老师、也拦;不写不限(《产品规划.md》拍板 29,改了下面拍板 4)。
- 没画成:请孩子看着分好的几幅自己讲一遍,不说没画成,也不编「画家累了」。

## 四、出题:题目要用上新学的词

### 4.1 出题人和答题人想的不一样

孩子做看图说话时是答题人:看图 → 想词 → 说话。出题人反过来:**先有词,再想一个故事让这些词都用得上,再把每个词变成图上看得见的东西**,答题人看图才会想到它。学到的是:**词是从画面来的**。「羞愧」要画成低头、脸红;「满满一筐」要画成筐里堆得冒尖。

### 4.2 出题四步

挑词(三四个)→ 编故事,让挑的词都有地方用 → 词落到幅(看图的人怎么看得出来)→ 孩子说要问看图的人什么,老师整理成题干、念给孩子听。

- 「播种」「睡大觉」能直接画;「羞愧」「着急」画表情和动作;「突然」「终于」画不出来,只放进词语宝库。
- **一幅最多落两个词**。全挤在最后一幅,答题人只会用一个。
- 题干照练习册:「图上画了谁?他们在干什么?结果怎样?用上词语宝库里的词,写几句话。」

### 4.3 词从哪来

「我来出题」按钮下的参数 `词`(§七)。老师在每条消息的 `activity:` 里读到;填了,「老师怎么带」里 `{{有 词}}` 那段才在。拍板 5 说的「之后接这周的词」还没做(§八)。

### 4.4 题做好了去哪

- 孩子端那张 `paint` 卡就是一页题:题干、图、词语宝库。
- 家长在那个话题的录像里看得到这张卡,「经过」里一行「画图」写用的模型与秒数,或没画成的原因。
- 拿去考爸爸妈妈:孩子当老师,用看图说话的顺口溜问。在家里当面做,应用不管。

## 五、提示词

两段都在 activity 文件里:**「老师怎么带」**与**「画家收到什么」**。画家那段老师不写:画风、不要的在 activity 文件里,家长可改;版式、角色、分幅由应用接。老师只写分幅和角色,换了模型、换了 CLI,图的样子不跟着漂。

### 5.1 老师那一节

写法照《写提示词.md》。`paint` 卡只跟着这个 activity 走(头上 `cards: read paint`),语文老师自己的卡里没有(《activity设计.md》拍板 11)。改了先 `cotutor activity check chinese-tutor 你说我画`,再 `cotutor activity eval chinese-tutor 你说我画`(例子在 `你说我画.例子.md`:真老师、模拟孩子、假画家)。

### 5.2 `paint` 卡的写法

真相在 `cards/paint/card.md`(例子即测试)。`题:` `词:` 出题才写;`角色:` 一行一个「名字:样子」,孩子没说样子就只写名字,每幅都画同一个样子靠它;`1.` 起一幅一行,一到四幅,只写**看得见的**,每幅写出角色的名字。解析不成整张退成文字卡。

孩子看到:题干一行;画好前是分好的几幅和「画家在画」;画好了图淡入,宽屏上图在左、词语宝库在右;点开铺满能双指放大。`角色:` 不显示。没画成就一直是分好的几幅。

### 5.3 应用拼给画图模型的那段

activity 文件「画家收到什么」的 `画家` 围栏是模板:中间几行是画风(家长改这里),应用填三个插槽(`src/paint/prompt.ts`):

- `{{版式}}`:四幅「一张四格连环画,四格按 2×2 排……每格左上角一个圆圈数字」;两三幅从左到右横排,也带圆圈数字;一幅「一张画。」,不提编号(提了模型就往图上点 ①③Ⓐ,10-21 起)。
- `{{角色}}`:「同一个角色在每一格里长相、颜色、衣服都照这样画:」下面一行一个;没写角色就空。
- `{{分幅}}`:「第 1 格:……」一行一格;一幅是「画面:……」。

反向提示词是 `画家不要` 围栏。题干与词语宝库不进画,由孩子端排在图外面。没有 activity 文件或那一节,照出厂原文(`PAINT_PROMPT_DEFAULT`、`PAINT_NEGATIVE`)。

## 六、怎么画(技术)

### 6.1 一张四格,不画四张

- **角色一致**是连环画成败的关键。四张分开画,同一只小熊四个样子,孩子会觉得「画家没听我说」。一张图里画四格,模型自己会让四格的角色对上。
- 一张图一次计费、一次等待;正好就是练习册的样子。
- 代价:每格只有四分之一的像素,iPhone 竖屏小。点开铺满放大能补。

### 6.2 接百炼

- `src/paint/draw.ts`:百炼文生图的同步接口,图片地址会过期,拿到就下载。出错、超时都不抛。
- key 与端点按模型定(`src/lib/qianwen.ts`):Token Plan 有这个模型就走它,不然走百炼按量(先看家长端配的 `~/.config/cotutor/bailian.json`)。key 只进请求头。
- `cotutor.json` 的 `paint`:模型缺省 `qwen-image-3.0-pro`(约 10–20 秒),尺寸缺省 `1280*1280`;两三幅横排换成 `1664*928`。

### 6.3 卡和画的接法

- 画是**这张卡的资产**,和卡的配音同一个时机:runner 一轮跑完,板书里有 `paint` 卡就起 `startPaints`(`src/paint/painter.ts`),整个进程一条队,一张一张画。先过 activity「应用拦的」(`activity-state.ts` 的 `paintGate`),没过记成没画、不占张数。
- 存在这张卡的资产目录 `conversations/<老师>/<日期>.<job>.cards/<n>/`:`paint.png` 是图,`paint.json` 是记录(在画 / 画好了 / 没画成,交给画家的整段、模型、几秒、原因)。有记录的不重画;`cotutor replay` 不画。
- 下发时 `enrichPaints` 补上画好没有与图的路径(家长端多一行原因);孩子端在画时隔几秒拉一次,图到了淡入。「在画」5 分钟还没落成(服务重起过)算没画成。
- **坏了 = 没有**:没 key、超时、内容审核没过,孩子端停在分好的几幅,不出错误字;原因只给家长。
- 一天画几张不限(《产品规划.md》拍板 29,推翻下面拍板 6);今天画了几张在工作台概览数。

### 6.4 内容

- 孩子说的话不直接进画图模型:中间隔着老师,老师写的分幅只写看得见的。孩子说打打杀杀,老师照守则往回带。
- 画家那段的画风与「画家不要」固定了画风与禁忌;百炼自己也审,被拒按「坏了 = 没有」。
