## 一、10-17 那堂口语课

当时口语课自己一个模块:拍一页 → 口语单 → 跟我读(应用的状态机定节奏、嘴照读)→ 打电话(嘴自己聊,口语单在系统提示里,老师说话时麦不推)。Ray 只打过这一次。聊段原文(`transcript.json`):

```
老师  Hi Ray! What color is the duck?
孩子  What color is the duck?          老师  What color is the duck?
孩子  我我卡了,给卡。                    老师  What color is the duck?
孩子  鸭子什么颜色的?                    老师  Yellow.
孩子  爸爸,就是你,你多少钱?              老师  Say it again.
孩子  关门,自己去。                      老师  Close the door.
孩子  我不想读。                         老师  I don't want to read.
```

嘴一个人带不了:不会往下引,把孩子的话当成要翻译的(同《实时老师设计.md》§五 P1 第 5 条)。内容要由脑定,嘴只接住、照念。

## 一之二、跟读为什么生硬(10-17 逐句)

同一份 `transcript.json` 的跟读段(47 秒,6 项):

| 时刻 | 老师 | 孩子 | 生硬在哪 |
|---|---|---|---|
| 0:01 | duck,鸭子。 | 怎么?你读一下。duck,鸭子。 | 上来就念,没说要干什么,孩子先问「怎么?」 |
| 0:08 | Nice! under,在……下面。 | under under 在下面。 | 夸一句 + 下一项,夸的是提示词里写死的几句轮着来(Nice / Good job / Great) |
| 0:19 | Good job! bus,公共汽车。 | Boss. | |
| 0:26 | Great! The ducks are under the bus. | The dog. | 整句听一遍就要跟;孩子读两个词停下想,0.9 秒没声就算读完 |
| 0:34 | Good try. I'm driving my car. | 他不等人的。 | 「Good try」按读到多少挑,其实是在打分;孩子抱怨,没人接 |
| 0:41 | Listen again. No, you're walking. | 那我们直接打电话吧。 | 孩子的中文当成没读,说「Listen again」却念了下一句 |
| 0:47 | Great job! Now let's talk! | | 孩子说要打电话,回的是「Great job!」 |

五样:**没说玩法**;**一个腔调**(六项一个节奏,夸的话和孩子说了什么无关);**不等人**(长句半截被截);**不听人话**(中文全当跟读);**像作业**(六项全过一遍才能聊,孩子想跳)。毛病不在「跟读」本身,在它是一条流水线:应用定节奏、嘴照念,中间没有一个懂孩子的人。

## 二、为什么整个搬上来

10-20 比过三种:只换芯(打电话改全双工)、只把打电话搬上实时老师页、整个搬。Jack 拍整个搬(拍板 1),理由是跟读生硬。不是把跟读的状态机搬过来(生硬会一起过来),而是脑写跟读、应用只管等。

## 三、现在的样子

### 三之一 孩子看到的(画布 C 行)

1. 英语老师卡上「口语课」→ 拍一页 → 口语单(改词)。
2. 按钮「先热身,再打电话」(孩子记得「打电话」,10-17 他说「那我们直接打电话吧」)→ 英语老师的实时页:「口语单拍好啦」和同一颗按钮,点之前不接、不开麦;点了开麦(一直听),嘴先说「好,我们先热热身!」,脑写的热身随后到。
3. **热身**(老师说中文,6–10 拍):板上一张一张单词卡、句子一张点读卡;一拍念完,那张卡一圈慢慢呼吸的光(轮到你,不倒计时),孩子开口光变实;跟了,老师接一句和那个词有关的(嘎嘎嘎!)再来下一拍。最后一两拍「你先说」:老师说中文,孩子说英文。
4. 热身最后一句说要打电话 → **响铃**(头像晃,「老师打电话来了」;铃声垫着脑写开场)→ 老师英文开场。
5. **打电话**(老师说英文):一问一答;新句型板上一张 `text` 卡,要说的词留 `___`;孩子说中文,老师用英文说一遍再请他说;确实跟不上才夹半句中文(§三之五)。老师说话时能插嘴。
6. 到点(从响铃算)老师收尾。家长端记录里是英语老师的一个话题(一份录像),老师在给家长的话里写一两句摸底。

### 三之二 热身怎么带

activity 里「一段好的热身」拿 10-17 那份口语单写成,加上孩子大概这样:

```
(word 卡 🦆 duck)
老师  我们先热热身!我说一个英文,你学一个,像回声。我先来:duck!   [[echo duck]]
孩子  duck
老师  嘎嘎嘎!小声一点,像小老鼠:duck…                            [[echo duck]]
(read 卡 The ducks are under the bus.)
老师  搭积木!the bus.  →  under the bus.  →  一整句……             [[echo …]] 每截一个
老师  你先说:鸭子,英文怎么说?                                   [[say duck]]
孩子  duck!
老师  热身好啦!老师给你打个电话,电话里我只说英文哦,听不懂就说「听不懂」。   [[call]]
```

老师的话(玩法、花样、接孩子的那句)用中文,英文只出现在要跟的词、截和拟声里:孩子不说英语,玩法得听得懂。对着 §一之二 的五样:

| 生硬 | 热身怎么改 | 谁管 |
|---|---|---|
| 没说玩法 | 第一拍一句中文说玩法,老师先示范 | 脑(activity 写法) |
| 一个腔调 | 每拍换个花样(回声、小声大声、像动物、搭积木);接孩子的那句跟**词**有关,不说「读得不错」「再来一遍」 | 脑 |
| 不等人 | 一拍只跟一个词或三四个词的一截,长句从后往前搭;孩子开口了等他说完(server_vad 1.6 秒静音);8 秒没开口不催,接着下一拍 | 脑拆句,应用等 |
| 不听人话 | 不像跟读的(中文、和那句不沾)照一直听收下、交脑,排着的热身丢掉;「直接打电话吧」→ 老师一句话收、`[[call]]` | 应用判,脑接 |
| 像作业 | 6–10 拍,口语单不必全跟,剩下的句子留到打电话里演 | 脑 |

念偏了(「Boss」)不纠(§六 6):后面的拍里 bus 又出现,就是再听再说。屏上不显示孩子说成了什么。

### 三之三 摸底

老师要知道孩子今天的底子,打电话才知道说多难的英文。不另做测验,应用从热身每一拍的转写里记,**不靠嘴听发音**(§五之二 coach)。记的是:跟没跟(8 秒没开口、像跟读、对老师说的)、开口快不快(那句在孩子端放完到开口几秒)、说出了记号里的几个词(`coverage`;转写会往对的词上靠,只说明说出来了,不说明念对)、`[[say]]` 那拍自己说不说得出(跟得上不等于会)、夹不夹中文(夹了 = 词和意思对上了)。

拼成一拍一行(`warm.ts` 的 `warmLines`,样子照 `tests/live-warm.test.ts`):

```
跟 duck:说了「duck」,开口 0.8 秒
跟 bus:说了「Boss.」(转写里没有 bus),开口 1.1 秒
跟 The ducks are under the bus:说了「The ducks… under the bus」,说出 4/5 个词,开口 1.8 秒
自己说 bus:没开口
跟 duck:没跟,对你说「那我们直接打电话吧」
```

- **交脑**:热身里每次交脑都带上到那时为止的摸底(上下文包 `live.warmup`)。activity 让脑照它定打电话多难:整句跟得上的问要说一句的,只跟得上单词的问一个词就能答的。
- **给家长**:脑在收的那一节的尾巴里写一两句摸底(只写看到的);每拍存进录像(`{t:'echo'}`),能逐拍看。
- 不给孩子看:屏上没有分数、对勾、「说出了几成」。

### 三之四 三个记号:`[[echo 词]]`、`[[say 词]]`、`[[call]]`

写在讲稿那句末尾,解析在 `src/lib/board.ts` 的 `rawLine`:不锚卡,记在这句上(`BoardLine.echo`、`call`);一句几个算最后一个;不认识的记号本来就忽略。`echo` / `say` 念完,孩子端亮这句锚的那张卡(上面最近的一张,同 `[[play]]`)。记号只写在 activity「口语课」里,`cards/板书怎么写.md` 没有。

| 记号 | 意思 | 应用做什么 |
|---|---|---|
| `[[echo 词]]` | 跟我说:老师说了「词」,孩子跟 | 念完关闸等孩子;「词」用来判像不像跟读、记摸底;没写就取这句里的英文 |
| `[[say 词]]` | 你先说:老师没说「词」,孩子自己说 | 同 echo;摸底记成「自己说」 |
| `[[call]]` | 热身完了,打电话 | 念完孩子端响铃;这一轮后面的讲稿丢掉;应用起一轮交脑(`app: call` + 摸底);从这起嘴先说的换英文、开始计分钟 |

**等孩子的规矩**(`queue.ts`、`call.ts`):
- 同 `[[play]]`:并段到这句,交给嘴以后关闸,孩子跟完(`echoed`)才交下一拍。一拍接一拍**不等脑**:脑一轮写完整段热身,应用按孩子的快慢放。
- 关闸时孩子开口,转写先过一直听的 `judge`(空的、语气词放过,接着等);收下的由 `warm.ts` 的 `echoKind` 分:
  - **像跟读**:说出了记号里的词(四个字母以上差一个字母也算,带中文也算);或四个英文词以内没中文(「Boss.」);或三个汉字以内没英文(你先说答的「鸭子」、「嘎嘎嘎」)→ 开闸,不交脑,记一拍。
  - **对老师说的**(「我不想读」)→ 同一直听的收下:交脑(带上摸底),这一轮排着的拍丢掉。
- 那句在孩子端放完起 8 秒(`ECHO_WAIT_MS`)没开口 → 记「没开口」,接着走;**连着两拍**(`QUIET_BEATS`)→ 停下,应用起一轮交脑(`app: quiet`),脑中文问一句或直接 `[[call]]`。到点时孩子正说着,等判完再算。
- 抢着跟:嘴还在念孩子就开口,转写和嘴刚说的一样会按回声放过,那拍算没开口(摸底偏低一点);念完再跟就不比回声(`judge` 的 `mouthOn`)。
- 录像每拍一条 `{t:'echo'}`(词、你先说、说了 / 没开口 / 对老师说的、转写、开口几秒、说出几成),只记不发。

**孩子端**(`liveStep`;仲裁表在《工作流程.md》,对 `tests/live-player.test.ts`):念完 `echo` / `say` 那句,安静、卡亮;孩子开口(`vad`)光变实;下一句或嘴说别的就收。念完 `call` 那句响铃(孩子端自己的铃声),铃响着不推麦,嘴一出声铃停;服务端铃响够 3 秒(`RING_MS`)才把开场交给嘴。按讲稿推(`read` 带 `echo` / `call`),没有新的消息。

### 三之五 打电话:尽量英文

- **开场**:`[[call]]` 那句在孩子端放完是打电话的起点;服务端马上起一轮交脑(`app: call`,嘴不先说),铃响够了才把脑写的英文开场交给嘴。
- **英文为主**(activity「打电话」那节,应用不拦):先接住孩子这句,末句问一个问题,一句不超过八个词,用口语单的词。孩子说中文是听懂了:用英文说一遍,再请他说那个词。**确实跟不上**(「听不懂」「不会」,或问了两次还答不上)才说半句中文提示,接着用更简单的英文再问,不整句翻译。孩子跟家里人说的别翻译。
- **嘴先说的换英文**:打了电话,拍照、没听清那两句换英文(`cue.ts` 的 `CATCH_EN`);孩子说话嘴照旧不先说(《实时老师设计.md》拍板 14)。
- **时间**:从响铃算,缺省 5 分钟(activity 参数「打电话几分钟」,口语课页照 `talk.minutes` 填);上下文包 `live.phone` 带打了几分钟,脑到点收尾。应用不兜底挂(§七 4)。

## 四、险

1. **打电话每轮等脑**:孩子说完要等判停(1.6–1.8 秒)、转写、脑的第一句、嘴出声,嘴不先接。热身一拍接一拍不等脑;热身第一拍有「先热热身」垫着,开场有铃声垫着。
2. **抢着跟被当回声**:§三之四。
3. **脑写的热身不好**:太长、忘了记号、整句跟、夸来夸去、说英文。没写 `[[echo]]` 最坏是老师一个人念完;没写 `[[call]]` 就一直是热身(不响铃、不换英文),不卡住。
4. **摸底不准**:转写往对的词上靠会偏高,抢着跟被放过会偏低。只用来定难度、给家长一个大概。
5. **打电话里脑不守英文**:大段中文、整句翻译;qwen-flash 连一问一答都守不住(§五)。应用不拦。
6. **「嗯」、笑声会让老师小声一下**:server_vad 的代价,收下 / 放过兜。
7. **孩子不说英语**:真用的数据少;验收靠探针(Ray 10-17 的原声当孩子)和真机试。

## 五之二、官方博客说的(2026-10-20 读)

《Qwen3.8-Omni-Flash:耳聪目明,办事得力》(qwen.ai/blog?id=qwen3.8-omni-flash)「实时口语陪练」的演示视频有语义判停、句粒度纠错、单词带读、词粒度纠错四段,都是大人提明确要求、读长句、错得明显;一年级孩子说中文、要人往下引,打电话照旧要脑。示例代码一直推麦、服务端判轮次,回声靠耳机。

三个探针(`scripts/probe-live-vad.mjs coach / context / noise`,真百炼):
- **noise**:semantic_vad 噪声、「嗯」、笑声都不报开口,真插话每次都报;server_vad 噪声不报,「嗯」、笑声都报。
- **context**:**semantic_vad 把一两个词的回答全丢了**(「好的」「Boss.」、Yes / Red / Yellow,嘴先问过也一样);server_vad 全收(「嗯」转成「And.」)。打电话里孩子常只答一个词,semantic_vad 用不了。
- **coach(纠音)**:**分不出对错**。duck/dock、bus/boss 这类单词对,念偏的也夸、念对的反倒带读;「The docks are onder the boss.」转写成了正确的句子,嘴夸「Good job.」。听懂好,打分不行。

所以跟读不纠音(§六 6);一直听缺省 server_vad(《一直听设计.md》拍板 3)。

## 六、拍过的

原来的「要拍板的」都拍了(拍板 1、3、4),编号照旧。
