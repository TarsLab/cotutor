# 口语课:拍一张今天学的,先热身、再和英语老师用英语打电话

> 孩子在口语课页 `/talk` 拍课本上今天学的那页,老师读出口语单,孩子改好,点「先热身,再打电话」交给英语老师的实时页上课(activity「口语课」:热身 → 响铃 → 打电话 → 到点收尾)。口语课页只管拍、读、改,自己不打电话(拍板 22);上课那一段的设计与真跑在《口语课实时设计.md》。代码:口语课页在 `src/talk/`,交接在 `src/server/talk-run.ts` 与 `app.ts` 的 `kidSendInput`。
> 正文 2026-10-22 收成现状;原文在 git 历史 812491d(口语课页自己那通电话的代码在 5dee62a 之前)。
> **词**:「口语课」= 这个模块,和它交给英语老师的那一课。「口语单」= 从照片里读出来的今天要练的词和句,孩子改过才交给老师。「热身」「打电话」是那一课的两段,见《口语课实时设计.md》。

## 一、为什么这么切

- **口语单从照片来,孩子自己拍、自己改**(拍板 2、12)。2026-10-10 实测 3.8-omni 读印刷体稳(课本、练习册)、手写不稳;口语单只要印刷体。读出来的孩子对着照片看一眼就能改。
- **口语课页只拍、读、改,上课交给英语老师**(拍板 21、22)。10-17 Ray 试的那次,口语课页的嘴一个人带不了聊、跟读也生硬(《口语课实时设计.md》§一、§一之二);有脸的老师都走实时以后(《产品规划.md》拍板 30),口语课页那通电话整个删了。
- **孩子端的约定照守**。屏上不画对错、不打分;发音不评(嘴分不出念对念偏,《口语课实时设计.md》§五之二)。

## 二、流程

```
孩子(iPad,英语老师卡上的「口语课」→ /talk)
 1 拍课本那页(或相册选);有上次交给老师的口语单,最上面给「接着上」(写拍的日期)
 2 服务端交给 qwen3.8-omni-flash(兼容接口,不想):读出词(英 + 中,带单词卡的 emoji 与拼读分段)和句(英 + 中),只读印刷体
 3 照片在左、口语单在右:点一项改英文和中文,能补、能删;「先热身,再打电话 · 几个」→ talk/<id>/talk.json 定稿(ready)
英语老师的实时页(/?tutor=<英语老师>&talk=<id>)
 4 左栏「口语单拍好啦」+「先热身,再打电话」;孩子点了才起声音、开麦(口语课总是一直听)
 5 发出去的第一条带 talk:新话题跑 activity「口语课」
家长(家长端「记录」)
 6 英语老师的一个话题,热身和打电话一份录像;老师在给家长的话里写一两句摸底
```

## 三、通话怎么接(服务端中转)

口语课页不再自己打电话(拍板 22)。原来这里讲的服务端中转(服务端连百炼 realtime、孩子端 ↔ 本服务另一条 WebSocket、key 不出服务端、孩子端采 16k 放 24k)搬进了 `src/live/`(`realtime.ts`、`ws.ts`、`audio-client.ts`),现在是实时老师那条线(《实时老师设计.md》)。跟读手动轮次、聊 `semantic_vad`、两条会话的原文在 git 历史 812491d。

## 四、代码与数据

- **代码** `src/talk/`:`route.ts`(`/talk`、`/api/talk/*`)、`page.ts`(孩子两屏:拍照、口语单;拍照屏同拍照听写的骨架 `src/server/photo-ui.ts`)、`store.ts`(读写目录)、`list.ts`(照片 → 口语单)。`app.ts` 的 `route()` 里一行交给它;这里引用 cotutor,cotutor 别处不引用这里。交给老师的 `src/server/talk-run.ts` 只读 `talk/<id>/talk.json`,拼成 activity「口语课」的参数(口语单、打电话几分钟、家长的话)。
- **数据** `workspace/talk/<id>/`(id = 日期-时分):`talk.json`(口语单:读出来的 + 改过的;`status` 是 draft / ready;`listBy` 记 omni 读的还是改过的;读失败的原因与耗时)、`photo.jpg`。不进对话索引、不写 vault。那一课的消息与录像在英语老师的话题里,话题第一条记 `talk: <id>`。
- **配置** `cotutor.json` 的 `talk`:`enabled`(出厂关;开了学科是英语的老师卡上自动有「口语课」,拍板 20)、`listModel`(缺省 `qwen3.8-omni-flash`;omni 只有百炼按量的 key)、`minutes`(打电话几分钟,缺省 5)、`note`(家长给老师的话)。后两样家长端「首页」里改。
- **测试**:`tests/talk-flow.test.ts`(口语课页的接口,假 omni)、`tests/talk-live.test.ts`(交给老师)、`tests/server.test.ts` 里 `/talk` 那条(页面里没有 `/parent`、`/parent/talk` 是 404);页面走 `scripts/probe-talk-page.mjs`(假的读口语单 `COTUTOR_TALK_FAKE_LIST`)。

## 拍板记录

1. **选跟读 + 全双工,不选打电话 / 字幕流**(2026-10-10,Jack)。理由:适合小孩;先跟读新词句、再用它们聊,比自由聊有抓手。
2. **口语单从家长拍的照片来**(2026-10-10,Jack):家长拍最近学的单词句子,模型读出来,孩子跟读的、聊的都是这些。
3. **新的功能模块,不进老师团**(2026-10-10,Jack 定「新模块」;代码单独放 `src/talk/`、页面 `/talk` 是本稿的建议,照小老师的做法)。
4. **跟读与聊各开一条 realtime 会话**(2026-10-10,实测定的):百炼不让在喂过音频后改 `silence_duration_ms`,一条会话切不了;第二条的系统提示带跟读的情况。
5. **聊那段老师说话时麦克风默认不送声音**(2026-10-10,`talk.interrupt` 缺省 false):WebSocket 这条路没有回声消除,先保证不自己打断自己;要插嘴家长开 `interrupt: true`,iPad 上试过再说。
6. **口语单与通话都不动孩子端、不进对话**(2026-10-10):`/talk` 自己一页,家长把 iPad 递过去;首页按钮等用过两周再说。
7. **常驻在英语老师卡上**(2026-10-10,推翻 6 的「首页按钮等用过两周再说」;原型 <https://claude.ai/artifact/JNVPmYKVnJ5cer2VmnYDux>):先在 iPad 真机跑通一次(AudioWorklet、主屏幕图标、回声)再挂;挂是家长在 `cotutor.json` 里给英语老师配常驻入口,不按学科自动挂。
8. **家长补充 = 给老师的话**(2026-10-10):家长在家长端写一段(「这周学颜色和玩具,多问他喜欢什么颜色的车」),跟读与聊两条会话的系统提示都带上;口语单照旧从照片来。
9. **跟我读不用按,两段照旧**(2026-10-14,Jack;推翻原型第一版「跟读并进聊」,原型 <https://claude.ai/artifact/Bia2YDS3LnQH6vRiamRgGa>):孩子读完自动下一句,几秒没出声老师再读一遍,流程照旧是机械的跟读;打电话功能不动,只换样子(§8.2)。等 5 秒、自动再读 2 遍、读到过半算读完,照建议,用一周看录像再调。
10. **读了一点不另等**(2026-10-14,Jack):不到一半就老师再读,不再等 2 秒拼成同一遍。
11. **记录里口语课那一行点进去就是录像**(2026-10-14,Jack):同话题、听写;老记录没有录像的换到回看页。记在《家长录像设计.md》拍板 19。
12. **孩子自己拍口语单**(2026-10-15,Jack;推翻 2 的「家长拍」与 6 的「不动孩子端」;设计稿 <https://claude.ai/artifact/6uL5XfzhFEfX74cmeWbF9c>):家长有时帮着拍,用的也是孩子这条路。英语老师卡上的「口语课」点进去先是拍照屏(同拍照听写的骨架,`src/server/photo-ui.ts`:老师大头像、对话气泡「Hi」与「口语课」、拍照 / 相册);拍完照片放左边、右边「老师在看这一页…」,读完原地填上口语单;孩子对着照片看,点一项能改英文和中文、能补、能删(Jack 定「孩子能改字」);「开始跟读 · 几个」点下去直接开麦开始,原来的开始屏去掉。
13. **`/parent/talk` 删掉**(2026-10-15,Jack):拍、改、回看都不在家长端了。回放从记录进录像(《家长录像设计.md》拍板 19);给老师的话、聊几分钟照旧在设首页。没有录像的老口语课,录像外壳只说「这一次没有录像」。
14. **入口一直在**(2026-10-15,Jack):不再等家长做好单子才出现。有上次的口语单,拍照屏最上面给「接着上」(最近那份,不论哪天,写拍的日期),首页卡的小字写「接着上 · 几月几日的」。
15. **跟读只读一遍**(2026-10-15,Jack;改 9、10):老师每句读一遍,不自动再读(没出声不再读、读得不到一半也不再读),孩子读了就往下走;5 秒没出声「再听一遍」描上老师的颜色、轻轻闪一次,外圈的倒计时去掉。单词后面老师说中文意思,句子后面不说(句子的中文印在卡上)。
16. **打电话卡住有提示卡**(2026-10-15,Jack):老师问完 4 秒没出声,或孩子点字幕卡角上的「不知道怎么说?」,浮出提示卡;正面中文(说一说:它是什么颜色的?),点一下翻过来是英文句型带空(It's ___.)和口语单上能填的词。句型由便宜的文字模型按老师这一问现出,没回来就从口语单挑一句;卡不出声;老师接下一句时收起(做的时候改的:孩子照着卡读的时候不收,不然读到一半卡没了);出现、翻面、填词记进录像。矮屏(iPad 横着以外)卡出来时老师头像收起,一屏放得下。2026-10-15 真连跑过(`probe-talk-page.mjs --real`,现画一页印刷体课本):omni 读口语单 1.9–2.8 秒,red、car、It is a red car. 都读对,emoji、分段带着;qwen3.8-flash 出卡多在 0.5–1.8 秒,偶尔 4–6 秒。真连改了三处:提示词写明「问了就一定出卡、en 是他的回答不是老师的问题、只是接话就 skip」;有空但口语单上没词可填也收(I am ___ years old.);兜底只在老师这句带问号、且和口语单的一句有实词重合时才出(原来 How old are you? 会配上 It is a red car.),超时 4 → 6 秒。卡回来时老师已经开口说下一句,旧卡不发。
17. **点单词卡的「听」不当孩子说的**(2026-10-15):念的时候麦不推(原来就是),念完多等 300 毫秒再推;保险时长按字数算,不写死 4 秒。
18. **打电话不显示剩下几分钟**(2026-10-15,Jack):右上角只写「打电话」。计时照旧:到点老师收尾再挂,孩子 3 分钟没出声挂。
19. **不限每天打几次**(2026-10-15,Jack)。
20. **开了口语课,英语老师自动挂上入口**(2026-10-15,Jack;改 7 与《首页设计.md》拍板 18 的「口语课要家长自己挂」):`talk.enabled` 仍要家长开一次(要 key、花钱);开了以后学科是英语的老师没写 `extras` 时缺省带口语课。
