> **词**:「口语课」= 这个模块:一张照片、一份口语单、一次通话。「口语单」= 从照片里读出来的今天要练的词和句,家长改过才给孩子。「跟读」= 老师一句、孩子一句。「聊」= 全双工那段,老师用口语单上的词句和孩子对话。不叫「口语老师」:老师团里没有新的老师文件,通话那头是 realtime 模型,音色、提示词在模块里。

最早的想法(原话):

> 家长会拍照,输给大模型最近学到的单词句子,然后「跟我读」,让小孩先跟读一遍新的单词句子,然后「全双工」,用最近学到的单词句子和小孩对话,英文为主,中文为辅。这个场景用一个新的功能模块。

结论先行:**一个新模块 `src/talk/`,页面 `/talk`,代码和数据都单独放;一次通话是一条 realtime 会话,先跟读后聊。** 家长在手机上拍课本,`qwen3.8-omni-flash` 读成口语单,家长改一改交给孩子;孩子在 iPad 上开 `/talk`:跟读那段按住说话(手动轮次),聊那段麦常开(semantic VAD);两边的声音和字幕落进 `talk/<id>/`,家长在同一页回看。不进老师回路:没有板书、没有卡、不写 vault、不算每日条数。

## 一、为什么这么切

- **先跟读再聊,是同一次会话的两段。** 跟读时老师念、孩子念,老师听见了就知道他会哪几个词;接着聊就有了底。两段用一条 WebSocket,口语单在会话开头作为系统提示给进去,中间换一次轮次模式(手动 → semantic VAD)和一次指令(「现在用这些词和他聊」)。
- **口语单由家长拍、家长改。** 10-10 实测 3.8-omni 读印刷体稳(课本、练习册),读手写不稳;口语单只要印刷体。读出来的东西家长看一眼就能改,孩子永远拿不到错的。
- **英文为主、中文为辅,写进提示词,也写进屏上。** 老师每句英文下面一行中文小字(一年级孩子看得懂);老师说中文只做三件事:解释一个词、给一个台阶、收尾。
- **孩子端的约定照守。** 屏上不画对错、不打分、不说「你错了」;读得不对老师只再读一遍、请他再试一次。发音打分不做(koubo 的边界,10-09 实测 omni 评发音自相矛盾)。
- **为什么不是老师团里的一位老师。** 老师团的形状是「老师文件 + CLI + 板书 + 配音」,realtime 一样都不走;硬塞进去两头都别扭。它是一个场景模块,像小老师。

## 二、流程

```
家长(手机 /talk)
 1 拍课本那页(或相册选)→ POST /api/talk/photo
 2 服务端交给 qwen3.8-omni-flash(不想):读出词(英 + 中)和句(英 + 中),只读印刷体
 3 家长在口语单上改:删、补、改中文;「给孩子」→ talk/<id>/list.json 定稿
孩子(iPad /talk,家长递过去)
 4 跟读:一句一张卡(大字 + 拆音 + 中文),「再听老师读一遍」「按住跟我读」「下一句」;读完一遍换到聊
 5 聊:麦常开,老师用口语单上的词句和他聊 5 分钟;随时插嘴;到时老师收尾、挂断
家长(手机 /talk)
 6 回看:两段的字幕、两边的原声、用到了哪几个词;删这一次
```

每一步孩子看到什么,见原型第一排;屏上的字就是提示词要的样子。

## 三、通话怎么接(服务端中转)

- **一条 realtime 会话一次通话。** 服务端起 `wss://<WorkspaceId>.cn-beijing.maas.aliyuncs.com/api-ws/v1/realtime?model=qwen3.8-omni-flash-realtime`;孩子端 ↔ 本服务是另一条 WebSocket(serve 已是 HTTPS,WSS 顺手)。key 只在服务端(同 listen.ts:`DASHSCOPE_API_KEY`,没有读本机 qwen 的配置)。不让 iPad 直连阿里云。
- **音频**:孩子端 AudioWorklet 采 16k 单声道 PCM 往上推;下来的是 24k PCM,孩子端按块排进 AudioContext 播。孩子端现在只有 MediaRecorder 和 `<audio>`,这是新的。
- **跟读段 = 手动轮次**(`turn_detection: null`):按住 append,松手 `commit` + `response.create`;老师说话时麦不开,没有回声问题。每一句由应用驱动:`conversation.item.create` 一条文字「Read aloud exactly: "It's a red car." Then wait for the child.」,老师念;孩子按住读;老师听了只说一两句(「Nice!」「再来一遍,大声一点」),不评对错。
- **聊那段 = semantic VAD**(`turn_detection: semantic_vad`,`silence_duration_ms` 调到 1200 以上:一年级孩子想词的停顿长)。应用发一条指令切段:「Now chat with the child for 5 minutes using these words…」。回声是这段最大的险(§五 1)。
- **字幕**:老师的字从 `response.audio_transcript.delta` 来;孩子那句的转写用 `qwen3-asr-flash-realtime` 做输入转写(realtime 会话自带的配置),显示「你:…」。
- **提示词**(模块里,不是老师文件;家长在设置里能改一份 md):人设(英语老师,慢、短句、一句一问)、英文为主中文为辅的三条、不评对错、口语单、孩子档案里的名字和喜欢的东西(只读 vault 的档案)。
- **音色**:realtime 的音色里挑一个(缺省 Tina;Serena「温柔小姐姐」也合适),和老师团的 voxtell 音色不是一家;家长在设置里选、试听。

## 四、代码与数据

- **代码**:`src/talk/`——`route.ts`(`/talk`、`/api/talk/*`、WebSocket 升级)、`page.ts`(家长三屏 + 孩子两屏,一页)、`store.ts`(读写目录)、`realtime.ts`(连百炼,事件进出)、`list.ts`(照片 → 口语单,调 omni)、`lib/`(纯函数:口语单的形状、字幕拼接、用到了哪些词)。`app.ts` 里一行交给它,像 xlaoshi。`src/schema/`、`kid-page.ts`、`kid-board.ts` 不动。
- **数据**:`workspace/talk/<id>/`(id = 日期-时分):`photo.jpg`、`list.json`(读出来的 + 家长改过的,带 `edited`)、`session.json`(时长、两段各到哪、音色、模型、token)、`transcript.json`(一行一句:谁、字、起止毫秒、哪一段)、`kid.pcm` / `tutor.pcm`(或转成 m4a)、`used.json`(口语单上哪些词在聊里出现过)。不进对话索引、不进录像、不算每日条数、不写 vault。
- **配置**:`cotutor.json` 加 `talk: { enabled, model, voice, minutes, prompt? }`;出厂关着。

## 五、要先解决的(按险排)

1. **iPad 回声**(聊那段)。WebSocket 这条路没有回声消除,老师的声从喇叭出来又进麦,模型听见自己。先试 `getUserMedia({ echoCancellation: true })` 在 iPad Safari 上够不够;不够就学 live-voice-tutor:老师在说时静掉上行、停了再冷却一秒;再不够才考虑 WebRTC 直连(自带消除,但要 AppServer 发临时凭证)。
2. **iPad 上采 16k PCM、播 24k PCM。** AudioWorklet 在 Safari 上要先有一次点击解锁;主屏幕图标打开时麦能用(10-09 查过,死的是识别不是麦)。
3. **提示词守不守**:不评对错、句子短、中文只在三处、聊的时候真用口语单的词。一分钟一轮真跑才知道。
4. **音色英语发音**好不好听,没测过。
5. **录音数据政策**(《产品规划》待拍板 1):现在的 listen 是松手传一句,这个是按住就流上去,聊那段麦常开。要家长拍一下。
6. **一次多少钱**:国际价 realtime 音频输入 $0.93/M、输出 $1.87/M,音频 7 token/秒;5 分钟聊天算上每轮重复的上下文,估 0.1–0.3 美元量级;人民币看控制台。qwen-voice-chat 的作者估 ¥0.4/小时。

### 8.1 跟我读:不用按,读完自动下一句

**谁判「读完了」**:**relay 按响度判**孩子开口、停(`lib/read-flow.ts` 的 `vadStep`:响 200 毫秒算开口,静 `endMs` 算停,门限跟着底噪走),开口起把声音(带 300 毫秒前垫)推给模型,停了 commit,百炼的转写模型给字;**往不往下走由应用定**(`readStep`),模型只管念。跟读那条会话照旧手动轮次。原先想用百炼的 server_vad + `create_response: false`,10-14 真连在这台机器上被工作区端点拒了(403 `Endpoint.AccessDenied`),没验成;按响度判不靠它,也离线可测。

- **回声**:老师念的时候孩子端不推声音(同聊那段 `interrupt=false`)。老师什么时候放完由 relay 估(这次回答第一块声音到的时刻 + 声音长度 + 300 毫秒),孩子端不用报——录像也照这个时刻。
- **规则**(数都进 `cotutor.json` 的 `talk.read`,先按这个):
  1. 老师读一句,放完开始等。
  2. 孩子开口 → 停了 → 转写回来。转写里有这句的词过半(单词就是那个词;四个字母以上差一个字母也算)→ **读完了**:塞一条「孩子读了「…」。先用一两个词接,再读下一句:…」+ `response.create`,接和下一句一次说完,中间不冷场。
  3. 不到一半、或跟这句一点不沾(说中文、「我不会」)→ 老师再读一遍(算一次自动再读)。不另等(拍板 10)。不评对错,屏上不画。
  4. 转写是空的(咳嗽、碰桌子)→ 接着等,不算一次。
  5. 放完 5 秒没开口 → 老师再读一遍。连着 2 遍还没出声 → 不再催,等着;屏上「想读就读,或者点下一句」。自动再读用完了,孩子再开口不管读成什么都往下走,不卡在一句上。
  6. 最后一句读完 → 老师「Great! Now let's talk.」→ 关跟读会话、开聊的会话(同现在)。
- **手动的照留**,降成小按钮:再听一遍、下一句、直接打电话(家长在旁边想跳就跳)。没有「按住跟我读」。
- **屏上**:当前那句一张大卡——单词用单词卡的样子(emoji + 四线三格,讲到时写一遍,同 `cards/word` 的舞台那种大小),句子用点读卡的样子(米色底白行,老师念到哪荧光到哪);上面一行是老师说的(英文 + 中文小字);下面一个状态条:绿「先听老师读」/ 蓝「轮到你,跟着读一遍」(话筒外一圈倒计时,走完老师再读,音量条)/「你读的 Blue! → 下一句」/ 绿「老师再读一遍」。顶上第几句的圆点。
- **改哪些**:`relay.ts`(跟读段的状态机换成 read-flow,去掉 hold / release)、`realtime.ts`(`turnDetection` 带 `create_response`)、`prompt.ts`(跟读的提示词改成「只念我给你的句子 + 一两个词接」)、`page.ts` 孩子两屏。

### 8.3 录像:录数据,不录屏幕(同《家长录像设计.md》)

现在落盘的 `kid.wav` / `tutor.wav` 是两边各自首尾相接的,没有时刻,对不上;`transcript.json` 只有每句的起始毫秒。录像要三样:

1. **`talk/<id>/events.jsonl`**(relay 写,一行一事,`t` = 离开始的毫秒):跟读段 `read`(第几句、老师读 / 再读 auto|manual)、`listen`(开始等)、`kid` 开口 / 停、`said`(转写 + 判成 done / partial / off)、`next`(auto|manual);打电话段 `turn`、`card`(亮哪张)、`cut`(插嘴掐断);两段都有 `phase`、`end`。孩子端看到的几乎全从这条线来;孩子端只多报 `view`(屏幕尺寸)与点「听」。
2. **`call.wav`**:对齐墙钟的双声道(左孩子 16k 升到 24k、右老师 24k)。孩子的块按到达时刻放;老师的块照孩子端 `A.play` 的排法排(上一块放完或到达 + 60 ms,取晚的),`flush` 处截断——和孩子听到的一样。挂了在 `finishCall` 里拼,旧的两个 wav 不再写。
3. **`lib/reel.ts`(talk 自己的)**:`talkFrameAt(events, t)` → 这一刻是哪段、第几句、哪张卡亮、字幕到哪、状态条是什么、剩几分钟。纯函数,`tests/talk-reel.test.ts`。

**家长端怎么看**:照《家长录像设计.md》拍板 13–16 的统一播放器——上半是孩子端页面本身的录像模式(`/talk?reel=<id>`,只读,iframe 按 view 开再等比缩,照 `talkFrameAt` 画;同听写 `/dictation?reel=`),下半是 `src/server/reel-dock.ts` 的录像栏,只经把手说话(`chapters`:跟我读一句一章、打电话一章;点:孩子开口、讲到一张卡、没出声再读、插嘴)。外壳 `/parent/talk/reel?id=`(同 `/parent/dictation/reel`),轨道纯函数经 `src/server/inline-lib.ts` 内联进页面,钟、把手、放声音学 `src/dictation/reel-mode.ts`。空白照听写的压法。声音只有一条 `call.wav`,拖到哪 `currentTime` 到哪。**入口**:家长端记录里口语课那一行点进去就是录像、停在最后一帧(拍板 16 现在写着「口语课照旧进它的回看页」,做到这一期时推翻它);回看页的字与原声并进「经过」。只录推上去的声音;删一次口语课连录像一起删。
