
小学低年级有一个很常见的课堂测试，家庭作业。就是听写。

这个场景的输入和输出都很明确。

中文 听写，通常是对着当天的生词拍照，得到要 听写的词语（通常是一个字，或者两个字的词语）。

老师 念出词语，孩子在 ipad 的田字格上写字。

老师再判断写的对不对，笔顺，是否美观。

我对技术的一些不成熟的设想是，用 excalidraw (或者不用)， 录制一段视频。把视频发给 视觉大模型 ，去判断。之前 还做了田字格的卡片，也可以把 对应的田字格的卡片视频 作为对比，一起发给模型。


英语的单词听写，类似 中文听写。

## 第一版(2026-10-10 落地)

原型:https://claude.ai/artifact/WfKtooajFintau63RUHXqJ

- 入口:首页的 `tingxie` 卡(只用在首页),正文一行一个词,词后空一格写念法;孩子端首页 JSON 只有几个词,字剥掉。
- 孩子端 `/tingxie?home=<首页 id>&n=<第几张>`:开始 → 老师念两遍 → 一词几格田字格 → 写好了 → 全写完交卷 → 对答案(书上的字淡淡叠着,可拿开)→ 点字逐笔看(书上的字在孩子写的上面一笔一笔写,当前一笔橙色)→ 再写一遍(左边范字,点了看笔顺)→ 对好了回首页。
- 比对不经大模型:照搬 hanzi-writer 3.7.2 的 strokeMatches(均距、起止、方向、Fréchet 形状、长度),写完一起两两配对,剩下的放宽 1.5 倍再配一遍;写偏写小先挪进标准框再比。分不出笔画一样只差长短的字(土 / 士、己 / 已)。
- 家长端 `/tingxie/parent`:第一遍 → 重写并排,逐字一句(少第几笔、多几笔、先后、写反方向、占格、擦过几次),问了才改 / 自己改;「要再练的词」复制成下一张听写卡。
- 数据:workspace 的 `tingxie/<id>.json`,不进 git;配音缓存 `.cotutor/tingxie-say/`;没音色退浏览器合成声。
