## 一、第一性原理:家长要什么,要守什么

家长在 `/parent` 上要的就三件事:**看**(孩子今天学了什么,已有)、**定**(老师接下来怎么讲:商量讲法、看一版效果)、**给**(孩子从家长看过的那一版开始)。

要守的只有四条,每一条都能从已有的数据得到:

| 要守的 | 看什么(都从「话题第一条带不带 `prepThread`、孩子开口没有」推) | 今天已经在这么判断的 |
|---|---|---|
| 孩子看不到家长和老师备课的话 | 话题第一条的 `from`、开场在哪 | `kidConversation` 的问句只认 `from: kid`;`kidThreads` 只列孩子开过口的话题 |
| 备课不写进孩子的记忆 | 这一轮是不是备课轮 | runner 记忆那处已经按 `replayOf` / `tryout` 分支 |
| 备课不算进记账 | 话题里孩子开口没有 | `diary.ts` 只收 `from: kid` 的 |
| 备课不占孩子的每日上限 | 消息的 `from` | `kidMessageCount` 只数 `from: kid` |

## 二、为什么推翻 09-22 / 09-23 的做法

09-22 的起点是「试用落 `evals/`」,四条都靠换目录守住。代价是一串跟着来的机关:试用不能挡孩子,所以起第二个 runner;备课在 `evals/`、孩子在 `conversations/`,给孩子就得跨目录复制(`forkThread`);复制过去的话题没有会话,所以要 `resumed:`;复制哪几节得有规则,所以有「开场」的定义和「回到这一节」;孩子要有入口,所以有 `opening` 按钮、按过就藏、备课话题删了就藏。家长端也就多了试用模式、「试一试」「试过的」「重来」「以前试过的」「回到这一节」「排到首页」「已排到首页」。

原文第一节反对「孩子接着同一段会话」的四条理由,换到同一个目录之后逐条看:

1. **孩子会看到老师对家长说的话** → 孩子端只下发开场及以后的轮;开场之前的轮不下发。
2. **记账会把备课记成孩子学过的** → 记账只算孩子开过口的话题;日记本来就只收 `from: kid`。
3. **会话层回滚做不了** → 不回滚。家长说「第二节重写,别出 2/4」,老师在同一个会话里改;被否掉的那一版留在会话里,老师反而知道家长不要什么。
4. **老师本来就不靠会话记忆** → 还是对的,只是这里用不着另拼一段上下文:会话本身就是连着的。

## 三、备课话题

### 3.1 开

- 清单(《家长板书页设计.md》§2.2)每位老师一块的右上角「新话题」(替掉「试一试」):进这位老师的板书页,空白态,输入条在,家长说第一句。
- 发的是 `POST /api/conversations/<老师>/messages`(家长真发那条,`from: parent`),`newThread: true, prep: true`;第一条记 `prepThread: true`,落 `conversations/`,新会话。工作台 `/dev` 与 `cotutor send` 也走这条接口、缺省也是 `from: parent`,它们不带 `prep`,开的话题照旧孩子看得到——「从哪个端发起」看的是这个字段,不是 `from`。
- 家长在备课话题里按「继续」、做卡「交给老师」:这条接口收 `action`;做卡走 `PUT /api/conversations/<老师>/cards/<job>/<n>`,只认备课轮的卡(孩子的话题里 409)。孩子端往没交的备课话题里发 400。
- 老师看得出是家长:上下文包 `from: parent`(已有)。

### 3.2 规则

| | 备课轮(家长开的话题,孩子开口之前) | 其余的轮 |
|---|---|---|
| 孩子端 | 没交给孩子:不下发;交了:只下发这节课的卡与挂在上面的讲稿(第四节),家长的话不下发 | 照旧 |
| 记忆段 | **不写** vault,原文进 `memoryDraft`,家长端旁注「本来会记住的」 | 照旧 |
| 每日上限 | 不算(本来就只数 `from: kid`) | 照旧 |
| 记账 | 不记(孩子没开过口的话题不起记账) | 照旧 |
| 配音、板书后期 | 开(要听、要看孩子会看到的样子) | 照旧 |
| 卡 | 家长能做(看效果);交给孩子时这节课那几张卡的状态清掉 | 照旧;家长在孩子的话题里仍不能替孩子答 |
| 费用 | ~~家长端每轮一个小标签~~ 2026-09-28 去掉:订阅之下 CLI 报的美元数没有参考价值,家长端(清单的 `$`、节尾的旁注)一律不显示,只在工作台「看原文」与 `cotutor show` | 家长端不显示 |

「孩子开口」= 话题里出现第一条 `from: kid` 的消息。之后家长在这个话题里再发,和家长真发进孩子的话题一样。

### 3.3 在里面怎么备

就是说话。「今天讲分数,用披萨,先出三道选择」是讲法也是第一句;「继续」看下一节;「第二节重写,只比大小」让老师改;想只商量不出板书,说「先别写板书」。一期不做「只商量」开关,真跑下来家长嫌老师不听再加(上下文包 `board: off`,已有)。

## 四、这节课:备课的结果就是一叠卡

> 2026-09-25 定(拍板 18–22)并落地,原型在画布「备课原型」上;探针 `scripts/probe-parent-board.mjs` 的「备课」几腿走一遍。取代 09-24 的「从这里给孩子」(开场)与 09-25 早先的「对孩子藏起来」:那两个都是在一串话题上间接算出孩子看什么,家长要在脑子里做减法。

### 4.1 看得出来:正常的卡给孩子,灰的不给

- 备课话题里老师写出来的每张卡**默认进这节课**,正常显示;老师写得好,家长什么都不用做。
- 不给孩子的卡**整张变淡去色**(约五成不透明、去掉颜色),像网页控件不可用的样子;文字仍读得清,还能点开看题、答题。
- **卡上不放任何控件**。板书上正常的就是孩子会看到的,灰的就是不给的——所见即所得。

### 4.2 怎么改

- **整节**:节头一个文字按钮「整节不要」/「整节要」。最常用:让老师「第二节重写」之后,旧的那节点一下「整节不要」。
- **单张**:点开卡(舞台,和孩子端点卡一样),舞台顶栏一个「给孩子」开关。两步,但单张改得少;真常用再加 iPad 长按菜单当快捷方式。
- 没有卡的轮(只说话的商量、出错的)不进这节课,孩子本来也看不到。
- 顺序就是生成的顺序;拖动排序等用起来再说。

### 4.3 底部「这节课」

- 备课话题的输入条上面常驻一条:「这节课 · N 张卡」+ 卡名一行(截断)+「看孩子会看到什么」+「交给孩子」。一张卡都没有时按钮灰着。
- **看孩子会看到什么**:按孩子端的样子铺开这节课(答案不显示、讲稿照念),从头能听一遍。
- **交给孩子**:一小块只填按钮字(≤ 16 字,预填第一张卡上的第一句截 16 字)。不填讲法:老师在同一个会话里,家长交代过什么它都记得。服务端做三件事:记下这节课交了、清掉这节课那几张卡上家长做过的状态、往首页草稿追加一行 `接着 <今天> <话题> <按钮字>` 再发布(检查有「要改」就不发、列出来,草稿里那行留着;同 09-24)。
- 交了之后底部写「已交给孩子 · 首页上是「…」」,**孩子开口前照样能改**(点灰、点亮,首页按钮不变);孩子开口后开关与节头按钮都锁住。
- 只交今天的(二期再说隔天)。

### 4.4 孩子那边

- 首页就是一个 ↻「接着」,孩子端 JSON 带 `open`:按了只打开、不发字、不起老师、零费用、一个字不变(同 09-24)。
- 下发的只有这节课:一轮里只留进课的卡;讲稿只留挂在这些卡上的句子(句子的锚 = 卡的下标),这一轮有卡进课时,卡前的开场白(锚为空的句)也带上;一张卡都没进课的轮整轮不下发。板书后期的排版只留挑中卡所在的行,空行去掉。配音一句一个文件,跟着句子走。
- 孩子的第一句照常发进这个话题,runner resume 原会话;这一条的上下文包多一段 `lesson:`——孩子看到的那几张卡(一张一行,`describeCard`,和 `cards:` 一个写法),老师照它接,不用猜哪些版本孩子没看过。守则那句改成「有 `lesson:` 就是家长备好的课交给孩子了,孩子看到的就是这几张;直接答孩子这句、往下讲,别复述家长的话,别提 `lesson:` 以外的卡」。
- 从这一轮起一切照旧:记忆落 vault、上限算、晚上记账。

### 4.5 家长回看

同一个话题,清单里一行,交了标「已交给孩子 · N 张卡」。孩子开口后没进课的卡在家长这边仍是灰的,开关锁住。

## 十一、素材:备课备的是对话里等不起的东西

> 2026-10-02 草案(拍板 36–41),没落地。起因:家长 10-01 记的想法——孩子真用时一开口,备好的讲稿就跟不上,备课省下的时间马上没了;讲的话老师当场就能说,孩子问了也马上能改,备课值得花时间的是当场做不出来的东西。乐高动画(figshot,《脑暴-乐高动画讲题的场景.md》)一段十几分钟到半小时,在对话里等不起;家长在备课时还要对它的颜色、比例、动作、空间布局提意见。

### 11.1 按等不等得起分,不按语言 / 画面分

| 多久出来 | 例子 | 在哪做 |
|---|---|---|
| 秒级 | 文字、题、田字格、单词卡(老师只写一个字,笔画数据现成) | 对话里老师直接写 |
| 几分钟 | drawtell 课包(画图老师一轮) | 两边都行;对话里现做走场景卡,备课时做好、家长审过的当素材 |
| 十几分钟以上 | 乐高动画 | 只能备课时做 |

**素材** = 备课时做好、家长审过、对话里老师按需拿出来的慢东西。讲稿不是素材:老师当场写,按孩子当时的样子写。

### 11.2 一份素材长什么样

放 workspace 的 `materials/<id>/`(id 规则同课包:小写字母、数字、连字符),一份 `material.md` + 媒体。不放 vault,理由同课文件(§10.2):是运行件,过不了「一年后还想翻」那一问。`materials/` 不进骨架,技能写时自己建。

- 乐高的:分段的 mp4 放在目录里,`1.mp4` `2.mp4` …,一段一个文件。
- drawtell 的:课包仍在 `bundles/<id>/`(画图老师只写那里),`material.md` 的 frontmatter 写 `bundle:` 指过去;课包的一步就是一段。

完整的一份见 `tests/fixtures/materials/pingjunfen/material.md`(2026-10-02 照 figshot 的 share-2 / 3 / 6 三段真片子写的,也是解析器的测试输入)。形状:

| 部分 | 写什么 | 应用怎么用 |
|---|---|---|
| frontmatter | `tutor:`(哪位老师的)、`media: clips`(本目录 `1.mp4` `2.mp4` …)或 `bundle` + `bundle: <课包 id>` | `materials:` 按 `tutor` 挑 |
| `<!-- 给人看 -->` | 谁读、片子从哪来(figshot 的场景文件、日期)、改了怎么验;三四行 | 不用;老师 Read 时会读到,所以要短 |
| `# 标题` | 演的是哪个道理,一句 | `materials:` 那一行 |
| 能讲: / 不能讲: | 各几条;不能讲写清片子的边界(总数、有没有余数) | 「能讲」第一条进 `materials:` 那一行 |
| `## 画面里的东西` | 对照表:题目里的 → 画面里的;下面写画面里**没有**的 | 不解析 |
| `## 一段一段` | 编号一段一条:讲什么、几秒,下面几行画面,最后一行「停在:」末帧是什么 | 段数要和 mp4 个数对上(check) |
| `## 什么时候用` | 几种孩子的情形 → 放哪几段 | 不解析 |

- **映射表是核心**(「画面里的东西」):题目里的什么,对应画面里的什么。它是备课第 1、2 步(读懂题目、在 2D / 3D 里找等价物)的产出,家长审的就是它,老师引用时也靠它知道画面里有什么。
- **一段 = 一个动作或一个关系**,播完停在末帧。末帧要写出来(「停在:」):老师是对着这一帧往下说的。
- **不配音**:段里没有讲稿、没有声音、不出字幕,老师按孩子当时的样子说(拍板 38)。drawtell 课包当素材放时,课包自带的讲稿与配音也不放。
- **按题型做、能换参数**:「平均分(人数可变)」「相遇(速度可变)」,而不是「练习册第 12 页第 3 题」。每题半小时、家长每题都要审,按题做攒不起来;生成脚本在 figshot 那边(`scenes/share.gen.ts` 改一个 `n` 出三问),cotutor 只收成品。「能讲 / 不能讲」两行写清哪些题能拿它讲。
- **正文只写给老师**(《写提示词.md》第二节):家长审的就是这份正文;片子从哪来、怎么重做放进文件头的「给人看」注释。老师读它是为了知道画面里有什么、什么时候拿,不是照念。
- **写出画面里没有的**:没有字、没有数字、没有声音。老师会对着画面说话,不写它就可能说「你看上面写着 9」。

### 11.3 老师怎么知道有、怎么拿

- **上下文包 `materials:`**:这位老师名下的素材(`tutor:` 对得上),一行一个:`<id> · <标题> · 能讲:<第一条>`;课文件尾巴 `## 素材` 列了的排前面、一定在,别的按改动时间新的在前,一共最多 20 条。细节老师自己 Read `materials/<id>/material.md`(同 `photos:`、`lessonFile` 的做法)。
- **素材卡**(新种类 `material`):围栏里只写 id。讲稿 `[[play 2]]` 锚到第 2 段:念到那句,先念完,再铺满播第 2 段,播完停在末帧,接着念下一句;`[[play]]` 不带数 = 从第 1 段起一段段播完。孩子点卡也能自己播,每段末停住等「继续」。

  ````markdown
  ```material
  pingjunfen
  ```
  ````

  状态:看到第几段、看完没(同场景卡)。没有答案,不用剥。
- **不复用场景卡**:场景卡放新 id 就起画图老师、花一轮钱;素材 id 写错不该起任何东西,该退文字卡 + 提醒(家长端看得见)。两种卡的意思也不同:场景卡是「现做」,素材卡是「拿现成的」。
- 守则(`cotutor-tutor`)加一句:有 `materials:` 就是家长备好的现成动画;孩子卡住、或做完要讲道理时拿;先让孩子说,再放;话要配着画面说,画面里没有的别说成有。

### 11.4 课文件跟着变:缺省一节、一两张卡

- `cotutor-prep` 技能缺省写**一节**:题(choice / fill / text)+ 末句问句;要用的素材列在尾巴 `## 素材`(一行一个 id),**不铺在板上**——孩子先做题,做完老师再拿。解析器从尾巴里摘出 `## 素材` 那段,别的照旧是讲法(`brief`)。
- **拍板 34 不推翻**:一节的课文件,「最后一节之后孩子再开口才真发」就是「孩子一开口就交给老师」。多节照旧能写、照旧那样播;check 超过两节给提醒「孩子要听完 N 节才能打断」。
- 英语老师要知道的「最近学了哪些词、句型」不是素材,是上下文:记在 vault 的学习进度里,单词卡老师当场就写得出来。
