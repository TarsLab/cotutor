## 1. cotutor.json(每个 workspace 一份)

承接 drawtell.json 的做法(`paths` 角色映射 + `gen.agents` 的 {run, resume} 模板),加老师表与政策。

```jsonc
{
  "version": 1,
  "title": "小明的老师们",                       // 孩子端标题,无品牌
  "kid": { "slug": "ming", "name": "小明", "grade": "二年级" },
  "server": { "port": 5180 },                  // 一 workspace 一进程
  "paths": {                                   // 角色 → 目录;vault 侧目录名由这家自定(缺省就是下面这些中文名,《obsidian仓库设计.md》§2)
    "vault": "~/Library/Mobile Documents/iCloud~md~obsidian/Documents/Ming",
    "diary": "日记", "plans": "计划", "profile": "孩子.md", "timetable": "课程表.md", "textbooks": "教材", "reference": "参考",
    "captures": "captures"                     // 作业照片,相对 workspace 根(vault 里存文字不存图)
  },
  "vault": { "keepScore": 4 },                 // 话题打几星起,记账时摘要与骨架才进日记
  "policyDefaults": {                          // 老师条目缺省继承
    "replyMaxChars": 60, "dailyMessages": 30, "dailyRegen": 3, "reviewGate": false,
    "forms": ["L0", "L1", "L3", "L4"], "contextPack": { "recent": 10, "planLines": 10, "profileLines": 8 }
  },
  "tutors": {                                // key = 老师文件的 frontmatter name;以 -tutor 结尾的是老师(有脸),其余是工具人(2026-09-16)
    "math-tutor": { "display": "数学老师", "subject": "数学", "avatar": "avatars/math-tutor.png", "voice": "<voxtell 音色 id>", "enabled": true },   // avatar:emoji,或根以内的图片相对路径(figshot 写 avatars/<老师>.png,孩子端 /api/kid/avatar/<老师> 取)
    "reading-tutor": { "display": "朗读老师", "subject": "英语", "avatar": "📖", "voice": "<voxtell 音色 id>", "enabled": true, "policy": { "forms": ["L0", "L1", "L3"] } },
    "planner": { "display": "规划老师", "avatar": "🗓", "enabled": true, "hidden": true }   // 孩子端不露
  },
  "runtimes": {                                  // 运行时;占位:{agent} {agentBody} {prompt} {session}
    "default": "claude",
    "claude": {
      "run":    ["claude", "--agent", "{agent}", "-p", "{prompt}", "--dangerously-skip-permissions", "--output-format", "stream-json", "--verbose", "--max-budget-usd", "2"],
      "resume": ["claude", "--agent", "{agent}", "-p", "--resume", "{session}", "{prompt}", "--dangerously-skip-permissions", "--output-format", "stream-json", "--verbose", "--max-budget-usd", "2"]
    },
    "qwen": {
      "run":    ["qwen", "-p", "{prompt}", "--append-system-prompt", "{agentBody}", "--yolo", "--output-format", "stream-json", "--max-wall-time", "10m"],
      "resume": ["qwen", "-p", "{prompt}", "--resume", "{session}", "--append-system-prompt", "{agentBody}", "--yolo", "--output-format", "stream-json", "--max-wall-time", "10m"]
    }
  }

```

**字段归属规则**:老师的 `.md` 文件里只有 `name` / `description` / `maxTurns` / `permissionMode` / `memory` + 正文(系统提示);**人设、政策、开关全在 cotutor.json**,老师团页只改 cotutor.json;老师文件是拷进 workspace 的出厂件(2026-09-09 拍板),家长要改口气可以直接改它,`cotutor upgrade` 不会覆盖改过的。老师身份键 = agent `name`。

拍板(2026-09-08):`voice` 先用 voxtell 的音色 id;`hidden` 够用。

拍板(2026-09-17):`tts` 除 `say` 外多一条 `voices`(缺省 `voxtell voices --json`),stdout 是 `{voices: [{voice, name, gender?, age?, trait?, scene?, lang?}]}` 或直接数组;家长端音色页据此列表,试听走 `say`。换别的 TTS 只要两条命令模板都给得出来。

## 2. 上下文包(每条消息前缀)

应用拼,固定 YAML 块,老师不用自己找。纯函数 `buildContextPack()` 在应用仓,带测试。

```yaml
cotutor:
  from: kid            # kid | parent | system
  at: 2026-09-08T16:20
  slot: 数学 16:00-17:00          # 课程表命中才有
  focus:                          # 当前对象,可缺
    artifact: 2026-09-08-两位数退位
    step: 3
    circled: ["借位那一步"]
  plan:                           # 本周计划中与本老师相关的行,≤ planLines
    - 周三前把两位数退位讲一遍
  recent:                         # 最近 recent 条本学科观察,只带 date + claim
    - 2026-09-06 两位数退位错 3 次
  vault:                          # 家长的 Obsidian 仓库在哪(2026-09-15):root 绝对路径,其余角色相对 root、在外面就绝对;老师按 cotutor-vault 技能拼路径
    root: "/Users/x/Documents/Ray"
    diary: 日记
    textbooks: 教材
---
妈妈我不懂这一步
```

`from: system` 用于应用发起的消息(记账、交接、定时)。孩子由 workspace 决定,不进包。

拍板(2026-09-08):`recent` 与 `planLines` 先定 10 条;`---` 分隔符照用。

## 3. 对话索引与转录

每条消息 = 一次 `-p` 运行 = 一份 NDJSON(沿用 `gen-*.log` 的做法)。索引一天一份:

```
conversations/<tutor>/<date>.json
conversations/<tutor>/<date>.<job>.log        # stream-json 原样
conversations/<tutor>/<date>.<job>.err.log
```

```jsonc
{
  "tutor": "math-tutor", "date": "2026-09-08",
  "session": { "id": "b596…", "agent": "claude" },           // 当天会话,首条消息后写入
  "messages": [
    { "job": "1620-a1", "thread": "1620-a1", "at": "…", "from": "kid", "text": "妈妈我不懂这一步", "focus": { "artifact": "…", "step": 3 },
      "result": "ok", "costUsd": 0.12, "kidText": "这一步是借位……", "artifacts": ["2026-09-08-两位数退位/补讲-3"],
      "timing": { "startedAt": "2026-09-08T08:20:18.498Z", "firstCardMs": 12709, "doneMs": 15207, "dubbedMs": 16100 } }   // 埋点(2026-09-11):从进程起算的毫秒
  ],
  "sessions": { "1620-a1": { "id": "b596…", "agent": "claude" } },   // 每个话题自己的会话(2026-09-11);session 只是当前话题的
  "costUsd": 1.23
}
```

`kidText` 与 `artifacts` 是孩子视图的物化结果(§4),写进索引后孩子端不再解析日志。**话题**(2026-09-11 拍板):`thread` = 话题第一条消息的 job;一个话题 = 一段连续问答 = 老师的一个会话,一天可多个,每个话题的会话在 `sessions[thread]`,顶层 `session` 只是当前(末条所在)话题的。开新话题(发消息带 `newThread`、`from: system`、今天第一条)不 resume、不带旧话题卡上的状态;指定 `thread` 接着今天的旧话题就 resume 它的会话;以前几天的只能看。旧索引没有 `thread` / `sessions`:读时按同一规则现算(第一条与 system 消息各开一个,其余跟前一条;顶层 session 算当前话题的),不改文件。`timing` 是这轮的用时(2026-09-11 埋点):`firstCardMs` = 流式时第一张卡闭合(整块出的运行时没有)、`doneMs` = 进程退出、`dubbedMs` = 配音收尾(没配音就没有);家长视图每轮一行,顶部今日中位。

拍板(2026-09-08):跨天自动新开,零点后第一条消息不带 `--resume`。

## 4. 孩子视图规则(精简)(stream-json 事件 → 孩子看到什么)

机械规则,不靠模型判断:

| 事件 | 家长视图 | 孩子视图 |
|---|---|---|
| `result.result`(本次运行的最终文本) | 显示 | **只显示最后一段**:先剥离固定段(2026-09-17 起只剩「记账」),以空行分段取最后一段(家规让老师把给孩子的话放最后一段,前面是给家长看的思路;2026-09-08 R1 实测老师会在前面自言自语,故取最后一段),再按 `replyMaxChars` 截断;截断则同时把整段留给家长 |
| 中间 `assistant` 文本(工具调用之间的话) | 显示 | 不显示 |
| `tool_use` / `tool_result`(含 `parent_tool_use_id` 非空的子代理事件) | 折叠显示 | 不显示 |
| thinking / hook / 限流噪声 | 过滤(现有 gen-transcript 规则) | 不显示 |
| `result.subtype` 非 success | 红色通知 | **什么都不出现**;老师头像不灰,下一条照常 |
| 本次运行新增的 artifacts.jsonl 行 | 卡片 | **产物卡** |

TTS 只读 `kidText`。理由:「最终文本」是两个 CLI 都有的稳定锚点,老师不必学任何标记;想对孩子说的话放最后一段,是老师文件正文里一句话的事。

拍板(2026-09-08):规则照本节试跑;`replyMaxChars` 先用 60;截断占位句先加,试用后调。

## 5. 日记与记账段;artifacts.jsonl

**观察的真相在 vault 的日记**(2026-09-14 拍板,《obsidian仓库设计.md》;原来的 `observations.jsonl` 退役)。记账由家长触发(家长端「记账」/ `cotutor bookkeep`):这天每个还没记过、有孩子的话或打了分的话题,各起一轮 `from: system` 的任务,resume 那个话题的会话,老师只回一段固定形状的「## 记账」,**应用**按它渲染日记(`lib/diary.ts`),老师不直接写 vault:

```markdown
## 记账
- thread: 1620-1
  name: 找规律填数(递减)                     ← 话题名 ≤ 12 字;日记的 H2 = 学科 · 话题名
  textbook: 人教数学一下#4 100以内数的认识     ← 教材目录的「册#节」(记账消息里列了可选项);认不出就不写
  summary: 讲了…难点在…                       ← 只有话题打分 ≥ vault.keepScore 时才要
  steps: 抄数列 → … → 倒着加回去检查          ← 同上;讲解的骨架,一行
  observations:
    - 两位数减一位数跨十时会停一拍
```

落进 `日记/<日期>.md` 的一段(孩子问的话总是记;摘要 / 星 / 教材链接 / 课包 / 骨架只在打分够时有;`- 观察:` 行是上下文包 `recent:` 的来源,最近 14 天、按 H2 的学科过滤,家长改一句删一行下一轮就变):

```markdown
## 数学 · 找规律填数(递减)

> [!question] 孩子问
> 80 再少 2 为什么是 78?

讲了…难点在… ★★★★ → [[人教数学一下#4 100以内数的认识]] · 课包 2026-09-05-guilv1
骨架:抄数列 → … → 倒着加回去检查

- 观察:两位数减一位数跨十时会停一拍
```

打分的单位是话题:索引 `ratings[thread]`(1–5,`PUT /api/conversations/<老师>/<日期>/threads/<话题>/rating`、`cotutor rate`),记过的话题 `booked[thread]` = 记账那轮的 job,不再记。~~档案 `孩子.md` 的「> [!abstract] 现在」callout 整段进上下文包 `profile:`(≤ profileLines 行)~~(2026-09-17 改:档案与老师的入口文件按 `cotutor:` 属性找,原文接在 YAML 块后的 `<vault-note>` 里,上下文包加 `semester` / `profile` / `entry` / `refs`,`profileLines` 换成 `entryChars`;见《obsidian仓库设计.md》§9)。机器写 vault 的封闭清单:日记追加、计划新建、教材缺失时建骨架;永不写标签、图片,永不改家长写过的字。

产物账本 `artifacts.jsonl` 照旧:追加式,一行一条,`id` 唯一;改状态追加新行,同 `id` 后者为准(不改历史)。

```jsonc
// ledger/artifacts.jsonl
{ "id": "2026-09-08-两位数退位", "kind": "课包", "by": "math-tutor", "at": "…", "status": "ready",
  "path": "bundles/2026-09-08-两位数退位", "source": { "conversation": "math-tutor/2026-09-08", "job": "1620-a1" }, "hash": "sha256:…" }
{ "id": "2026-09-08-两位数退位", "status": "accepted", "by": "parent", "at": "…" }
{ "id": "2026-09-08-两位数退位", "at": "…", "costUsd": 0.56, "durationMs": 258000, "source": { "conversation": "scene-maker/2026-09-08", "job": "1630-1" } }   // 应用在 scene-maker 那轮收尾追加
```

`kind` 枚举:课包 / 补讲 / 批改 / 计划 / 其它;`status` 枚举:draft / ready / accepted / retired。`hash` 与现有 reviews.json 的 manifest 指纹同义,验收开关关掉时 accepted 行可以不存在。`costUsd` / `durationMs` 是做这个产物花的钱与时长(2026-09-11):scene-maker 自己只记 ready / retired 那行,应用在它那轮收尾时追加一行费用(同 id 后者为准);它忘了记账,应用补一整行(有 manifest → ready,没有 → retired)。

拍板(2026-09-08):reviews.json 并入 artifacts.jsonl,一处真相。2026-09-14:观察移到日记,`retracted` 追加行随之作废(家长直接删那一行)。
