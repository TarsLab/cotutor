# cotutor 契约草案

> 2026-09-08。《产品规划.md》与《agent层设计.md》定了概念与归属,这里给契约层每个文件一个**具体形状**。2026-09-08 已逐条拍板(各节末尾),形状的真相在 `src/schema/`(zod,类型即文档),本文只留「为什么」。前提:一孩一 workspace `~/cotutor/<slug>/`,cwd 取老师目录,记账由家长触发。

## 1. cotutor.json(每个 workspace 一份)

承接 drawtell.json 的做法(`paths` 角色映射 + `gen.agents` 的 {run, resume} 模板),加老师表与政策。

形状的真相在 `src/schema/config.ts`(workspace 里另有生成的 `.cotutor/cotutor.schema.json` 给编辑器补全)。

**字段归属规则**:老师的 `.md` 文件里只有 `name` / `description` / `maxTurns` / `permissionMode` + 正文(系统提示);**人设、政策、开关全在 cotutor.json**,老师团页只改 cotutor.json;老师文件是拷进 workspace 的出厂件(2026-09-09 拍板),家长要改口气可以直接改它,`cotutor upgrade` 不会覆盖改过的。老师身份键 = agent `name`。

拍板(2026-09-08):`voice` 先用 voxtell 的音色 id;`hidden` 够用。

拍板(2026-09-17):`tts` 除 `say` 外多一条 `voices`(缺省 `voxtell voices --json`),stdout 是 `{voices: [{voice, name, gender?, age?, trait?, scene?, lang?}]}` 或直接数组;家长端音色页据此列表,试听走 `say`。换别的 TTS 只要两条命令模板都给得出来。

## 2. 上下文包(每条消息前缀)

应用拼,固定 YAML 块,老师不用自己找;`---` 之后是消息本身。形状的真相在 `src/schema/context-pack.ts`:`from` / `at` / `slot` / `focus` / `plan` / `recent` / `vault`(路径,老师按 cotutor-vault 技能拼),2026-09-17 起加 `semester` / `profile` / `entry` / `memory` / `refs`;档案、入口文件、记忆的原文接在 YAML 块后的 `<vault-note role=…>` 里,只在话题第一条带(《obsidian仓库设计.md》§8)。2026-09-18 起有脸的老师另带 `rules` 与 `<cotutor-rules>`(机器技能 cotutor-tutor 的原文,排在笔记前面,同样只在话题第一条带),见《agent层设计.md》§3。

`from: system` 用于应用发起的消息(记账、场景作业)。孩子由 workspace 决定,不进包。

拍板(2026-09-08):`recent` 与 `planLines` 先定 10 条;`---` 分隔符照用。

2026-09-17 加两段(《首页设计.md》§六),只在孩子从首页按钮进来的那条出现:`home`(按钮上的字 + 家长备好的讲法;讲法从服务端的发布件取,不经过孩子设备)、`continue`(接着以前某天的某个话题:那个话题最后一节的讲稿与卡、话题名、那天索引的路径;只在新话题的第一条)。

## 3. 对话索引与转录

每条消息 = 一次 `-p` 运行 = 一份 NDJSON(沿用 `gen-*.log` 的做法)。索引一天一份:

```
conversations/<tutor>/<date>.json
conversations/<tutor>/<date>.<job>.log        # stream-json 原样
conversations/<tutor>/<date>.<job>.err.log
```

```jsonc
{
  "tutor": "math-tutor", "date": "2026-09-08",
  "session": { "id": "b596…", "agent": "claude" },           // 当天会话,首条消息后写入
  "messages": [
    { "job": "1620-a1", "thread": "1620-a1", "at": "…", "from": "kid", "text": "妈妈我不懂这一步", "focus": { "card": "1620-a1/2" },
      "result": "ok", "costUsd": 0.12, "kidText": "这一步是借位……", "artifacts": ["2026-09-08-两位数退位/补讲-3"],
      "timing": { "startedAt": "2026-09-08T08:20:18.498Z", "firstCardMs": 12709, "doneMs": 15207, "dubbedMs": 16100 } }   // 埋点(2026-09-11):从进程起算的毫秒
  ],
  "sessions": { "1620-a1": { "id": "b596…", "agent": "claude" } },   // 每个话题自己的会话(2026-09-11);session 只是当前话题的
  "costUsd": 1.23
}
```

`kidText` 与 `artifacts` 是孩子视图的物化结果(§4),写进索引后孩子端不再解析日志。**话题**(2026-09-11 拍板):`thread` = 话题第一条消息的 job;一个话题 = 一段连续问答 = 老师的一个会话,一天可多个,每个话题的会话在 `sessions[thread]`,顶层 `session` 只是当前(末条所在)话题的。开新话题(发消息带 `newThread`、`from: system`、今天第一条)不 resume、不带旧话题卡上的状态;指定 `thread` 接着今天的旧话题就 resume 它的会话;以前几天的只能看。旧索引没有 `thread` / `sessions`:读时按同一规则现算(第一条与 system 消息各开一个,其余跟前一条;顶层 session 算当前话题的),不改文件。`timing` 是这轮的用时(2026-09-11 埋点):`firstCardMs` = 流式时第一张卡闭合(整块出的运行时没有)、`doneMs` = 进程退出、`dubbedMs` = 配音收尾(没配音就没有);家长视图每轮一行,顶部今日中位。

拍板(2026-09-08):跨天自动新开,零点后第一条消息不带 `--resume`。

2026-09-17 加(《首页设计.md》§5.2):消息的 `via` = 孩子从首页哪个按钮进来的(`{home, button, label}`,开场按钮那条的 `text` 是按钮上的字,日记的「孩子问」不记它),`continues` = 这个话题接着以前哪天的哪个话题(新会话,不跨天 resume)。孩子端每次发消息都显式带 `newThread` 或 `thread`;服务端「缺省接当前话题」的规则只给家长端与 `cotutor send`。2026-09-24 加(《备课设计.md》):消息的 `prepThread`(家长端「新话题」开的备课话题,只在第一条)、`memoryDraft`(备课轮没写进 vault 的记忆段原文);索引的 `openings`(话题 → 开场那一轮:交给孩子了,孩子端从这一轮看起)。备课话题孩子开口之前孩子端不下发、不写记忆、不记账。

## 4. 孩子视图规则(精简)(stream-json 事件 → 孩子看到什么)

机械规则,不靠模型判断:

| 事件 | 家长视图 | 孩子视图 |
|---|---|---|
| `result.result`(本次运行的最终文本) | 显示 | **只显示最后一段**:先剥离固定段(「记账」「记忆」),以空行分段取最后一段(老师文件让老师把给孩子的话放最后一段,前面是给家长看的思路;实测老师会在前面自言自语,故取最后一段),再按 `replyMaxChars` 截断;截断则同时把整段留给家长 |
| 中间 `assistant` 文本(工具调用之间的话) | 显示 | 不显示 |
| `tool_use` / `tool_result`(含 `parent_tool_use_id` 非空的子代理事件) | 折叠显示 | 不显示 |
| thinking / hook / 限流噪声 | 过滤(现有 gen-transcript 规则) | 不显示 |
| `result.subtype` 非 success | 红色通知 | **什么都不出现**;老师头像不灰,下一条照常 |
| 本次运行新增的 artifacts.jsonl 行 | 卡片 | **产物卡** |

TTS 只读 `kidText`。理由:「最终文本」是两个 CLI 都有的稳定锚点,老师不必学任何标记;想对孩子说的话放最后一段,是老师文件正文里一句话的事。

拍板(2026-09-08):规则照本节试跑;`replyMaxChars` 先用 60;截断占位句先加,试用后调。

## 5. 日记与记账段;artifacts.jsonl

**观察的真相在 vault 的日记**(《obsidian仓库设计.md》)。记账由家长触发(家长端「记账」/ `cotutor bookkeep`):这天每个还没记过、有孩子的话或打了分的话题,各起一轮 `from: system` 的任务,resume 那个话题的会话,老师只回一段固定形状的「## 记账」,**应用**按它渲染日记(`lib/diary.ts`),老师不直接写 vault:

```markdown
## 记账
- thread: 1620-1
  name: 找规律填数(递减)                     ← 话题名 ≤ 12 字;日记的 H2 = 学科 · 话题名
  textbook: 人教数学一下#4 100以内数的认识     ← 教材目录的「册#节」(记账消息里列了可选项);认不出就不写
  summary: 讲了…难点在…                       ← 只有话题打分 ≥ vault.keepScore 时才要
  steps: 抄数列 → … → 倒着加回去检查          ← 同上;讲解的骨架,一行
  observations:
    - 两位数减一位数跨十时会停一拍
```

落进 `日记/<日期>.md` 的一段(孩子问的话总是记;摘要 / 星 / 教材链接 / 课包 / 骨架只在打分够时有;`- 观察:` 行是上下文包 `recent:` 的来源,最近 14 天、按 H2 的学科过滤,家长改一句删一行下一轮就变):

```markdown
## 数学 · 找规律填数(递减)

> [!question] 孩子问
> 80 再少 2 为什么是 78?

讲了…难点在… ★★★★ → [[人教数学一下#4 100以内数的认识]] · 课包 2026-09-05-guilv1
骨架:抄数列 → … → 倒着加回去检查

- 观察:两位数减一位数跨十时会停一拍
```

打分的单位是话题:索引 `ratings[thread]`(1–5,`PUT /api/conversations/<老师>/<日期>/threads/<话题>/rating`、`cotutor rate`),记过的话题 `booked[thread]` = 记账那轮的 job,不再记。档案与老师的入口文件按 `cotutor:` 属性找,原文进上下文包(§2)。机器写 vault 的封闭清单:日记追加、记忆追加;永不写标签、图片,永不改家长写过的字。

产物账本 `artifacts.jsonl` 照旧:追加式,一行一条,`id` 唯一;改状态追加新行,同 `id` 后者为准(不改历史)。

```jsonc
// ledger/artifacts.jsonl
{ "id": "2026-09-08-两位数退位", "kind": "课包", "by": "math-tutor", "at": "…", "status": "ready",
  "path": "bundles/2026-09-08-两位数退位", "source": { "conversation": "math-tutor/2026-09-08", "job": "1620-a1" } }
{ "id": "2026-09-08-两位数退位", "at": "…", "costUsd": 0.56, "durationMs": 258000, "source": { "conversation": "scene-maker/2026-09-08", "job": "1630-1" } }   // 应用在 scene-maker 那轮收尾追加
```

`kind`:课包 / 其它;`status`:draft / ready / retired。`costUsd` / `durationMs` 是做这个产物花的钱与时长:scene-maker 自己只记 ready / retired 那行,应用在它那轮收尾时追加一行费用(同 id 后者为准);它忘了记账,应用补一整行(有 manifest → ready,没有 → retired)。

```markdown
week: 2026-W37
status: draft          # draft | confirmed,家长改成 confirmed 即真相
---
## 数学老师
- 周三前把两位数退位讲一遍,用数轴不用竖式
- 周五出两道类似题看会不会

## 英语老师
- 继续 U3,每天 10 分钟

## 家长
- 周六和孩子一起复述退位
```
