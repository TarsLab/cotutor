## 1. cotutor.json(每个 workspace 一份)

承接 drawtell.json 的做法(`paths` 角色映射 + `gen.agents` 的 {run, resume} 模板),加老师表与政策。

```jsonc
{
  "version": 1,
  "title": "小明的书房",                       // 孩子端标题,无品牌
  "kid": { "slug": "ming", "name": "小明", "grade": "二年级" },
  "server": { "port": 5180 },                  // 一 workspace 一进程
  "paths": {                                   // 角色 → 目录;vault 侧目录名由这家自定
    "vault": "~/Library/Mobile Documents/iCloud~md~obsidian/Documents/Ming",
    "photos": "照片", "diary": "日记", "plans": "计划", "profile": "孩子.md", "timetable": "课程表.md"
  },
  "policyDefaults": {                          // 老师条目缺省继承
    "replyMaxChars": 60, "dailyMessages": 30, "dailyRegen": 3, "reviewGate": false,
    "forms": ["L0", "L1", "L3", "L4"], "contextPack": { "recent": 10, "planLines": 10 }
  },
  "teachers": {                                // key = agent 文件的 name
    "math-teacher": { "display": "数学老师", "subject": "数学", "avatar": "🧮", "voice": "<voxtell 音色 id>", "enabled": true },
    "reading-teacher": { "display": "朗读老师", "subject": "英语", "avatar": "📖", "voice": "<voxtell 音色 id>", "enabled": true, "policy": { "forms": ["L0", "L1", "L3"] } },
    "planner": { "display": "规划老师", "avatar": "🗓", "enabled": true, "hidden": true }   // 孩子端不露
  },
  "agents": {                                  // 运行时预设;占位:{agent} {agentBody} {prompt} {session}
    "default": "claude",
    "claude": {
      "run":    ["claude", "--agent", "{agent}", "-p", "{prompt}", "--dangerously-skip-permissions", "--output-format", "stream-json", "--verbose", "--max-budget-usd", "2"],
      "resume": ["claude", "--agent", "{agent}", "-p", "--resume", "{session}", "{prompt}", "--dangerously-skip-permissions", "--output-format", "stream-json", "--verbose", "--max-budget-usd", "2"]
    },
    "qwen": {
      "run":    ["qwen", "-p", "{prompt}", "--append-system-prompt", "{agentBody}", "--yolo", "--output-format", "stream-json", "--max-wall-time", "10m"],
      "resume": ["qwen", "-p", "{prompt}", "--resume", "{session}", "--append-system-prompt", "{agentBody}", "--yolo", "--output-format", "stream-json", "--max-wall-time", "10m"]
    }
  }
}
```

**字段归属规则**:老师的 `.md` 文件里只有 `name` / `description` / `maxTurns` / `permissionMode` / `memory` + 正文(系统提示);**人设、政策、开关全在 cotutor.json**,助教团页只改 cotutor.json,永不改链进来的定义文件。老师身份键 = agent `name`。

拍板(2026-09-08):`voice` 先用 voxtell 的音色 id;`hidden` 够用。

## 2. 上下文包(每条消息前缀)

应用拼,固定 YAML 块,老师不用自己找。纯函数 `buildContextPack()` 在应用仓,带测试。

```yaml
cotutor:
  from: kid            # kid | parent | system
  at: 2026-09-08T16:20
  slot: 数学 16:00-17:00          # 课程表命中才有
  focus:                          # 当前对象,可缺
    artifact: 2026-09-08-两位数退位
    step: 3
    circled: ["借位那一步"]
  plan:                           # 本周计划中与本老师相关的行,≤ planLines
    - 周三前把两位数退位讲一遍
  recent:                         # 最近 recent 条本学科观察,只带 date + claim
    - 2026-09-06 两位数退位错 3 次
---
妈妈我不懂这一步
```

`from: system` 用于应用发起的消息(记账、交接、定时)。孩子由 workspace 决定,不进包。

拍板(2026-09-08):`recent` 与 `planLines` 先定 10 条;`---` 分隔符照用。

## 3. 会话索引与转录

每条消息 = 一次 `-p` 运行 = 一份 NDJSON(沿用 `gen-*.log` 的做法)。索引一天一份:

```
conversations/<teacher>/<date>.json
conversations/<teacher>/<date>.<job>.log        # stream-json 原样
conversations/<teacher>/<date>.<job>.err.log
```

```jsonc
{
  "teacher": "math-teacher", "date": "2026-09-08",
  "session": { "id": "b596…", "agent": "claude" },           // 当天会话,首条消息后写入
  "messages": [
    { "job": "1620-a1", "at": "…", "from": "kid", "text": "妈妈我不懂这一步", "focus": { "artifact": "…", "step": 3 },
      "result": "ok", "costUsd": 0.12, "kidText": "这一步是借位……", "artifacts": ["2026-09-08-两位数退位/补讲-3"] }
  ],
  "costUsd": 1.23
}
```

`kidText` 与 `artifacts` 是精简视图的物化结果(§4),写进索引后孩子端不再解析日志。

拍板(2026-09-08):跨天自动新开,零点后第一条消息不带 `--resume`。

## 4. 精简视图规则(stream-json 事件 → 孩子看到什么)

机械规则,不靠模型判断:

| 事件 | 家长视图 | 孩子视图 |
|---|---|---|
| `result.result`(本次运行的最终文本) | 显示 | **只显示最后一段**:先剥离「待裁量」段与「转交」段(§6),以空行分段取最后一段(家规让老师把给孩子的话放最后一段,前面是给家长看的思路;2026-09-08 R1 实测老师会在前面自言自语,故取最后一段),再按 `replyMaxChars` 截断;截断则同时把整段留给家长 |
| 中间 `assistant` 文本(工具调用之间的话) | 显示 | 不显示 |
| `tool_use` / `tool_result`(含 `parent_tool_use_id` 非空的子代理事件) | 折叠显示 | 不显示 |
| thinking / hook / 限流噪声 | 过滤(现有 gen-transcript 规则) | 不显示 |
| `result.subtype` 非 success | 红色通知 | **什么都不出现**;老师头像不灰,下一条照常 |
| 本次运行新增的 artifacts.jsonl 行 | 卡片 | **产物卡** |

TTS 只读 `kidText`。理由:「最终文本」是两个 CLI 都有的稳定锚点,老师不必学任何标记;想对孩子说的话放最后一段,是老师文件正文里一句话的事。

拍板(2026-09-08):规则照本节试跑;`replyMaxChars` 先用 60;截断占位句先加,试用后调。

## 5. observations.jsonl 与 artifacts.jsonl

追加式,一行一条,`id` 唯一;改状态追加新行,同 `id` 后者为准(不改历史)。类型进 @tarslab/schema:`ObservationV0` / `ArtifactEventV0`。

```jsonc
// ledger/observations.jsonl
{ "id": "o-20260908-001", "date": "2026-09-08", "author": "math-teacher", "subject": "数学", "topic": "两位数退位减法",
  "claim": "借位时忘了个位先减 1,连错 3 次", "evidence": { "conversation": "math-teacher/2026-09-08", "job": "1620-a1" }, "retracted": false }
{ "id": "o-20260908-001", "retracted": true, "by": "parent", "date": "2026-09-09" }        // 纠错行

// ledger/artifacts.jsonl
{ "id": "2026-09-08-两位数退位", "kind": "课包", "by": "math-teacher", "at": "…", "status": "ready",
  "path": "bundles/2026-09-08-两位数退位", "source": { "conversation": "math-teacher/2026-09-08", "job": "1620-a1" }, "hash": "sha256:…" }
{ "id": "2026-09-08-两位数退位", "status": "accepted", "by": "parent", "at": "…" }
```

`evidence` 指向会话 + job 或产物 id,二选一;`kind` 枚举:课包 / 补讲 / 批改 / 计划 / 其它;`status` 枚举:draft / ready / accepted / retired。`hash` 与现有 reviews.json 的 manifest 指纹同义,验收开关关掉时 accepted 行可以不存在。

拍板(2026-09-08):`retracted` 用追加行;reviews.json 并入 artifacts.jsonl,一处真相。

## 6. 老师间交接

跨老师只走文件 + 应用转发,老师之间不直接通话。两层:

1. **被动**:产物与观察进账本,别的老师下次的上下文包里就有。零机制,先用这个。
2. **主动**(R5 起,作业助教认完学科要交给学科老师):老师在最终文本里写一个固定段,应用解析后 resume 目标老师一次,`from: system`。形状照抄待裁量的做法(`HoldupAskV0` 的 frontmatter 模式),契约 `HandoffV0`:

```markdown
## 转交
to: math-teacher
why: 照片是数学作业,第 3、5 题错
refs: [captures/2026-09-08-abcd]
```

解析在应用侧纯函数,解析不出整段当正文(格式是增强不是门槛,同 holdup.ts)。

拍板(2026-09-08):第一期只允许一跳。

## 8. 计划文件 `计划/<周>.md`(vault)

家长要能随手改,应用要能抽「与本老师相关的行」,所以按老师分 H2,行内自由:

```markdown
---
week: 2026-W37
status: draft          # draft | confirmed,家长改成 confirmed 即真相
author: planner
---
## 数学老师
- 周三前把两位数退位讲一遍,用数轴不用竖式
- 周五出两道类似题看会不会

## 朗读老师
- 继续 U3,每天 10 分钟

## 家长
- 周六和孩子一起复述退位
```

解析与课程表同法:纯函数 `plan.ts`,H2 标题对 `teachers[].display`,错误即修复指南带行号;H2 对不上的段只给家长看。

拍板(2026-09-08):H2 用显示名;`status` 之外不加 `confirmedAt`。

## 9. 技能仓划分
