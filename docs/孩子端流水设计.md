# 孩子端流水设计

> 2026-10-22 起。孩子端按铁律不显示任何错误,出了事只有家长事后能查。现在能查的只有两样:按住说话那几条路的诊断(`.cotutor/voice-diag.jsonl`)和录像用的实录(`<日期>.<job>.play.jsonl`)。孩子在哪台设备上开的、页面脚本有没有出错,都查不到。本文定孩子端各页往服务端记什么、怎么认设备、存在哪、工作台怎么显示。拍板在文末。

## 一、记什么

| # | 记什么 | 什么时候记 | 做到哪 |
|---|---|---|---|
| 1 | **哪一台设备**:设备编号、家长起的名 | 每次打开 | 这期做 |
| 2 | 浏览器与环境:浏览器信息、Safari 版本、是不是 iPad、是不是从主屏幕打开、屏幕尺寸与像素比、语言 | 每次打开 | 这期做认设备要的那几样,跟着 1 一起记 |
| 3 | 服务端版本:serve 跑的是哪个 git 提交、什么时候起的 | 每次打开 | 下一期 |
| 4 | **页面脚本出错**:报错、哪一行、当时在哪位老师那里 | 出错时 | 这期做 |
| 5 | 权限与能力:麦克风给没给、有没有语音识别、能不能自动出声 | 打开时、变了时 | 下一期 |
| 6 | 连接:断线断了多久、实时老师连不上几次 | 断、续时 | 下一期 |
| 7 | 用了多久:几点打开、切到后台、关掉 | 打开、前后台切换、关 | 下一期,和用量统计一起 |

不记:

- **地理位置**:要弹权限框问孩子,家里也用不上。
- **每条消息都带一遍浏览器信息**:同一次打开里不变,打开时记一次;消息上只带设备编号。

## 二、设备怎么认

- **服务端种 cookie**:`cotutor_kid`,随机编号,活 400 天(浏览器允许的最长),`Path=/`、`SameSite=Lax`、`HttpOnly`,走 HTTPS 时加 `Secure`。孩子端页面一打开就报「打开」(`POST /api/kid/log`),请求里没有这枚 cookie,就在回应里种上。
- **为什么不用 localStorage**:Safari 对页面脚本写的存储有一条,七天没来过就清掉。服务端种的 cookie 不受这一条管;`HttpOnly` 也让页面脚本读不到、改不了。
- **一枚 cookie 算一台设备**:同一台 iPad 上,Safari 里开的和「添加到主屏幕」的图标是两枚 cookie,算两台设备,各起各的名;列表上标「主屏幕」好分。清了网站数据、换个浏览器,就是新设备。
- **设备表** `.cotutor/devices.json`(应用写):一台一项,记第一次、最近一次打开的时刻,开过几次,最近一次的浏览器信息,自动标签,家长起的名。
- **自动标签**由浏览器信息算(`src/lib/kid-device.ts`):`iPad · Safari 27 · 主屏幕`。两个坑:
  - iPad 的 Safari 缺省「请求桌面网站」,浏览器信息写的是 Macintosh,要看触点数(`maxTouchPoints > 1`)才认得出是 iPad。
  - 新版 iOS 浏览器信息里的系统版本冻住了(Ray 的 iPad 写 `CPU OS 18_7`,Safari 却是 `Version/27`),标签只写 Safari 版本,不写系统版本。
- **只登记孩子端的打开**:家长端 `/parent`、录像 `/reel`、`/dictation?reel=`、`/talk?reel=`、预览 `/preview` 也是孩子端那份页面,但开在家长自己的设备上,不报「打开」,不登记设备(出错照记,见下一节)。
- **消息上记设备**:孩子发的每一条记 `deviceId`。服务端从 cookie 取,不靠页面带;孩子端发消息的 HTTP 接口和实时老师的 WebSocket 两条路都取。工作台、`cotutor send` 发的没有。

## 三、出错怎么记

- **各页共用一段脚本** `KID_LOG_JS`(`src/server/kid-log.ts`),做法照 `KID_NAV_JS`:ES5,没有反斜杠与反引号,插进各页的模板字符串。用在首页 / 老师页(`kid-page.ts`,各种模式都带)、听写(中、英)、口语课;舞台(`/stage/`,React 包)在 `src/stage/main.tsx` 里装同样的监听。`tests/kid-log.test.ts` 盯着这几页都带它。
- **收两种**:`window` 的 `error`(只收脚本错,图片、声音读不出不收,那些各页本来就有退路)与 `unhandledrejection`。
- **一条记**:报错(截到 300 字)、位置(行:列)、调用栈(截到 1500 字)、哪一页、什么模式(孩子端 / 家长端 / 录像 / 预览)、页面版本;老师页另带当时的老师、话题、是不是实时。
- **护栏**:同一次打开里,同一条报错(报错 + 位置)只报一次,最多报 20 条,防一个死循环把文件写满。这是防失控的护栏,不是用量限额。
- 孩子端照旧什么都不显示。

## 四、怎么存

- **流水** `.cotutor/kid-log/<日期>.jsonl`:一行一件事,`k` 是 `open`(打开)或 `error`(出错),以后加 `net`、`perm`、`hide` 这类。服务端补上时刻、设备编号、来源地址(局域网地址,只作参考)。
- 删话题不动它。不自动清:一天几十行。
- **接口** `POST /api/kid/log`:孩子端路径(在 `access.ts` 的 `/api/kid/` 前缀里,设了 PIN 也开);正文不超过 4000 字,`k` 不认得回 400;回 `{ok, device}`,没 cookie 时顺手种上。mock 照收不落盘。

## 五、工作台怎么显示

**概览**加一张「设备」卡,放在「老师今天」下面、一样宽;右边照旧是「要看一眼」与体检:

| 名字 | 自动标签 | 最近打开 | 今天 | 近 7 天出错 |
|---|---|---|---|---|
| Ray 的 iPad | iPad · Safari 27 · 主屏幕 | 今天 20:53 | 6 次 | |
| 没起名 | Mac · Safari 26 | 10-19 21:02 | | 2 |
| 更早的 1 台 › | | | | |

- 近 30 天开过的设备,最近开的在前;一台一行:名字(没起就是「没起名」,点了改)、自动标签、最近打开、今天开了几次、近 7 天出错几条(有才写,砖红)。
- **起名**:点名字变输入框,回车存、Esc 不存(`PATCH /api/dev/devices/<编号>`,写进设备表),空着存 = 去掉名字。
- 30 天以前的折起来:「更早的 N 台」,点开同样一台一行。

**要看一眼**多一种「页面」(砖红):同一条报错(报错 + 位置 + 页面版本)七天里合成一条,写「×N · 哪几台设备」;点开在原地展开调用栈、哪一页、什么模式、第一次与最近一次;带了老师与话题的,多一个「去那天的对话」。和慢的、出错的、带提醒的轮次一起按时刻排,最多 8 条。

**对话页**每一轮底下那排埋点,孩子发的轮多一枚设备名的签(没起名写自动标签)。

家长端这期不显示。

## 六、怎么验

- `tests/kid-log.test.ts`:
  - 接口:没 cookie 种上、带了不再种;孩子端模式登记设备、别的模式不登记;出错记一行;坏正文、太长、`k` 不认得回 400。
  - 自动标签:iPad Safari、iPad 桌面模式(Mac 的浏览器信息 + 触点)、iPhone、Mac、Chrome、主屏幕。
  - 消息记 `deviceId`(HTTP 一条、WebSocket 一条)。
  - 概览:设备卡的数、页面出错合并成一条;改名、去掉名字。
  - 各页都带 `KID_LOG_JS`,能插进模板字符串。
- 页面:`scripts/probe-kid-log.mjs --base <serve 地址>`(**会写**,拿试用 workspace):老师页、听写各开一次,种了设备 cookie、设备卡今天两次;页面里故意抛的错、没接住的 Promise 各成一条「页面」;设备卡点名字起名、回车存,最后名字回到空。`scripts/probe-dev.mjs` 照旧走一遍概览;孩子端探针照旧不红(mock 收 `/api/kid/log`)。
