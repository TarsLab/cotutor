# 孩子端流水设计

> 2026-10-22 起。孩子端按铁律不显示任何错误,出了事只有家长事后能查。现在能查的只有两样:按住说话那几条路的诊断(`.cotutor/voice-diag.jsonl`)和录像用的实录(`<日期>.<job>.play.jsonl`)。孩子在哪台设备上开的、页面脚本有没有出错,都查不到。本文定孩子端各页往服务端记什么、怎么认设备、存在哪、工作台怎么显示。拍板在文末。

## 一、记什么

| # | 记什么 | 什么时候记 | 做到哪 |
|---|---|---|---|
| 1 | **哪一台设备**:设备编号、家长起的名 | 每次打开 | 这期做 |
| 2 | 浏览器与环境:浏览器信息、Safari 版本、是不是 iPad、是不是从主屏幕打开、屏幕尺寸与像素比、语言 | 每次打开 | 这期做认设备要的那几样,跟着 1 一起记 |
| 3 | 服务端版本:serve 跑的是哪个 git 提交、什么时候起的 | 每次打开 | 第二期 |
| 4 | **页面脚本出错**:报错、哪一行、当时在哪位老师那里 | 出错时 | 这期做 |
| 5 | 权限与能力:麦克风给没给、有没有语音识别、能不能自动出声 | 打开时、变了时 | 第二期 |
| 6 | 连接:断线断了多久、实时老师连不上几次 | 断、续时 | 第二期 |
| 7 | 用了多久:几点打开、在前台多久 | 切到后台、离开页面、开着每 5 分钟 | 第二期 |

不记:

- **地理位置**:要弹权限框问孩子,家里也用不上。
- **每条消息都带一遍浏览器信息**:同一次打开里不变,打开时记一次;消息上只带设备编号。

## 二、设备怎么认

- **服务端种 cookie**:`cotutor_kid`,随机编号,活 400 天(浏览器允许的最长),`Path=/`、`SameSite=Lax`、`HttpOnly`,走 HTTPS 时加 `Secure`。孩子端页面一打开就报「打开」(`POST /api/kid/log`),请求里没有这枚 cookie,就在回应里种上。
- **为什么不用 localStorage**:Safari 对页面脚本写的存储有一条,七天没来过就清掉。服务端种的 cookie 不受这一条管;`HttpOnly` 也让页面脚本读不到、改不了。
- **一枚 cookie 算一台设备**:同一台 iPad 上,Safari 里开的和「添加到主屏幕」的图标是两枚 cookie,算两台设备,各起各的名;列表上标「主屏幕」好分。清了网站数据、换个浏览器,就是新设备。
- **设备表** `.cotutor/devices.json`(应用写):一台一项,记第一次、最近一次打开的时刻,开过几次,最近一次的浏览器信息,自动标签,家长起的名。
- **自动标签**由浏览器信息算(`src/lib/kid-device.ts`):`iPad · Safari 27 · 主屏幕`。两个坑:
  - iPad 的 Safari 缺省「请求桌面网站」,浏览器信息写的是 Macintosh,要看触点数(`maxTouchPoints > 1`)才认得出是 iPad。
  - 新版 iOS 浏览器信息里的系统版本冻住了(Ray 的 iPad 写 `CPU OS 18_7`,Safari 却是 `Version/27`),标签只写 Safari 版本,不写系统版本。
- **只登记孩子端的打开**:家长端 `/parent`、录像 `/reel`、`/dictation?reel=`、`/talk?reel=`、预览 `/preview` 也是孩子端那份页面,但开在家长自己的设备上,不报「打开」,不登记设备(出错照记,见下一节)。
- **消息上记设备**:孩子发的每一条记 `deviceId`。服务端从 cookie 取,不靠页面带;孩子端发消息的 HTTP 接口和实时老师的 WebSocket 两条路都取。工作台、`cotutor send` 发的没有。

## 三、出错怎么记

- **各页共用一段脚本** `KID_LOG_JS`(`src/server/kid-log.ts`),做法照 `KID_NAV_JS`:ES5,没有反斜杠与反引号,插进各页的模板字符串。用在首页 / 老师页(`kid-page.ts`,各种模式都带)、听写(中、英)、口语课;舞台(`/stage/`,React 包)由服务端出 `index.html` 时插同一段(`stageIndex`),只记出错。`tests/kid-log.test.ts` 盯着这几页都带它。
- **收两种**:`window` 的 `error`(只收脚本错,图片、声音读不出不收,那些各页本来就有退路)与 `unhandledrejection`。
- **一条记**:报错(截到 300 字)、位置(行:列)、调用栈(截到 1500 字)、哪一页、什么模式(孩子端 / 家长端 / 录像 / 预览)、页面版本;老师页另带当时的老师、话题、是不是实时。
- **护栏**:同一次打开里,同一条报错(报错 + 位置)只报一次,最多报 20 条,防一个死循环把文件写满。这是防失控的护栏,不是用量限额。
- 孩子端照旧什么都不显示。

## 四、怎么存

- **流水** `.cotutor/kid-log/<日期>.jsonl`:一行一件事,`k` 是 `open`(打开)、`error`(出错),第二期加 `perm`(权限变了)、`net`(断线、实时连不上)、`fg`(在前台多久)。服务端补上时刻、设备编号、来源地址(局域网地址,只作参考)。
- 删话题不动它。不自动清:一天几十行。
- **接口** `POST /api/kid/log`:孩子端路径(在 `access.ts` 的 `/api/kid/` 前缀里,设了 PIN 也开);正文不超过 4000 字,`k` 不认得回 400;回 `{ok, device}`,没 cookie 时顺手种上。mock 照收不落盘。

## 七、第二期

### 7.1 服务端版本(3)

- serve 起来时记下:版本号(`package.json`)、git 提交(包目录是 git 仓才有:短哈希,有没有没提交的改动)、启动时刻。`/api/health` 带上提交。
- 打开那行由服务端补 `srv`:版本号、提交、启动时刻。页面不用带。
- **工作台侧栏的服务状态**写「起了 N 分 · v0.2.0 · 47ffcdc」。仓里的提交已经不是启动时那个了,侧栏变琥珀:「代码更新了,重起 serve 才用上」——Ray 跑的是仓里检出的分支,这样一眼看出要不要重起(`/api/health` 现查 `git rev-parse HEAD`,十秒内复用)。
- 设备卡「最近打开」悬停写那次打开时服务端的提交。

### 7.2 权限与能力(5)

- 打开那行加 `caps`:
  - 麦克风权限:`granted` / `denied` / `prompt`,问不出写 `unknown`(`navigator.permissions`,Safari 16 起有)。
  - 有没有麦克风接口(`getUserMedia`)、有没有语音识别(`SpeechRecognition`)。
- 变了再记一行 `k: 'perm'`:
  - 麦克风权限变了(`permissions` 的 `onchange`)。
  - 老师的声音头一回被浏览器拦了(`play()` 拒了 `NotAllowedError`),一次打开只记一次。
- 设备表记最近一次的 `caps`。设备卡上这台有毛病才多一枚签:「麦克风拒了」(砖红)、「没有语音识别」(琥珀)、「声音被拦过」(琥珀,近 7 天有过)。

### 7.3 连接(6)

- **断线**:老师页心跳不通(头像变灰那一下)到再通,记 `k: 'net', what: 'offline', ms`。断着发不出去,通了再报。
- **实时老师**:WebSocket 不是孩子自己收的、自己关了,记 `k: 'net', what: 'live', opened, ms`。`opened` 是 false = 连不上(回落成板书),true = 连上以后断了。
- **要看一眼**多一种「连接」(琥珀):一台设备一天合一条,写「断线 3 次,最长 2 分 10 秒 · 实时连不上 2 次、断了 1 次」。

### 7.4 用了多久(7)

- 孩子端模式的页面(老师页、听写、口语课)在前台就计时:切到后台、离开页面时记 `k: 'fg', ms`;一直开着,每 5 分钟也记一笔(没电、浏览器被杀,不至于全丢)。舞台开在老师页里,不另算;家长端、录像、预览不算。
- **概览「今天」卡**多两格:前台多久、几点到几点(第一次打开到最后一笔前台)。近 7 天的柱子悬停写那天前台多久。
- **设备卡「今天」**写「2 次 · 48 分」。
- 这是孩子端开着的时间,不是学了多久;页面开着、人走开了也算在里面。

### 7.5 怎么验

- `tests/kid-log.test.ts`:那段脚本在假 window 里报 `caps`、麦克风变了记 `perm`、声音被拦只记一次、断线通了报时长、前台计时(切后台、离开、5 分钟一笔、家长模式不计);接口收三种新行;打开那行服务端补 `srv`。
- `tests/dev-overview.test.ts`:今天前台多久与几点到几点、设备卡的「· 48 分」与毛病签、「连接」一台一天合一条;`/api/health` 带提交、代码更新了。
- `scripts/probe-kid-log.mjs` 加:真 Chrome 离开老师页记一笔前台、断网再通记一笔断线(CDP 的 `Network.emulateNetworkConditions`)、侧栏写跑的提交。
