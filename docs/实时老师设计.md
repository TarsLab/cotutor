# 实时老师:嘴开口、脑写板书

> 2026-10-19 起;10-22 起是有脸的老师唯一的做法(《产品规划.md》拍板 30:没配百炼孩子端打不开,没有板书退路)。正文 2026-10-22 收成现状;10-19 的设想、P0–P5 分期、探针计划、待拍板与量什么,原文在 git 历史 facdd86。页面的样子在《实时老师页设计.md》,不用按住说话的那种在《一直听设计.md》,谁出声、谁停的仲裁表在《工作流程.md》§孩子端「实时老师」。
> **词**:「实时」= 老师用 realtime 模型开口、老师 CLI 在后面写板书的做法。「嘴」= realtime 那头,出声。「脑」= 老师 CLI(老师文件、技能、vault 照旧),写卡、写讲稿。「连接」= 一条 realtime WebSocket(「会话」留给 CLI 的 session);一个话题可以换几条连接。

结论先行:**孩子松手,嘴照着脑写的讲稿一句一句念;卡由脑写,一拍关了就铺;嘴自己不讲内容。** 松手到听到老师 3–5 秒(以前板书时语文中位 4.6 秒、数学 17.9 秒),脑照旧可以想。

## 一、为什么

ray 10-13 到 10-18 的真数据(`conversations/*/<日期>.json` 的 `timing.firstReadyMs`,孩子发出到第一句能念):

| | 中位 / 九成 | |
|---|---|---|
| 语文老师(qwen3.8-max,随口的话不想) | 4.6 / 8.1 秒 | 看图说话那串 10 轮,每轮 4–8 秒 |
| 数学老师(同模型,effort medium = 每轮想 low) | 17.9 / 33.2 秒 | 拍照那几轮 27–51 秒;10-18 一个话题 25 轮 |
| 口语课(realtime) | 首包 0.6–0.8 秒 | 加上孩子停顿的判定,体感约 2 秒 |

- 一问一答的场景(看图说话:孩子一句短话、老师一句)每轮等 4–8 秒,一个话题十轮,大半时间在等。
- 数学慢在想:同一个模型不想是 4–5 秒。想是要的(讲题要对),但不该让孩子在想的时候干等。
- 实时把「开口」和「想」拆开:开口的(嘴)快而浅,想的(脑)慢而深,脑不在孩子等的路上,数学反而可以想得更多。
- Ray 不说英语,口语课测不出这条路;语文、数学是他天天用的,真用就是测。

## 二、孩子看到的

- 老师页:平板横屏左边一张白纸(孩子刚说的那句、老师在说的那句、一颗大按钮——头像在按钮里,按住说话),右边铺满的是板;竖屏和手机字幕在输入条上方。样子与按钮的动画在《实时老师页设计.md》。
- 松手:嘴不先接话,等脑的第一句(拍板 14),一般 3–5 秒;拍照先说「我看一看图片」(读图 14–29 秒)。
- 老师在说时按住说话 = 打断,嘴马上停;这一轮没念的讲稿丢掉,脑照样写完、卡照铺(拍板 17)。
- 板是脑写的笔记 + 练习(拍板 20):新的一件事脑起一节、写一行节头;孩子的话不上板,在左栏看。卡上没有「?」,想问某张卡就点开它再按住说(拍板 18);没有占位卡(拍板 19)。
- 有自己声音的卡(点读、单词、田字格)点了就念,那是卡的配音,不是嘴;嘴的声音一到,卡先停。
- 「再听一遍」:安静时字幕下一行小字,放这一轮嘴照念过的声音,家长提醒着用(拍板 21)。
- 嘴连不上、断了(网、欠费):老师灰着写「正在叫老师」,孩子端自己隔 2、4、8… 秒(最长 30 秒)再连;这时打的字、首页按钮的开场排着,连上就发。不报错,不退回别的样子(《产品规划.md》拍板 30)。
- 孩子端的约定照守:没有错误与评判,卡上不画对错,答案不下发。改口只说老师自己。

## 三、嘴和脑怎么分工

**嘴**(百炼 realtime,缺省 `qwen3.8-omni-flash-realtime`;一位老师一个音色,`live.voices`,出厂语文 Serena、数学 Andre、英语 Theo Calm,别的 Serena):
- 每次开口都由应用给词(P1 实测,§五):`response.instructions` = 「原样说:『…』」(`src/live/lib/cue.ts`)。嘴自己不讲新内容、不判作业、不说答案、不评对错。
- 先说一句的只有三种:拍照「我看一看图片」、转写是空的「没听清,再说一遍吧」、口语课开课「好,我们先热热身!」。别的(说话、打字、交卡、首页按钮的开场)都不先说,等脑的第一句(拍板 14)。
- 按住说话的声音一边说一边推给嘴,松手提交;嘴的转写交给脑。

**脑**(老师 CLI,resume 同一个会话;实时那一轮的消息带 `live: true`):
- 每轮拿到:孩子的话(嘴的转写)、上一轮念到第几句被打断(`cut`;一句没念到是 `cut: 0`,拍板 17)、这期间板上的事(交了哪张卡、画了什么)。
- 回的是板书:卡 + 讲稿 + 给家长的尾巴。讲稿不配音、不截(拍板 16),定稿一句交一句给嘴照念(照念排队 `src/live/lib/queue.ts`);讲稿第一句直接说正事(守则「实时」一节)。`[[play]]`(放小课堂一段)、`[[echo]]` / `[[say]]` / `[[call]]`(口语课的热身与打电话,《口语课实时设计.md》)管先后。
- 脑在写时孩子又说了:排着,写完和别的排着的合成一条再交(最多一轮在写、一条在排)。

**应用**(`src/live/`):
- 一次通话 = 孩子端一条 WebSocket(`/api/live/<老师>/ws`,`route.ts`)对一个 `LiveCall`(`call.ts`):嘴的连接、脑的轮、照念、打断、录像都在这里;孩子端发一条的验与拼和 HTTP 共用 `app.ts` 的 `kidSendInput`。
- 换连接:嘴每次回答都带着整条连接的历史,上一次回答的输入过了 3000 token 就在安静时换一条新的;一直听时放过的句子多了,离上次回答 240 秒也换(百炼 commit 了不回答 300 秒会把会话弄死)。
- 心跳与现连:没在推声音时定时推一段静音、推完马上 clear(只推不 clear 会 `response_idle_timeout`);嘴断了现连两次,还连不上就告诉孩子端 `down`、挂掉,孩子端自己再连。
- 录像:嘴和孩子的声音混成一条 `<日期>.live/<时分秒>.wav`,进出的每条消息带毫秒落同名 `.reel.json`(`CallRecorder`);每轮嘴照念的声音另落 `<日期>.<job>.mouth.wav` 给「再听一遍」。工作台时间线多一道 `mouth`(按下、松手、每句开始放、被打断)。

孩子端这一头:谁出声、谁停在 `src/lib/live-board.ts` 的 `liveStep`;板上的节在 `kid-board.ts` 的 `step`;按钮的样子在 `voice-view.ts` / `voice-ui.ts`。

## 五、真跑数据

P1 探针(2026-10-19,`scripts/probe-live.mjs`;报告与 wav 在本机 scratchpad,不在仓里):
1. **快**:Ray 的 40 段真录音,松手(commit)到第一块声音中位 0.84 秒、九成 1.09 秒、最慢 2.8 秒;孩子那句的转写 0.3–0.5 秒就回来(长段约 1 秒)。现在语文 4.6 秒、数学 17.9 秒。
2. **听得准**:realtime 自带的转写比当时浏览器认的好得多:三个Siri → 三个 three、是否 → 四 four、腿的英语 → 鸡腿的英语、太太太爱心 → 太太太开心、Siri → Sandwich、乘法口诀那段从乱码变成「一一得一,一二得二…」、¥18 → 十八块。认错的:您好 → 银行、强强 → 讲讲。
3. **看得见图**:看图说话那幅图缩到长边 1024(约 128 KB)交进去,问「图上的小朋友在干什么」,答「有的在打乒乓球,有的在跳绳,还有的在踢毽子」,对,首包约 1 秒。一帧上限 262144 字节,长边 1280 的一发整条连接就断(`appendImage` 已拦)。

5. **嘴自己带不了**:
   - 看图说话照 activity 带:开场编了一句「你看板上写着『谁』」、没问问题;之后六轮只接话(「对,他们在操场上。」「哦,是下课的时候。」),一个问题都没问,活动走不下去;最后倒是背出了顺口溜。
   - 没前情时随口接 Ray 的话,数学会算错:「三个人分十四颗,每人三颗,还多两颗」。
