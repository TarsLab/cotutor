## 二、平板:左栏是说话的地方(拍板 22、23)

**为什么挪**:平板横放在桌上,按底边的条太贴桌;手指往下多一点碰到 iPadOS 底部手势,系统抢走这次触摸,浏览器发 `pointercancel`,孩子端当松手发了出去(`kid-page.ts` 里 `pointercancel` 与 `pointerup` 走同一个 `release`),孩子还在说。voice-diag 原来两种都记 `up`,分不出来;现在分开记(`cancel`),用一阵看有多少。

**排法**(1180×760 横屏,Safari 有地址栏时的视口;按视口高 flex 排,不写死):

- **板是主体**:占满整屏、纸色(主题的 `--bg`),不套卡片框;内容从左栏右边排起,往下翻时从浮着的「更多」底下过去。
- **左栏是贴边的一整张白纸**:上、左、下不留边,没有圆角和阴影,右边一道细线加很淡的影子和板分开。
- **字幕占左栏上半**:回首页胶囊下面到按钮上面都是字幕——孩子刚说的那句(蓝字,老师开口后变淡,下次说话换掉)、上一句(淡)、在说那句(大)、「再听一遍」。节头不再是孩子的话(§三),孩子说了什么在这里看。
- **头像和按住说话合成一颗按钮**(312×120):头像在按钮左头,右边是字和波形;按钮中心在屏高约三分之二,离底边约 200,平板横放在桌上手指也碰不到系统的底部手势。上滑取消的门限随按钮高度。脑在写时按钮灰着、头像转圈,按了说「老师在想,等一下再说」。口语课一直听时同一颗是麦克风开关。
- **画板、拍照、相册、打字放最底下**(离底边 20;画板是 10-24 加的,四个一排间距 24,《画板设计.md》拍板 7)。打字时一条输入条贴着软键盘上沿横跨全屏,发出或收起键盘就回去。
- **回首页在左上、「更多」在右上**,左右手一样;回首页那颗放 logo 与老师的首字(§二之三),不放会动的头像——老师是谁、在干什么只在按钮里那一处(手机是字幕那行的小头像)。
- **左撇子镜像**:白纸挪到右边、按钮里的头像在右头、波形往左走。家长在工作台切,存 `cotutor.json` 的 `kid.hand`(`right` 缺省 / `left`),孩子端下次进老师页生效。
- 竖屏平板、手机:照旧底部栏(字幕一行在输入条上方)。板是同一个 `#board`,只是控件位置按端分。

## 二之二、按钮(10-21 下午 iPad 真机后,原型 D、E 排)

真机上 Safari 有地址栏,视口只有约 760 高;原来左栏按 820 高绝对定位,按住说话那块压住了孩子那句,老师的字幕几乎被挤没。Jack 提了四点,就是 §二 的白纸、合成一颗按钮、字幕占上半、小钮放最底下。

**按钮的动画**(原型 E 排,会动;Jack 提「孩子的波往头像走、老师的波从头像往外走」,在这上面加了两处区分):

- **老师在说要收着做**(Jack 10-21:有字幕在变、有声音,动画太强会把孩子的注意力从内容上拉走):头像旁紧挨着三道小弧(像喇叭「)))」),不走动、不缩放,只有深浅跟嘴的音量(最淡约 0.12、最深约 0.45,平滑约 200 毫秒);头像外圈不再一圈圈放大,只慢慢明暗。孩子那边照旧会走——那是他自己在说,要看得见声音收到了。
- **两种声音三处不同**:老师的是**三道小弧**、老师的颜色、朝外(不走动);孩子的是**竖条**、白色(按着时整块是蓝的)、从按钮另一头往头像里走,走到头像就收进去、头像外圈亮一下(老师在听)。只靠方向,小孩瞥一眼分不清;形状和底色也不同,静着看一帧也认得出。
- **跟真音量**:老师的从嘴的声音取(孩子端放音那条链上接一个 AnalyserNode),一声出一道,高低跟音量;孩子的从麦克风音量取(按住时本来就在量),每 60 毫秒一根。没声音就不出——老师两句之间停了就是停了;孩子按着没出声出小点慢慢走,3 秒还没声音小字换成「我还没听到声音」(麦克风坏了也看得出)。
- **不是老师在线说话就不画波**:卡在念、再听一遍、小课堂在放,按钮照安静的样子(按住照样打断它们)。孩子看波就知道是不是能接话的老师在说。
- **各场景**:E1 老师这边(安静、正在叫老师、老师在说、两句之间、老师在想、在看你的图片);E3 孩子这边(按着在说、按着没出声、上滑松手取消、松手收尾、太短 / 没听清、老师在想时按了);E4 别的声音;E5 口语课一直听(在听、孩子说、老师说、孩子插话时老师的声波淡到三成两股对着走、麦关了、轮到你跟读时按钮和单词卡一起呼吸、打电话响铃头像晃)。
- **打断那一下**(E2):按上去不满 150 毫秒什么都不变;满了嘴停、路上的声波 0.15 秒缩回头像、整块变蓝;松手时路上剩下的竖条 0.4 秒走进头像,按钮回灰白、头像转圈。
- 镜像时方向反过来;「减弱动态效果」打开时不走,只跟音量变高低。

各场景都在工作台「工具」里的「按钮样张」一页(`src/lib/voice-scenes.ts`);状态到样子是纯函数 `src/lib/voice-view.ts`,画法一个内联件 `src/server/voice-ui.ts`,页面只给状态和音量(拍板 23)。

## 二之三、空板(原型 F 排,10-21 晚 Jack 看 iPad 截图后)

真机上空板三处别扭:左上角「新话题」小标签没什么用;左栏字幕位在没人说话时填的是老师名字,看着像标题放错了地方;板中间孤零零一句「想问什么?」——板书模式下它和板中间的大头像、名字是一组(老师在问),实时为了一页一张脸把头像藏了,这句就没了主。

原则:**老师对孩子说的话都在左栏,板只放板书。**
- 开场问句(「想问什么?」「换个话题吧,想问什么?」、有 firstQuestion 时下面一行「比如:…」)是左栏字幕位的第一句;名字是它上面一个说话人小标签(老师的颜色),不再单独当一行大字。
- 「接着刚才的:宇宙怎么写 · 14:28」(F2)、今天点过同一个按钮时的「接着刚才那个 / 重新开始」(F3)、口语单拍好的「先热身,再打电话」(F4,没点之前按钮灰着写「点上面开始」)都是老师给的选择,跟在那句下面。
- 板空着就是一张干净的纸;孩子一开口,左栏换成对话的字幕,板上等脑写。
- 去掉「新话题」小标签(空板本身就说明是新话题);「以前的」「接着哪天」那两种照旧有(那时板上是别的日子的东西,要说清楚)。
- 手机(F5):开场问句在字幕行(小头像旁、上面一个名字小标签),「接着刚才的」在它上面一条。
- 不要「xx老师」那行字;老师是谁看返回胶囊:整颗填学科色,logo 后面接老师名字的首字(原型 G1,《产品规划.md》拍板 26);老师页、听写中英文、口语课、舞台四处胶囊一样。


## 三、板交给脑:笔记 + 练习(拍板 20)

**板上现在的杂,多半是应用机械拼的,不是脑写的**:节头 = 孩子原话(只去口头禅,「老师。」「那。」也各成一节);末句是问句就补一张提问卡(抄字幕上那句);不出卡的一轮留讲稿原文(拍板 8)。实时的板不配音,不必跟嘴同步,这三样都交给脑判断。

**一节一件事**:新一节的开头由脑定——它觉得是新的一件事(换了一道题、孩子问了新的),就写一个节头起一节;不是(「没见过」「下一题」以外的追问、交卡、「我不会」)就接着上一节往下长。补读音那道题 10-20 是 2100–2105 五轮,该是一节。

**写法**(提示词与解析器):

- 节头用现成的写法:只有一行 `# 标题` 的文字卡(`text.ts` 的 `heading`,原来是节里的小标题)。实时里它的意思变成「从这里起新一节」,标题就是节头(脑写的一行摘要)。一轮里可以有几个。
- 没写节头的轮,卡接在上一节后面;话题第一轮没写,第一节只有时间。
- 不补提问卡(`board.ts` 的 askCard 实时不跑)。
- 不出卡的一轮板上什么都不留(撤拍板 8 的留讲稿)。
- 卡和讲稿不同步:讲到某句不描边;田字格落下时写一遍;`[词]` 标注、圈、下划线在卡落下时画。`[[play]]` `[[echo]]` `[[say]]` `[[call]]` 管先后,照旧。
- 板上写什么(给脑的话):已经定下来的(讲完的、孩子答过的)记成笔记;要孩子做的出成练习(选择、填空);不抄字幕上那句话;**不写这一步要孩子自己想的答案**(同讲稿「一步一步教」,《agent层设计.md》拍板 21)。
- 板上的字可以比孩子听到的多:脑写板时不知道会不会被打断;打断后多出来的,有重放、有 `cut`。
- 兜底:文字卡里 `= ` 开头的行下发前剥掉、解析器报一条提醒(10-20 21:24「( )穷( )尽 = 山 = 水」:文字卡不剥,答案上了板)。

**孩子端怎么排**:`kid-board.ts` 的 `sectionsFromMessages` 在实时把连着的几轮并成一节,遇到节头卡起新的。

**孩子说的话**:不进板;左栏字幕上方那一行(§二)。孩子说话答问题卡的答案栏(《工作流程.md》拍板 17)实时没有了——没有补的提问卡,选择、填空照旧点着答。

**量**:activity eval(判只看板)加两条:板上没有这一步的答案;节头不是孩子原话照抄。

## 四、字幕重放(拍板 21)

重放是家长提醒着用的(Jack 10-20 前在板书模式里手动放过几次,孩子一次没自己用过),做成左栏字幕下一行小字「↺ 再听一遍」,不做孩子找的大按钮。

- **放什么**:这一轮老师说的,从第一句放(家长的用法是「老师刚讲过了」——是一段讲解,不是一句)。放着时字幕跟着走、前面一个小喇叭,那行变「■ 停」。
- **什么时候有**:安静时(嘴不在说、孩子没按着、脑不在写、卡不在念)。
- **谁打断谁**(《工作流程.md》实时那张表要加的行):安静 · 点再听 → 在重放;在重放 · 按住说话 / 打字发出 / 交卡 → 停,其余同那几行;在重放 · 嘴的声音到了 → 停,放嘴的;在重放 · 点卡上的声音 → 停,念卡;在重放 · 放完 / 点停 → 安静。重放不发任何东西给服务端。
- **声音从哪来**:服务端经手嘴的每一块声音(`call.ts` 的 `onAudio`),每句从哪开始也算得出(`readAt`;一段里第二句起按字数摊,差一点,放的时候往前让 200 毫秒)。按轮落一个文件(`<日期>.<job>.mouth.wav` 加每句的起点),**连孩子按下时清掉的那部分也留**(嘴出声比放快,一段 1.9 秒出完、放 11.6 秒,没放的多半已经出完)。脑写了还没交给嘴、脑还没写的几句没有声音,不补。孩子端走一个新的只读 API 取;录像照旧 call.wav。
- 手机:点字幕那一行同上。更早几轮的重放(点板上的节)以后再说。

## 五、拆掉的(拍板 18、19)

- 卡角「?」:仲裁表那几行、`liveStep` 的 `ask`、孩子端 `.again.ask`、只为它的服务端字段;想问某张卡 = 点开它再按住说(消息带 focus,`liveBody` 已经这样)。有声音的卡留喇叭。
- 占位卡:实时不挂 `wait-card`;等脑看左栏头像(手机看小头像)。

## 七、险

- **脑起节的口味**:起得太勤又回到一轮一节,太懒一节拖一整晚。先看一晚,不行在提示词里给例子(10-20 那段古诗练习就是现成的)。
- **板跑在嘴前面**:板 4–10 秒写完,嘴要念到 15–30 秒,孩子先看到笔记再听到讲。笔记只记定下来的,所以不碍事;练习卡本来就在讲稿末尾用。
- **左栏挤**:字幕长句(实时讲稿不截了,拍板 16)在 300 宽里要换好几行;放不下时上一句先藏,在说那句最多 6 行,再长就滚。
- **镜像之后的手**:右手写字、左手按是右撇子的样子;左撇子镜像以后板在左边,写字的手会不会挡住板,真用看。
