# 看录像:家长端按时间重看孩子的一个话题

> **词**(拍板 2):「录像」= 一个话题按时间排好的一条轨道,说明每一刻板上是什么、老师在说哪句、孩子做了什么;代码里叫 `reel`。**不叫「回放」**:「回放」已经是 `cotutor replay`(evals/,`replayOf`)。
> 代码:`src/lib/reel.ts`(轨道,纯函数)、`src/server/reel-dock.ts`(录像栏)、`src/server/kid-page.ts`(孩子的屏幕的录像模式、`openReel`、实录采集)、`src/server/app.ts`(`/reel`、`/play`、`liveCalls`)、`src/dictation/reel-page.ts` 与 `reel-mode.ts`(听写的录像)、`src/live/recorder.ts`(通话录像)。
> 正文 2026-10-22 收成现状(拍板 23 之后:只认实录);9 月推算期的设计、两期与四次改版的落地记录、原声与 omni 听写都在 git 历史 812491d。

结论先行:**录数据,不录屏幕。** 孩子端页面本来就是「数据 → 画面」:卡在索引里,板书按节画,老师的声音在通话录像里。所以录像只要一条带时间的轨道,放的时候用孩子端那份渲染代码去画。录像 = **孩子的屏幕**(孩子端页面本身,iframe 里的录像模式,只读)+ **录像栏**(进度条、这一刻、经过)。两种轮:

- **实时的轮**照那次通话放:`<日期>.live/<时分秒>.reel.json` + 同名 `.wav`(§3.2)。
- **不是实时的轮**(家长端试发、`cotutor send`、系统开头的)在写完那一刻整节铺上,不出声。

孩子在屏幕上做了什么(弹窗、按住、打字、发照片、翻、切后台、卡的每一次改动)记在 `play.jsonl`(§四)。

## 一、为什么不录屏幕

| 做法 | 不要的理由 |
|---|---|
| 真录屏(getDisplayMedia / 孩子端 MediaRecorder 录画面) | iPad Safari 不支持持续录屏;一个话题几十 MB;跳不到「孩子交卡那一刻」;Claude Code 分析不了 |
| 录 DOM(rrweb 一类) | DOM 是从数据派生的,录派生物又大又脆:页面改一版,旧录像就放不对;还会把孩子打字的中间态一起录下来 |
| 录播放器的输入事件,回放时重跑 `step` | 仲裁表几天改一次,旧录像用新代码重跑会跑出另一个样子 |
| **录结果**(本文) | 板上有什么、说到哪、卡的状态几点变成什么;和代码版本无关,体积按 KB 算,渲染照用现成的 |

## 二、录像用到的数据

| 要还原的 | 来源 |
|---|---|
| 孩子几点开口、说了什么、按了交给老师、带的照片 | 索引消息 `timing.startedAt`、`text`、`action`、`photos`、`via` |
| 孩子在卡上做的(交给老师时) | 消息的 `cards[]` |
| 老师每张卡什么时候出来 | `<日期>.<job>.events.jsonl` 的 `main card` |
| 实时的轮:孩子按下 / 松手、嘴接住、每句开始放的时刻、两边的声音 | `<日期>.live/<时分秒>.reel.json`(每条进出的消息带毫秒,`playing` 是嘴的声音在孩子端放的时段)+ 同名 `.wav`(两边按孩子端的放法混好的一条);`app.ts` 的 `liveCalls` 读 |
| 卡的每一次改动、弹窗、按住、打字、发照片屏、翻、切后台、屏幕尺寸 | 孩子端实录 `<日期>.<job>.play.jsonl`(§四) |

## 三、轨道 `src/lib/reel.ts`

### 3.1 纯函数

`buildReel({messages, events, cards, now, plays?, calls?}) → Reel | null`(一轮都没有才是 null;孩子没开过口的话题也有录像,拍板 17);`reelFrameAt(reel, t)` 给这一刻的节、卡的状态、字幕、浮层、弹窗;`reelClock` 管压过空白的时钟。不碰 DOM、不读盘,`tests/reel.test.ts` 离屏测。和 `kid-board.ts` 一个做法:服务端算好下发,页面把它剥掉类型内联(`src/server/inline-lib.ts`),拖进度条时现算;所以顶层名字都带 reel 前缀,只准从 kid-board 取运行时的东西。记账、整理记忆的轮不进录像(晚上的系统轮,进了会把录像拖到半夜)。

### 3.2 两种轮

- **实时的轮**(消息带 `live`、在通话里找得到 `turn`)走 `callTrack`:孩子按住到松手是原声(clip `voice`,带嘴认成的字),嘴接住是一段嘴的声音(clip `mouth`,带它说的),每句从孩子端开始放它的那一刻(`read`)到下一句或这段放完,下一次按下就截断;卡闭合了就铺(`main:card`)。声音都在那条 `.wav` 里,句与段带 `seek`,页面从 `#t=` 那一处放。孩子端的 play 记录不改这些轮。
- **不是实时的轮**,以及没有通话录像的实时轮(比如服务挂了没落盘),走 `staticTrack`:写完那一刻整节铺上,不出声。

通话录像由 `src/live/call.ts` 在一次通话(一个老师页一条连接)挂了时落盘(`CallRecorder`,`src/live/recorder.ts`)。还没验:家长端真看一次实时话题的录像(拖进度条、倍速时 `#t=` 换段的手感)。

### 3.3 空白压缩

一个话题动不动二十分钟,大半是孩子在想、在做卡,或者走开了。

| 空白 | 真实时长 | 压成 |
|---|---|---|
| 孩子开口 → 老师第一声 | ≤ 10 秒 | 不压,这就是孩子感受到的慢 |
| 同上 | > 10 秒 | 前 10 秒照放,其余压成标签「⏳ 等老师 23 秒」 |
| 老师说完 → 孩子下一次开口 | > 5 秒 | 压成 1.5 秒的标签「⏩ 孩子想了 2 分 10 秒」 |

数在 `REEL_WAIT_KEEP_MS` / `REEL_THINK_MIN_MS` / `REEL_GAP_PLAY_MS`(待定 4)。孩子的动作把空白切开:改卡、开关弹窗前后各留 1 秒照真实时间放,按住、打字、发照片屏的时段算忙;切开的后一段字幕写「⏩ 又过了 N」。录像栏上「跳过空白」开关缺省开着(`role=switch`),关了是完整版,总长跟着变(拍板 14)。

### 3.4 接口

`GET /api/conversations/<老师>/<日期>/threads/<id>/reel` → `Reel` + 这个话题的节(答案不剥)+ `kid`(孩子端条目,剥了答案,铺孩子的屏幕用)+ `device` + `face` + `realtime`(话题里有实时的轮)+ `live`(今天的话题,或有在写的轮)。服务端读索引、events、`scanCards`、play.jsonl、`liveCalls`,再调 `buildReel`;页面不自己读。

## 四、孩子端实录

只记孩子看到、做了什么,不记输入事件(理由见 §一最后一行)。形状是 `PlayRecord`(`src/lib/reel.ts`),验在 `playRecordOk`。

### 4.1 记什么

| 记录 | 从哪来 |
|---|---|
| `stage {job, card, open}` | 弹窗开 / 关(讲稿推上来的也记) |
| `visible {on}` | 切后台 / 回来 |
| `card {job, card, state}` | **服务端** `putCardState` 顺手追加;孩子端发的卡改动不收 |
| `view {w, h, kb, v}` | 进老师页、转屏、键盘起落停手 300 毫秒,变了才记;kb 是 iOS 键盘缩掉的 visualViewport 高(80 以下当 0);v 是页面源码的 hash |
| `hold {e, …}` | 按住说话:down / audio 话筒开了 / slide 进出取消区 / up 松手(`cancel` = 系统抢走了触摸,照旧当松手)/ end 收尾,r = sent · unclear · cancel,lv = 按下起每 100 毫秒一位的音量 |
| `type {e, v?}` | focus / v(300 毫秒一次)/ send / blur |
| `ps {e, tool?}` | 发照片屏:open / tool(crop · pen · rot)/ send / cancel |
| `scroll {job, card, dy}` | 孩子自己拖、滚轮之后停手 400 毫秒,锚在最上面露出来的那张卡 |

节用 job,不用页面里的下标。

### 4.2 存在哪

`conversations/<老师>/<日期>.<job>.play.jsonl`,job 取这个话题当时最后一轮的;卡的改动记进卡所在那轮。`store.deleteThread` 按 `<日期>.<job>.*` 删话题时一起删。

### 4.3 怎么发

- 只在孩子端、今天、能发消息的话题记(以前的只读看、家长端看录像都不记)。新话题发出第一句之前还没话题 id,攒着,有了再发。
- 每 10 秒一批 `POST /api/kid/conversations/<老师>/play {thread, sentAt, records}`,页面隐藏时 `sendBeacon`;一批最多 400 条;发不出去就丢,不重试。
- 服务端按 `sentAt` 把孩子端的钟差校到服务端,只收今天这个话题的、job 在这个话题里的、形状对的;坏的丢掉,不回错(孩子端不报错)。
- mock 的 `/play` 攒在内存给 `/reel` 用。

### 4.4 不录的

- 不按住时的麦克风;按住的那一句流式推给嘴,声音在通话录像里。
- 摄像头画面,只有发出去的照片。
- 点读点了哪段、图片放大拖动。

### 4.5 没发出去的按住(拍板 10)

连着 3 次没发出去、中间没发成一句(开口或打字发出去)成一串 `misses`(`reelMissRuns`,`REEL_MISS_STREAK`,待定 5);上滑取消也算没发出去。进度条每次一个淡点,一串一条;录像栏写「⚠ 按住说话连着 N 次没发出去 · 第 k 次 · 话筒没开 / 话筒没声音」;`/api/overview` 每个话题多一个 `misses`(最长的一串,够 3 次才有),家长清单那一行写同一句。

### 4.7 录像里的弹窗与「想了多久」(拍板 5)

起因:数学老师的答题卡在弹窗里说「右边空 ___ 格」「哪块板凸点多」,弹窗里只有这一张卡,「左边 / 右边」根本看不到;家长要看到孩子当时面对的是什么、在弹窗里想了多久才答。

- **弹窗开、关**照 `stage` 记录:录像里在那一刻只读地打开同一张卡的弹窗,和孩子端同一套渲染;点不动,跟着记录关。
- **孩子在弹窗里的每一步**照 `card` 记录一步步出现:轻卡(选择…)重画弹窗,重卡(画板、讲解动画)重发一次 card 消息;画板在舞台包里按笔数换 key 重装(`src/stage/main.tsx`)。
- **想了多久**(`reelCardTook`):弹窗打开到这张卡第一次改动,减去中间切到后台的时间;之后再改算「改过 N 次」。录像里弹窗开着、孩子还没动时字幕写「⏱ 想了 12 秒」;「经过」里「做了」那条写「想了 12 秒 · 改过 1 次」(这张卡从同一话题上一条消息到这条之间的所有弹窗加在一起)。只在家长接口(`cards[].took`)。只露「想了多久」这一种时长(拍板 1)。

## 五、录像页

- **入口**(拍板 16、19):家长端「记录」里话题那一行点了是 `openReel`,iframe 开 `/reel?tutor=&date=&thread=[&at=][&end=1]`(`MODE.reel`;不叫 `/parent/reel`:孩子端页面里不出现 `/parent`),停在最后一帧不放,退出回清单;`?tutor=&thread=` 直接开那个话题的录像。口语课(2026-10-22 起)就是英语老师的实时话题,同一种录像。
- **孩子的屏幕**(拍板 6、15、20):孩子端页面的录像模式,按 `view` 的尺寸开(没有 view 按 `device`:iPad 横屏 1180×820、竖 820×1180、手机 390×844,转屏中途也跟着变),家长页 `ResizeObserver` 等比缩进上半;整页深底,孩子的屏幕圆角嵌在中间。每 100 毫秒算一次 `reelFrameAt`,板书现画;字幕、浮层、输入条照孩子端自己的画法,这一刻的样子放在 `S.reel.view`,**不写 `S.state`、不 dispatch**(player.test 守着)。实时的轮画成实时老师页的样子:左栏字幕照这一刻,卡角没有钮,标注在卡露出来时就画好。按住浮层照 `hold`(字到这一刻、波形照记下的音量),输入框照 `type`,键盘高在底下垫一块示意键盘,发照片屏照 `ps`,孩子自己翻的照 `scroll`。
- **点不动、停着能翻**:点、按在捕获阶段挡掉,滚动不受影响;一按播放就回到跟着走。
- **跟着长**:`live` 的话题停在最后时每 5 秒重拿一次,轨道长了就接上、停在新的最后。
- **录像栏**(`reel-dock.ts`,拍板 13–15、20–22):不认场景,只经把手(`get / marks / chapters / speeds / play / seek / seekAt / drag / real / speed / stop`)说话。展开 = 「这一刻」那行 + 带点的进度条 + 控制行;收起 = 一行(这台设备记在 `parent-reel-min`)。时间和视频一样,从 0:00 起,当时几点在下面一行小字。一轮一章,⏮ ⏭ 落在章尾。「经过 ▴」展开成事件列表(孩子开口、做了、等老师、孩子想了、弹窗、打字、拍照、没发出去、等孩子、没成、答案、画图给家长的、提醒、记账、整理记忆…),当前那条亮着,点一条跳过去;默认收起。类名带 `rl-` 前缀。版本对不上(`view.v`)标「画法已更新」(拍板 9)。
- **声音**:iframe 放声音用家长页那个 Audio(`window.__cotutorAudio`,家长点开录像时解锁过),不然 Safari 不出声。
- **听写**(拍板 13):`/dictation/reel?id=` 是外壳,iframe 开 `/dictation?reel=<id>`(英文 `&lang=en`),轨道是 `src/dictation/lib/reel.ts`(`drBuild` / `drFrameAt`),一个词一章,同一条录像栏;空白 4 秒以上压成 1.5 秒,倍速 1 / 2 / 4;念的那一刻放 `/api/dictation/<id>/say/<i>`。
