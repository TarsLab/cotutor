# cotutor 家长手册

> 给只想用、不改代码的家长。装好、建一个孩子的老师团、在页面上把老师配好、iPad 上给孩子用。命令只有五条,其余都在浏览器里点。改代码的看《开发者手册.md》。

## 1. 装

需要三样:

- **Node**(≥ 22.18):<https://nodejs.org> 装 LTS 版。
- **一个会说话的 AI 命令行**:Claude Code(`npm i -g @anthropic-ai/claude-code`,登录一次)或 Qwen Code(`npm i -g @qwen-code/qwen-code`)。老师就是它们跑出来的。
- **cotutor**:`npm i -g cotutor`。

可选:**voxtell**(老师的声音,不装就用浏览器自带的声)、**mkcert**(iPad 上按住说话要用,`brew install mkcert && mkcert -install`)。

## 2. 建老师团

```sh
cotutor init ming --name 小明
cotutor doctor
cotutor serve
```

第一条在 `~/cotutor/ming/` 建一个孩子的老师团(孩子端标题是「小明的老师们」):四位老师(数学、语文、英语、画图)、账本、对话目录、一份 `cotutor.json`。第二条逐项体检,不过的每条都带修复命令。第三条起服务,打印两个网址:孩子端 `/`,家长端 `/parent`。

画图老师孩子看不到,它在背后做讲解动画(第 4 章)。

`~/cotutor/ming/` 里全是你家的数据,建议 `git init` 一下,改坏了能回退。

不想先花钱就看看孩子端长什么样:`cotutor mock` 起一份模拟接口,板书、卡、舞台都能点,不经真实老师,也不需要先 init。

## 3. 孩子端 `/`:一页板书

iPad 或任何浏览器打开。孩子先看到的是**首页**:最上面每位老师一张卡,卡上几个按钮;下面是你排的几张卡(要今晚先看一眼的一句话、要再写一遍的字……)。页面上只有这些,没有别的:

![孩子端首页](images/孩子端首页.png)

> 本章三张图都截自 `cotutor mock`(不花钱、不需要 workspace,自己也能开来点)。

老师卡上的按钮就是进老师的门:

- **✨ 新话题**:每位老师都有,永远是第一个。点了是空白的老师页,等孩子开口。
- **↻ 接着刚才的**:今天和这位老师聊过才有,回到今天那个话题接着聊。
- **▶ 开场**(比如「我要预习小蝌蚪找妈妈」)与 **↻ 接着**(比如「接着写看图写话」):是你排首页时定的(5.2「排明天的首页」)。孩子一点,老师页打开,按钮上的字立刻发给老师,老师照你们商量好的讲法开讲;「接着」以前某天的话题,老师会拿到那天最后一节讲到哪、板上有什么。

你还没排过首页(刚装好就是这样),首页就是每位老师一张只有「新话题」的卡,别的什么都没有。

点进去就是这位老师的**板书页**。孩子问一句,老师答一次,板上就多**一节**。

### 3.1 一节是什么样

![板书页](images/孩子端板书.png)

- **卡先铺开**:老师这一节要用的卡一次摆在板上。
- **讲稿一句一句念**:念到哪句,那张卡就**亮起来**(橙色描边),卡上对应的词**画出标注**——正在定义的词绿底、公式和要记住的一句荧光黄、关键数字橙色下划线、选项紫框、标题里的词画圈,线条是当场描出来的,并滚到那张卡。
- **末句是问句就停下**:右下角出现「继续」。孩子可以直接说话回答,也可以点「继续」听下一节。
- **底下那条字幕**就是老师正在说的那句。孩子随时能按暂停。
- **没听清能再听**:一张卡讲完,右上角会出一个小喇叭,点了老师把讲这张卡时说的几句(第一遍念时这张卡亮着的那几句)再念一遍,标注跟着再描;节头(时间 · 节名)念完也有喇叭,点了整节从头念;点字幕上的字,重念那一句。念完回到原来的位置(停下等答的还等着)。老师在想、正在念的时候喇叭是藏着的,不会打断新回答;再听时字幕颜色淡一些、前面有个小喇叭,右边是方块「停」。再听用的是当时的配音,不花钱。

输入条照着孩子熟悉的样子做:**相机 | 发消息或按住说话 | 加号(相册)**。按住说话用的是浏览器自带的识别(Safari 和 Chrome 有,没有就只剩打字)。卡按颜色分角色:蓝是定义与结论,绿是方法,米色是事实与例子,紫是要孩子做的题,深色是封面,白底是公式与图;颜色的值在第 6 章说的主题文件里,能改。平板横屏时一行可以放两三张卡(由老师那轮的「排版」定,手机上自动折成一列)。

### 3.2 点一张卡,进舞台

点板上任何一张能做的卡,它会放大成**舞台**盖住板书那块,讲稿暂停:

![舞台:选择题](images/孩子端舞台.png)

选完、填完、画完,点「交给老师」,老师下一节口头说对不对。**卡上永远不画对错**——对错只在老师嘴里。孩子做过的选择和填的字存在自家电脑上,重开页面还在。

老师这一节的末句是问句、又刚好锚在一张能做的卡上时,舞台会自动打开,孩子不用去找。

### 3.3 卡有九种

| 卡 | 孩子看到什么 |
|---|---|
| 一段字 | 标题卡、要点、公式、一步一步;只看不动 |
| 点读 | 一段一段的文言或课文,点一下念这一段(老师配了音色就是她的声音) |
| 选择题 | 点开是大按钮,选完交给老师 |
| 填空 | 点开逐空输入 |
| 图片 | 点开能放大、双指缩放 |
| 讲解动画 | 点开一步一步画出来(画图老师做的,见第 4 章) |
| 画板 | 孩子自己在上面画:笔、橡皮、黑红蓝三色、撤销、清空(点两下),老师画的底图是灰的、孩子的笔是黑的;点「给老师看」把画交上去,卡上就变成这张画 |
| 田字格 | 一到四个字,一字一格,讲到时逐笔写一遍;孩子点哪个字,哪个字再写一遍 |
| 代码 | 原样的一段文字 |

用哪几种、一节放几张,是老师自己判断的。随口一问就只有一两句话,没有卡。

### 3.4 孩子那边永远没有的东西

没有报错、没有评判、没有工具日志、没有你们家长的对话,也**没有通往家长端的入口**。

到了每天能问的条数上限:字幕行变成「今天聊够啦,明天再来」,首页那位老师的卡变灰。服务没开也是老师卡变灰,不会弹任何错。

### 3.5 iPad / iPhone 上要先做一次

按住说话要 HTTPS,所以第一次要给这台 Mac 签一张证书,再让平板或手机信任它。在 Mac 上:

```sh
cotutor cert
```

它给这台 Mac 签一张证书(放在 `~/.config/cotutor/certs/`,几个孩子共用一张,Wi-Fi 换了 IP 就再跑一次),并打印 `rootCA.pem` 的位置。把这个文件隔空投送到设备上装好,**再到 设置 › 通用 › 关于本机 › 证书信任设置 里把它的开关打开**(装了不等于信任,这一步最容易漏,而且每台设备各做一次)。然后重启 `cotutor serve`,它会打印一行「扫码页」(`https://localhost:<端口>/qr`,在这台 Mac 上打开;`cotutor serve --open-qr` 顺手打开,家长端右上角也有「扫码打开」):用设备的相机扫屏幕上的二维码就进去了,不用输地址;⌘P 打印出来可以贴在书桌上。个别设备扫完一直转圈(主机名解析到了走不通的 IPv6 地址),就点页面最下面的「换数字地址这张」再扫一次。

**加到主屏幕(全屏)**:在 Safari 里打开孩子端之后,点顶部的分享按钮 → **添加到主屏幕** → 添加。以后从桌面那个图标进来就是全屏的,没有地址栏也没有工具栏,孩子按不到别的网页,地址也不用再输第二次。图标是应用自己画的一张橙色小卡片,名字取 cotutor.json 里的 `title`;改了 `title` 之后删掉重加一次才会变。

分设备的完整步骤、要重做的时机、报错对照表在《iPad与iPhone.md》。

### 3.6 老师的声音

装了 voxtell 之后,顶栏「音色」页列出全部音色(近六百个,能按名字、特质、场景搜,按性别、年龄筛)。每一行「试听」是真合成一句(同一句同一个音色只花一次钱),听中了点「给 X 用」就写进这位老师;右上「给谁挑」换老师,上面那行常驻这位老师现在用的是哪个、能「清掉」。试听句可以改成自己想听的话。老师团页里每位老师的「音色」框旁也有「去挑」。配了之后老师的讲稿就用那个声音念,点读卡的每一段也用它;不配就用浏览器自带的声。

### 3.7 按住说话是怎么听的

孩子说的话变成字,这一步**全在浏览器里**,cotutor 的服务不碰声音:

- 用的是 Safari / Chrome 自带的语音识别(中文)。iPad 上是苹果的识别,Chrome 上是 Google 的;声音会经过它们的服务器,cotutor 只拿到识别出来的字。cotutor 不录音、不存声音文件。
- 手感照着孩子熟悉的聊天软件:**按住**输入条 0.15 秒开始听(轻点是打字),**松手就发**出去,不用再确认;说到一半不想发了,手指**往上滑**一下再松开就取消。
- 识别准不准,取决于浏览器自己的引擎,cotutor 改不了。数学口语(「八加五」「三分之二」)和童声是最容易识错的,识错了就打字。
- 三个前提:HTTPS(3.5 那一步)、第一次要允许麦克风、浏览器有这个功能。三样缺一样,话筒就不出现,只剩打字,页面上不会报错。

### 3.8 新话题与以前的

老师页没有顶栏(2026-09-20 起,板书和卡的弹窗因此高出一截):左上角一颗「‹ 头像」的胶囊,点它回首页;右上角是喇叭(老师念不念)和「更多」。空白的老师页中间写着这是哪位老师。看以前的话题、刚开新话题时,头像旁边有一枚小标签说明现在在哪。

从首页进老师页时,话题由点的按钮定(见 3 章开头);进来之后点右上角「更多」,弹出带说明的两项:

- **✨ 新话题**:板书清空,出一句「换个话题吧,想问什么?」。这时什么都还没发生,孩子说出第一句话老师才真的新开一个会话——不带上刚才的板书,也不接着刚才的上下文(老师的记忆和账本照旧在,不是失忆)。回首页或点「以前的」就当没按过。老师还在想的时候按不了。
- **🕓 以前的**:按天列出这位老师的话题(今天、昨天、几月几日),每行是孩子当时的第一句话、时间、几节几张卡。点**今天的**旧话题回到那一页,可以接着聊,老师会接上那个话题的会话;点**以前几天的**只能看:从第一句重新播一遍,卡能点开看当时选的、填的,不能改,底下一颗「回到今天」。列表拉最近 30 天。

家长端对话页里,一天有多个话题时每条消息标「话题 <id>」,话题之间有分隔线;发消息旁的「新话题」勾上就是替孩子新开一个。终端 `cotutor send <老师> "<话>" --new` 同样。

### 3.9 拍作业(2026-09-14 起;发照片屏 2026-09-18 起)

在哪位老师的页上拍,照片就直接给谁——数学作业就在数学老师页拍,不用先经过谁认学科;首页不能拍。输入条左边的相机是直接拍,右边「＋」里有「相册」和「拍照」。拍照一次一张,相册一次最多选 4 张(一份作业的几页一起发)。拿起相机老师就先停下。

拍完、选完先到**发照片屏**,不会马上发出去:
- **裁剪**:拖四个角、拖框平移,「整张」还原,「好了」收下。去掉桌面、只留那道题。
- **圈画**:一支半透明的红笔,「撤销」「清空」。圈出问的是哪道——老师会先讲圈住的那道。
- **转 90°**:拍歪了转正,已经圈的、裁的跟着转。
- **说一句**:按住说(认出的字显示出来,再按住就重说),或点一下打字;× 清掉。不说也能发。
- 几张时下面有缩略图条,点一张切过去改它,角上 × 去掉那张。

「发给老师」:发出去的是改过的样子(裁过、带红圈),原图不另存;说的那句和几张照片是同一条消息,没说话老师那边看到的是「(拍了 N 张)」。传到一半断了,发照片屏不关、改过的都在,再点一次就行。「取消」什么都不发。

板书节头上会回显小图,点小图看大图(双指放大、双击复位,几张左右翻;不打断老师)。老师自己看图认题:第一句会说认出是哪本、哪页、哪道,板书上第一张卡就是原图(或抄下来的题面),一页好几道会列题号问孩子讲哪道。要孩子在自己的作业上圈错题、写答案时,老师会出一张以照片为底的画板卡,点开就能在照片上画,「给老师看」交回去。拍糊了、拍不全,老师会在讲稿里让孩子再拍一张。

照片存在 workspace 的 `captures/<日期>/` 里(不进 Obsidian 仓库,不进 git);晚上记账时日记里只写老师认出的文字——册子、页、题号、题面——不会有照片路径。想看发出去的图去家长端。照片在设备里按原分辨率裁、画,最后缩到长边 2000 再传,一张几百 KB 到一兆出头。

## 4. 画图老师

出厂四位里的一位,孩子看不到它,也不会直接找它。

学科老师碰到「画出来才讲得清」的题(找规律、行程、面积推导这种),会先在板上放一张**讲解动画卡**,卡上写着孩子看不见的题面与讲法。应用看到就自动起画图老师的一轮:它把这道题写成一个一步一步画的课包,配上这位老师的声音,还会派一个小助手照检验单逐帧对一遍。做好以后孩子那张卡自己就能播:

![讲解动画的一帧](images/讲解动画一帧.png)

几件该知道的事:

- **这是这套里最贵的一件**。实测一个课包 4.3 分钟、$0.56;每轮的花费上限 8 美元写在运行时模板里。
- **每天最多做几个由你定**:`scenes.dailyMax`,缺省 2。到了上限,老师照样讲,只是不再起新的动画。
- **做的过程中孩子看到的是「图还在路上」**,做好了那张卡自己变成可播,不用刷新。
- **课包是派生物**:都在 `bundles/` 里,删了可以重做,不进 git。

## 5. 家长端 `/parent`

五个标签(对话 / 老师团 / 音色 / 设置 / 首页;音色见 3.6):

- **对话**:左边是老师,点一位就能说话。顶上那条钉着不动:今天几轮、花了多少、快不快。底下的输入框也钉着,不会被长内容顶走。
  **一轮就是一张卡**,从上到下:谁问的 → 老师在板上写的 → 这轮的用时与花费 → 「孩子看到」→ 画图作业 / 出错的话。中间那块**和孩子看到的板书长得一样**:大标题、带序号的步骤、居中的公式、选择题(正确的那项标着「答案」,只有你看得见)、填空(空里填着答案)、点读的词、图片、讲解动画。讲稿按句编号,句子里老师要在卡上圈出来的词是墨绿色的,最后一句是问句会写「⏸ 停下等孩子」(中间的问句不停);老师这一问没配选择 / 填空卡时,板书最后会多一张「提问」卡,写着这句问话——应用替老师补的,孩子回头能看到老师问了什么。
  老师用了什么工具默认收着,点「转录」才展开——你平时不用看日志。想知道老师原话长什么样、孩子为什么没听到某句,点「看原文」(下面)。
  输入框下有一颗**「📷 照片」**:选一张或几张作业照片,缩略图先排在输入框上(点 × 去掉),按发送就和这句话一起给老师,和孩子在自己那页拍的是同一条路;发过的照片在那轮的问句下面,点开看原图,转录里能看到老师 Read 了哪张。
- **老师团**:**一位老师一行**。改过的设置直接挂在行上(比如「每句 40 字」),没改过的写「全部继承」——谁被你调过一眼就看出来。点一行展开:显示名、学科、头像、音色(旁边「去挑」跳到音色页听着选)、开关、孩子端露不露,还有字数与每日条数这些旋钮;继承的框里是灰字「继承 30」,你写过的会亮起来。行里「老师文件」展开就是这位老师的性子和讲法(一段中文),想让数学老师说话慢一点、多打比方,就在这里改。**＋ 新老师**在标题栏上:填个英文名和显示名,一位新老师就有了。自家加的老师能删,出厂的四位只能关(关了会留在列表里变灰,随手能开回来)。
- **设置**:分三块——路径(Obsidian 仓库、课程表、计划,右边灰字是现在真正用的绝对路径)、服务(端口、证书)、配音。配音那块有个**「试一句」**:按一下就合成一句放给你听,配音没配对当场就知道,不用等孩子那边没声音才发现。升级之后这里顶上可能出现一张「缺 N 项出厂件」的卡,见第 9 章。
- **首页**:孩子端首页的预览、检查、发布,和上次孩子点了什么;怎么排见 5.2。

### 5.1 看原文:孩子为什么没听到那句

每一轮右下角有「看原文」。点开是右边一个抽屉,把这一轮拆成八站,从上到下就是老师那句话走过的路(有卡的轮次多一站「板书后期」,画图老师做出课包的多一站「账本」):

1. **上下文包** — 我们真正发给老师的东西(她看到了档案、入口文件、记忆,哪些计划、哪些最近观察、孩子在卡上做了什么)。
2. **时间线** — 这一轮每道工序(老师、配音、后期)各花了多久。
3. **老师原文** — 老师写回来的原话,每一行右边标着「这句是讲稿、要念」「这几行是一张卡」「这段是给你的、孩子看不到」。哪一行出了毛病,毛病就写在那一行下面。
4. **解析结果** — 我们从原话里读出了几张卡、几句话。
5. **下发给孩子** — 真发出去的那几句(太长被截掉的部分画着删除线,孩子听不到)、每张卡剥掉答案之后的样子。
6. **配音** — 每句话的声音生成了没有;没生成就是孩子端用浏览器自带的声音念。
7. **读了什么** — 老师这轮翻了哪些文件;没翻就是只凭上下文包答的。
8. **转录与报错** — 老师用了哪些工具、出错的原因。

平时用不到。孩子说「老师讲了一半」「那张卡没出来」的时候,从上往下看一眼就知道断在哪一层。

不喜欢点页面也可以直接改 `~/cotutor/ming/cotutor.json`,编辑器会有补全和提示(文件首行指向了一份 schema);改坏了页面顶栏会红字提醒,服务仍用上一份。

### 5.2 排明天的首页

孩子学完以后,在 Mac 上打开终端,进到孩子的 workspace(如 `cd ~/cotutor/ming`),开 Claude Code(`claude`),说「总结一下今天,排明天的首页」。workspace 里装好了技能 `cotutor-home`,它会:

1. **看今天**:读今天每位老师的对话,也看上次的首页孩子点了什么;在对话里给你每位老师两三行总结——学了什么、停在哪、哪里卡住。总结不另存文件。
2. **问你要不要记账**:要留下来的,给话题打星、记账(第 8 章),进 Obsidian 的日记。记账每个话题要老师跑一轮,会先问你。
3. **和你商量下次**:每位老师几个按钮(孩子看到的字,如「我要预习小蝌蚪找妈妈」)、每个按钮给老师的**讲法**(从哪开始、重点、讲到哪收,孩子看不到),再加几张给孩子看的卡。每条带一句为什么,你改到满意为止。
4. **写草稿、检查**:你点头后它写 `home/draft.md`,跑 `cotutor home check`。「要改」的(比如指的话题找不到、首页放不了的卡)它会改掉;「提醒」的(比如哪位老师没写卡)会跟你说。
5. **你看预览**:家长端顶栏「首页」,左边就是孩子会看到的样子(手机 / 平板两种),按钮点了不会真发,只告诉你会发给谁、讲法是什么;右边是检查结果、每个按钮的讲法、上次孩子点了什么。
6. **你说「发吧」才发布**:`cotutor home publish`(或页面上的「发布」)。孩子端刷新就是新首页,不用重起服务。

几件该知道的:

- 草稿、发布过的每一份都在 workspace 的 `home/` 里(`draft.md`、`published.json`、`history/`),不在 Obsidian。想回到以前的某份:`cotutor home publish --from home/history/<那份>.md`。
- 有「要改」的时候不会发布;实在要发,`--force`(或页面上勾「丢掉要改的那几张照发」)会丢掉那几张卡或那几个按钮。
- 首页不会自己过期,几天前发布的照样显示;超过 3 天,家长端「首页」页和 `cotutor doctor` 会提醒你该排新的了。
- 孩子点了哪个按钮,记在那条消息上;`cotutor home show` 或「首页」页的「孩子点了什么」能看到。
- 按钮上的字不算孩子说的话,日记的「孩子问」里不会有它。
- 不想开终端,也可以直接改 `home/draft.md`(写法在 workspace 的 `.claude/skills/cotutor-home/references/首页语法.md`),再在「首页」页点发布。

## 6. 你能拧的旋钮

都在老师团页上(整体的在「全局」卡,某一位的在她自己的卡里,留空 = 跟着全局走)。

| 旋钮 | 缺省 | 管什么 |
|---|---|---|
| 单条回复字数上限 | 60 | 老师讲稿**每一句**的字数,超了在句末截断 |
| 每日消息上限 | 30 | 孩子每天能发几条。点「继续」不算,交答案算;你自己发的不算 |
| 动笔前想多久 | low(数学老师 medium) | 孩子问完到听见第一个字要等多久,主要看这个。`low` = 想得少、开口快(约 10–20 秒);`medium` = 多想一会儿,算题的老师用;`high` = 最慢最细,孩子要多等半分钟以上。老 workspace 升级后数学老师不会自己变成 medium,在她的卡里选一下 |
| 板书 | auto | `auto` = 老师自己判断要不要出卡;`off` = 这位老师只说话,不出卡 |
| 板书后期 | auto | 老师写完一节,一个便宜的快模型(几厘钱、几秒)决定哪个词划重点、用哪支笔、每张卡什么颜色、平板上哪几张并排;`off` = 素版(颜色按种类、一行一张)。`cotutor.json` 的 `policyDefaults.post`:`mode` / `runtime`(缺省 `claude-fast`)/ `timeoutMs`(缺省 10000,超时这一拍出素版) |
| 每天最多几个讲解动画 | 2 | 配在**画图老师**那张卡上;见第 4 章,这是花钱的大头 |
| 孩子端不露 | 画图老师是 | 打开就是「只和家长打交道的老师」 |
| 开启 | 开 | 关掉两个端都看不到这位老师 |
| 音色 | 空 | 见 3.6 |

再往下的旋钮(每轮花费上限、用哪个 AI 命令行、模型)在 `cotutor.json` 的 `runtimes` 里,要用编辑器改——页面上改错一个引号会把老师全弄哑,所以没放上去。

**换皮**:孩子端板书的样子(板的底色、卡的颜色、笔的颜色、圆角、字号)全在 `themes/default/kid.css` 里,是你家的文件,改一个值、刷新页面就有,不用重启。旁边的 `theme.json` 是「槽」的清单(哪几种底色、各给什么用),一般不用碰。想留着出厂的那份做对照,`cotutor add-theme 名字` 拷一份出来改,再把 `cotutor.json` 里 `kid.theme` 改成那个名字就换过去了。改坏了(比如 `theme.json` 少了个引号)服务会先用出厂的那份顶着,`cotutor doctor` 的 `theme.manifest` 会告诉你坏在哪。

## 7. 花多少钱

钱花在 AI 命令行上(你自己的 Claude / Qwen 账号),cotutor 本身不收费也不联网。

| 一次什么 | 实测 |
|---|---|
| 孩子问一句、老师答一节 | 约 $0.1–0.2 |
| 一个讲解动画 | 4.3 分钟、$0.56(上限 8 美元) |

板书后期每轮另算(haiku,约 $0.003,记在「看原文」的「板书后期」站里)。**在哪看**:家长端「对话」标签里,每一轮老师名字旁边有一行「首卡 12.7s · 整轮 15.2s · 配音 16s · $0.10」(首卡 = 孩子看到第一张卡等了多久;整轮 = 老师说完;配音 = 声音也好了),顶部与底部各一行「今日 N 轮 · 费用 $x · 首卡中位 · 整轮中位」。画图老师那轮还多一项「课包 <id>」,课包花的钱与用时也记进账本 `ledger/artifacts.jsonl`。终端里 `cotutor send` 每轮也打印这些。

**怎么封顶**:每天的条数(30 条)、每天的讲解动画个数(2 个)、每轮的花费上限(运行时模板里的 `--max-budget-usd`,问答 2 美元、画图 8 美元)。三道闸都在你手里。

## 8. 你的 Obsidian 仓库

一个孩子一个仓库,设置页把 vault 指到仓库根。它是老师们的长期记忆,也是你手机上翻看的地方。

你写的笔记**靠文件开头的属性认,不靠文件名和目录**——改名、挪位置都不影响。属性名是英文(程序读的),其余随你:

- **档案**(属性 `cotutor: profile`,整个仓库一篇,文件名随意)。`school_start: 2025-09` 写读一年级的年月,老师据此知道现在是几年级哪个学期(9–1 月上学期、2 月寒假、3–6 月下学期、7–8 月暑假;特殊情况直接写 `semester: 二年级上`)。正文写孩子的情况:性格、喜欢什么、要避开什么。每位老师每个话题开头都整篇读到。
- **每科每学期一篇入口文件**(`cotutor: subject`、`subject: 语文`、`semester: 二年级上`;习惯放 `课程/二年级上/语文.md`)。这学期学到哪、常问什么、你想怎么讲,写这里;那一科的老师每个话题开头整篇读到。长的资料另建笔记,在这里 `[[链过去]]`,老师只拿到路径,用到才读。到了新学期要新建一篇(不改上学期的);没建的话老师照常教,家长端那条消息下面会提醒你,`cotutor doctor` 也会说该建在哪。
- **教材**(`cotutor: textbook` + 同样的 `subject` / `semester`,可以没有):一课一节,节下 `页:` `识字:` `写字:` 这些行头;加一段 `### 口径` 写你想怎么讲这一课。老师只拿到路径,讲到才查。
- **记忆**(`记忆/<老师名>.md`,属性 `cotutor: memory`、`agent:`):**老师自己记的**。老师觉得以后用得上的(这个孩子怎么教管用、你在对话里交代的做法),会在回复里写下来,应用加上日期追加到这篇末尾,家长端那条消息下面显示「记住了」;以前记的过时了,老师也会改掉或删掉(这篇里的任何一行,包括你手写的)。你每次点「记账」之后,每位老师还会把自己的记忆整理一遍,合并重复的、改掉过时的,家长端显示「整理了记忆」。你可以随便改、删、分小节,下个话题老师看到的就是你改过的;vault 用 git 的话,整理前后的差别 `git diff` 就看得到。
- `日记/<日期>.md` **老师记的**,一个话题一段:孩子问的话、打分够的话题有一段摘要与讲法骨架(带 `[[教材#单元]]` 链接与课包 id)、几行「- 观察:」。观察行是老师下一轮「最近观察」的来源:你改一句、删一行,下一轮就变;你自己往任何一段里加话都行,老师永不改你的字。
- `课程表.md`,你写(见下)。
- `计划/<周>.md` 你写的周计划(`## 数学老师` 这样按老师分段),每位老师每轮带上自己那段;状态写成 confirmed 才算数。
- `参考/` 你的自由区:题型、薄弱点、政策,怎么分类都行,机器只读不写。

**打分与记账**:家长端每个话题头上有五颗星。学习结束后给值得记的话题打星(4 星起才算「值得」,`vault.keepScore` 可改),再点顶栏的「记账」:每个还没记过的话题老师各写一次,应用把它落进当天的日记;不打分的话题只记孩子问的话。孩子端永远看不到星,也看不到记账那轮。

仓库里**没有**照片和图片:老师认出来的题目文字、册子页号才进日记,能搜得到;jpg 搜不到。作业照片留在 `~/cotutor/<孩子>/captures/`。也没有机器打的标签——标签留给你自己打。

### 8.1 课程表

在你的 Obsidian 仓库里写一个 `课程表.md`:

```markdown
| 星期 | 时间 | 学科 |
|---|---|---|
| 一 | 19:00–19:40 | 语文 |
| 二 | 19:00–20:00 | 数学 |
| 六 | 09:30–10:10 | 英语 |
```

设置页把 vault 指到仓库根、课程表填文件名,孩子端的「一周」就画出来了,老师也知道现在是什么时段。课程表不是必需的,不写就不画时段。

## 9. 升级

```sh
npm i -g cotutor@latest
cotutor init <孩子的英文名>      # 幂等补缺:新版多出来的目录、skill、机器文件;已有的一律不动
cotutor upgrade                  # 老师文件、skill、主题换新版
cotutor upgrade --config         # cotutor.json 补缺:新老师、新运行时、命令模板里的新旗标
cotutor doctor                   # 逐项体检
```

`cotutor upgrade` 把没改过的老师文件换成新版;你改过的一律保留,只打印新旧差异让你自己定(`cotutor upgrade --force 数学老师的英文名` 才覆盖,原文留 `.bak`)。`cotutor doctor` 能看每位老师是出厂件还是你改过的。出厂主题 `themes/default/` 同一个规矩:没改过的换新,改过的不动(想要新版就删掉那个目录再 `cotutor upgrade`,或者先 `add-theme` 把你改的拷走)。

`cotutor.json` 是**你的政策文件**,机器永远不会自己改它。所以新版带来的新老师(比如画图老师)、新运行时、命令模板里的新旗标不会自己出现在你这份里,而且缺了不会报错,只是那个功能悄悄没有。`cotutor upgrade --config` 就是补这个:先 `cotutor upgrade --config --dry-run` 看要补哪几项,确认了再不带 `--dry-run` 跑一次。**只加缺的**,你改过的值(预算、缺省运行时、每句字数、关掉的老师)一个都不动。不想开终端的话,家长端**设置页**顶上会出现同一张提示卡,写清楚缺哪几项,点「补上」即可;`cotutor doctor` 里这条叫 `config.migrate`。

出厂老师改名(比如朗读老师 `reading-tutor` 改成英语老师 `english-tutor`)也走这条,但只能在终端里跑,而且要先停了 `cotutor serve`:它会把这位老师在 cotutor.json 里的那一条(音色、开关都留着;显示名和头像还是出厂的才跟着换)、老师文件、会话目录、对话、头像、vault 里的记忆笔记、首页草稿一起挪到新名字下,`--dry-run` 先列出要挪什么。当天没聊完的话题续不上,新话题不受影响。周计划、课程表里写的是显示名(「## 朗读老师」),要你自己改。

## 10. 不对劲时

先 `cotutor doctor`;想连老师和声音一起真试一下,`cotutor doctor --live`(会花一分钱)。它会把「模型版本不认」「没登录」「配音命令找不到」这些直接说成该做什么。

| 现象 | 多半是 |
|---|---|
| 老师一直在想,然后家长端出红条 | 看红条下面的原因;常见是 AI 命令行版本与模型不匹配,doctor --live 会告诉你怎么改 |
| 有字没声音 | 老师没填音色,或 voxtell 没装(这时用浏览器的声,不算坏) |
| iPad 上没有话筒 | 用了 http,或证书没装信任 |
| 孩子端头像全灰 | 服务没开;只灰一位是今天的条数用完了 |
| 老师只说话不出卡 | 这位老师的「板书」拧到了 off,或者她判断这一句不值得出卡 |
| 讲解动画卡一直是「图还在路上」 | 画图老师那轮没跑成:家长端切到画图老师看那一轮的红条;也可能今天的个数用完了 |
| 点开讲解动画什么都不出现 | 舞台包没打(npm 装的包自带;从仓库跑要 `pnpm run build:stage`),`cotutor doctor` 的 `stage.bundle` 会点名 |

## 11. 你的数据在哪

运行记录全在 `~/cotutor/<孩子>/`:对话(每天一份索引 + 原始记录 + 配音 + 孩子在卡上做的 + 你打的星)、产物账本、课包、作业照片、`cotutor.json`。长期记忆(连同老师的记忆)在你的 Obsidian 仓库(第 8 章)。不上传任何地方;AI 命令行自己怎么联网是它们的事。

## 想给所有老师加一条共同的规矩

老师各自的性格和做法在 `.claude/agents/<老师>.md` 里,想改哪位就改哪份。想一句话管住所有老师(比如「别提考试」),在 workspace 根目录自己建一个 `CLAUDE.md`(用 qwen 的再建一份同样内容的 `QWEN.md`),每位老师每轮都会读到。机器不生成、不覆盖、不检查这个文件;没有它老师也不缺指令。
