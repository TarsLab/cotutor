# 家长端 `/parent`:记录与首页

> 2026-09-22 起。起因:原来的 `/parent`(09-22 起改叫工作台 `/dev`,拍板 13)是桌面页,面向配置与调试;家长拿起 iPad 想看「今天都学了什么、老师怎么讲的、孩子答了什么」,没有一页给这个用。现在 `/parent` 分两块:「记录」(本稿)与「首页」(`/parent/home`,设孩子的首页,《首页设计.md》)。本稿原写的「家长板书页」——用孩子端页面画板书、节与节之间插旁注——10-14 换成了录像(《家长录像设计.md》拍板 16–18),旁注进了录像的「经过」。正文 2026-10-22 收成现状,原文在 git 历史 812491d。
> **词**:「记录」= 家长端看孩子学了什么的那一块。「录像」= 点一件事看到的、孩子当时那一屏照数据重画(《家长录像设计.md》)。「经过」= 录像栏里展开的一条一条:孩子说的、做的、答案、老师写给家长的,孩子的屏幕上没有。

结论先行:**`/parent` 是家长自己的页,孩子端没有通往它的入口;「记录」一天一条时间线,点一件就是它的录像(停在最后一帧),答案、给家长的话、记住了什么在录像的「经过」里。** 数据走家长接口(答案不剥、系统发的话也在),孩子接口不动。家长要试老师现在怎么讲,到孩子端当一回孩子,回来删掉那个话题(§五)。

## 一、为什么不是孩子端「更多」里的一个开关

最初的想法是在孩子端「更多」菜单里放一个面向家长的开关,开了多显示几种「卡」。不这么做,三个理由:

1. **撞约定**。「孩子设备上没有通往家长端的入口」(《产品规划.md》两个端)。菜单里的开关就是入口,孩子一定会翻到。
2. **过滤失守**。记忆条目是老师对孩子的观察,家长尾巴是写给家长的评价,今天它们永远不进 `/api/kid/*`(《契约草案.md》§4,过滤在服务端做)。开关一开,要么孩子接口开始带家长数据,要么孩子页里长出第二条数据流去请家长接口。哪一种都在削「孩子端永远没有评判」这条约定。
3. **词会污染卡的协议**。仓里的「卡」是老师在围栏里写、`cards/<kind>/card.md` 八栏定义、点了进舞台、状态存服务端的东西。孩子的话、记忆改动不是老师写的、没有状态、不进舞台,做成卡种会让 `src/cards/` 注册表与 cotutor-board 技能多出一堆「老师不该写的卡」。

独立路由还有一个好处:后面迭代(家长发消息、打星、拍照)只动这一页,不碰孩子端的仲裁表。

## 二、页面

> 2026-10-10 起家长端分「首页」「记录」两块(拍板 20),两页顶上同一排标签互相跳。孩子端页面里不写家长端的路径,标签的地址从这一页的地址拼(服务端只在家长模式塞进 `MODE.links`)。

### 2.1 入口

- 路由 `/parent`,查询串 `?tutor=<名>&date=<日期>&thread=<话题>` 直开那个话题的录像;都不带就开在今天(2.2)。
- 扫码页多印一个码「家长那张」,工作台 `/dev` 右上角有「家长端」。
- 自己的 manifest `/parent/manifest.webmanifest`(名字「<title> · 家长」),加到主屏幕是单独一个图标。
- 锁:缺省没有密码(学习时把 iPad 交给孩子,学完拿回来);要锁用 `cotutor pin` 设一个机器级 PIN(`src/server/access.ts`,《产品规划.md》拍板 21),别的设备在 `/parent`、`/dev` 上输一次,本机免输。

### 2.2 今天的清单

- 顶上一条七天(拍板 24),以今天结尾:每天下面学科色的点是那天有动静的老师,‹ › 一次翻七天,点一天看那天。
- 下面是这一天的时间线,最新的在最上面,不分老师:左边几点开始、用了几分钟,竖线上的点是老师的颜色,两件事之间隔得久写「隔了 N 分钟」。每件事上半截是孩子在首页点的那一颗(新话题气泡带孩子问的第一句、开场 / 接着的胶囊、小课堂海报、听写格子、口语课),下半截是家长才有的:几节几张卡、停在哪、记过账没有、五颗星、「删」。系统起的话题也列。
- 「这一天老师跟你说的」:iPad 横着在右边,竖着或手机接在时间线后面——老师写给家长的话、记住了什么、听写里要再练的词、日记(记了几个、还有几个没记)和「记账」。
- 按住说话连着三次以上没发出去的话题,行上写「⚠ 按住说话连着 N 次没发出去」(《家长录像设计.md》拍板 10)。
- **删**:点一下变「确定删?」,3 秒内再点才删;`DELETE /api/conversations/<老师>/<日期>/threads/<id>` → `store.deleteThread`:索引里那个话题的消息、会话、星、记账标记去掉,那些轮的文件按 `<日期>.<job>.*` 整个删,老师还在写的 409。这个话题留下的痕迹一起撤(拍板 18):各轮写进 vault 记忆的行倒着撤、记账写进日记的那段摘掉;后来被家长或「整理记忆」改过的找不到就不动,弹一句哪条没撤成。`captures/` 的照片不删。
- 后端不通整页灰,和孩子端一样。

### 2.3 录像

点一件就是它的录像(拍板 22;《家长录像设计.md》拍板 16):孩子当时那一屏照数据重画,停在最后一帧;往前拖或点 ▶ 看过程。原写的「板书 + 旁注」那一页 10-14 删了。

## 三、旁注

原来插在节与节之间的旁注(孩子说的、照片、孩子在卡上做的、答案、给家长的、记住了、记账、提醒、出错),10-14 起是录像的「经过」(《家长录像设计.md》拍板 16)。不放思考摘要、工具行、用时、费用、会话 id:那是调试面,在工作台 `/dev`。例外是录像栏上那一刻的说明:等了老师多久、孩子想了多久(拍板 17)。

## 四、数据与代码

都在家长命名空间下,孩子接口(`/api/kid/*`)与 `kidConversation` 不动。

### 4.1 接口

- `GET /api/overview/<日期>`(或 `today`):2.2 的清单。
- `GET /api/conversations/<老师>/<日期>/threads/<id>/reel`:一个话题的录像(轨道 + 家长条目 + 孩子端条目,《家长录像设计.md》§3.4)。
- `GET /parent` → `kidPage(title, { parent: true })`;录像里孩子的屏幕是孩子端页面本身开在 iframe 里(`/reel`)。

### 4.2 家长条目

由 `src/lib/kid-view.ts` 的 `parentConversation` 出,和 `kidConversation` 同一个循环、对同一份索引,形状同 `KidMessage`,家长多看到的都是可选字段:不剥答案、不丢记账 / 整理记忆的轮、带 `from`、`via`、`parentText`、`remembered`、`warnings`、`error`。

### 4.3 测试

`tests/server.test.ts` 盯着同一份索引下 `/api/kid/…` 的输出不变(护栏)、家长接口答案在、出错的轮有 error、清单;`tests/kid-view.test.ts` 盯着两边的差集恰好是那几个字段;页面走 `scripts/probe-parent.mjs`。

## 五、试效果:到孩子端当一回孩子,回来删

家长改了老师文件的正文、在 vault 里加了一节题型,想看老师现在会怎么讲(拍板 18、19):打开孩子端,当孩子和老师聊;聊完回到 `/parent` 把这个话题「删」掉,它写进记忆、日记的一起撤。在孩子端试,听到的就是孩子的节奏;老师拿到的就是孩子的上下文包,改动在新话题里生效。要拿旧问题比差异,终端里 `cotutor replay`。
