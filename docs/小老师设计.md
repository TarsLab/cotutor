# 小老师:孩子边画边讲,家长和 Claude Code 先看懂,再追问

> 家长端的试验页 `/parent/xlaoshi`:家长出一道题,孩子在 iPad 上边画边讲;家长回看、改转写,在 workspace 根开 Claude Code 写出初步理解和两三个追问,再当面问。第一版 2026-10-09 做了(五屏一页,§三),还在家长这边用,没搬孩子端。代码都在 `src/xlaoshi/`,`app.ts` 的 `route()` 里一行接入;孩子端、家长端清单上都没有入口,地址自己开。原型:<https://claude.ai/artifact/RyBTC8csepmjP4GVCMzcag>。
> 正文 2026-10-22 收成现状;原文在 git 历史 812491d。
> **词**:「小老师」= 给一个题目,孩子在画板上一边画一边讲,讲的是他自己对这道题的理解。不叫「小课堂」:小课堂已经是「做好的课,孩子从头看到尾」。

## 一、为什么值得做

- **小课堂倒过来**。小课堂是老师讲、孩子看;小老师是孩子讲、大人看。形状一样:话 + 画 + 一个时钟。追问时放他自己讲的那一段,费曼法里最难的一步(指着原话问)有现成的路;以后还能导成一堂小课堂(§四 7)。
- **合 ray 的长处**。他有阅读困难、写字有抵触,讲和画是他顺手的两样。
- **笔迹带时刻才看得出的东西**。原型第 4 屏的例子:嘴上说「一个一个地分」,笔迹却是十八个圈一开始就六个一行地画——他先知道了 6,不是分出来的。只看最后那张图、只听转写都看不出来。

## 二、为什么先在家长那边

- **没验证的都是家长兜得住的**:转写认错、录音丢了、模型看错图。孩子端不能露错(约定:孩子端永远没有错误与评判),家长的工具上可以摊开。
- **家长在旁边就是兜底**:追问由家长当面问,不接老师。
- **不碰孩子端**:`kid-page.ts`、仲裁表都不动;不进对话、不进录像。
- **缺口只给家长看**:孩子只看得到问题,问法是「这里我没听懂」,不是「你错了」。政策「孩子的话只作问题,永不进批改路径」删了(拍板 6),约定不动。
- **单开一页,不做进家长板书页**:那页是孩子端页面带家长模式、只看(拍板 3)。地址在 `/parent/xlaoshi`(拍板 5),家长端的锁(`src/server/access.ts`)管着。

## 三、家长那边怎么走(原型五屏)

一页五屏,按 hash 切:`#/` 出题、`#/talk/<id>` 讲、`#/review/<id>` 回看、`#/notes/<id>` 初步理解、`#/ask/<id>/<k>` 追问。

| 一步 | 谁在看 | 做什么 |
|---|---|---|
| 出题 | 家长 | 写题目,「交给他」;下面是讲过的几次和各自走到哪一步。画板只有空白底(拍板 8) |
| 讲 | 孩子 | 点「开始讲」才录;右上一直是「在录 1:08」;浏览器在后台认,**不显示转写**;「讲完了」(十分钟自己停) |
| 回看 | 家长 | 按记下的笔迹现画、放原声;右边转写(浏览器的,或 paraformer 补转的,§五),点一句跳过去,点字就改;能「用 paraformer 重转」 |
| 交给 Claude Code | 家长 | 页上给一句能复制的话;在 workspace 根开 Claude Code 说「读 xlaoshi/怎么看.md,看看 xlaoshi/<id>」,它读 `timeline.md` 与 `frames/`,只写 `notes.md` |
| 初步理解 | 家长 | 页面只读 `notes.md`:讲到了 / 说的和画的对不上 / 还没讲到,各带时刻;勾要问的追问 |
| 追问 | 孩子和家长一起看 | 问题大字;放他讲的那段;录他的回答、让他画一画;家长记一笔(进 `asks.json`,`timeline.md` 末尾「追问的回答」里看得到) |

- 题出了没讲,家长也能记一句(「他说不想录」),这是要验的第一件事。
- 理解放在家长的 Claude Code 里:看图、听长段话的轮次慢,在这里慢不碍事,认错了家长当场纠正。

## 四、代码与数据的边界(原型第 6 张)

1. **一个目录** `src/xlaoshi/`:`route.ts`(页面与接口)、`page.ts`(五屏一页)、`store.ts`(读写目录)、`paraformer.ts`(补转)、`guide.ts`(给 Claude Code 的说明)、`lib/`(笔迹、出帧 PNG、转写、`timeline.md`、`notes.md`,纯函数离屏测);测试 `tests/xlaoshi.test.ts`、`tests/xlaoshi-flow.test.ts`;手动验收 `scripts/probe-xlaoshi.mjs`。
2. **依赖单向**:它引用 workspace 的类型、`RouteResult`、`src/lib/qianwen.ts`(找百炼 key);cotutor 别处一个都不引用它,只有 `app.ts` 的 `route()` 里一行把 `/parent/xlaoshi` 与 `/api/xlaoshi/*` 交给它(xlaoshi-flow 测试兜着)。拆掉 = 删目录 + 删那一行和它的 import。
3. **数据自己一块** `workspace/xlaoshi/<id>/`(id = 日期-时分):`session.json` + `topic.md`(题目、家长记的一句)、`talk.json`(讲了多久、浏览器认出的段、每 100 毫秒的音量、补转的状态)、`strokes.json`(每一笔的点,点带时刻;撤销、清空记成那一笔的 `gone`)、`audio.<ext>`(原声)、`transcript.json`(浏览器的或 paraformer 的,带原因,家长改过的行带 `edited`)、`timeline.md` + `frames/`(由上面几样生成:一句一行、那段画了几笔、那段结束时的画面;服务端自己画 PNG,不加依赖)、`notes.md`(Claude Code 写)、`asks.json` + `asks/`(追问的回答:录音、笔迹、家长记)。不进对话索引、不进录像。整个 `xlaoshi/` 不进 workspace 的 git:服务自己放一份 `xlaoshi/.gitignore`(拍板 10)。
4. **画布不用舞台包**:不走 `src/stage/`(excalidraw,改了要 `build:stage`、会长首屏)。自己一张 `<canvas>` + pointer 事件,「一笔 = 颜色 + 粗细 + 点列」,回放用同一份数据现画。搬去孩子端时再接 drawtell:点列转成手画笔画交给它。
5. **不碰 cotutor.json**:没有开关,在不在看路由在不在。
6. **分析不做出厂技能**:给 Claude Code 的说明在 `src/xlaoshi/guide.ts`,服务列表时写成 workspace 的 `xlaoshi/怎么看.md`(每次覆盖)。出厂技能牵扯 `SHIPPED_SKILLS`、init、upgrade,成熟再说。
7. **留一个出口**(还没做):把一次讲课烤成 `lectures/<id>/`(`video.mp4` + `lecture.md`)——孩子端已经认的形状,导出后小课堂按钮、`lecture` 卡、老师卡的 `讲法:` 都能直接用。

## 五、转写:浏览器先认,不够才叫 paraformer(拍板 7)

- **讲的时候浏览器在认**:`page.ts` 里一次认一句,停了就再起一段;一起就断、连着五回就不再起,只录原声。MediaRecorder 用同一路麦克风录原声(48 kbps)。每段开始的时刻就是转写的一行,不用另外分句。
- **讲完自动看够不够**(`lib/transcript.ts` 的 `needParaformer`),下面任一条成立就把整段原声交给 paraformer、用它那份;都不成立用浏览器那份,不调:
  - 这台没有浏览器识别;
  - 有声没字:音量显示在说话,却 3 秒以上没认出字;
  - 字太少:说了 5 秒以上,一秒不到一个字。
- **家长也能叫**:回看页「用 paraformer 重转」;家长改过的行留着。
- **记一笔**:哪路转的、为什么叫、家长改了几处,进 `transcript.json`,列表和 `timeline.md` 头上都看得到。用这份数据看浏览器那份什么时候就够了。
- **追问的回答也一样**:浏览器没认出字、有录音、拿得到 key,就叫 paraformer 补那一条(`heardBy: paraformer`)。
- **paraformer 怎么调**:ffmpeg 把原声转成 16k 单声道 PCM,走百炼实时识别的 WebSocket(`paraformer-realtime-v2`),约 5 倍速推;长句按词上的句读切成几行。key 用百炼按量那把(Token Plan 没有 paraformer;先看家长端配的,再看 `DASHSCOPE_API_KEY`、本机 qwen、voxtell 的配置,`src/lib/qianwen.ts`),只在内存里用。
- 原声要传到阿里云,和《产品规划.md》待拍板 1(录音数据政策)有关。

## 六、要验的(「成熟」的标准)

| 要验的 | 怎么算过 |
|---|---|
| 孩子愿不愿意讲 | 一次能讲多长、一周几次、录的时候抗不抗拒 |
| iPad 上记笔迹 | 手指、笔都顺,手掌不误触,笔迹和声音对得上 |
| 转写 | 孩子的口语认对多少,家长要改多少字;几次是浏览器那份就够、几次要叫 paraformer |
| Claude Code 找缺口 | 家长认可的比例;只靠转写 + 笔迹时刻够不够,要不要看图 |
| 家长花的时间 | 从讲完到问题写好几分钟;超过十几分钟就坚持不下去 |
| 问法 | 哪几种问题孩子接得住 |

后两项稳到家长基本不用改,才搬到孩子端:先把「讲」交给孩子自己(首页一个按钮),再考虑追问交给老师(导出成小课堂 + `讲法:`),最后才考虑去掉家长那一步。

## 七、没验的

第一版的验收是无头 Chrome 加假麦克风(`scripts/probe-xlaoshi.mjs`)和一段 `say` 合成的中文过真 paraformer。还没验:iPad Safari 真机(浏览器识别和录音同时开、Pencil 与手掌、长讲时段与段之间漏不漏字、m4a 原声的回放与拖动)、真孩子讲、Claude Code 照 `怎么看.md` 写出来的 `notes.md` 好不好用。

## 拍板记录

1. **先在家长那边做,用一段时间,成熟了再搬孩子端**(2026-10-09)。理由:没验证的(转写、笔迹、模型看懂、孩子愿不愿意)都是家长兜得住的,孩子端的约定不允许露错。
2. **代码独立**:`src/xlaoshi/` 一个目录,依赖单向,`route()` 里一行接入;数据在 `workspace/xlaoshi/<id>/`,不进索引、录像、条数(2026-10-09)。
3. **不做进 `/parent`,单开一页**(2026-10-09)。理由:`/parent` 是孩子端页面的家长模式、拍过只看。
4. **叫「小老师」,不叫小课堂**(2026-10-09)。理由:词表里小课堂已经是「做好的课,孩子看」。
5. **路由 `/parent/xlaoshi`**(2026-10-09)。
6. **删掉政策「孩子的话的用途:只作问题,永不进批改路径」,现在就删**(2026-10-09,《产品规划.md》拍板 19)。理由:小老师就是拿孩子的讲解找缺口;这条只写在表里,没有对应的机制。约定「孩子端永远没有错误与评判」不动。
7. **转写浏览器先认,不够才叫 paraformer**(2026-10-09)。理由:浏览器识别不花钱、讲的时候就有、自带每句的时刻;它不够的时候(没有识别、有声没字、字太少)才把原声交给 paraformer,家长也能手动重转。不等 voxtell / koubo 的 transcribe。
8. **第一版画板只有空白底;导出成小课堂后做**(2026-10-09)。理由:先验孩子愿不愿意讲、Claude Code 找得准不准,底图和导出不挡这两件事。
9. **给 Claude Code 读的是 timeline.md + frames/,不是 transcript.md**(2026-10-09)。理由:说的和画的要按时刻摆在一起才看得出对不上;帧由服务端按每句结束的时刻画成 PNG,Claude Code 用 Read 直接看图。推翻 §四原来的 `transcript.md`。
10. **`xlaoshi/` 不进 git;设想稿留在 `docs/wip/`**(2026-10-09)。理由:里面有孩子的原声;设想稿还在验,不进仓。
