# 小课堂:做好的课,孩子看完再和老师聊

> 2026-10-06 起。接替《备课设计.md》(2026-10-05 作废,拍板 46–53)。原型:<https://claude.ai/artifact/5GDjAv7sdm7iBg4YWQDYXA>(六张 iPad 横屏:首页入口、播放中、暂停圈一圈、看完开口、老师回放那一段、家长端)。材料:drawtell `dist/player`(`buildAnimatedSvg`、`computeStepWindows`、`stretchToAudio`、`ChalkBlock`)、ray 的课包 `bundles/2026-09-18-po13-jian-8/`(6 步,`manifest.steps[].line / audioDurationMs / elementIds`,`scene.skeletons[]` 带坐标与文字)、`src/stage/scene.tsx`、`src/server/kid-page.ts`、《家长录像设计.md》(录数据不录屏幕)。拍板在文末。
> **词**:「小课堂」= 一段做好的课(先是 drawtell 课包,以后是视频),老师的声音讲、画面跟着走,孩子从头看到尾。「圈」= 孩子暂停后在画面上圈的一处,带一个时间点。「圈的卡」= 一处圈变成的卡,进板书。

结论先行:**看完再聊**。孩子从首页按钮进来,小课堂铺满放,一口气放完;中途能暂停、拖、圈,不能问。看完了输入条才亮,孩子开口时,圈过的几处一起交给老师。课包的圈由应用算成文字(那一刻在讲什么、圈住了什么),不发图;视频的圈发带圈的截图。老师答的时候不另讲一遍,回到小课堂里放那一段。

## 一、为什么这样

- **讲和聊分开**。10-01 真用:孩子一开口,备好的讲稿就跟不上(《备课设计.md》拍板 36)。小课堂把「讲」整段做好,孩子看的时候不插话;聊的时候老师当场说。拍板 38「素材不配音」只管素材,不管小课堂。
- **答案由小课堂呈现**。课是家长审过的;老师再讲一遍容易讲得不一样。老师先接孩子的话,再把孩子带回课里那一段。
- **孩子指,不用说清楚**。ray 有阅读困难、写字有抵触。说清「哪里不懂」难,圈出来容易。老师拿到确切的时间点和圈住的东西,比孩子转述准。

## 二、孩子那边怎么走

| 一步 | 孩子看到的 | 原型 |
|---|---|---|
| 进 | 首页老师卡上一个「小课堂」按钮:标题、时长、「看完再问老师」 | 1 |
| 看 | 课铺满,老师的声音讲。下面一条进度条:步骤点(点哪个从哪段开头放)、拖动、时间。没有输入条 | 2 |
| 停、圈 | 按暂停才能圈:「圈一圈」「擦掉」「接着看」。进度条上在那一刻留一个蓝色记号 | 3 |
| 看完 | 课收成板书顶上一张小课堂卡(末帧、圈了几处、「再看一遍」);下面一排圈的卡,不想带的点 × 去掉;输入条亮 | 4 |
| 聊 | 孩子按住说话或打字;这一条带上圈的卡。老师照常回一节板书 | 5 |

- **一口气放完**:课包自带的气口(`pauseAfter`)在小课堂里不停。暂停只由孩子按。
- **看完 = 放到过结尾一次**。拖到结尾也算,不防。
- **没问题就走**:没有「看懂了」之类的按钮。看完不问,这一课不进索引(七);首页还能再点进来看。
- **再看一遍**:从头放;圈的卡还在,再圈就多几张。下一条消息带上还没交出去的。

## 三、播放器:cotutor 自己的,不用 `ChalkPlayer`

`ChalkPlayer` 是接力式:一步画完停在气口,只能跳到步开头(「不做段内 scrub」)。场景卡还要这个样子,不动它。小课堂要像视频:一个时钟、拖到任意一刻、知道停在第几秒。用 drawtell 公开的零件在 `src/stage/lecture.tsx` 里拼:

1. `stretchToAudio` 按配音拉长笔画,`buildAnimatedSvg` 画成一张带 SMIL 逐笔动画的 SVG,`computeStepWindows` 给每步的笔画时间窗。
2. **一个时钟**:每段长 = max(这步画多久, 这步配音多久)。课长 = 各段相加。
3. **时刻 → 画面与声音**(纯函数,`src/lib/lecture.ts`):落在第 i 段、段内 `o` 毫秒 → SVG 停在 `min(窗起点 + o, 窗终点 − ε)`(画完了就定格,声音接着讲),这一段的 mp3 从 `o` 放。
4. **拖**:拖的时候 `setCurrentTime` 现画、不出声;松手从那一刻接着放(同家长端看录像)。
5. **一个 `<audio>` 全程复用**:首页按钮那一下解锁;换段换 src(iOS 规矩,同 drawtell)。
6. **两种画面,一个接口**:`{ duration, currentMs, play, pause, seek(ms), onTime }`。课包是 SVG,视频是 `<video>`(第四步)。进度条、时间记号、圈一圈只写一份。

要先真机试:每帧 `setCurrentTime` 在 iPad 上顺不顺;不顺就平时让 SMIL 自己走,只在拖与换段时对一次。声音与画面每段开头对齐一次。

## 四、圈:时间点 + 一条路径

- 时间点记毫秒,显示「分:秒」(1:30);一小时以上才带小时。
- 课包:路径存课包画面坐标(SVG `getScreenCTM()` 反算,屏幕怎么缩放都不碍事)。视频:存画面的 0–1 相对坐标。
- **圈住了什么**(纯函数 `describeMark`,只给课包):
  1. 那一刻在第几段、正在念哪一句(段的 `line`)。
  2. 那一刻画面上已经有的元素:前面各步全部,这一步按笔画时间窗画到哪儿算到哪儿。
  3. 圈的包围盒和元素的包围盒求交:文字元素取文字;课包有 `blocks`(drawtell 的词级命中块)先认块的 `text`;线、框这类没字的,用画出它那一步的 `line` 和离它最近的文字说。
  4. 拼成一段话:「1:30 圈的,那时正在讲『拆开一捆,从 10 根里拿走 8 根』;圈住了:文字『一捆 10 根』和第 1 步画的那捆小棒。」
  5. 圈在空白处、什么都没认出来 → 退回带截图(同视频)。
- 视频:截当前帧,叠上圈,存 `captures/`;再附上那一刻前后的原话(视频有原话时)。

## 五、圈的卡:孩子做的卡,进板书

- 第一种孩子做的卡(`mark`):缩略图 + 圈 + 时间点。不由老师写,老师的围栏里不认它。
- **画法**:课包的不存图,存 `{来源, 时刻, 路径}`,显示时现画那一刻再叠圈(录数据不录屏幕)。视频的存截下来的那张图。
- **位置**:回答它的那一节的开头,在老师的卡前面(像节头回显作业照片,但是一张正常大小的卡)。不并进老师那一节的卡:老师讲稿锚卡用的是自己那几张的编号。
- 看完后、发消息前,在小课堂卡下面排一排,能删。
- 家长端:圈的卡下面一行字,就是老师拿到的那段(课包)或「发了截图」(视频)。
- 老师在讲稿里用嘴指(「你圈的这里」);老师自己再摆出这张卡,放以后。

## 六、老师拿到什么

孩子看完后的第一条,上下文包多一段 `lecture:`:

```yaml
  lecture:
    title: "13 减 8,怎么拆"
    source: "bundle 2026-09-18-po13-jian-8"
    length: "1:40"
    lines:
      - "0:00 先看 13 减 8。13 根小棒,就是一捆 10 根,再加 3 根散的。"
      - "0:18 8 根要从哪儿拿?散的只有 3 根,不够。"
      - …
    watched: "看完了,停过 2 次"
    marks:
      - "0:26 圈的,那时正在讲『8 根要从哪儿拿?…』;圈住了:文字『散的 3 根』和上面的 3 根小棒"
```

- 视频的圈在 `photos:` 里带图,这一轮带工具(读图),会慢;课包的不带。
- 守则(cotutor-tutor)加一节「孩子刚看完小课堂」:先接孩子这句、对着他圈的地方说;别把课再讲一遍;要讲道理,放课里那一段。
- **放那一段**:小课堂卡(`lecture`),老师写 id 与一段时间(`2026-09-18-po13-jian-8 0:34-0:52`),讲稿 `[[play]]` 锚到它:念到那句,放那一段(带原来的声音),放完停在末帧接着念(同素材卡)。时间从 `lines:` 里挑,对齐段的开头。

## 七、数据

- 首页按钮:老师卡里一行 `小课堂 <课包 id> <字>`(`讲法:` 照旧能挂)。首页检查查课包在不在、是不是这位老师的(课包的 `scene.subject` 对老师的 subject,对不上提醒)。
- 孩子在小课堂里没开口之前,索引里没有它;看完不问就走的,哪里都不记(不为家长另记一笔)。孩子第一条消息记 `lecture: { source, watchedMs, finished, pauses, marks[] }`;`marks[]` 一处一条:`{ atMs, path, text? , image? }`。板书顶上的小课堂卡、节头的圈的卡,都从这一条画。
- 一节的卡、讲稿、上限、记忆、记账、删话题全照旧:小课堂之后就是一个普通话题。

## 八、先后

1. **课包小课堂**:首页按钮、播放器(时钟、拖、步骤点、不停气口)、看完才能开口、上下文包 `lecture:`、守则一节。
2. **圈一圈**:暂停后叠一层画笔、`describeMark`、圈的卡(看完那排、节头、家长端)。
3. **老师放那一段**:`lecture` 卡与 `[[play]]`。
4. **视频来源**:`lectures/<id>/lecture.md`(标题、每章时间点与原话)+ `video.mp4`;截图卡。
5. **录像**:看课那一段也进录像(停、拖、圈)。

## 九、要盯的

- 孩子会不会真看完;拖到结尾的多不多(看 `watchedMs` 与时长)。
- `describeMark` 说得准不准:家长端对着截图看那段字。
- 老师会不会忍不住把课再讲一遍。
- 课包是画图老师做的,讲稿没有家长审过的那份细;做小课堂的课包要在 Claude Code 里和家长来回改(技能另写)。

## 拍板记录

**2026-10-06**:

1. **小课堂先做 drawtell 课包,视频第二**。课包的每一步自带讲的原话、配音时长、元素坐标:老师要的文字、进度条的段、圈住了什么都现成;视频要另写原话与时间点。孩子看起来一样。
2. **看完再聊**:看的时候不能问,看完输入条才亮。理由:讲和聊分开(一);答案由课里那一段呈现,不在中途另讲。
3. **圈记时间点,不记第几步**。理由:课包按时刻能算出那一刻画面上已经有什么、在念哪一句,比「第几步」准;课包和视频用同一种记号。
4. **课包的圈只发文字,算不出来才发图;视频的圈发带圈的截图**。理由:带图的轮要用工具读图,慢(10-04 统计:用工具的轮首拍中位数 31.7 秒,不用的 6.8 秒)。
5. **圈的卡是一种卡,进板书**:孩子、老师、家长看的是同一张。课包的存数据现画,视频的存图。
6. **不用 `ChalkPlayer`,在 cotutor 里用 drawtell 的零件拼小课堂播放器**。理由:`ChalkPlayer` 是接力式、不做段内拖动,场景卡还要它这样;drawtell 发版要家长本人;用顺了再整理回 drawtell。
7. **小课堂里不停课包的气口**:一口气放完,暂停只由孩子按。
8. **没有「看懂了」**:看完不问就走。理由:家长不要;多一个按钮就多一轮老师的钱和一条规矩。
9. **老师放课里的那一段**:`lecture` 卡写课包 id 与一段时间,讲稿 `[[play]]` 锚到它,放原来的声音,放完停在末帧接着念(六)。理由:答案由小课堂呈现(拍板 2)。
10. **首页按钮写 `小课堂 <课包 id> <字>`**,和「接着」行同一种写法;首页检查查课包在不在,科目对不上只提醒。
11. **孩子没开口之前不记**:点了小课堂按钮、看完就走,索引、录像都没有它。理由:家长不需要;要开口才有话题,和别的话题一样。
