# 小课堂:做好的课,孩子看完再和老师聊

> 2026-10-06 起。接替 2026-10-05 删掉的备课。原型:<https://claude.ai/artifact/5GDjAv7sdm7iBg4YWQDYXA>(六张 iPad 横屏:首页入口、播放中、暂停圈一圈、看完开口、老师回放那一段、家长端)。材料:drawtell `dist/player`(`buildAnimatedSvg`、`computeStepWindows`、`stretchToAudio`、`ChalkBlock`)、ray 的课包 `bundles/2026-09-18-po13-jian-8/`(6 步,`manifest.steps[].line / audioDurationMs / elementIds`,`scene.skeletons[]` 带坐标与文字)、`src/stage/scene.tsx`、`src/server/kid-page.ts`、《家长录像设计.md》(录数据不录屏幕)。拍板在文末。
> **词**:「小课堂」= 一段做好的课(先是 drawtell 课包,以后是视频),老师的声音讲、画面跟着走,孩子从头看到尾。「圈」= 孩子暂停后在画面上圈的一处,带一个时间点。「圈的卡」= 一处圈变成的卡,进板书。

结论先行:**看完再聊**。孩子从首页按钮进来,小课堂铺满放,一口气放完;中途能暂停、拖、圈,不能问。看完了输入条才亮,孩子开口时,圈过的几处一起交给老师。课包的圈由应用算成文字(那一刻在讲什么、圈住了什么),不发图;视频的圈发带圈的截图。老师答的时候不另讲一遍,回到小课堂里放那一段。

## 一、为什么这样

- **讲和聊分开**。10-01 真用:孩子一开口,备好的讲稿就跟不上。小课堂把「讲」整段做好,孩子看的时候不插话;聊的时候老师当场说。
- **答案由小课堂呈现**。课是家长审过的;老师再讲一遍容易讲得不一样。老师先接孩子的话,再把孩子带回课里那一段。
- **孩子指,不用说清楚**。ray 有阅读困难、写字有抵触。说清「哪里不懂」难,圈出来容易。老师拿到确切的时间点和圈住的东西,比孩子转述准。

## 二、孩子那边怎么走

| 一步 | 孩子看到的 | 原型 |
|---|---|---|
| 进 | 首页老师卡上一个「小课堂」按钮:标题、时长、「看完再问老师」 | 1 |
| 看 | 课铺满,老师的声音讲。下面一条进度条:步骤点(点哪个从哪段开头放)、拖动、时间。没有输入条 | 2 |
| 停、圈 | 按暂停才能圈:「圈一圈」「擦掉」「接着看」。进度条上在那一刻留一个蓝色记号 | 3 |
| 看完 | 课收成板书顶上一张小课堂卡(末帧、圈了几处、「再看一遍」);下面一排圈的卡,不想带的点 × 去掉;输入条亮 | 4 |
| 聊 | 孩子按住说话或打字;这一条带上圈的卡。老师照常回一节板书 | 5 |

- **一口气放完**:课包自带的气口(`pauseAfter`)在小课堂里不停。暂停只由孩子按。
- **看完 = 放到过结尾一次**。拖到结尾也算,不防。
- **没问题就走**:没有「看懂了」之类的按钮。看完不问,这一课不进索引(七);首页还能再点进来看。
- **再看一遍**:从头放;圈的卡还在,再圈就多几张。下一条消息带上还没交出去的。

## 三、播放器:cotutor 自己的,不用 `ChalkPlayer`

`ChalkPlayer` 是接力式:一步画完停在气口,只能跳到步开头(「不做段内 scrub」)。当时场景卡还要这个样子,不动它(场景卡 2026-10-07 删了)。小课堂要像视频:一个时钟、拖到任意一刻、知道停在第几秒。用 drawtell 公开的零件在 `src/stage/lecture.tsx` 里拼:

1. `stretchToAudio` 按配音拉长笔画,`computeStepWindows` 给每步的笔画时间窗。画面是课包烤好的(`bake.json`,drawtell/render 按这一刻每个元素画了多少现画;2026-10-07 起,见拍板 31、34);最早用 `buildAnimatedSvg` 画成带 SMIL 的 SVG。
2. **一个时钟**:每段长 = max(这步画多久, 这步配音多久)。课长 = 各段相加。
3. **时刻 → 画面与声音**(纯函数,`src/lib/lecture.ts`):落在第 i 段、段内 `o` 毫秒 → SVG 停在 `min(窗起点 + o, 窗终点 − ε)`(画完了就定格,声音接着讲),这一段的 mp3 从 `o` 放。
4. **拖**:拖的时候 `setCurrentTime` 现画、不出声;松手从那一刻接着放(同家长端看录像)。
5. **一个 `<audio>` 全程复用**:首页按钮那一下解锁;换段换 src(iOS 规矩,同 drawtell)。
6. **两种画面,一个接口**:`{ duration, currentMs, play, pause, seek(ms), onTime }`。课包是 SVG,视频是 `<video>`(第四步)。进度条、时间记号、圈一圈只写一份。

要先真机试:每帧现画在 iPad 上顺不顺(只改正在画的那一两笔)。声音与画面每段开头对齐一次。

## 四、圈:时间点 + 一条路径

- 时间点记毫秒,显示「分:秒」(1:30);一小时以上才带小时。
- 课包:路径存课包画面坐标(SVG `getScreenCTM()` 反算,屏幕怎么缩放都不碍事)。视频:存视频自己的像素坐标(`videoWidth × videoHeight`;圈的那层 SVG 的 viewBox 就是它,一样反算)。不用 0–1:路由把坐标取整(拍板 21)。
- **圈住了什么**(只给课包;drawtell/core 的 `circleHits` 认、`describeCircle` 说,cotutor 的 `describeMark` 拼上时刻与那句讲稿,拍板 28–30):
  1. 那一刻在第几段、正在念哪一句(段的 `line`)。
  2. 那一刻画面上已经有的元素:前面各步全部,这一步按笔画时间窗画到哪儿算到哪儿。
  3. 元素的取样点过半落在圈里算圈住。认的顺序:课包的分组(`groups`,圈住一组的大半就说组名,「散的 3 根小棒」)> 词级命中块(`blocks`,在 manifest.json)> 带 `label` 的元素 > 文字 > 线、框这类没字的,按第几步、什么、颜色归一堆,附上离它最近的字。
  4. 拼成一段话:「1:30 圈的,那时正在讲『拆开一捆,从 10 根里拿走 8 根』;圈住了:文字『一捆 10 根』和第 1 步画的那捆小棒。」
  5. 圈在空白处、什么都没圈住 → 说离它最近的那样东西(「圈在『3』旁边」);那一带还没画东西就照实说。不退回截图(拍板 13)。
  6. 文字的宽按 drawtell 的字宽表(用真播放器量的手写字体,汉字一个字号宽,数字、字母各有各的宽);新 build 的课包在 `scene.json` 里带 `bounds`,先用它。框、椭圆只认边上的点,圈在框里面的东西不算圈住了框;橡皮那一笔不算东西。
- 视频:截当前帧(canvas 画那一帧、叠上圈,jpeg,长边最多 1280),孩子开口时先传进 `captures/`(同作业照片),消息带路径;那段话只说那一刻在讲哪句、截图是 `photos:` 第几张。

## 五、圈的卡:孩子做的卡,进板书

- 第一种孩子做的卡(`mark`):缩略图 + 圈 + 时间点。不由老师写,老师的围栏里不认它。
- **画法**:课包的不存图,存 `{来源, 时刻, 路径}`,显示时现画那一刻再叠圈(录数据不录屏幕)。视频的存截下来的那张图。
  - 课包的缩略图:播放器装好时把 SVG 原样发给页面;页面克隆一份(id 加前缀,一页多份不串)、`setCurrentTime` 停在那一刻、叠上圈。刷新过、家长端手上没有 SVG,就装一个看不见的舞台(`kind: lecture-svg`)要一份。
- 点圈的卡:从那一刻停着打开小课堂(家长端、以前的话题只看不圈)。
- **位置**:回答它的那一节的开头,在老师的卡前面(像节头回显作业照片,但是一张正常大小的卡)。不并进老师那一节的卡:老师讲稿锚卡用的是自己那几张的编号。
- 看完后、发消息前,在小课堂卡下面排一排,能删。
- 问过以后「再看一遍」又圈了:板书末尾排一排(能删)、写「下次说话会一起带给老师」;下一条消息带上(`again`),那一节前面只画圈的卡。
- 家长端:圈的卡下面一行字,就是老师拿到的那段(课包)或「发了截图」(视频)。
- 老师在讲稿里用嘴指(「你圈的这里」);老师自己再摆出这张卡,放以后。

## 六、老师拿到什么

孩子看完后的第一条,上下文包多一段 `lecture:`:

```yaml
  lecture:
    title: "13 减 8,怎么拆"
    source: "bundle 2026-09-18-po13-jian-8"
    length: "1:40"
    lines:
      - "0:00 先看 13 减 8。13 根小棒,就是一捆 10 根,再加 3 根散的。"
      - "0:18 8 根要从哪儿拿?散的只有 3 根,不够。"
      - …
    watched: "看完了,停过 2 次"
    marks:
      - "0:26 圈的,那时正在讲『8 根要从哪儿拿?…』;圈住了:文字『散的 3 根』和上面的 3 根小棒"
```

- 视频的圈在 `photos:` 里带图,这一轮带工具(读图),会慢;课包的不带。
- 守则(cotutor-tutor)加一节「孩子刚看完小课堂」:先接孩子这句、对着他圈的地方说;别把课再讲一遍;要讲道理,放课里那一段。
- **放那一段**:`lecture` 卡,老师写 id 与一段时间(`2026-09-18-po13-jian-8 0:19-0:30`),讲稿 `[[play]]` 锚到它:念到那句,放那一段(带原来的声音),放完停在末帧接着念。时间从 `lines:` 里抄,应用对齐到段界(拍板 16)。写法在 `cards/lecture/card.md`,机制在《卡片协议.md》「小课堂卡」。

## 七、数据

- 首页按钮:老师卡里一行 `小课堂 <课包 id> <字>`(`讲法:` 照旧能挂)。首页检查查课包在不在、是不是这位老师的(课包的 `scene.subject` 对老师的 subject,对不上提醒)。
- 孩子在小课堂里没开口之前,索引里没有它;看完不问就走的,哪里都不记(不为家长另记一笔)。孩子第一条消息记 `lecture: { bundle, title, watchedMs, finished, pauses, again?, video?, marks[] }`;`marks[]` 一处一条:`{ atMs, svgMs, path, text?, image? }`(`svgMs` 是缩略图停在 SVG 的哪一刻;`text` 是给老师的那段话;`image` 是视频的截图,`captures/` 里)。孩子端下发不带 `text`,家长端带。截图不记进消息的 `photos`(节头不重复回显),只进上下文包。板书顶上的小课堂卡、节头的圈的卡,都从这一条画。
- 一节的卡、讲稿、上限、记忆、记账、删话题全照旧:小课堂之后就是一个普通话题。
