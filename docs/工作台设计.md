# 工作台设计

> 2026-10-16 起。工作台 `/dev` 是给有技术背景的家长与开发者的桌面页(《产品规划.md》「工作台」),之前没有自己的设计语言:蓝灰配色、顶上一排标签,和已经成形的孩子端、家长端不像一家。本文定它的样子、概览页的数字怎么算、activity 页怎么改。设计稿 <https://claude.ai/artifact/4dV77o7wD2A5Z3nhwphgCV>(四屏 + 一张规范)、activity 页 <https://claude.ai/artifact/Srg1Pe4z51iUbei1TxNtLp>(四屏)。拍板在文末。代码:`src/server/dev-theme.ts`(色板与基本件)、`dev-page.ts`(页面)、`dev-overview.ts`(概览的数)、`dev-activities.ts`(activity 页的接口)、`qr-page.ts`、`voice-test-page.ts`、`voice-gallery-page.ts`。

## 一、设计语言「纸面控制台」

骨架照常见的云控制台(左边分组的侧栏、浅底、大圆角白卡、上面一排常用入口、下面数字卡),颜色与字从家长端、孩子端来。五条:

1. **同一张纸**。纸 `#F5F3EE`、墨 `#2B2B2B`、橙 `#B4531F` 与家长端同源;状态色取孩子端主题的 tints(moss / sand / sky)外加一个砖红。
2. **白卡浮在纸上**。内容进 18px 圆角白卡;侧栏直接坐在纸上,不画竖线。层级靠底色,不靠阴影。
3. **数字一律等宽**。耗时、钱、token、job、路径、时刻都用等宽 + tabular-nums,上下对得齐。
4. **颜色只干三件事**。橙 = 主操作、当前位置的强调、改过的值;tint = 状态;学科色 = 老师(只画在头像的缺口环上)。别的都是墨与灰。
5. **出错照直说**。孩子端没有对错,工作台有:慢、回退、失败都写成字(状态签、一句人话 + 一行原文),不只靠颜色。

按钮两种实心:橙是「写进去」(保存、发送),墨是「跑一次」(记账、重跑)。其余是白底描边的次要钮、橙底浅色的「看原文」、砖红字的危险钮。

色板、字号、圆角都是 `dev-theme.ts` 里的变量(`--ground` `--surface` `--accent` `--ok` `--warn` `--info` `--err`、`--mono`、`--r-card` 等);页面样式只用变量,不写死颜色。四页(`/dev`、`/dev/qr`、`/dev/voice-test`、`/dev/voice`)把 `DEV_CSS` 放进自己 `<style>` 的最前面。

## 二、布局

- **侧栏**(232px,手机上变成顶上一条横排):品牌、workspace(标题 + 根目录)、概览、对话;「老师」组:老师团、activity(有写坏的亮红点)、音色;「工具」组:扫码打开、按住说话试验、按钮样张(新标签页);「去看」组:孩子端、家长端(新标签页);设置;底下常驻服务状态(在线、起了多久、版本;cotutor.json 改坏了变红)。当前那项白底浮起,不用橙。
- **概览**(缺省进这页,`#overview`):常用六格、今天 / 近 7 天 / 用量三张卡、老师今天(表)、要看一眼 + 体检。
- **对话**:老师一列(淡的 = 孩子端不露)、顶上老师名与这天的合计、中间消息流(灰底里一轮一张白卡)、底下输入卡。一轮的五段不变(问句、板书、埋点、孩子看到 / 给家长、通知块)。
- **看原文**:不再是右边的抽屉,盖住侧栏右边整块,像一页:面包屑(对话 / 老师 / 时刻)、标题、job、左边几站、右边内容。`Esc` 或「关」回对话,地址照旧是 `#chat?raw=<job>`。
- **activity**(`#activity?a=<老师>/<名>` 直达):左边按老师列、中间原文、右边检查 / 老师收到什么 / 和出厂比,见第四节。
- **老师团 / 音色 / 设置**:页头一行标题,下面白卡。头像统一成家长首页那个缺口环(学科色)+ 白脸。
- **按钮样张**(`/dev/voice`,《wip/实时老师设想.md》拍板 23):孩子端实时老师页那颗「头像 + 按住说话」的每一种样子摆在一页上,用的是真的按钮(`src/server/voice-ui.ts`)和真的状态 → 样子(`src/lib/voice-view.ts`),场景表是 `src/lib/voice-scenes.ts`(加一种场景在那里加一格,测试与这一页都跟着有);声音是模拟的(老师一段一段说、孩子说说停停、按着没声音),最上面一颗自己循环「打断的那一下」,有镜像开关。改动画只改 voice-ui.ts 开头的调参表,开这一页看全部。按钮自己的颜色是孩子端的,页面其余照工作台的色板。
- **设置**:路径、服务、配音、孩子端。孩子端一栏只有「惯用手」:右手(缺省)/ 左撇子,写 `cotutor.json` 的 `kid.hand`;左撇子时平板横屏实时老师页的左栏白纸(连按住说话那颗按钮)挪到右边、按钮里头像在右头(《wip/实时老师设想.md》拍板 22、23)。kid 的别的字段照旧直接编辑文件。
- **音色页两半**(2026-10-19):页头切「板书配音」(voxtell 的音色,写 `tutors.<老师>.voice`;板书时讲稿与卡的声音,实时时只管卡自己的声音)/「实时的嘴」(百炼 realtime 认的 56 个,`src/live/voices.ts`,写 `live.voices.<老师>`)。实时那半多一行总开关(`live.enabled`)、「给谁挑」只列有脸的老师、按方言筛;试听是真让嘴照念一句(`/api/tts/realtime/preview`,存在 `.cotutor/live-preview/`),「清掉」= 这位老师回到板书。

## 三、概览的数

`GET /api/dev/overview`(`dev-overview.ts`)每次现读近七天各老师的会话索引,只读不写:

| 数 | 怎么算 |
| --- | --- |
| 轮 | 只算孩子的话(`from: kid`);记账、整理记忆这类应用派的任务(`from: system`)另记「应用的任务 N 轮」 |
| 首句就绪中位 / 整轮中位 | 今天孩子那些轮的 `timing.firstReadyMs`(没有就 `firstCardMs`)/ `doneMs` 的中位数 |
| 慢的 | 首句就绪(没有就首卡)超过 15 秒,与对话页埋点染色同一条线 |
| 用量 | 近七天按运行时分:报钱数的(claude)记美元,只报 token 的(qwen)记输入 / 输出 token;任务也算 |
| 画图 | 今天画了几张 / `paint.daily` |
| 老师今天 | 每位开着的老师:今天几轮、首句中位、最近一轮;运行时是今天最后一轮用的,没跑过显示 cotutor.json 配的 |
| 要看一眼 | 近七天出错的、慢的、带提醒(`warnings`)的轮次,新的在前,最多 8 条;点一条直达那一轮的看原文 |

体检是 `POST /api/dev/doctor`:跑一次不带 `--live` 的 doctor(不起老师、不配音、不花钱),都好只说一句,有毛病的一项一行(说明 + 修法),全部折起来。要真连老师跑一句仍在终端 `cotutor doctor --live`。

没有的数不编:Token Plan 的余量、口语课通话分钟现在都拿不到,不放。

## 四、activity 页

activity 是孩子从首页一个按钮进去的一种做法,一个 activity 一个文件,在老师的家里(`agents/<老师>/activities/<名>.md`,形状见 `src/schema/activity.ts`)。这一页看、改已有的;新建、改名、删在 workspace 里和 Claude Code 说(cotutor-tune)。

- **列表**:按 cotutor.json 的老师排,每个标状态——出厂(和包里一样)、改过、可升级(没改过,是旧版出厂的)、自家的(不是出厂的)、N 处要改(检查过不去)。下面一行是首页上几个按钮用它、几个例子;听写这种不起老师的写进哪一页。例子文件(`<名>.例子.md`)不当 activity 列。
- **原文**:直接改 md,参数不做表单(文件本来就写给人读)。上面一排是节,一节一个读者(家长填的 / 应用算的 / 应用拦的给你,老师怎么带是老师的系统提示,画家收到什么给百炼文生图),点了跳过去。行号旁:橙 = 没存的改动,红 = 要改,黄 = 提醒;底栏写光标那一行的问题。实现是透明的 textarea 叠在逐行底色层上,两层同字、同宽、同折行,textarea 跟着内容长高、不自己滚。
- **检查**:边改边查(停手 300 毫秒,`POST …/check`,不落盘)。带行号的问题点了跳过去;参数、应用算的、拦法、卡、工具人一张表;首页上用到它的按钮,每个按这份解析,解析不出的标「孩子端不出」;最下面是回归命令(`cotutor activity eval`,花钱,只给命令不在网页跑;没例子的给 `cotutor send --activity`)。
- **老师收到什么**:选首页某个按钮(缺省是参数最多的那个)或自己填参数,看按参数裁好、注释剥掉的「老师怎么带」——这个话题老师的系统提示(qwen 的 `systemBody`、claude 的 `--agents`),后面再接这几种卡的板书写法;工具人那节原样列出,插槽由应用填。
- **和出厂比**:按行比出厂那份(含没存的),点一块跳到那一行;「恢复出厂」只换这一个,原文留 `.bak`(`restoreActivity`,和 `cotutor upgrade --force <老师>/<名>` 同一条路,但不碰别的)。
- **存**:⌘/Ctrl + S 或「保存」。存了就生效:下一轮起照新的带,正在进行的话题也换(activity 每轮现读)。有要改的先问一句:首页上用它的按钮孩子端先不出、进行中的话题下一轮照这份带。存的时候带读进来时的 hash(`PUT`,`base`),磁盘上那份变了(Claude Code、编辑器改过)回 409,页面亮「撞车」条、停住保存,能「看那边改了什么」或「丢掉我的,重读」。页面没改动时别处改了,切回窗口或每 10 秒看一次,悄悄读进来。
- **只认列得出的名字**:接口路径里的老师与名字要在 `listActivities` 列出的那些里,不拼路径。
- **新话题 = 老师文件**(拍板 11):列表里每位老师先是一行「新话题」(工具人叫「老师文件」),改的是 `.claude/agents/<老师>.md`——不走 activity 的话题(首页的新话题、开场按钮、隔天接着一个不是 activity 的话题)老师照它带。同一个编辑器、同一套撞车保护,接口另走 `/api/dev/tutor-files/<老师>`(`src/server/dev-tutor-files.ts`),只认 cotutor.json 里有的老师。不一样的地方:节是「头」(给 CLI 的 frontmatter)、「开头」与正文里每个 `##`;检查只查 frontmatter 在不在、`name` 是不是老师键、正文空不空,cotutor.json 的键与两家 CLI 不都认的键只提醒;**有要改的不让存**(老师文件写坏了这位老师整个起不来,没有首页护栏兜着);首页上照它带的列新话题与开场按钮;老师收到什么是去掉 frontmatter 的正文(后面接板书写法),下面折着话题第一条带的守则(机器件,这里不改);回归给 `cotutor replay`。存了新开的话题照新的带,正在聊的那个老师可能还照旧的(claude resume 沿用会话开始时的系统提示,《agent层设计.md》拍板 10 的更正)。老师团页行里的「改老师文件 →」跳到这里。
