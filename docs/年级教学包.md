# 年级教学包

面向中国大陆小学一至六年级,当前出厂只提供二年级。其他年级由后续贡献补齐。老师与 activity 按年级独立维护,不引入提示词继承系统。

## 三个信息来源

| 信息 | 真相 | 用途 |
|---|---|---|
| 孩子当前年级、学期 | vault 档案 `school_start`,可用 `semester` 覆盖 | 按现有机制推算,挑选学科入口文件 |
| 已安装教学包 | `.cotutor/shipped.json` 的 `teachingPack.grade` | init、upgrade、恢复出厂、工作台出厂差异选择来源 |
| 已学内容、教材版本、实际能力 | 学科入口文件、教材、本次材料和回答 | 决定这节内容与提示程度 |

选择教学包不修改孩子档案。`kid.grade` 旧字段不参与教学包选择。学期变了只提醒,不自动覆盖文件、不切换正在进行的话题。

## 文件与加载

```text
grades/grade-2/
  README.md
  agents/
    chinese-tutor.md
    chinese-tutor/activities/预习.md
    chinese-tutor/activities/预习.例子.md
    math-tutor.md
    math-tutor/activities/...
    english-tutor.md
    english-tutor/activities/...
  examples/                         可选的课包与使用说明
```

`cotutor grades` 列出完整的可安装包。目录名仅认 `grade-1` 到 `grade-6`,包需有 README、三位老师文件和各自的 activities 目录。没有注册表。

`cotutor init ming --grade 2` 选择出厂来源,未指定时新 workspace 默认二年级并明确提示;已有 workspace 沿用已安装包。不存在的年级在写文件之前拒绝。

安装后的路径不变:

- 老师: `agents/<老师>.md`。
- activity 和例子: `agents/<老师>/activities/<名>.md`。
- 普通聊天读老师文件;activity 独立使用自己的「老师怎么带」。
- 名字、头像、音色、运行时、档案仍按现有机制共享。

示例课包供家长选择安装,不会自动发布首页。图片例子的包内退路也按已安装年级定位。

## 升级与旧 workspace

- 无 `teachingPack` 字段的历史出厂内容固定归为二年级来源,不随未来新安装的默认年级改变。只读时不写回,init / upgrade 时补记。
- 补记时保留全部旧 hash。未改过的旧文件按旧 hash 更新,改过的保留并展示差异。
- 无 hash 的不同内容继续当自定义处理,不把家长文件重新认作出厂件。
- 技能、主题写清单时保留教学包来源;恢复出厂仍备份原文为 `.bak`。
- 来源字段损坏、已选年级在当前包中不存在时,报错并停止出厂文件操作,不静默回退。
- doctor 检查包可用性、旧来源待补记、档案学期与包年级不一致。后两项是提醒,不是阻止日常使用的条件。

**更新版本与切换年级不同。** 当前只有二年级包,暂不提供原 workspace 的年级切换命令;init / upgrade 都拒绝借参数切换。新增年级后,跨年级切换需另做可预览的迁移:备份、逐文件处理自定义冲突、保留旧包供已有话题使用。不能直接改 `teachingPack.grade` 冒充迁移。

## 二年级内容

三科分别有独立的预习、批改、复习文件,入口名称一致、具体教学步骤不同。

- 预习:根据材料接触一个新内容,完成一小步即可。
- 批改:核对已写答案,一次订正一处;模糊照片先补拍,空白题按求助处理。
- 复习:依据明确范围或学习记录,少量回忆与运用;不凭年级随机出题。
- 语文:新增生活写话;看图说话的旧 ID 保留,按钮可以显示「看图写话」。
- 英语:口语课根据热身表现调整难度,不把二年级等同于初学英语。
- 数学:小课堂保留看完课后问答的行为,典型题型通过配套课包提供;不自动加测。

工具识别与画图的代码兜底提示词不假设年级;有 activity 时仍优先用其工具段落。

## 英语运行设置

英语 `qwen-flash` 在 `effort: low` 时偶尔只出卡、不写讲稿,或把材料判断过程念出来。完整示例能改善但没有消除。新 workspace 保持同一个模型,将英语老师的 `policy.effort` 设为 `medium`;会增加思考时间。

旧 workspace 的配置仍不自动覆盖。使用这些新活动时,建议在 `cotutor.json` 的 `tutors.english-tutor.policy` 中设置 `"effort": "medium"`,并在自己配置的模型上跑例子。教学包本身不绑定模型。

## 贡献与验证

贡献某一年级时,独立写该包的老师与 activity 文件,可参考二年级但要改教法和例子。不能只把「二」替换成另一个数字。README 说明适用范围、教材/进度前提、可用 activity、已做和未做的验证。

activity 的文件形状、参数与检查命令见 [写提示词](写提示词.md)。

公共协议与守则留在现有代码和技能里;年级教法写在老师及 activity 的完整文件中。activity 不继承老师正文,两边都需要检查。

评估支持「每节有讲稿」:拒绝只有卡、空回复和没有轮次,避免孩子看到卡却听不到下一步。

每个新 activity 至少包含:

1. 输入材料、第一句、教学步骤、结束条件。
2. 缺少材料、给定范围后多轮互动、孩子想停的例子。
3. 不清楚照片、不会、已经会了等适用的边界例子。
4. 静态检查结果,以及真实模型评估和人工看输出的记录。

例子评估先发送 activity 名字,再发送 `孩子:` 行;要验证第一句孩子的话,`最多轮` 至少为 2。

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm build:stage
pnpm smoke
cotutor activity check --workspace <试用目录>
cotutor pack math-tutor --activity 批改 --param '范围=23 + 18 = 31' --workspace <试用目录>
cotutor activity eval math-tutor 批改 --runs 3 --workspace <试用目录>
```

真实评估会调用模型并产生费用,记录保留在试用 workspace 的 `evals/`。自动检查只覆盖部分行为,需要人工核对有没有泄题、加题、误判转写或替孩子写作。

2026-10-27 的代码与模型验证结果见 [二年级验证记录](../grades/grade-2/VALIDATION.md),包含修正前的失败、修正后的定向复验及尚未做的真人验收。
