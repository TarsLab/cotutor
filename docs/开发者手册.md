# cotutor 开发者手册(2026-09-11)

> 面向改仓库的人:从检出到家长端聊三轮、孩子端在 iPad 上按住说话,每步写了「看到什么算对」和「不对时看哪里」。只想用不想改代码的家长看《家长手册.md》。设计与拍板见《产品规划.md》,仓库怎么长的见根目录 CLAUDE.md,这里只讲怎么跑。

## 0. 准备

| 要什么 | 怎么确认 | 备注 |
|---|---|---|
| Node ≥ 22.18 | `node -v` | bin 直跑 src,不用构建 |
| `claude` 或 `qwen` 至少一个 | `claude --version` / `qwen --version` | 本机 claude 2.1.220 不认全局 settings 里的模型,**运行时模板要加 `--model sonnet`**(第 2 步会改) |
| voxtell(配音,可选) | `voxtell doctor` | 没发 npm,从 [TarsLab/voxtell](https://github.com/TarsLab/voxtell) 检出后 `pnpm i && pnpm add -g .` 让它进 PATH;不配就用浏览器的声 |
| mkcert(iPad 上录音要,可选) | `mkcert -CAROOT` 能打出目录 | 没有:`brew install mkcert && mkcert -install` |
| 本仓 | `git clone https://github.com/TarsLab/cotutor && cd cotutor && pnpm i && pnpm test` | 22 个测试文件全绿再往下;要看孩子端还得 `pnpm run build:stage`(舞台包,dist/ 不在 git 里) |

下文的 `cotutor` 都指本仓的 `bin/cotutor.js`。首次用 pnpm 全局命令要先 `pnpm setup`(把 `~/Library/pnpm/bin` 写进 shell 配置)并重开终端;然后在仓库根 `pnpm add -g .` 一次,`cotutor` 就在 PATH 上(pnpm ≥ 10 已删掉 `pnpm link --global`;bin 直跑 src,改完代码不用重链);不想污染全局就 `alias cotutor='node <检出目录>/bin/cotutor.js'`。

**在 Claude Code 会话里试**要先 `unset CLAUDECODE CLAUDE_CODE_ENTRYPOINT CLAUDE_CODE_SESSION_ID CLAUDE_CODE_CHILD_SESSION CLAUDE_PID CLAUDE_EFFORT`,否则老师起不来(嵌套会话被拒)。在普通终端里不用管。

## 1. 建 workspace

```sh
cotutor init ming --name 小明 --port 5180
```

看到什么算对:`~/cotutor/ming/` 下有 `cotutor.json`、`CLAUDE.md`、`QWEN.md`、`agents/<六位老师>/`、`ledger/`、`conversations/`、`scenes/` `bundles/` `snaps/`,`.claude/agents/` 里六个老师文件(拷自仓库 `agents/*.md`,是你家的,想改口气直接改)、`.claude/skills/` 里四个领域 skill(拷自 drawtell-skills,画图老师用),`.cotutor/` 下有 `shipped.json`(出厂 hash)、`板书语法.md`(给老师看的卡语法表,机器文件)、`drawtell`(壳脚本)。重跑一次全是 `exists` / `kept`,不会覆盖你改过的东西;仓库更新后跑 `cotutor upgrade`,没改过的老师文件换新,改过的只打印 diff。
`cotutor.json` 是政策文件,机器不改它,所以新版多出来的老师、运行时、命令模板旗标要 `cotutor upgrade --config`(先 `--dry-run` 看)补,doctor 里这条叫 `config.migrate`。

顺手 `cd ~/cotutor/ming && git init && git add -A && git commit -m init`:老师记忆、账本、政策都是不可再生状态,改坏了靠 git 回退。

## 2. 改 cotutor.json

用编辑器打开 `~/cotutor/ming/cotutor.json`,改四处:

1. **模型**:`runtimes.claude.run` 与 `runtimes.claude.resume` 两个数组末尾各加 `"--model", "sonnet"`。
2. **音色**(想听声音才改):`tutors.math-tutor` 里加 `"voice": "qwen-audio-3.0-tts-plus-longhongxinxu"`(`voxtell voices --grep 女` 能查别的);`tts.say` 出厂就是 `voxtell say …`,voxtell 在 PATH 上(第 0 步 `pnpm add -g .`)就不用动;没链的话把前两项改成 `"node", "<voxtell 检出目录>/bin/voxtell.js"`。
3. **vault**(有 Obsidian 仓库才改):`paths.vault` 指到孩子的 vault 根,`paths.timetable` 写课程表文件名(如 `"课程表.md"`)。不配就相对 workspace 根,课程表放 `~/cotutor/ming/timetable.md` 也行。
4. 其余不动。`_note` 里有每个字段的说明。

课程表格式(表头 星期 / 时间 / 学科,孩子列可选):

```markdown
| 星期 | 时间 | 学科 |
|---|---|---|
| 一 | 19:00–19:40 | 语文 |
| 二 | 19:00–20:00 | 数学 |
| 六 | 09:30–10:10 | 英语 |
```

想让「今天」立刻有高亮时段,临时加一行 `| <今天周几> | 00:00–23:59 | 数学 |`。

## 3. 体检

```sh
cotutor doctor
```

必需项(✗)全过才能往下;`!` 是建议。这几项现在应该是:`cotutor.json` ✓、`config.migrate` ✓(老 workspace 会点名缺的出厂件,见 §1)、六位老师的 `.claude` 文件 ✓ 与 `origin`「出厂件,最新」、`board.syntax` ✓、`stage.bundle` ✓(打过舞台包才有)、`drawtell` ✓、`skill.*` 四条 ✓、`timetable` ✓(写了几个时段)或「没有课程表」、`https` !(还没签证书)、`tts` ✓ 或 !、`runtimes.claude` ✓。每条不过的都带修复命令。

## 4. 起服务,先在 Mac 上试

```sh
cotutor serve
```

打印两个地址(本机名与局域网 IP),孩子端 `/`,家长端 `/parent`。没证书时走 HTTP,会提醒一句 iPad 录音要 HTTPS,Mac 上不影响。

### 4.1 家长端 `/parent`

浏览器开 `http://localhost:5180/parent`:

1. 左栏是开着的老师(含孩子看不到的规划老师),点「数学老师」。
2. 底部选身份「家长」、运行时「claude(缺省)」,输入「我家孩子二年级,42-17 这种退位减法总错,该怎么讲?」,⌘+Enter 发。
3. 看到什么算对:发出去的话在上面,下面出现「老师在想……」,十几秒后出现老师的话(主线说话)、末尾「本轮结束 · N 轮 · $x」,再下面一行绿色「孩子看到:……」——那是孩子端会听到的讲稿(正文里的普通段落,一行一句;围栏是板上的卡,后面会写「板书 N 张卡 M 句」)。
4. 再发两条:「那用数轴讲怎么讲?一句话说给孩子听」「妈妈说的数轴我不懂」(身份切成「孩子(模拟)」)。页脚「会话 xxxxxxxx(claude)」三轮都是同一个 id,回复接得上前文,就是 resume 通了。
5. 运行时切「qwen」再发一条:会新开会话(id 变),再发一条又 resume 上;切回 claude 也一样。
6. 若老师回复里带「## 待裁量」段,会渲染成黄卡 + 选项按钮;点一个按钮 = 以家长身份回一句「待裁量「…」:选「…」」。
7. 老师用了工具会折成「用了 N 步工具」,子代理的话折成「子代理 · N 条」;出错是红条,下面附 err.log 尾巴。
8. 老师写了「## 转交」段的那轮会多一行「转交 → 画图老师:…」,后面跟「已起 scene-maker 的 <job>」(runner 自动起了目标老师的一轮)或「没起(见提醒)」;孩子在板书上做过的选择与填空显示成「孩子在板书上做的:…」,带正确答案。老师名字旁一行「首卡 Xs · 整轮 Ys · 配音 Zs · $c」(索引里的 `timing`,整块出的运行时没有首卡);首尾各一行「今日 N 轮 · 费用 $x · 首卡中位 · 整轮中位」,末行还带「会话 …」。scene-maker 那轮多「课包 <id>」,`ledger/artifacts.jsonl` 里多一行 `costUsd` / `durationMs`。

顶部「老师团」标签:每位老师一张卡,改显示名 / 头像 / 音色 / 开关 / 孩子端不露 / 政策覆盖(留空 = 继承),点「保存」写回 cotutor.json;把「朗读老师」的「开启」勾掉保存,回到「对话」标签它就从左栏消失了,孩子端也没了。全局卡能改标题、缺省预设、政策缺省。在编辑器里直接改 cotutor.json 也行,服务每个请求都看文件时间,改坏了顶栏会红字提示、仍用上一份。

### 4.2 孩子端 `/`(先在 Mac 的 Safari 或 Chrome 看)

孩子端从 2026-09-10 起不是聊天窗,是**板书页**:老师回一次 = 板上一节,卡先铺开、讲稿一句句念、笔跟着声音标注、末句问句停下来等孩子。下面按这个形态走一遍。

**先打舞台包**:`pnpm run build:stage`(esbuild 把 `src/stage/` 打成 `dist/stage/`,场景卡的 drawtell 播放器 + 画板卡的 excalidraw 编辑器)。包是**拆开**的:`stage.js` 只有 21K,其余在同目录一百多个 `chunk-*.js` 里按需取(命令会打印「打开舞台先下多少」);真开一次场景舞台下 3.4MB、画板舞台 1.5MB。没打的话轻卡照常、重卡点开什么都不出现,`cotutor doctor` 的 `stage.bundle` 会点名。npm 装的包自带,改了 `src/stage/` 要重打。

> 想自己量:无头 Chrome 开 `--remote-debugging-port`,`Network.setCacheDisabled` 之后导航到 `/stage/?bundle=/api/bundles/<id>/&autoplay=1`,把 `Network.loadingFinished` 的 `encodedDataLength` 加起来。**别在孩子端页面那层量**——舞台在 iframe 里,页面那层的 Network 事件不含它。

**不花钱先看形态**:`node bin/cotutor.js mock`(不需要 workspace,`--scenario limit|offline` 换场景)。语文老师三节走完 点读 → 选择题 → 填空 → 画板,数学老师第三节是一张场景卡(课包样本在 `tests/fixtures/bundles/`)。调试参数:`/?tutor=chinese-tutor&step=<节>.<句>` 停在某句,`&stage=<节>.<卡>` 直接开舞台。下面第 1–3 步在 mock 里就能验,第 4 步起要真 workspace。

1. **首页**:一排老师头像(不含 hidden 的规划与画图)、「今天可以问」三个话头、今天的时段、一周小路(课程表里有课的日子一站,今天最大;没课程表就只有今天)。
2. **一节**:点「语文老师」→ 打字「画蛇添足是什么意思?」回车。看到什么算对:先出「让我想想…」,老师那轮跑起来后**卡一张张露出来**(流式:`--include-partial-messages` 的增量喂 `parseBoard(partial)`,只追加卡、不播),整轮跑完这一节转正,再**从第一句开始念**;念到哪句底部字幕就是哪句,句子里 `[方括号]` 标的词在卡上画出橙色标注并滚过去。末句是问句 → 停下,右下角「继续」。
3. **舞台**:点选择题卡 → 盖住板书那块、讲稿暂停、大按钮;选一个 → 「交给老师」。字幕行回显「你:A …」,接着老师的下一节。填空卡逐空输入;点读卡每段点了念(老师配了 voice 的,那轮跑完几秒后各段 mp3 陆续落在 `conversations/<老师>/<日期>.<job>.cards/<n>/`,没生成好之前是浏览器合成声);图片卡双指缩放;画板卡画完「给老师看」导出 png。`Esc` 或右上角 × 关舞台。
4. **真老师**(要 workspace,花钱):`cotutor serve` 后开 `http://localhost:5180/`,问「25加17等于多少」。随口一问就该是一两句话、没有卡;问「三角形面积怎么算」这种才该出卡。回 `/parent` 看同一轮:绿色「孩子看到:」后面跟着「板书 N 张卡 M 句」,孩子在卡上做过的显示成「孩子在板书上做的:…」并带答案。
5. **状态是孩子的、存服务端**:交完答案重开孩子端页面,选中的、填的还在(`conversations/<老师>/<日期>.<job>.cards/<n>.json`,不进索引、可以删)。
6. **场景卡**:数学老师碰到要画的题会放一张场景卡 + 写「## 转交」,runner 自动起画图老师那一轮(见 §4.1 的「转交 →」)。做好之前卡上是「图还在路上」,做好后孩子端下一次轮询就能播(4 分钟、半美元量级,`scenes.dailyMax` 缺省 2)。
7. **断网与上限**:`Ctrl+C` 停掉服务 → 5 秒内所有头像变灰、板书页退出,没有任何报错文案;重新起又恢复。老师团页把「每日消息上限」改成 1 保存,孩子端再发一条后字幕行变「今天聊够啦,明天再来」、首页头像灰(点「继续」不算数,交答案算)。记得改回来。
8. **平板横屏**:窗口拉宽到 1100 以上,板书排两列、没有左栏(无头截图:`--force-device-scale-factor=2 --window-size=1180,820`;手机版式用 `--window-size=780,800`,窗口最小宽约 500,直接写 390 会被裁)。
9. **孩子端不该有的**:搜页面源码,`/parent`、「错误」、工具名都不该出现;孩子设备上没有通往家长端的入口(2026-09-10 拍板,原来的「家长 · 长按」已删)。

## 5. iPad 真机(R0 第 2 项也在这一步)

1. Mac 上签证书:`cotutor cert`。它用 mkcert 把本机名、`.local` 名、局域网 IP、localhost 都签进机器级的 `~/.config/cotutor/certs/`(证书是这台机器的,不是孩子的,所有 workspace 共用;IP 变了只重签一次),并打印根证书位置(`mkcert -CAROOT` 下的 `rootCA.pem`)。单个 workspace 要用别的证书才配 `server.https`。
2. 把 `rootCA.pem` 隔空投送到 iPad → 设置 › 已下载描述文件 › 安装 → 设置 › 通用 › 关于本机 › 证书信任设置 › 打开那条。这是 iPad 信任自签证书的唯一办法,一台 iPad 做一次。
3. 重启 `cotutor serve`,这次打印的是 `https://…`。
4. iPad Safari 开 `https://192.168.1.5:5180/`(用 serve 打印的那个 IP;Mac 与 iPad 同一 Wi-Fi)。锁屏图标正常、没有证书警告就对了。加到主屏幕会去掉地址栏。
5. 点数学老师,**按住话筒说一句**:第一次 Safari 会问是否允许麦克风。看识别出来的字准不准、松手有没有发出去、几秒后有没有听到回答——这三个观察写回《产品规划.md》R0 第 2 项。
6. 若识别根本不出字:说明 iPad 这版 Safari 的语音识别不可用,先用打字,voxtell transcribe 要提前做(产品规划里写的备选路)。

识别的逻辑(`src/server/kid-page.ts` 输入条那段,搜 `SpeechRecognition`):全在浏览器,服务端没有语音接口。`pointerdown` 起 150ms 定时,到点才算「按住」(轻点走打字),先停老师的配音,再 `new SpeechRecognition()`(`zh-CN`、单句 `continuous: false`、`interimResults: true`,每次 `onresult` 把所有片段拼成当前文本);松手 `stop()`,`onend` 时文本非空就直接 `send()`,不经确认;按住时上滑 60px 标 cancelled,松手改走 `abort()` 并卸掉 `onend`。`onerror` 静默。没有 `SpeechRecognition` 构造器、非 HTTPS、或没给麦克风权限,输入条只剩打字。声音不落盘、不经过 cotutor,识别质量与语言由浏览器决定;要换成自家识别(voxtell transcribe)就是把这段换成录音 + 上传,接口还没有。

## 5.5 加一位自家的老师

```sh
cotutor add science-tutor --display 科学老师 --subject 科学 --avatar 🔬
```

它写 `.claude/agents/science-tutor.md`(模板带着出厂老师的全部约定,正文里有一句括号提示让你填这位老师的性子)、在 cotutor.json 的 `tutors` 里加一条、建 `agents/science-tutor/`。服务不用重启,两个端刷新就多一位;`cotutor doctor` 里它的 `origin` 行是「自家加的老师」,`cotutor upgrade` 永远不碰它。不要了就删文件加删配置那条。

## 6. 终端里发一条(不开页面)

```sh
cd ~/cotutor/ming
cotutor send math-tutor "42-17 怎么讲?"           # 家长身份
cotutor send math-tutor "为什么要借位" --from kid  # 孩子身份,算进每日上限
cotutor send math-tutor "再讲一遍" --preset qwen  # 换运行时
```

打印孩子看到的那句、待裁量 / 转交段(若有)、会话 id 与费用。和页面走的是同一条路,只是同步等它说完。

## 8. 不对时看哪里

| 现象 | 看 | 多半是 |
|---|---|---|
| 家长端发出去一直「老师在想」然后红条 | 红条下的 err.log 尾巴;或 `conversations/<老师>/<日期>.<job>.err.log` | 没加 `--model sonnet`(API Error 400 版本不够);在 Claude Code 里没 unset `CLAUDECODE` |
| 回复出来了但没有声音 | err.log 里「cotutor tts: 没合成(…)」 | `tts.say` 指的 voxtell 不在 PATH;老师没配 voice(这时用浏览器的声,不算错) |
| 孩子端没有话筒 | 浏览器 | 没有 `webkitSpeechRecognition`(Firefox),或 iPad 上用了 http |
| iPad 打不开 https | 证书信任设置 | 根证书没装或没打开信任;IP 变了要重签 `cotutor cert`(证书在 `~/.config/cotutor/certs/`,与 workspace 无关) |
| 老师头像全灰 | `cotutor serve` 还在跑吗;`/api/health` | 后端不通;或每日上限到了(只灰那一位) |
| 顶栏红字「cotutor.json 改坏了」 | `cotutor doctor` | JSON 少个逗号;服务仍用上一份 |
| 课程表没画出来 | `cotutor doctor` 的 timetable 项 | 表头缺列、时间格式不对,都带行号 |
| 重卡(场景 / 画板)点开一片空白 | `cotutor doctor` 的 `stage.bundle` | 没跑 `pnpm run build:stage`;改了 `src/stage/` 也要重打 |
