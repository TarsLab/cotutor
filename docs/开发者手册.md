# cotutor 开发者手册(2026-09-11)

> 面向改仓库的人:从检出到家长端聊三轮、孩子端在 iPad 上按住说话,每步写了「看到什么算对」和「不对时看哪里」。只想用不想改代码的家长看《家长手册.md》。设计与拍板见《产品规划.md》,仓库怎么长的见根目录 CLAUDE.md,这里只讲怎么跑。

## 0. 准备

| 要什么 | 怎么确认 | 备注 |
|---|---|---|
| Node ≥ 22.18 | `node -v` | bin 直跑 src,不用构建 |
| `claude` 或 `qwen` 至少一个 | `claude --version` / `qwen --version` | 本机 claude 2.1.220 不认全局 settings 里的模型,**运行时模板要加 `--model sonnet`**(第 2 步会改) |
| voxtell(配音,可选) | `voxtell doctor` | 没发 npm,从 [TarsLab/voxtell](https://github.com/TarsLab/voxtell) 检出后 `pnpm i && pnpm add -g .` 让它进 PATH;不配就用浏览器的声 |
| mkcert(iPad / iPhone 上录音要,可选) | `mkcert -CAROOT` 能打出目录 | 没有:`brew install mkcert && mkcert -install` |
| 本仓 | `git clone https://github.com/TarsLab/cotutor && cd cotutor && pnpm i && pnpm test` | 22 个测试文件全绿再往下;要看孩子端还得 `pnpm run build:stage`(舞台包,dist/ 不在 git 里) |

下文的 `cotutor` 都指本仓的 `bin/cotutor.js`。首次用 pnpm 全局命令要先 `pnpm setup`(把 `~/Library/pnpm/bin` 写进 shell 配置)并重开终端;然后在仓库根 `pnpm add -g .` 一次,`cotutor` 就在 PATH 上(pnpm ≥ 10 已删掉 `pnpm link --global`;bin 直跑 src,改完代码不用重链);不想污染全局就 `alias cotutor='node <检出目录>/bin/cotutor.js'`。

**在 Claude Code 会话里试**要先 `unset CLAUDECODE CLAUDE_CODE_ENTRYPOINT CLAUDE_CODE_SESSION_ID CLAUDE_CODE_CHILD_SESSION CLAUDE_PID CLAUDE_EFFORT`,否则老师起不来(嵌套会话被拒)。在普通终端里不用管。

## 1. 建 workspace

```sh
cotutor init ming --name 小明 --port 5180
```

看到什么算对:`~/cotutor/ming/` 下有 `cotutor.json`、`CLAUDE.md`、`QWEN.md`、`agents/<六位老师>/`、`ledger/`、`conversations/`、`scenes/` `bundles/` `snaps/`,`.claude/agents/` 里六个老师文件(拷自仓库 `agents/*.md`,是你家的,想改口气直接改)、`.claude/skills/` 里四个领域 skill(拷自 drawtell-skills,画图老师用),`themes/default/`(孩子端的主题:`theme.json` 槽的清单 + `kid.css`,拷自仓库 `themes/default/`,是你家的),`.cotutor/` 下有 `shipped.json`(出厂 hash)、`板书语法.md`(给老师看的卡语法表,机器文件)、`drawtell`(壳脚本)。重跑一次全是 `exists` / `kept`,不会覆盖你改过的东西;仓库更新后跑 `cotutor upgrade`,没改过的老师文件换新,改过的只打印 diff。
`cotutor.json` 是政策文件,机器不改它,所以新版多出来的老师、运行时、命令模板旗标要 `cotutor upgrade --config`(先 `--dry-run` 看)补,doctor 里这条叫 `config.migrate`。

顺手 `cd ~/cotutor/ming && git init && git add -A && git commit -m init`:老师记忆、账本、政策都是不可再生状态,改坏了靠 git 回退。

## 2. 改 cotutor.json

用编辑器打开 `~/cotutor/ming/cotutor.json`,改四处:

1. **模型**:`runtimes.claude.run` 与 `runtimes.claude.resume` 两个数组末尾各加 `"--model", "sonnet"`。
2. **音色**(想听声音才改):`tutors.math-tutor` 里加 `"voice": "qwen-audio-3.0-tts-plus-longhongxinxu"`(`voxtell voices --grep 女` 能查别的);`tts.say` 出厂就是 `voxtell say …`,voxtell 在 PATH 上(第 0 步 `pnpm add -g .`)就不用动;没链的话把前两项改成 `"node", "<voxtell 检出目录>/bin/voxtell.js"`。
3. **vault**(有 Obsidian 仓库才改):`paths.vault` 指到孩子的 vault 根,`paths.timetable` 写课程表文件名(如 `"课程表.md"`)。不配就相对 workspace 根,课程表放 `~/cotutor/ming/timetable.md` 也行。
4. 其余不动。`_note` 里有每个字段的说明。

课程表格式(表头 星期 / 时间 / 学科,孩子列可选):

```markdown
| 星期 | 时间 | 学科 |
|---|---|---|
| 一 | 19:00–19:40 | 语文 |
| 二 | 19:00–20:00 | 数学 |
| 六 | 09:30–10:10 | 英语 |
```

想让「今天」立刻有高亮时段,临时加一行 `| <今天周几> | 00:00–23:59 | 数学 |`。

## 3. 体检

```sh
cotutor doctor
```

必需项(✗)全过才能往下;`!` 是建议。这几项现在应该是:`cotutor.json` ✓、`config.migrate` ✓(老 workspace 会点名缺的出厂件,见 §1)、六位老师的 `.claude` 文件 ✓ 与 `origin`「出厂件,最新」、`board.syntax` ✓、`stage.bundle` ✓(打过舞台包才有)、`drawtell` ✓、`skill.*` 四条 ✓、`timetable` ✓(写了几个时段)或「没有课程表」、`https` !(还没签证书)、`tts` ✓ 或 !、`runtimes.claude` ✓。每条不过的都带修复命令。

## 4. 起服务,先在 Mac 上试

```sh
cotutor serve
```

打印两个地址(本机名与局域网 IP),孩子端 `/`,家长端 `/parent`。没证书时走 HTTP,会提醒一句平板 / 手机录音要 HTTPS,Mac 上不影响。

**什么时候要重启**:只有 `cotutor.json` 是热的(每个请求看它的 mtime,改了立刻生效,家长端改的、`cotutor upgrade --config` 补的、`cotutor add` 加的老师都不用重启)。两个页面和 runner 是代码,`serve` 起来时就编进进程,**改了 `src/` 下任何东西都要 Ctrl+C 重起**,浏览器刷新是看不到的。老师文件(`.claude/agents/*.md`)每轮起进程时现读,改了下一轮就生效,也不用重启。

### 4.1 家长端 `/parent`

浏览器开 `http://localhost:5180/parent`(调试:`?tutor=math-tutor` 直接停在某位老师,`#chat?raw=<job>` 直接开某一轮的「看原文」):

1. 左栏是开着的老师(含孩子看不到的规划与画图,灰点标出来),点「数学老师」。顶栏钉着:老师名、日期选择、今日合计(轮数 / 费用 / 首卡中位 / 整轮中位 / 会话)——合计只在顶栏印一次。
2. 底栏也钉着(只有中间消息流滚动):输入框 + 身份 / 运行时 / 话题三颗下拉。输入「我家孩子二年级,42-17 这种退位减法总错,该怎么讲?」,⌘+Enter 发。
3. 看到什么算对:**一轮 = 一张卡**,从上到下五段——问句(孩子蓝 / 家长橙 / 系统灰)、**板书**、埋点一行、「孩子看到」、通知块。板书是**按 kind 渲染的卡片**,不是围栏原文:`text cover` 是大标题、`text step` 带序号圆点、`text formula` 居中等宽、`choice` 列选项并给正确项打「答案」、`fill` 把空画成下划线填上答案、`read` 一段一个小块、`image` 直接显示、`scene` 显示课包 id 与「打开看看」。讲稿按句编号,句里 `[方括号]` 标的词染成墨绿,末句问句后面缀「⏸ 停下等孩子」。
4. 埋点那一行:老师名 + 「首卡 Xs · 整轮 Ys · 配音 Zs · $c」(索引里的 `timing`,整块出的运行时没有首卡;首卡超 15s 染琥珀)+ scene-maker 那轮的「课包 <id>」。右边两个按钮:**看原文**(下面 4.1.1)与**转录 N**(工具行、子代理,默认收着——家长默认看不到日志)。
5. 「孩子看到」压成卡底一行(讲稿拼起来 + 「板书 N 张卡 M 句」);老师写的「## 家长」尾巴单独一行橙标签「给家长」。
6. 通知块各有颜色:**待裁量**琥珀带选项按钮(点一个 = 以家长身份回一句)、**转交**墨绿带目标老师与课包 id 和「已起 scene-maker 的 <job>」、**出错**砖红带 err.log 尾巴、**提醒**(warnings)灰。
7. 再发两条验 resume:顶栏「会话 xxxxxxxx」三轮同一个 id;运行时切 qwen 会新开会话(id 变)。话题下拉选「＋ 新话题」= 不接上文,多话题时消息流里有「—— 新话题 HH:MM ——」分隔。

#### 4.1.1 看原文:一轮拆成六站

每轮右下角「看原文」开右抽屉(`Esc` 关,地址栏会变成 `#chat?raw=<job>`,刷新还在)。调试时要回答的不是「老师写了什么」,而是**「这一层是谁吃掉的」**——孩子没看见那张卡,可能是老师没写、可能 `kidSource` 没挑中那一段、可能 `parseBoard` 没认出那个标签、也可能 `stripSecrets` 剥过头。左边六站,每站带状态点与体量:

| 站 | 里面是什么 | 从哪来 |
| --- | --- | --- |
| 上下文包 | 真发给老师的那份 prompt(消息正文在最后)+ 完整命令行(可复制到终端跑),两个「复制」按钮 | `conversations/<老师>/<日期>.<job>.run.json`(2026-09-11 起每轮落一份;之前跑的显示「没落」) |
| 老师原文 | 解析器真正吃的那份正文,**逐行标出解析器怎么读的**:右边写着「讲稿 1 · 播」「卡 2 · text step」「段「转交」· 不进板书」「家长尾巴 · 孩子看不到」,被固定段吃掉的行灰底,warning 钉在出问题的那一行下面。顶上能「复制原文」「存成 fixture」(下载成 `<老师>-<日期>-<job>.md`,放进 `tests/fixtures/board/`);底下折着「没进板书正文的中间话」 | `.log` → `kidSource` → `annotateSource`(`src/lib/board.ts`) |
| 解析结果 | **拿当前解析器重解一遍**与索引里存的逐条比(`+` / `-` / `·`)。索引是物化的,存的是当时那版解析器的结果——改完 `parseBoard` 想知道老样本会不会变,只有这里看得到。下面是提醒与解析出的 JSON | 现算,不写盘 |
| 下发给孩子 | 真发出去的讲稿(按 `replyMaxChars` 截掉的尾巴画删除线)、每句的 mp3 在不在;卡是**剥完答案**的 props,孩子在卡上做过的显示成「孩子:…」 | 索引 + `.cards/` + 文件在不在 |
| 配音与资产 | 同上(讲稿那一半),没配音色时写「没配音 · 孩子端用浏览器的声」 | 文件在不在 |
| 转录与报错 | 工具行、子代理、收尾原因、stderr 尾巴 | `.log` / `.err.log` |

顶上「复制整轮」= 上下文包 + 原文 + 命令行拼成一段,贴 issue 用。孩子端一个字段都没加:这六站全从家长域的接口来(`GET /api/conversations/<老师>/<日期>/raw/<job>`)。

顶部「老师团」标签:**一位老师一行**(头像、显示名、`name`、改过的政策 chip、已关闭标灰),点一行才展开九项政策;继承的字段淡显「继承 30」,写过的加墨绿左边线和「全局 60 · 改过」,谁被调过一眼看得出。行里「老师文件」按钮展开这位老师的正文(系统提示)。「＋ 新老师」收在标题栏按钮里。全局面板在最上面。「设置」标签分路径 / 服务 / 配音三块,路径右列常驻解析后的绝对路径,配音能**试一句**(跑一次 `tts.say`,回音色 / 耗时 / 大小并当场播——`tts.say` 配错是最常见的坏法,以前要等孩子那边没声音才发现)。在编辑器里直接改 cotutor.json 也行,服务每个请求都看文件时间,改坏了顶栏会红字提示、仍用上一份。

### 4.2 孩子端 `/`(先在 Mac 的 Safari 或 Chrome 看)

孩子端从 2026-09-10 起不是聊天窗,是**板书页**:老师回一次 = 板上一节,卡先铺开、讲稿一句句念、笔跟着声音标注、末句问句停下来等孩子。下面按这个形态走一遍。

**先打舞台包**:`pnpm run build:stage`(esbuild 把 `src/stage/` 打成 `dist/stage/`,场景卡的 drawtell 播放器 + 画板卡的 excalidraw 编辑器)。包是**拆开**的:`stage.js` 只有 21K,其余在同目录一百多个 `chunk-*.js` 里按需取(命令会打印「打开舞台先下多少」);真开一次场景舞台下 3.4MB、画板舞台 1.5MB。没打的话轻卡照常、重卡点开什么都不出现,`cotutor doctor` 的 `stage.bundle` 会点名。npm 装的包自带,改了 `src/stage/` 要重打。

> 想自己量:无头 Chrome 开 `--remote-debugging-port`,`Network.setCacheDisabled` 之后导航到 `/stage/?bundle=/api/bundles/<id>/&autoplay=1`,把 `Network.loadingFinished` 的 `encodedDataLength` 加起来。**别在孩子端页面那层量**——舞台在 iframe 里,页面那层的 Network 事件不含它。

**不花钱先看形态**:`node bin/cotutor.js mock`(不需要 workspace,`--scenario limit|offline` 换场景)。语文老师三节走完 点读 → 选择题 → 填空 → 画板,数学老师第三节是一张场景卡(课包样本在 `tests/fixtures/bundles/`)。调试参数:`/?tutor=chinese-tutor&step=<节>.<句>` 停在某句,`&stage=<节>.<卡>` 直接开舞台,`&device=phone|tablet-portrait|tablet-landscape` 强制按某个端折行。数学老师第一节是勾股定理(原型「cotutor 板书卡片」的样张:封面 / `#` 标题的 text / 公式 / 短选项横排的选择题)。下面第 1–3 步在 mock 里就能验,第 4 步起要真 workspace。

1. **首页**:一排老师头像(不含 hidden 的规划与画图)、「今天可以问」三个话头、今天的时段、一周小路(课程表里有课的日子一站,今天最大;没课程表就只有今天)。
2. **一节**:点「语文老师」→ 打字「画蛇添足是什么意思?」回车。看到什么算对:先出「让我想想…」,老师那轮跑起来后**卡一张张露出来**(流式:`--include-partial-messages` 的增量喂 `parseBoard(partial)`,只追加卡、不播),整轮跑完这一节转正,再**从第一句开始念**;念到哪句底部字幕就是哪句,句子里 `[方括号]` 标的词在卡上画出橙色标注并滚过去。末句是问句 → 停下,右下角「继续」。
3. **舞台**:点选择题卡 → 盖住板书那块、讲稿暂停、大按钮;选一个 → 「交给老师」。字幕行回显「你:A …」,接着老师的下一节。填空卡逐空输入;点读卡每段点了念(老师配了 voice 的,那轮跑完几秒后各段 mp3 陆续落在 `conversations/<老师>/<日期>.<job>.cards/<n>/`,没生成好之前是浏览器合成声);图片卡双指缩放;画板卡是工作台(自己的七个钮,excalidraw 的壳藏掉;竖屏钮在一行、横屏在左列),画完「给老师看」导出 png,紧凑态变成缩略图。`Esc` 或右上角 × 关舞台。画板整条链不用手点:`node scripts/probe-canvas.mjs`(先把语文老师推到第三节)用 CDP 在 iframe 里画三笔、撤销一笔、交上去,逐项打勾。
4. **真老师**(要 workspace,花钱):`cotutor serve` 后开 `http://localhost:5180/`,问「25加17等于多少」。随口一问就该是一两句话、没有卡;问「三角形面积怎么算」这种才该出卡。回 `/parent` 看同一轮:绿色「孩子看到:」后面跟着「板书 N 张卡 M 句」,孩子在卡上做过的显示成「孩子在板书上做的:…」并带答案。
5. **状态是孩子的、存服务端**:交完答案重开孩子端页面,选中的、填的还在(`conversations/<老师>/<日期>.<job>.cards/<n>.json`,不进索引、可以删)。
6. **场景卡**:数学老师碰到要画的题会放一张场景卡 + 写「## 转交」,runner 自动起画图老师那一轮(见 §4.1 的「转交 →」)。做好之前卡上是「图还在路上」,做好后孩子端下一次轮询就能播(4 分钟、半美元量级,`scenes.dailyMax` 缺省 2)。
7. **断网与上限**:`Ctrl+C` 停掉服务 → 5 秒内所有头像变灰、板书页退出,没有任何报错文案;重新起又恢复。老师团页把「每日消息上限」改成 1 保存,孩子端再发一条后字幕行变「今天聊够啦,明天再来」、首页头像灰(点「继续」不算数,交答案算)。记得改回来。
8. **平板横屏**:窗口拉宽到 1100 以上,板书居中最宽 1040、没有左栏;一行几张卡由 `section.layout`(板书后期为某个端分的行)定,没有后期时一行一张;手机打开平板排的板书按 `rowsFor` 折(两张都短才并排)(无头截图:`--force-device-scale-factor=2 --window-size=1180,820`;手机版式用 `--window-size=780,1688`,窗口最小宽约 500,直接写 390 会被裁)。选中态:讲到哪张卡哪张橙色描边(`.c.now`),`&step=` 停在某句时也在。
9. **孩子端不该有的**:搜页面源码,`/parent`、「错误」、工具名都不该出现;孩子设备上没有通往家长端的入口(2026-09-10 拍板,原来的「家长 · 长按」已删)。
10. **新话题**:头部 ✨ → 板书清空、字幕行空、副标题「新话题」;此时索引一个字没变(`conversations/<老师>/<日期>.json` 不动)。发一句 → 家长端那条带新的 `thread`(= 自己的 job),`resume: false`(新会话),`sessions` 里多一条;再发一句 → resume 新话题的会话。老师还在想时 ✨ 变灰。调试:`?tutor=math-tutor&new=1`。
11. **以前的**:头部 🕓 → 右侧面板按天列话题(`GET /api/kid/conversations/<老师>/history`)。点今天的旧话题 → 板书换成它、副标题「今天的话题 · HH:MM」、能接着聊(家长端看 `thread` 回到旧 id,resume 的是旧话题的会话 id);点以前的日期 → 只读回放:从第一句播、没有「继续」、选择 / 填空点不开、输入条换成「回到今天」。调试:`&panel=1` 开面板,`&hist=<日期>.<话题>` 直开回放(mock 里昨天是 `0930-13`)。

## 5. iPad / iPhone 真机(R0 第 2 项也在这一步)

> 只想照着做、不关心为什么的,看《iPad与iPhone.md》——那份按设备分步写,带重做时机与报错对照表。

1. Mac 上签证书:`cotutor cert`。它用 mkcert 把本机名、`.local` 名、局域网 IP、localhost 都签进机器级的 `~/.config/cotutor/certs/`(证书是这台机器的,不是孩子的,所有 workspace 共用;IP 变了只重签一次),并打印根证书位置(`mkcert -CAROOT` 下的 `rootCA.pem`)。单个 workspace 要用别的证书才配 `server.https`。
2. 把 `rootCA.pem` 隔空投送到设备 → 设置 › 已下载描述文件 › 安装 → **设置 › 通用 › 关于本机 › 证书信任设置 › 打开那条**。装了不等于信任,信任开关是独立一步,而且每台设备各做一次(iPad 上开过,iPhone 上还得再开)。
3. 重启 `cotutor serve`,这次打印的是 `https://…`。
4. Safari 开 `https://<局域网 IP>:<端口>/`(用 serve 打印的那个 IP;Mac 与设备同一 Wi-Fi)。**用 IP,别用 `<主机名>.local`**:主机名同时解析出 IPv4 与 IPv6,有些设备挑中 IPv6 那条而它在家用路由器下走不通,表现是一直转圈后「服务器停止响应」。锁头正常、没有证书警告就对了。加到主屏幕(分享 › 添加到主屏幕)会去掉地址栏与工具栏,图标与 manifest 由 `src/lib/icon.ts` 现生成。
5. 点数学老师,**按住话筒说一句**:第一次 Safari 会问是否允许麦克风。看识别出来的字准不准、松手有没有发出去、几秒后有没有听到回答——这三个观察写回《产品规划.md》R0 第 2 项。
6. 若识别根本不出字:说明 iPad 这版 Safari 的语音识别不可用,先用打字,voxtell transcribe 要提前做(产品规划里写的备选路)。

识别的逻辑(`src/server/kid-page.ts` 输入条那段,搜 `SpeechRecognition`):全在浏览器,服务端没有语音接口。`pointerdown` 起 150ms 定时,到点才算「按住」(轻点走打字),先停老师的配音,再 `new SpeechRecognition()`(`zh-CN`、单句 `continuous: false`、`interimResults: true`,每次 `onresult` 把所有片段拼成当前文本);松手 `stop()`,`onend` 时文本非空就直接 `send()`,不经确认;按住时上滑 60px 标 cancelled,松手改走 `abort()` 并卸掉 `onend`。`onerror` 静默。没有 `SpeechRecognition` 构造器、非 HTTPS、或没给麦克风权限,输入条只剩打字。声音不落盘、不经过 cotutor,识别质量与语言由浏览器决定;要换成自家识别(voxtell transcribe)就是把这段换成录音 + 上传,接口还没有。

## 5.5 加一位自家的老师

```sh
cotutor add science-tutor --display 科学老师 --subject 科学 --avatar 🔬
```

它写 `.claude/agents/science-tutor.md`(模板带着出厂老师的全部约定,正文里有一句括号提示让你填这位老师的性子)、在 cotutor.json 的 `tutors` 里加一条、建 `agents/science-tutor/`。服务不用重启,两个端刷新就多一位;`cotutor doctor` 里它的 `origin` 行是「自家加的老师」,`cotutor upgrade` 永远不碰它。不要了就删文件加删配置那条。

cd ~/cotutor/ming

## 8. 不对时看哪里

| 现象 | 看 | 多半是 |
|---|---|---|
| 家长端发出去一直「老师在想」然后红条 | 红条下的 err.log 尾巴;或 `conversations/<老师>/<日期>.<job>.err.log` | 没加 `--model sonnet`(API Error 400 版本不够);在 Claude Code 里没 unset `CLAUDECODE` |
| 回复出来了但没有声音 | err.log 里「cotutor tts: 没合成(…)」 | `tts.say` 指的 voxtell 不在 PATH;老师没配 voice(这时用浏览器的声,不算错) |
| 孩子端没有话筒 | 浏览器 | 没有 `webkitSpeechRecognition`(Firefox),或平板 / 手机上用了 http |
| iPad 打不开 https | 证书信任设置 | 根证书没装或没打开信任;IP 变了要重签 `cotutor cert`(证书在 `~/.config/cotutor/certs/`,与 workspace 无关) |
| 老师头像全灰 | `cotutor serve` 还在跑吗;`/api/health` | 后端不通;或每日上限到了(只灰那一位) |
| 顶栏红字「cotutor.json 改坏了」 | `cotutor doctor` | JSON 少个逗号;服务仍用上一份 |
| 课程表没画出来 | `cotutor doctor` 的 timetable 项 | 表头缺列、时间格式不对,都带行号 |
| 重卡(场景 / 画板)点开一片空白 | `cotutor doctor` 的 `stage.bundle` | 没跑 `pnpm run build:stage`;改了 `src/stage/` 也要重打 |
| 场景卡一直「图还在路上」 | 家长端切到画图老师那一轮;`ledger/artifacts.jsonl` | 那轮红条(预算 / 模型);或今天到了 `scenes.dailyMax` |
| 老师板书写了却没出卡 | 家长端那轮的「板书 N 张卡」与 warnings | 围栏标签不认识(当 code 卡)、政策 `board: off`;解析器永不抛,只降级 |
| 回复整块出、不是一张张露卡 | `cotutor.json` 的 claude 模板 | 缺 `--include-partial-messages`(老 workspace:`cotutor upgrade --config`);qwen 没有对应开关,本来就是整块 |
| 老师自己派了子代理去画图 | 那轮的转录里有「子代理」且费用异常 | claude 模板缺 `--disallowedTools Agent`(同上,`upgrade --config` 补) |

费用参考:数学老师问答一轮 $0.01–0.18(首轮带上下文包贵一点),配音按字算;画图老师一个课包实测 4.3 分钟、$0.56(上限 8 美元)。
