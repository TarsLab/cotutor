材料:`src/server/post.ts`、`src/lib/postprocess.ts`、`src/lib/post-html.ts`、`src/lib/post-fixtures.ts`;`scripts/post-eval.ts`。按拍调用的流程在《工作流程.md》§二。

结论先行:**后期这道工序(老师定内容、快模型提案、契约校验、坏了素版)不改;要让开发者能摆弄它。** 三块:提示词成文件、样本即测试、三层测试。坑一条:后期子进程要带 `MAX_THINKING_TOKENS=0`,否则 haiku 一拍 35–69 秒。

## 一、主张

### A. 提示词成文件:骨架和主题 css 同一套,占位符是生成的部分

提示词整份是 `themes/<主题>/post.md`,地位和 `kid.css` 一样:出厂在包里的 `themes/default/`,init 拷进 workspace,目录 hash 进 shipped.json,`cotutor upgrade` 没改过的换新、改过的报 diff,`cotutor add-theme` 拷一份来改;服务每次按 mtime 现读,读不到 / 缺必需占位符就退包里那份并在 doctor `theme.post` 点名。**家长或主题作者可以改任何一句话**;不能改的是占位符里生成的内容:

- `{board}`:这一拍的板书按孩子看到的结构给模型看(标准 HTML:`div.row` 一行、`div.c` 一张卡带 `data-tint / data-look`、这一拍的卡 class 带 now、讲稿 `p.line`),前面带 3–5 张已定的卡,只读。
- `{rules}`:一句几处、一卡几处、phrase 必须在卡上、said 必须在讲稿里、行的上限、标题行与交互卡独占——从校验器用的同一组常量生成,改校验器这段自动跟着变。
- `{patch}`:要回的补丁形状:只回 now 那张卡的壳 `<div class="c" id="cN" data-row data-tint data-look data-emoji>`,里面 `<mark data-pen data-said data-card>词</mark>`;不复述卡、不数下标。
- `{marked}`(可选):老师已标过的词;`{device}` `{tints}` `{looks}` `{pens}` `{defaultTint}` 从 theme.json 槽表拼。
- **必需**:`{board}` `{rules}` `{patch}`(`REQUIRED_SLOTS`),缺一个整份退出厂骨架并 warn;其余可选,不写就是不给模型这段信息。

板书要放在提示词最前:放中间 haiku 会当成系统说明、回「我还没看到板书」。全是标准 HTML,自定义的都是 `data-*`:模型看到的和要回的是同一个标签。校验器不分方言,丢掉的提案带原因。

主题和提示词放一起的理由:槽表(theme.json)说「这个槽给什么用」,提示词说「怎么选」,样子的真相全在一个目录里;换主题 = 换一整套审美。不放的地方:不放 `.cotutor/`(机器文件)、不放 cotutor.json、不放老师文件(后期不是老师)。

### B. 样本即测试:`tests/fixtures/post/<名>/`

```
tests/fixtures/post/math-tutor-1/
  section.md      老师原文(与 tests/fixtures/board 同一种写法;家长端「看原文」的 /fixture 站下载即得)
  expect.json     期望:{ device, must: [{card, phrase}], never: [{card, phrase}], rows?, look?: {卡号: [槽名]}, maxDropped? }
  prompts.md      各拍提示词的渲染快照(测试生成、提交入库;改了骨架 diff 里一眼看到提示词变了什么)
  runs/           评测留档(gitignore):每次真跑的原始输出、校验、分数
```

`expect.json` 故意是**部分匹配**:审美有余地,评测只问「该标的标了没(must)、不该标的没标(never)、行合法、底色在允许的槽里、丢了几条」。精确到每个 pen 就变成在测模型的脾气。

### C. 三层测试,只有一层花钱

| 层 | 命令 | 花钱 | 测什么 |
|---|---|---|---|
| 1 离线 | `pnpm test`(`tests/post-fixtures.test.ts`) | 否 | 每份样本:section.md 过解析器 → 各拍渲染提示词 == prompts.md 快照(不等就报第几行,`UPDATE_SNAPSHOTS=1` 重写);expect 里的每条本身合法;规则段与常量一致;主题 post.md 的占位符齐全 |
| 2 评测 | `node --experimental-strip-types scripts/post-eval.ts --workspace <dir> [--only 名] [--repeat n] [--serial] [--model 名]` | 是,每拍约 $0.015 | 对每份样本真起快模型 n 次:解析成功率、must 命中率、never 失手、行、底色、丢的条数、每拍 p50 / p95、费用;打印一张表,留档到 runs/;`--serial` 各拍顺着起(带已定的样子,和流式一样) |
| 3 回放 | `cotutor repost <老师> [日期] --all` | 是 | 对真 workspace 今天所有有卡的轮次重跑后期;家长端「看原文」的「板书后期」那站能看结果与「再做一次」 |

调提示词的日常:改 post.md → `pnpm test` 看快照 diff 是不是自己想改的 → post-eval 看分有没有掉 → 满意了连快照一起提交。评测走的就是 `runPost`,同一条路同一个校验;假 CLI 的 json 模式让评测命令本身在 `pnpm test` 里过一遍(不花钱)。

### D. 不做的

- **不把快模型做成会话或子代理**:它没有记忆、没有工具、不读 workspace,一次一拍。
- **不把校验搬进提示词**:提示词只是让模型少犯错,契约说了算;丢掉的提案带原因,是评测的信号,不是要消灭的东西。
- **不让快模型定时间**:标注什么时候画由 `markTiming` 按讲稿算,模型只给 `said`。
- **不做精确答案的样本**:见 B。
- **不做直连 API 运行时**:关掉思考、`--tools ""`、`--disable-slash-commands`、`--system-prompt` 一句之后,CLI 一拍输入从 27K token 降到约 500,p50 3.2 秒、一节约 $0.034;直连只再省起动那 1–2 秒。费用成了问题再回来。

## 二、拍板记录

1. 提示词整份成文件 `themes/<主题>/post.md`,和 kid.css 同一套机制(2026-09-13)。
2. 后期按拍:每拍超时 10 秒,超时素版不重来(2026-09-13,《工作流程.md》§六)。
3. 样本用部分匹配(must / never / rows / look),不做精确答案(2026-09-13)。
4. 直连 API 运行时暂不做(2026-09-13;2026-09-15 量了输入后确认,数据在 §一 D)。
5. 出厂骨架换成 HTML 方言:标准 HTML 进、div 壳补丁出、已标的词挂 `data-marked`(2026-09-14);JSON 方言 2026-09-17 删了。三份样本 16 拍:拍收到 16/16、底色 8/8、p95 6.4 秒;HTML 让模型看见卡的全文,它会再标老师已标的词(校验器丢),never 失手对 HTML 是噪声,别当退步。换 sonnet 结论不变,费用约 3 倍、每拍慢 1 秒。
6. 真 workspace 两天 25 拍回看后三处改(2026-09-20):① 解析器认 `class="c …"`(照抄成 `c c-tianzige now` 也认),按 id 挑 now 那张卡的壳,id 对不上才退回「不带 now 的最后一个」——原先 2 拍因此整拍作废;② 田字格卡不再是空壳,里面一句注释说写的是哪几个字、没有可标的文字,那一拍要回的形状里没有 `<mark>`,校验器对田字格的标注单报一条原因。字放 `data-chars` 属性上试过:规则、骨架、形状三处都写了不标,haiku 照标那几个字;放注释里 4 轮 0 处;③ 规则第一条改成「标注的词只从卡上取,不从讲稿里取」带反例,said 那条写明「只有 said 从讲稿里取」,emoji 写明不要 ZWJ 组合。语文 2026-09-19 那 9 轮在 workspace 副本里重做:「词不在卡上」6 处 → 0,形状作废 2 拍 → 0;剩下的丢弃是再标老师标过的词(见 5)。超时、多一次请求与缓存只写不读没动。
