# 日常使用

装好以后这台电脑上的事:后台服务、图标、地址、备份、升级、试用。安装看 [README](../README.md),平板看 [iPad 与 iPhone](iPad与iPhone.md)。

Windows 的 PowerShell 缺省禁止运行脚本,下面的 `cotutor`、`npm` 在那边写成 `cotutor.cmd`、`npm.cmd`。

## 后台服务

`cotutor service install` 把 cotutor 装成这台电脑的后台服务:登录后自己起来、崩了自己再起、关了终端照样跑,日志按天落文件。

```sh
cotutor service status     # 在不在跑
cotutor service logs       # 看日志
cotutor service restart    # 重起
```

- Mac 上用 launchd,Linux 上用 systemd 用户服务,Windows 上是一条用户自己的登录项(不用管理员、没有黑窗口)。
- Windows 第一次起来可能弹窗问「允许访问」,点允许,平板才连得进来。
- 第一次装会打开一次家长端,孩子的平板在那里扫码;不想弹,安装时加 `--no-open`。服务重启、登录电脑都不会自己弹出来,要看就点图标或跑 `cotutor open`。
- 要在终端里调试用 `cotutor serve`,先 `cotutor service stop` 让出端口。
- 换了 Node 版本、或包装到了别处,再 `cotutor service install` 一次。

## 菜单栏(任务栏)图标

Mac 和 Windows 上,`service install` 会一起装一个图标,不用开终端就能看状态:

- 正常时就是 logo;有事要处理出橙点;后台服务没在跑时 logo 变淡并出红点。状态变差时通知一次。
- 点开能看原因、打开家长端、重启服务、看日志。
- 「退出 cotutor」会停掉这台电脑上所有孩子的后台服务,平板打不开,下次登录自动恢复。
- Windows 的新图标先收在任务栏右下角的 `^` 里。
- 不要图标就 `cotutor tray off`,装服务时加 `--no-tray` 也行。
- Linux 上没做,用 `cotutor service status` 看。

## 地址与端口

地址认电脑名,换 Wi-Fi、路由器换 IP 都不用重签证书、不用重扫。

端口在 `init` 时选一次写进 `cotutor.json`,以后不变:

- 优先 443,地址里不用写端口(`https://<电脑名>.local/`)。
- 443 被占着或系统不让用(Linux 默认不让)就用 8443,再往后 8445、8447。
- 几个孩子各用各的,自动让开。
- 运行时被占只报错说明是谁占着,不会自己换,因为换了端口平板要重新扫码、重加图标。

## 数据在哪

默认 workspace(孩子的 cotutor 文件夹)是 `~/cotutor/<孩子>/`:

| 位置 | 内容 |
|---|---|
| `cotutor.json` | 配置 |
| `agents/<老师>/activities/` | 老师的 activity |
| `.agents/skills/` | 技能 |
| `conversations/` | 对话 |
| `ledger/` | 账本 |
| `captures/` | 照片 |
| `bundles/` | 课包 |
| `home/` | 首页 |

长期档案、记忆和日记在 vault(笔记文件夹),和 workspace 分开放:缺省是旁边的 `~/cotutor/<孩子>-vault/`,位置写在 `cotutor.json` 的 `paths.vault`。里面全是普通 markdown,不用装 Obsidian,想用 Obsidian 看就把它当库打开;规则见 [obsidian 仓库设计](obsidian仓库设计.md)。

想用自己已有的 Obsidian 库,第一次 init 时加 `--vault <路径>`(一个孩子一个库;Mac 上别用「文稿」「桌面」和 iCloud 云盘里的,后台服务读不到)。

## 备份

备份放在 cotutor 文件夹旁边的 `.backups/<孩子>/`,一份就是一个普通目录。

- 服务开着时每天自动备一份(留 14 份),`cotutor refresh` 前也备一份(留 5 份),没变的文件不占第二份地方;`cotutor backup` 随时手动备。
- **录音(wav)不在备份里**,它占了绝大部分地方;想留就自己拷 `conversations/`。
- 笔记文件夹里的 md 也备一份(在那一份的 `_vault/` 里);恢复时不动笔记文件夹,只告诉你那份在哪,要不要拿回来你定。
- 硬盘坏了这些也跟着没了,重要的话把 `.backups` 再拷到别处。

```sh
cotutor backup list                   # 看有哪些
cotutor backup restore <名字> --yes    # 恢复:先把现在的样子也备一份,再拷回去
```

## 升级

有新版本时,后台服务每天问一次 npm(只发一个普通请求,不带孩子或使用的任何信息),图标的菜单和家长端「首页」顶部会说,通知一次,孩子端不说。不会自动升级。不想让它问:在 `~/.config/cotutor/update.json` 写 `{"off": true}`。

```sh
cotutor update
```

它问 npm 有没有新版本,换上新程序,把每个孩子未修改的出厂老师、activity、主题与技能更新掉,再重起服务和图标。孩子正在通话时它不动;下载没成时服务也不动,还跑旧版。每个版本改了什么见 [更新说明](../CHANGELOG.md)。

- 家长改过的老师与主题保留并显示差异;机器技能会随版本覆盖。
- 只想换新一个孩子的出厂文件、不升级程序:`cotutor refresh`。
- 升完它提示要迁移配置时再跑下面两条。配置迁移只补缺,保留自定义配置。

```sh
cotutor refresh --config --dry-run    # 预览 cotutor.json 的迁移
cotutor refresh --config              # 执行配置迁移
```

## 试用不进孩子的记录

自己手动试功能时,命令加 `--sandbox`:第一次从真 workspace 分出一份到旁边的 `.sandbox/<目录名>/`(`~/cotutor/ray` → `~/cotutor/.sandbox/ray`)。

- 老师、activity、首页、主题、课包照拷,对话、照片、听写、账本不带,vault 拷一份;试的对话、记忆、日记都写在这份里。
- 页面标题前带「试用」,端口永远是真的那个 +1,可以同时开;`cotutor open --sandbox` 打开。
- 自动记账关着(要试记账,家长端点「记账」)。

```sh
cotutor serve --sandbox               # 试用的那份;没有就先分出来
cotutor send math-tutor --activity 检查作业 "我做完了" --sandbox
cotutor serve --sandbox --fresh       # 丢掉试过的,从真 workspace 重新分(真的那边改了 activity、vault 也用这个带过来)
```

## 访问锁

家长端与工作台需要访问锁时,运行 `cotutor pin` 设置本机 PIN。没设就全开。
