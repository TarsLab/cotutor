# 看图说话:一堂卡片小课堂,再拍图和语文老师一起说

> 2026-10-07 起,设计稿,还没动代码。起因:一本家长书里的「看图说话万能公式 5W+1H」(谁、什么时候、在哪里、在干什么、为什么、怎么样)和一个帮孩子记住它的顺口溜。材料:《小课堂设计.md》(视频小课堂第 4 步、`lecture` 卡)、《作业照片设计.md》、`src/server/lecture.ts`(`inspectLecture`、`storedMarks`)、`src/lib/lecture.ts`(`parseLectureDoc`、`videoClock`)、`src/server/tts.ts`、`src/lib/mp3.ts`、`agents/chinese-tutor.md`、`cards/tutor/card.md`(例子里已经有「接着写看图写话」)。拍板在文末。
> **词**:「卡片小课堂」= 用板书的写法(一行一句讲稿、围栏是卡)写成的小课堂,`cotutor lecture bake` 配上老师的声音、烤成视频,孩子那边就是一堂视频小课堂。「看图说话」= 孩子对着一幅(或几幅)图说一段话;要写下来的叫看图写话,先说后写。

结论先行:**两半,各用现成的路**。

- **讲**:5W+1H 做成一堂卡片小课堂。家长在 workspace 里写 `lectures/<id>/cards.md`,`cotutor lecture bake` 配音、按孩子端的卡样子一句一帧截图、拼成 `video.mp4` 和 `lecture.md`。孩子端、播放器、圈、`lecture` 卡、录像全走视频小课堂那条路,一行不改。只多一份 `layout.json`(每一帧上每张卡在哪),圈住了什么在服务端算成字,不发截图、不带工具。
- **说**:看完了,孩子拍一张作业上的图发给语文老师(看完输入条和相机就亮,今天就能发)。语文老师文件加一节「看图说话」:一节只问一个问题,孩子开口答,老师用他的原话攒成一张 `read` 卡「你说的话」,六个问完连成一段,请他自己说一遍。

## 一、为什么这样

- **公式是讲出来的,一段话是孩子说出来的**。公式家长审过一次就定了,适合做成课,孩子看一遍、以后放其中一段;一段话每张图都不一样、得一问一答,只能聊。和小课堂「讲和聊分开」(《小课堂设计.md》§一)是一回事。
- **卡片,不是课包**。六个问题全是字。drawtell 课包是一笔一笔写出来的,一屏字要画很久,做课包也要在 Claude Code 里来回好几轮;卡是孩子天天在板书上看的样子,家长写 md 就行。
- **烤成视频,不在孩子端另做一种播放器**。视频小课堂已经有时钟、拖、圈、截图、`lecture` 卡、录像、iPad 真机修过的声音;卡片小课堂烤成视频,这些全拿来用。另做「在孩子端按时钟放一节板书」要多一种画面、多一套圈住了什么、多一种缩略图、录像多一种段,每处都分三支。代价见拍板 3。
- **不是备课回来了**。备课(2026-10-05 删)是把写好的板书交给孩子的话题、孩子一开口讲稿就跟不上,还带四条只对备课话题的规矩。卡片小课堂是一堂课:看的时候不能问,看完才聊,聊的时候老师当场说;它是小课堂的第三种来源,不是话题。
- **一问一答,用孩子的原话**。ray 有阅读困难、写字有抵触;说清楚一整段难,一次答一个问题容易。他说的每句都进「你说的话」,点一下用老师的声音念给他听,看得到自己说出了一段。

## 二、孩子那边怎么走

| 一步 | 孩子看到的 | 用的是 |
|---|---|---|
| 进 | 首页语文老师卡上「小课堂 · 看图说话」 | 小课堂按钮,不改 |
| 看 | 铺满放:卡一张一张出来,老师的声音念;能停、拖、圈,不能问 | 视频小课堂,不改 |
| 看完 | 停在最后一帧(顺口溜),1 秒后出「圈一圈 / 再看一遍 / 去问老师」;点「去问老师」回板书,输入条、相机亮,课收成板书顶上带末帧缩略图的小课堂卡 | 不改(《小课堂设计.md》拍板 37) |
| 拍 | 拍作业上那幅图(能裁、能圈、能配一句「这是我的看图说话」),发 | 发照片屏,不改 |
| 说 | 老师一节问一个:「图上都有谁?」孩子按住说话答;每节末尾一张「你说的话」 | 语文老师新的一节(五) |
| 连 | 六个问完,「你说的话」是整段,老师请他自己连起来说一遍 | 同上 |

- 以后再做看图说话,不用再看课:首页挂一个普通按钮「我要看图说话」,讲法里写「照看图说话那节带」(六)。
- 中间卡住了,老师可以放课里那一个问题的那段(`lecture` 卡,时间照 `lines:` 抄)。

## 三、卡片小课堂

### 3.1 源:`lectures/<id>/cards.md`

````markdown
---
subject: chinese
voice: chinese-tutor
---
# 看图说话:六个问题

```text
# 谁
图上都有谁?
```
第一个问题,[谁]。图上有几个人?有没有小动物?
````

- 和板书同一套写法:围栏是卡,围栏外一行是讲稿一句,`[词]` 是标注。一张卡和它后面的讲稿是一拍,卡在念到它那一拍时出来(同板书的念到哪露到哪)。
- 只认不动的卡:`text`、`read`、`image`。别的种类首页检查报「要改」:能答的卡在课里没人答,田字格、单词卡是动画,烤不进一帧。
- `voice:` 写一位有脸的老师的键,用 cotutor.json 里他的音色配音;课是这位老师的声音,孩子看完问的也是他。`subject:` 同视频的 `lecture.md`。
- `image` 卡的路径相对 workspace 根,放 `lectures/<id>/` 里(例子见四)。
- 整堂课只有一节:没有 `## ` 尾巴。写了 `## ` 的段落首页检查提醒、不烤。

### 3.2 烤:`cotutor lecture bake <id>`

1. **配音**:每句讲稿用这位老师的音色合成(`tts.ts` 的 `synthesize`),落 `lectures/<id>/audio/<hash>.mp3`,hash = 音色 + 原话;没改的句子不重配。时长读 mp3(`mp3.ts`)。这位老师没配音色 → 不烤,说清楚。
2. **时钟**:一句一段,段长 = 这句的配音 + 0.4 秒气口;第一句从 0 起。和视频的 `videoClock` 是同一种时钟。
3. **一句一帧**:起一个看不见的 Chrome(同探针,CDP),开孩子端页面的「烤」样子:只有板,宽 1024 CSS px、4:3、DSF 2。念到第 k 句时板上该有的卡、亮的卡、`[词]` 的标注,和孩子端放板书时一模一样,用同一份 `renderSection` 与 `kid-board.ts`,不另写一份。截一张 png,同时读每张卡(`read` 卡读每一行)的框。
4. **拼**:ffmpeg 按段长把帧接成 H.264(`yuv420p`、`+faststart`),配音按时钟接成一条声轨,出 `video.mp4`(2048×1536,一帧不动的片子很小)。
5. **写**:`lecture.md`(`# 标题` + 一行一句「分:秒 原话」,头上一行注释「cards.md 烤出来的,别手改」)与 `layout.json`(下面)。帧与临时文件删掉。

`layout.json`:

```jsonc
{
  "source": "sha256 前 12 位:cards.md + 音色 + 图片",  // 对不上 = 改过没重烤
  "size": [2048, 1536],                                   // 视频像素,圈的坐标就是它
  "segments": [                                           // 一句一条,和 lecture.md 同序
    { "start": 0, "cards": [
      { "kind": "text", "label": "卡『谁:图上都有谁?』", "rect": [96, 120, 860, 300] },
      { "kind": "read", "label": "点读卡", "rect": [96, 460, 1856, 420],
        "rows": [{ "label": "『图上有谁先看清,』", "rect": [120, 480, 1800, 90] }] }
    ] }
  ]
}
```

- 要 Chrome 和 ffmpeg,都在做课的那台机器上。`cotutor doctor` 只在 workspace 里有 `cards.md` 时查 ffmpeg。
- 主题、卡的样式改了,烤好的视频不跟着变;`source` 不含它们,要样子跟上就重烤。

### 3.3 放:就是视频小课堂

- `inspectLecture` 照旧读 `lecture.md` + `video.mp4`,多认一件事:有 `cards.md` 时对 `layout.json` 的 `source`。没烤过 → 要改(「跑 `cotutor lecture bake <id>`」);烤过、后来改过 → 提醒(老视频照放)。
- 首页按钮、`lecture` 卡、录像、家长端不改。
- 上下文包的 `source:` 写 `cards <id>`,老师知道这堂课的圈是字、没有截图。

### 3.4 圈住了什么:按 `layout.json` 算,不发截图

视频小课堂的圈原来只能发截图、这轮带工具读图(《小课堂设计.md》拍板 4、22)。卡片小课堂每一帧上有什么是烤的时候量好的,可以和课包一样在服务端算成字:

1. 圈的时刻落在第几段 → 那一帧的卡(`segments[i].cards`)。
2. 卡(或 `read` 卡的一行)的框上取样点过半落在圈里 → 圈住了它。`read` 卡先认行、再认整张。
3. 都没过半 → 圈落在哪张卡里就说「圈在卡『…』上」;落在空白处说离它最近的那张。
4. 拼成一段:「0:31 圈的,那时正在讲『第三个,在哪里。看看四周有什么』;圈住了:卡『在哪里:在家、在学校、在公园?』」

- 截图照截(圈的卡的缩略图就是它,孩子端不改),只是不进上下文包 `photos:`、这一轮不带工具。
- 算在 `storedMarks` 里:视频有 `layout.json` 就走这一支。取样点在不在圈里,用 drawtell/core 认圈的同一个判定。

## 五、语文老师怎么带

落地在 `agents/chinese-tutor.md` 的「看图说话」与「一段好的回复(看图说话)」,规矩以那里为准。要点:

- 一节一问,问句写在末句,应用补成提问卡;不另写问题卡(拍板 13)。
- 第一句只说认出了哪道题、几幅图,图上画了什么留给孩子说(拍板 14)。
- 每节一张 `read` 卡「你说的话」,只放孩子这次说的一句(原话整理成句),前面的不再抄;一节最多换一个词(拍板 15)。
- 四幅图:谁、在哪里、什么时候问一次,在干什么一幅一次,为什么、怎么样放最后一幅。
- 题目的问题都要答到;词语宝库的词问到时提一句。
- 六个问完:整段(「什么时候」挪最前)+ 顺口溜两张 `read` 卡,请孩子连起来说;要写下来就一次写一句。

- 「你说的话」卡上不写标题:`read` 卡没有标题行,写了会被当成一段、配上音。孩子靠讲稿那句和每节都在同一个位置认它;真跑认不出来,再给 `read` 卡加 `# 标题`(卡片协议的改动,另记)。
- 第一轮带照片、要 Read,慢(首拍 30 秒上下,《小课堂设计.md》拍板 4);之后几轮只有孩子的话,照片还在会话里,不再读。
- 一幅图约 7 轮;四幅图真跑 13 轮(2026-10-08,见 8.1),每日上限 30 条(`dailyMessages`)只够做两套。
