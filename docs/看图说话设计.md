# 看图说话:拍图和语文老师一问一答说一段

> 2026-10-07 起。语文老师那半 2026-10-08 落地(`agents/chinese-tutor.md` 的「看图说话」与「一段好的回复(看图说话)」)。卡片小课堂那半(5W+1H 用板书写法写、配音、烤成视频)没做,它的设计(原 §三、四、七与 §八第 2–4 期)移出本文,原文在 git 历史 b3d4904。起因:一本家长书里的「看图说话万能公式 5W+1H」(谁、什么时候、在哪里、在干什么、为什么、怎么样)和一个帮孩子记住它的顺口溜。材料:《作业照片设计.md》、`agents/chinese-tutor.md`、`cards/tutor/card.md`(例子里已经有「接着写看图写话」)。拍板在文末。
> **词**:「看图说话」= 孩子对着一幅(或几幅)图说一段话;要写下来的叫看图写话,先说后写。「卡片小课堂」= 用板书的写法写成、烤成视频的小课堂(没做)。

结论先行:**孩子拍图,语文老师一问一答**。孩子拍一张作业上的图发给语文老师;老师一节只问一个问题,孩子开口答,老师用他的原话攒成一张 `read` 卡「你说的话」,六个问完连成一段,请他自己说一遍。原打算先用一堂卡片小课堂讲 5W+1H、看完再拍图,那半没做。

## 一、为什么这样

- **公式是讲出来的,一段话是孩子说出来的**。公式家长审过一次就定了,适合做成课,孩子看一遍、以后放其中一段;一段话每张图都不一样、得一问一答,只能聊。和小课堂「讲和聊分开」(《小课堂设计.md》§一)是一回事。
- **一问一答,用孩子的原话**。ray 有阅读困难、写字有抵触;说清楚一整段难,一次答一个问题容易。他说的每句都进「你说的话」,点一下用老师的声音念给他听,看得到自己说出了一段。

## 二、孩子那边怎么走

| 一步 | 孩子看到的 | 用的是 |
|---|---|---|
| 进 | 首页语文老师卡上「我要看图说话」 | 开场按钮,不改(六) |
| 拍 | 拍作业上那幅图(能裁、能圈、能配一句「这是我的看图说话」),发 | 发照片屏,不改 |
| 说 | 老师一节问一个:「图上都有谁?」孩子按住说话答;每节末尾一张「你说的话」 | 语文老师的「看图说话」一节(五) |
| 连 | 六个问完,「你说的话」是整段,老师请他自己连起来说一遍 | 同上 |

原设计在「拍」之前先看一堂卡片小课堂,卡住了老师还能放课里那一个问题的那段;那半没做。

## 五、语文老师怎么带

落地在 `agents/chinese-tutor.md` 的「看图说话」与「一段好的回复(看图说话)」,规矩以那里为准。要点:

- 一节一问,问句写在末句,应用补成提问卡;不另写问题卡(拍板 13)。
- 第一句只说认出了哪道题、几幅图,图上画了什么留给孩子说(拍板 14)。
- 每节一张 `read` 卡「你说的话」,只放孩子这次说的一句(原话整理成句),前面的不再抄;一节最多换一个词(拍板 15)。
- 四幅图:谁、在哪里、什么时候问一次,在干什么一幅一次,为什么、怎么样放最后一幅。
- 题目的问题都要答到;词语宝库的词问到时提一句。
- 六个问完:整段(「什么时候」挪最前)+ 顺口溜两张 `read` 卡,请孩子连起来说;要写下来就一次写一句。

- 「你说的话」卡上不写标题:`read` 卡没有标题行,写了会被当成一段、配上音。孩子靠讲稿那句和每节都在同一个位置认它;真跑认不出来,再给 `read` 卡加 `# 标题`(卡片协议的改动,另记)。
- 第一轮带照片、要 Read,慢(首拍 30 秒上下,《小课堂设计.md》拍板 4);之后几轮只有孩子的话,照片还在会话里,不再读。
- 一幅图约 7 轮;四幅图真跑 13 轮(2026-10-08,见 8.1),每日上限 30 条(`dailyMessages`)只够做两套。

## 九、要盯的

- 老师守不守一节一问;「你说的话」是不是孩子的原话,还是被改成了大人的句子。
- 「为什么」「怎么样」孩子答不答得出来;常卡在哪个,老师记进记忆。
- 一张图要几轮;第一轮读图的等待孩子受不受得了。
