# 老师与配置

老师是哪些文件、怎么加一位、年级教学包、用哪个模型、key 放哪。安装看 [README](../README.md);改老师怎么带看 [写提示词](写提示词.md)。

## 老师是文件

每位老师 = `cotutor.json` 里的一条(显示名、一句介绍、头像、音色、开关、政策)+ 自己的家 `agents/<老师>/`:

- 家里每个 activity 一个 Markdown 文件。activity 是孩子从首页一个按钮进去的一种做法,「老师怎么带」那一节就是系统提示,这一科通用的做法每份里都写一遍。
- 对话也在老师名下(`conversations/<老师>/`)。

出厂三位(数学、语文、英语)随包发布,init **拷贝**进你的老师们,改了就是你家的:

- `cotutor refresh` 只换没改过的,改过的打印差异让你定。
- 想回出厂的那份,`cotutor reset <老师>/<activity>`(你那份存成 .bak)。

`init` 还把做课包用的四个技能 chalk-* 和四个机器件 cotutor-tutor / cotutor-analyze / cotutor-tune / cotutor-home 拷进 `.agents/skills/`(Codex、Qwen Code 直接读;Claude Code 读的 `.claude/skills` 是链到它的)。

`cotutor.json` 首行指向一份 JSON Schema(`.cotutor/cotutor.schema.json`),编辑器里有补全与说明。

## 加一位老师

```sh
cotutor add science-tutor --display 科学老师 --subject 科学 --avatar 🔬
```

或者工作台(`/dev`)老师团页点「新老师」。新老师的家是空的,照出厂老师拷一份 activity 改,孩子才点得进去。没有注册表,删掉文件和那条配置就是删老师。

## 头像与声音

在家长端「首页」点老师的「样子与声音」改。

- **头像**:没设时,语文、数学、英语老师用包里自带的出厂头像(三个木钉娃娃),别的老师显示学科首字。头像可以是 emoji,也可以是 workspace 里的一张图(`avatars/<老师>.png`)。
- **用 figshot 搭一个**:[figshot](https://github.com/tarslab/figshot) 的 `figshot pick --workspace ~/cotutor/<孩子>` 让孩子自己搭一个乐高人仔当老师,存盘直接落到 `avatars/`。`cotutor.json` 里加一行 `"figshot": { "port": 8477 }`,孩子端首页就多一张「给老师们换个样子」,iPad 上点了直接进去(figshot 没开着时这张卡不出现)。
- **声音**:实时老师的声音由 realtime 模型提供;听写念词的配音也走百炼(同一把 key),出厂三位各有一个缺省的。点「换一个」在弹窗里挑:全部音色都在,能搜,能按男女、口音、中英、年纪、场景筛,能试听。

## 年级教学包

面向中国大陆小学一至六年级,当前提供二年级教学包。`cotutor grades` 查看可用年级;新建时未指定 `--grade` 默认二年级,未提供的年级不会自动回退。

出厂文件在 `grades/grade-2/`:

- 语文、数学有「课本」(预习、复习都在课本上做,要先把课本 PDF 放进 vault 的 `教材/`)和检查作业;英语有预习、检查作业、复习。孩子端老师牌上常驻这几块方砖。
- 语文有看图说话。
- 英语还有一块口语课方砖(拍今天学的那页,看着页跟读、一问一答)。
- 数学小课堂配合提前做好的课包。

孩子点进一块方砖,老师先不说话:课本已经翻到上次那一课(或家长在按钮上填的那一课),孩子说了话、拍了作业、按「给老师看」,老师才开始。他翻书、点读、写字,老师都看得到,不会插话。口语课例外,点进来老师先带着说。孩子没开口就回了首页,这一次不留记录。

家长按教材版本、学期和孩子实际进度设置材料。孩子当前学期由档案决定;升年级不会自动替换家长改过的 activity。贡献其他年级与验证方式见 [年级教学包](年级教学包.md)。

## 小课堂的课包

做小课堂的课包用 `cotutor chalk`(check / build / bake / snap / dub),烤画面与截图用本机的 Chrome(Windows 上没有 Chrome 就用 Edge)。

## 配置模型

**应用直连百炼。** 嘴(听孩子说、照着讲稿念)和脑(写讲稿和页上的动作)都用家长端「首页」填的那份百炼按量 API Key 与业务空间 ID。听写念词的配音、听写认字、照片上认字也用这份 key。

老师用哪个模型写在 `cotutor.json` 的 `runtimes` 里,出厂两个:

| 名字 | 模型 | 说明 |
|---|---|---|
| `api` | `qwen4-max` | 三位老师都用它 |
| `api-flash` | `qwen3.8-flash` | 便宜些;换之前先跑 `cotutor activity eval` 看例子过不过 |

嘴是 `qwen3.8-omni-flash-realtime`。模型、预算与老师运行时都在 workspace 的 `cotutor.json` 里,编辑器按首行 `$schema` 提供字段说明。

换了运行时,之前的话题接不上,也不导入历史:孩子接着说会开新话题;换之前聊的话题不记账,家长端卡上标「换过运行时 · 不记账」,记录照样能看。

## key 放哪

**key 只放 `~/.config/cotutor/`**(几个孩子的 workspace 共用),所有命令(`serve`、`send`、`replay`、`doctor`……)读同一处,环境变量(`DASHSCOPE_API_KEY` 之类)和别的工具的配置都不看:

| 文件 | 内容 | 谁写 |
|---|---|---|
| `bailian.json` | `{"apiKey": "sk-…", "workspaceId": "llm-…"}`,百炼按量 | 家长端「首页」;没有浏览器的机器照格式手写,或从别的机器拷过来 |
| `token-plan.json` | `{"apiKey": "sk-sp-…"}`,千问 Token Plan | 订了 Token Plan 的开发者手写;有它,Token Plan 有的模型先走它 |

手写的存成 UTF-8(不带 BOM)。配了什么、通不通看 `cotutor doctor`(`--live` 真连一次)。

## 百炼出了问题

百炼欠费、key 失效或这台电脑连不上百炼时,图标出橙点并通知,家长端首页说清楚是哪一种;要家长动手的那几种,孩子端显示「老师们还没到,叫爸爸妈妈来看一下」。处理好以后几分钟内自己恢复,也可以在家长端点「试连」。

页面上的老师起不来时,先看 `cotutor doctor` 和 `conversations/<老师>/<日期>.<job>.err.log`。
