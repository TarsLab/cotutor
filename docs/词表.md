# 词表

cotutor 自造的词,一个词一句话。写提示词、文档、界面文字都用这里的词;要用新词,先加进来(《写提示词.md》第六节)。

- 「代码里」是 schema 字段、文件或函数名,方便 grep。
- 「别说成」列的是容易混的说法。

## 人和页面

| 词 | 是什么 | 代码里 | 别说成 |
|---|---|---|---|
| 孩子端 | 孩子用的页面,在 iPad 或手机上:首页与板书页 `/`、听写 `/dictation`、口语课 `/talk`(拍口语单)。孩子端的路径都登记在免密白名单里 | `src/ui/kid/`、`access.ts` 的 `KID_EXACT` / `KID_PREFIX` | |
| 家长端 | 家长用的页面,都在 `/parent` 下:记录(清单,点一行是录像;打星、记账、删话题)、首页(排首页,听写、口语课的开关也在这)、设置 `/parent/settings`(按住说话那一栏放哪边)、打印二维码 `/parent/qr`、听写结果 `/parent/dictation` | `src/ui/parent/` | 工作台 |
| 工作台 | 开发和调老师用的桌面页,都在 `/dev` 下:概览、对话与看原文、老师团、activity、设置。日常排首页、扫码打开、头像与声音在家长端「首页」 | | 家长端 |
| 板书页 | 孩子端的老师页:一位老师、一个话题、一页板书 | | |
| 设备 | 孩子端开在哪个浏览器里:服务端种的一枚 cookie 算一台。同一台 iPad 上 Safari 与主屏幕图标是两台。家长在工作台给它起名 | `cotutor_kid`、`.cotutor/devices.json`、`deviceId` | 会话、连接 |
| 流水 | 孩子端各页往服务端记的事,一件一行:每次打开、页面脚本出错。按天存,删话题不动它 | `.cotutor/kid-log/<日期>.jsonl`、`KID_LOG_JS` | 日志、实录 |
| 舞台 | 孩子点开一张卡后铺满屏的那一层,在上面答题、画画 | `src/ui/stage/` | |
| 有脸的老师 | 旧说法:和工具人对着说的。2026-11-16 起 cotutor.json 里的都是老师,孩子端露不露看 `hidden`,直接说「老师」 | | tutor agent |
| 工具人 | activity 里替应用干一件小活的那一头(现在只有「认字」):`## <工具人>收到什么` 那一节是给它的模板。2026-11-16 以前也指键不以 `-tutor` 结尾的老师,那种没有了 | `ACTIVITY_TOOLS` | 子代理 |
| 老师团 | 一个孩子的全部老师(`cotutor.json` 的 `tutors`),当成一个整体来说:产品介绍「家里的 AI 老师团」、工作台「老师团」页、cotutor-tune。给孩子、家长看的句子里说「老师们」,如「Ray的老师们」「老师们休息中」 | `tutors` | 团队 |
| 老师文件 | 2026-11-16 以前的 `agents/<名>.md`,正文是普通话题的系统提示。不出厂、不读了;一科通用的做法并进每个 activity 的「<科>这一科」。旧 workspace 里的不删,refresh 与 doctor 提一句 | `retiredTutorFiles` | 提示词文件 |
| 年级教学包 | 某一年级的出厂老师和 activity 文件集合,安装后由家长维护 | `grades/grade-<n>/`、`teachingPack.grade` | 孩子档案、课程表 |
| activity | 孩子从首页一个按钮进去的一种做法,如看图说话。一个 activity 一个文件 | `src/schema/activity.ts` | 玩法、功能、模式、技能(那是 `skills/`) |
| activity 文件 | `agents/<老师>/activities/<名>.md`,在老师的家里。一节一个读者:家长填的、老师怎么带、<工具人>收到什么 | `src/runtime/activity.ts` | 提示词文件 |
| 老师守则 | 技能 cotutor-tutor 的正文:老师们共同的规矩。话题第一条注入 `<cotutor-rules>` | `tutor-rules.ts` | |
| 板书写法 | 技能 cotutor-board 的 SKILL.md。预载进系统提示,或放进 `<cotutor-board>` | `boardGuide` | |

## 一次对话

| 词 | 是什么 | 代码里 | 别说成 |
|---|---|---|---|
| 一轮 | 一条消息,加老师的一次回答 | | 一次对话 |
| job | 一轮的编号,形如 `1620-1`(时分-当天序号) | `job` | |
| 话题 | 一段连续的问答,孩子看到的一个「话题」。id 就是它第一条消息的 job | `thread` | 对话、会话 |
| 会话 | 脑那头接着聊的那段历史:同一话题、同一运行时就接着上一轮(resume);跨天新开;换了运行时,那个话题就算结束(接着说开新话题、不记账)。CLI 是它自己的 session,API 是应用存的模型历史 | `sessions[thread]`、`<日期>.<话题>.brain.jsonl` | 话题 |
| 对话索引 | 一位老师一天的记录 `conversations/<老师>/<日期>.json` | `conversation.ts` | 日志 |
| 任务 | `from: system` 的一轮,不是人问的,比如记账。别的轮都是 `from: kid`(工作台、`cotutor send` 发的也是) | | |
| 删话题 | 家长端清单上的「删」:话题的消息与每轮文件整个删,它写进记忆、日记的一起撤。家长在孩子端试完老师就这么收拾 | `deleteThread` | |
| 修饰词 | 围栏标签里种类后面的词。`formula` 这种是卡自己的;`same` `tint=` `look=` `emoji=` 是排版,哪种卡都认 | `mods` | 参数 |
| 小课堂 | 一段做好的课(课包 `bundles/<id>/`,或视频 `lectures/<id>/`),老师的声音讲、画面跟着走;孩子从首页的小课堂按钮进来,从头看完才能问老师 | `lecture` | 视频课、微课 |
| 画(一处) | 孩子在小课堂里停住后在画面上画的一处:停在同一刻画的几笔,一处一张截图给老师 | `mark` | 圈、标注、批注(那是老师在卡上画的) |
| lecture 卡 | 老师写在板书上的卡,放孩子看过的小课堂里的一段(带课里原来的声音);和节前那张「再看一遍」的小课堂卡(页面画的)不是一回事 | `lecture`(围栏) | 小课堂卡、场景卡 |
| 想要小课堂 | 老师写在给家长的尾巴里的一段 `## 想要小课堂`(`题面:` `讲法:`),请家长做一堂课;孩子看不到 | `parentText` | 场景作业 |
| 画的卡 | 画的一处变成的卡,孩子做的:那张截图 + 时刻;看完那排能删,问了以后画在回答它的那一节前面 | `c-mark` | 圈的卡、截图卡 |

| 拍给我看卡 | `photo` 卡:老师请孩子拍一张照片发来;下沿是「等你拍…」带拍照、相册,拍来的照片落回这里 | `photo` | 拍照卡、上传卡、image 卡(给孩子看的图) |

| 白纸条 | 要讲的那道题下面盖的一条白纸:页宽、跟着页滚,老师在上面摆点阵、方向盘、写字,孩子在上面画;一道题一条,讲别的收起来,回来原样在 | `Strip`、`src/board/strip.ts` | 白板、白板带子 |

| 底 | 上下文包 `board:` 里现在铺的那一页(课本哪一课、作业照片几张、白纸) | `slate.base` | 背景 |
| 板的日志 | 一节课里孩子在页上做的事,一件一行(`<date>.<话题>.board.jsonl`;名字没改);进上下文的是合并过的结果(上下文包的 `board:`) | `board-log` | |

## 实时老师

| 词 | 是什么 | 代码里 | 别说成 |
|---|---|---|---|
| 实时 | realtime 模型负责听说、脑写卡与讲稿的协作方式 | `live`(cotutor.json、消息) | 实时模式、语音模式 |
| 嘴 | 实时那头:百炼 realtime 模型,出声。只接住孩子的话、把给它的词照说,不讲新内容 | `src/runtime/live/call.ts` | 语音老师、副老师 |
| 脑 | 实时老师写卡和讲稿的那一头(activity、技能、vault 照旧),讲稿交给嘴照念。应用直连百炼(2026-11-02 以前也能起 Qwen Code) | `src/brain/`、`BrainExecutor` | 主老师 |
| 连接 | 嘴的一条百炼 realtime WebSocket,服务端连过去。一次通话里会换:断了现连,历史长了、换了一直听就在安静时换一条,孩子端不知道。孩子端与服务端之间那条(`/api/live/<老师>/ws`)不是它 | `RealtimeSession`、`src/realtime/bailian.ts` | 会话(那是脑的) |
| 接住 | 一轮开始脑还没写时嘴先说的那很短的一句。只用于三种情况:拍照「我看一看图片」、转写空的「没听清,再说一遍吧」、口语课开课「好,我们先热热身!」;别的嘴不先说 | `catchCue`、`caught` | 回应、确认、垫话 |
| 照念 | 嘴把脑写好的讲稿一字不改地念出来,写好一句交一句 | `readCue` | 朗读、复述 |
| 节头(实时) | 板上新一节的开头:脑写的一张只有一行 `# 标题` 的文字卡。守则不要求写(2026-11-04 去掉了),老师写了才有;没写,这一轮的卡接着上一节 | `heading`、`BoardEntry.head` / `cont` | 标题、小节标题、孩子的话 |
| 一直听 | 实时老师页上不用按住说话的那种说法:麦一直开着,孩子张嘴老师就听,说完了老师接;老师说话时也在听(全双工),孩子插嘴老师先小声、认出是孩子在说就停。口语课用;别的老师照 `live.listen`(缺省按住说),孩子端没有开关。和「按住说」相对 | `listen: 'open'`、`liveGate` | 常开麦、免按、电话模式 |
| 收下 / 放过 | 一直听时服务端切出来、转写回来的一句,算孩子对老师说的(收下 = 按下 + 松手)还是不算(放过:空的、老师没问时的语气词、老师自己的回声) | `judge`、`{t:'skip'}` | 过滤、丢弃 |
| 热身 | 口语课在英语老师实时页上的头一段:老师用中文带着孩子跟读,一拍一拍的小游戏(回声、小声大声、搭积木、你先说),顺带摸底 | `[[echo]]`、`[[say]]`、`src/scenes/talk/warmup.ts` | 跟读练习、预热 |
| 摸底 | 热身里应用每拍记的:跟没跟、开口快不快、说出了哪些词、自己说不说得出。只看转写,不说明发音;交给老师定打电话多难,老师在尾巴里写给家长 | `live.warmup`、`{t:'echo'}` | 测评、打分 |
| 打电话 | 口语课的第二段:响铃以后老师只说英文、一问一答聊口语单上的词,孩子确实跟不上才夹中文 | `[[call]]`、`live.phone` | 聊天、对话 |
| `[[echo 词]]` / `[[say 词]]` / `[[call]]` | 热身的三个记号,写在讲稿那句末尾:跟我说(念完等孩子跟)、你先说(念完等孩子自己说)、进打电话(念完响铃)。不锚卡,记在句子上 | `BoardLine.echo`、`call` | 指令、标签 |
