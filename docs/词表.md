# 词表

cotutor 自造的词,一个词一句话。写提示词、文档、界面文字都用这里的词;要用新词,先加进来(《写提示词.md》第六节)。

- 「代码里」是 schema 字段、文件或函数名,方便 grep。
- 「别说成」列的是容易混的说法。

## 人和页面

| 词 | 是什么 | 代码里 | 别说成 |
|---|---|---|---|
| 孩子端 | 孩子用的页面,在 iPad 或手机上:首页与老师页 `/`、听写 `/dictation`(口语课是英语老师的一块方砖,没有自己的页)。孩子端的路径都登记在免密白名单里 | `src/ui/kid/`、`access.ts` 的 `KID_EXACT` / `KID_PREFIX` | |
| 家长端 | 家长用的页面,都在 `/parent` 下:记录(清单,点一行是录像;打星、记账、删话题)、首页(排首页,听写、方砖的开关也在这)、设置 `/parent/settings`(按住说话那一栏放哪边)、打印二维码 `/parent/qr`、听写结果 `/parent/dictation` | `src/ui/parent/` | 工作台 |
| 工作台 | 开发和调老师用的桌面页,都在 `/dev` 下:概览、对话与看原文、老师团、activity、设置。日常排首页、扫码打开、头像与声音在家长端「首页」 | | 家长端 |
| 老师页 | 孩子端点进一位老师以后的那页:一节课的页铺满在舞台上,老师一边说一边在页上做动作;以前叫板书页 | | 板书页(旧说法) |
| 设备 | 孩子端开在哪个浏览器里:服务端种的一枚 cookie 算一台。同一台 iPad 上 Safari 与主屏幕图标是两台。家长在工作台给它起名 | `cotutor_kid`、`.cotutor/devices.json`、`deviceId` | 会话、连接 |
| 流水 | 孩子端各页往服务端记的事,一件一行:每次打开、页面脚本出错。按天存,删话题不动它 | `.cotutor/kid-log/<日期>.jsonl`、`KID_LOG_JS` | 日志、实录 |
| 舞台 | 铺满屏的那一层:一节课的页(课本、照片、白纸、小课堂)在上面画,舞台包 `src/ui/stage/` 在 iframe 里 | `src/ui/stage/` | |
| 有脸的老师 | 旧说法。cotutor.json 里的都是老师,孩子端露不露看 `hidden`,直接说「老师」 | | tutor agent |
| 工具人 | activity 里替应用干一件小活的那一头(现在只有「认字」):`## <工具人>收到什么` 那一节是给它的模板。不指哪位老师:键不以 `-tutor` 结尾的那种老师没有了 | `ACTIVITY_TOOLS` | 子代理 |
| 老师团 | 一个孩子的全部老师(`cotutor.json` 的 `tutors`),当成一个整体来说:产品介绍「家里的 AI 老师团」、工作台「老师团」页、cotutor-tune。给孩子、家长看的句子里说「老师们」,如「Ray的老师们」「老师们休息中」 | `tutors` | 团队 |
| 老师文件 | 旧东西:`agents/<名>.md`。不出厂、不读;一科通用的做法并进每个 activity 的「<科>这一科」。旧 workspace 里的不删,refresh 与 doctor 提一句 | `retiredTutorFiles` | 提示词文件 |
| 年级教学包 | 某一年级的出厂老师和 activity 文件集合,安装后由家长维护 | `grades/grade-<n>/`、`teachingPack.grade` | 孩子档案、课程表 |
| activity | 孩子从首页一个按钮进去的一种做法,如看图说话。一个 activity 一个文件 | `src/schema/activity.ts` | 玩法、功能、模式、技能(那是 `skills/`) |
| activity 文件 | `agents/<老师>/activities/<名>.md`,在老师的家里。一节一个读者:家长填的、老师怎么带、<工具人>收到什么 | `src/runtime/activity.ts` | 提示词文件 |
| 老师守则 | 技能 cotutor-tutor 的正文:老师们共同的规矩。话题第一条注入 `<cotutor-rules>` | `tutor-rules.ts` | |
| 讲稿与动作怎么写 | `cards/动作怎么写.md`:讲稿一行一句、末句问句才停、动作怎么写。跟在 activity 后面进系统提示。「板书写法」(技能 cotutor-board)没有了 | `actsGuide` | 板书写法(旧说法) |

## 一次对话

| 词 | 是什么 | 代码里 | 别说成 |
|---|---|---|---|
| 一轮 | 一条消息,加老师的一次回答 | | 一次对话 |
| job | 一轮的编号,形如 `1620-1`(时分-当天序号) | `job` | |
| 话题 | 一段连续的问答,孩子看到的一个「话题」。id 就是它第一条消息的 job | `thread` | 对话、会话 |
| 会话 | 脑那头接着聊的那段历史:同一话题、同一运行时就接着上一轮(resume);跨天新开;换了运行时,那个话题就算结束(接着说开新话题、不记账)。CLI 是它自己的 session,API 是应用存的模型历史 | `sessions[thread]`、`<日期>.<话题>.brain.jsonl` | 话题 |
| 对话索引 | 一位老师一天的记录 `conversations/<老师>/<日期>.json` | `conversation.ts` | 日志 |
| 任务 | `from: system` 的一轮,不是人问的,比如记账。别的轮都是 `from: kid`(工作台、`cotutor send` 发的也是) | | |
| 删话题 | 家长端清单上的「删」:话题的消息与每轮文件整个删,它写进记忆、日记的一起撤。家长在孩子端试完老师就这么收拾 | `deleteThread` | |
| 小课堂 | 一段做好的课(课包 `bundles/<id>/`,或视频 `lectures/<id>/`),老师的声音讲、画面跟着走;孩子从首页的小课堂按钮进来,从头看完才能问老师 | `lecture` | 视频课、微课 |
| 画(一处) | 孩子在小课堂里停住后在画面上画的一处:停在同一刻画的几笔,一处一张截图给老师 | `mark` | 圈(那是老师在页上做的) |
| 想要小课堂 | 老师写在给家长的尾巴里的一段 `## 想要小课堂`(`题面:` `讲法:`),请家长做一堂课;孩子看不到 | `parentText` | 场景作业 |

## 讲稿与页

| 词 | 是什么 | 代码里 | 别说成 |
|---|---|---|---|
| 讲稿 | 老师回复的正文,到第一个 `## ` 为止:一行一句,嘴照念,字幕行显示;动作写在句子后面。代码里还叫板书(`kidText`、`section`) | `kidText`、`lines` | 台词、板书(旧说法) |
| 卡 | 课里没有卡:老师写了围栏不上页、不念,给家长记一句。现在只剩首页的两种牌(老师牌、听写牌),代码里还叫卡(`cards/<kind>/`、`CARD_KINDS`) | `cards` | 组件 |
| 一节 | 老师一次回复写的讲稿:讲一个想法,讲完就停(要孩子做一步时末句请他做) | `section` | 一页 |
| 就绪 | 第一句出来了:嘴能开口念(首句就绪) | `firstReadyMs`、`ready:speak` | |
| 尾巴 | 讲稿第一个 `## ` 起的部分,孩子看不到。给家长的话、「## 记忆」「## 记账」都在这 | `parentText` | |
| 旁注 | 家长端在一轮一轮之间插的只读块(给家长的话、记住了) | | 卡 |
| 录像 | 家长端按时间重看孩子的一个话题(听写也有,`/parent/dictation/reel`:按笔迹的时刻一笔一笔重画):上半是孩子的屏幕(孩子端同一份页面开在 iframe 里,照当时的数据画)、下半是录像栏。录的是数据,不是屏幕 | `ui/kid/reel.ts`、`/threads/<话题>/reel`、`/reel`、`MODE.reel` | 回放(那是 `cotutor replay`)、再听、录屏 |
| 课包 | 用 `cotutor chalk` 做出的逐笔讲解动画,在 `bundles/<id>/`;家长在 workspace 里做,当小课堂放 | `bundle` | 动画文件 |
| 气口 | 课包里一步画完的停顿;小课堂放的时候不停 | | |
| 图形 | 白纸条、白纸页上能摆的预设的画:老师写 `[[摆 点阵 6 行 6 个]]`,应用排出画面、排在哪;孩子在上面圈、切、涂、转。现在有点阵、方向盘 | `src/chalk/kit/`、`[[摆 …]]` | 教具、画法(旧说法)、模板 |
| 铺哪种页 | activity 头上的 `base:`:`photo` 孩子拍的作业(进来先拍照,不拍就是白纸;不写也是它),`textbook` 课本,`lecture` 小课堂,`workbook` 练习册。以前的 `board: page`、`cards:` 不用再写,读进来就丢 | `base:`、`ActivityBase`、`activityBase` | 以板为主(旧说法)、板书模式 |
| 浮层 | 点字浮在页一角的那一块,应用自己弹、不等老师:汉字是田字格,英文单词是四线三格;点别的换成那个,× 收起 | `#st-pick`、`FLOATS` | 弹窗 |
| 课本页 | vault 里教材那篇旁边同名文件夹里的扫描页;拍照屏上「选课本页」挑一页,当孩子拍的照片用 | `textbook-pages` | 电子课本 |
| 课本 | 课本做底时页上铺的教材 PDF(activity 头上 `base: textbook`):家长从教育网站下载放进 vault 的 `教材/`,应用读它的文字层(逐字的位置、拼音、目录、页码),不拍照、不认图。一课的几页竖着连成一条,是一节课里的一页 | `base: textbook`、`book`、`src/memory/textbook-index.ts` | 电子课本 |
| 一节课 | 孩子从首页点进一个铺页的 activity 到回首页。铺着页,老师一边说一边在页上做动作,孩子在页上写、点、说;应用记着它此刻的样子。过渡期代码里还叫话题(`thread`),落盘的文件名不改 | `Lesson`、`<date>.<话题>.lesson.json`、`lessonStep` | 话题(旧说法) |
| 页 | 一节课铺着的东西:课本的一课(几页 PDF 连成一条)、孩子拍的作业照片(几张连成一条,最多 6 张)、白纸、一堂小课堂(按时刻编号,老师写 `[[看 0:19–0:30]]` 放课里一段)。每页上三层:老师的(记号、白纸条)、孩子的(笔、揭开、点过的)、开放的 | `LessonPage`、`PageSource` | 板、底(旧说法) |
| 页的文字层 | 页上印的字和它们的位置:课本是 PDF 的文字层,照片是认字认出的行、题、字词(换成课本的样子,`src/chalk/kit/photo.ts`)。看、圈、遮、盖、点字都照它找;第一次看到那一页时当一条 `<page>` 给老师 | `pageText`、`photoBookPage`、`pageNotes` | 全文(旧说法)、OCR |
| 白纸页 | 一节课里的一张白纸:没拍照片时就是它,老师 `[[翻 白纸]]` 也能加;整页就是一条白纸条,摆、写不用先看 | `WHITE_PAGE` | 白板 |
| 收笔 | 孩子在页上写完、抬笔以后停一会儿没再落笔(空位上 2.5 秒、白纸条上 6 秒,`live.pen`),应用替他把窗里的图交给老师,嘴先说「我看看你写的」 | `turnStep`、`app: pen` | 自动提交 |
| 动作 | 老师对页做的事,写在讲稿那一句末尾的双方括号里:翻、看、圈、遮、盖、写、擦、摆、请。那一句念完应用才做,第一句前面的马上做;不认得的丢掉、给家长记一行。写法在 `cards/动作怎么写.md` | `[[看 例 4]]`、`LineAct`、`src/board/acts.ts` | 卡、指令、cue |
| 白纸条 | 要讲的那道题下面盖的一条白纸:页宽、跟着页滚,老师在上面摆点阵、方向盘、写字,孩子在上面画;一道题一条,讲别的收起来,回来原样在 | `Strip`、`src/board/strip.ts` | 白板、白板带子 |
| 请 | 开放哪些作答:写、圈、点(点字)、涂、切、转、添、说。请着用笔的(写、圈、涂、切、添),孩子停了笔应用替他交;课本页上没请也能画,不替他交;别的页没请就只能看(语文课本上还能点字) | `[[请 圈]]`、`LessonPage.open` | 操作 |
| 窗 | 一节课里孩子屏幕上看见的那一块:老师写 `看:` 滚过去(大小不变),孩子手指拖动自己挪(页宽时只上下,双击在页宽和两倍之间切,不两指缩放);笔(Apple Pencil)只画不挪。孩子停下的地方说成一句告诉老师(`孩子在看`) | `frame`、`view` | 镜头、视口 |
| 题框 | 作业照片认出每道题的框(认字时要的);老师写 `[[看 第 3 题]]` 窗移到那一道,白纸条贴着题框的下沿。斜着拍的照片认不出题就落不了,给家长记一句 | `questions`、`BookBlock.area` | 分题、切题 |
| 练习册 | 照教材一个单元编的几页习题,孩子在 iPad 上用 Apple Pencil 直接在页上做。放在 vault 的 `练习册/`,一册一个文件夹:每页一张图 + `workbook.json`(文字层、每道题的作答区与物件、给老师的答案),和打印版出自同一份排版,框不用认。首页按钮挂 `activity 做练习册`、填「练习册:」,孩子点了就铺那一册 | `src/schema/workbook.ts`、`Workbook`、`base: workbook` | 习题集、作业本 |
| 作答区 | 练习册一道题里孩子作答的那一块:写(空格、横线、田字格、四线三格)、圈、画、连线、画线、描写。孩子落的笔照它归到哪一格;答案挂在作答区上,只给老师 | `WorkbookRegion`、`regions` | 填空区、答题框 |
| 遮拼音 | 动作「遮」:老师写字,应用照页的文字层找到它,盖住字头上的拼音;孩子点一下揭开,揭了哪些、没揭哪些告诉老师 | `[[遮 …]]`、`reveal` | 隐藏拼音 |
| 底 | 上下文包 `board:` 里现在铺的那一页(课本哪一课、作业照片几张、白纸) | `slate.base` | 背景 |
| 板的日志 | 一节课里孩子在页上做的事,一件一行(`<date>.<话题>.board.jsonl`;名字没改);进上下文的是合并过的结果(上下文包的 `board:`) | `board-log` | |
| 点字 | 孩子在页上点一个汉字(或英文单词),浮出它的田字格(四线三格)。应用照页的文字层在本地算,不经老师;点过的随下一轮告诉老师。数学的页上不弹(点的是数和算式) | `[[请 点]]`、`picked`、`bookPick` | 圈字 |
| 点读 | 语文课本的一课上,孩子点标题或段首的那块空白,孩子端用这位老师「点读的声音」一段一段读下去(诗一节一节);读的时候钮留在那一段前面,再点就暂停。页上不刷不画。不经老师,读到哪停的随下一轮告诉老师 | `bookReadParts`、`/api/kid/textbook/say`、板的日志 `read`、`reading` | 朗读、点字、照念 |
| 大概 | 应用按孩子笔画的位置算的一句(几道线、大致分成几份);和图对不上时老师信图 | `Kit.read` | 识别结果、判定 |

## 老师看到的

| 词 | 是什么 | 代码里 | 别说成 |
|---|---|---|---|

| 讲法 | 家长写给老师、孩子看不到的讲课要点,挂在首页按钮下面(`讲法:` 行),孩子点了进上下文包 `home:`;`## 想要小课堂` 里的 `讲法:` 是老师写给家长的 | `brief` | 提示 |

## 家长的 vault

| 词 | 是什么 | 代码里 | 别说成 |
|---|---|---|---|
| workspace | 一个孩子的全部:cotutor.json、activity、对话、照片、课包。一孩一个。跟家长说「孩子的 cotutor 文件夹」(小明的就是「小明的 cotutor 文件夹」,缺省 `~/cotutor/<slug>/`) | | 项目、孩子的文件夹(里面是程序的记录,孩子的档案在 vault) |
| sandbox | 手动试功能用的 workspace:命令加 `--sandbox`,从真 workspace 分出一份放在旁边的 `.sandbox/<目录名>/`,设置照拷,对话与照片不带,vault 拷一份;试的对话与 vault 的写入都留在它里面。页面标题带「试用」 | `src/app/cli/sandbox.ts`、`.cotutor/sandbox.json`、`SANDBOX_*` | 测试模式、mock(那是假接口) |
| vault | 孩子的长期记忆:档案、日记、记忆,全是 markdown,家长可以用 Obsidian 打开(不必装)。和 workspace 分开放,缺省在旁边的 `<目录名>-vault/`。老师不直接写。跟家长说「孩子的笔记文件夹」 | `paths.vault` | 知识库 |
| 档案 | `cotutor: profile` 的那篇:孩子是谁。每位老师每个话题第一条都拿到 | `profile` | |
| 入口文件 | `cotutor: subject` 的那篇,一科一学期一篇:学到哪、常问什么、家长想怎么讲 | `entry` | 学科文件 |
| 教材 | `cotutor: textbook` 的那篇。只给老师路径,要用自己读 | `refs` | |
| 记忆 | 老师自己记下的,每个 agent 独立一篇,activity 与普通聊天分开。老师回「## 记忆」段,应用增、改、删 | `memory` | CLI 的 memory |
| 孩子的记忆 | 关于孩子本人、换一科也成立的,所有老师共用一篇(`agent: all`,缺省 `记忆/孩子.md`)。老师在「## 记忆」里写 `孩子:` 开头的行,应用记进来;最多 20 条 | `child`、`childLines` | 共享记忆 |
| 建议 | 「## 记忆」段里的一条。应用校验过证据才写进记忆,对每条记下对没对上 | `memoryProposals`、`src/memory/proposals.ts` | |
| 取材 | 应用替老师从 vault 里查好、放进上下文包的:生字表、那一课的口径、以前讲过的骨架。只做关键词与标题匹配 | `lookup`、`src/memory/retrieval.ts` | 检索增强 |

## 实时老师

| 词 | 是什么 | 代码里 | 别说成 |
|---|---|---|---|
| 实时 | realtime 模型负责听说、脑写讲稿与动作的协作方式 | `live`(cotutor.json、消息) | 实时模式、语音模式 |
| 嘴 | 实时那头:百炼 realtime 模型,出声。脑先答的 activity 里只接住孩子的话、把给它的词照说,不讲新内容;嘴先答的在脑给的范围里接孩子的作答 | `src/runtime/live/call.ts` | 语音老师、副老师 |
| 脑 | 实时老师写讲稿与动作的那一头(activity、技能、vault 照旧),讲稿交给嘴照念。应用直连百炼 | `src/brain/`、`BrainExecutor` | 主老师 |
| 连接 | 嘴的一条百炼 realtime WebSocket,服务端连过去。一次通话里会换:断了现连,历史长了、换了一直听就在安静时换一条,孩子端不知道。孩子端与服务端之间那条(`/api/live/<老师>/ws`)不是它 | `RealtimeSession`、`src/realtime/bailian.ts` | 会话(那是脑的) |
| 接住 | 一轮开始脑还没写时嘴先说的那很短的一句。只用于这几种情况:拍照「我看一看图片」、转写空的「没听清,再说一遍吧」、收笔「我看看你写的」、嘴先答时孩子说中了嘴接的那一句;别的嘴不先说 | `catchCue`、`caught` | 回应、确认、垫话 |
| 照念 | 嘴把脑写好的讲稿一字不改地念出来,写好一句交一句 | `readCue` | 朗读、复述 |
| 一直听 | 实时老师页上不用按住说话的那种说法:麦一直开着,孩子张嘴老师就听,说完了老师接;老师说话时也在听(全双工),孩子插嘴老师先小声、认出是孩子在说就停。activity 头上写了 `listen: open` 的用(口语课);别的照 `live.listen`(缺省按住说),孩子端没有开关。和「按住说」相对 | `listen: open`、`liveGate` | 常开麦、免按、电话模式 |
| 收下 / 放过 | 一直听时服务端切出来、转写回来的一句,算孩子对老师说的(收下 = 按下 + 松手)还是不算(放过:空的、老师没问时的语气词、老师自己的回声) | `judge`、`{t:'skip'}` | 过滤、丢弃 |
| 请他说 | 讲稿那句末尾写 `[[请 说 duck]]`:那句念完应用停下等孩子说那一句,照转写比他说没说(英文按词、中文按字),说了接着念下一句,说的是别的交给老师。老师这句里自己说了那个词是跟我说,没说是你先说。哪个 activity 都能写(以前口语课热身的 `[[echo]]` `[[say]]`) | `[[请 说 …]]`、`BoardLine.echo`、`src/board/echo.ts` | 跟读闸、echo |
| 热身 | 口语课的头一段:老师用中文带着孩子一拍一拍地说(回声、小声大声、搭积木、你先说),每拍是一个请他说,顺带看看他今天的底子 | `[[请 说 …]]` | 跟读练习、预热 |
| 摸底 | 请他说的每一拍应用记的:说没说、开口快不快、说出了哪些词、自己说不说得出。只看转写,不说明发音;交给老师定接下来多难,老师在尾巴里写给家长 | `live.echo`、`{t:'echo'}` | 测评、打分 |
| 谁先答 | 孩子作答以后先由嘴答还是脑答,activity 头上写(`reply: mouth` 是嘴先答,不写是脑先答);代码不照学科分 | `reply:`、`ACTIVITY_REPLIES` | 快答模式 |
| 嘴先答 | 老师一轮最后一句请孩子说的,他答了嘴先在那个范围里接:说中了嘴接一句、老师接着写;没说中嘴提示一下再等他,连着两次还不行交给老师。嘴说过的下一轮带给老师 | `replyCue`、`live.mouth` | 嘴自己聊 |
