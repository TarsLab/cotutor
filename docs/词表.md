# 词表

cotutor 自造的词,一个词一句话。写提示词、文档、界面文字都用这里的词;要用新词,先加进来(《写提示词.md》第六节)。

- 「代码里」是 schema 字段、文件或函数名,方便 grep。
- 「别说成」列的是容易混的说法。

## 人和页面

| 词 | 是什么 | 代码里 | 别说成 |
|---|---|---|---|
| 孩子端 | 孩子用的页面 `/`,在 iPad 或手机上。有首页和板书页 | `kid-page.ts` | |
| 家长端 | 家长用的页面,都在 `/parent` 下:记录(清单,点一行是录像;打星、记账、删话题)、设首页、听写、口语课 | `MODE.parent` | 工作台 |
| 工作台 | 开发和调老师用的桌面页,都在 `/dev` 下:概览、对话与看原文、老师团、activity、音色、设置,扫码 `/dev/qr`。日常排首页在家长端「首页」 | | 家长端 |
| 板书页 | 孩子端的老师页:一位老师、一个话题、一页板书 | | |
| 设备 | 孩子端开在哪个浏览器里:服务端种的一枚 cookie 算一台。同一台 iPad 上 Safari 与主屏幕图标是两台。家长在工作台给它起名 | `cotutor_kid`、`.cotutor/devices.json`、`deviceId` | 会话、连接 |
| 流水 | 孩子端各页往服务端记的事,一件一行:每次打开、页面脚本出错。按天存,删话题不动它 | `.cotutor/kid-log/<日期>.jsonl`、`KID_LOG_JS` | 日志、实录 |
| 舞台 | 孩子点开一张卡后铺满屏的那一层,在上面答题、画画 | `src/ui/stage/` | |
| 有脸的老师 | cotutor.json 里键以 `-tutor` 结尾的老师。孩子看得到,拿老师守则 | `takesTutorRules` | tutor agent |
| 工具人 | 键不以 `-tutor` 结尾的老师。孩子看不到,只和应用打交道 | | 子代理 |
| 老师文件 | `.claude/agents/<名>.md`(仓里是 `grades/grade-<n>/agents/`)。frontmatter 是运行字段,正文是系统提示 | `agent-file.ts` | 提示词文件 |
| 年级教学包 | 某一年级的出厂老师和 activity 文件集合,安装后由家长维护 | `grades/grade-<n>/`、`teachingPack.grade` | 孩子档案、课程表 |
| activity | 孩子从首页一个按钮进去的一种做法,如你说我画。一个 activity 一个文件 | `src/schema/activity.ts` | 玩法、功能、模式、技能(那是 `skills/`) |
| activity 文件 | `agents/<老师>/activities/<名>.md`,在老师的家里。一节一个读者:家长填的、应用算的、应用拦的、老师怎么带、<工具人>收到什么 | `src/runtime/activity.ts` | 提示词文件 |
| 老师守则 | 技能 cotutor-tutor 的正文:有脸的老师共同的规矩。话题第一条注入 `<cotutor-rules>` | `tutor-rules.ts` | |
| 板书写法 | 技能 cotutor-board 的 SKILL.md。预载进系统提示,或放进 `<cotutor-board>` | `boardGuide` | |

## 一次对话

| 词 | 是什么 | 代码里 | 别说成 |
|---|---|---|---|
| 一轮 | 一条消息,加老师的一次回答 | | 一次对话 |
| job | 一轮的编号,形如 `1620-1`(时分-当天序号) | `job` | |
| 话题 | 一段连续的问答,孩子看到的一个「话题」。id 就是它第一条消息的 job | `thread` | 对话、会话 |
| 会话 | CLI 的 session。一个话题一个会话,续聊时 resume;跨天不 resume | `sessions[thread]` | 话题 |
| 对话索引 | 一位老师一天的记录 `conversations/<老师>/<日期>.json` | `conversation.ts` | 日志 |
| 任务 | `from: system` 的一轮,不是人问的,比如记账。别的轮都是 `from: kid`(工作台、`cotutor send` 发的也是) | | |
| 删话题 | 家长端清单上的「删」:话题的消息与每轮文件整个删,它写进记忆、日记的一起撤。家长在孩子端试完老师就这么收拾 | `deleteThread` | |
| 修饰词 | 围栏标签里种类后面的词。`formula` 这种是卡自己的;`same` `tint=` `look=` `emoji=` 是排版,哪种卡都认 | `mods` | 参数 |
| 小课堂 | 一段做好的课(drawtell 课包 `bundles/<id>/`,或视频 `lectures/<id>/`),老师的声音讲、画面跟着走;孩子从首页的小课堂按钮进来,从头看完才能问老师 | `lecture` | 视频课、微课 |
| 画(一处) | 孩子在小课堂里停住后在画面上画的一处:停在同一刻画的几笔,一处一张截图给老师 | `mark` | 圈、标注、批注(那是老师在卡上画的) |
| lecture 卡 | 老师写在板书上的卡,放孩子看过的小课堂里的一段(带课里原来的声音);和节前那张「再看一遍」的小课堂卡(页面画的)不是一回事 | `lecture`(围栏) | 小课堂卡、场景卡 |
| 想要小课堂 | 老师写在给家长的尾巴里的一段 `## 想要小课堂`(`题面:` `讲法:`),请家长做一堂课;孩子看不到 | `parentText` | 场景作业 |
| 画的卡 | 画的一处变成的卡,孩子做的:那张截图 + 时刻;看完那排能删,问了以后画在回答它的那一节前面 | `c-mark` | 圈的卡、截图卡 |

## 板书

| 词 | 是什么 | 代码里 | 别说成 |
|---|---|---|---|
| 板书 | 老师回复的正文,孩子看到的那块板。到第一个 `## ` 为止 | `kidText` | 回复 |
| 讲稿 | 板书里的普通行。一行一句,会被念出来 | `lines` | 台词 |
| 卡 | 板书里的一个围栏。标签是卡的种类,比如 `choice` | `cards` | 组件 |
| 一节 | 老师一次回复写的板书:讲一个想法,讲完就停(要孩子做一步时末句请他做) | `section` | 一页 |
| 一拍 | 一张卡,加上它后面到下一张卡之前的讲稿。不进契约,现算 | `beatsOf` | |
| 就绪 | 一拍关了:卡能铺、嘴能念这一拍的讲稿(第一拍就绪 = 首句就绪) | `firstReadyMs` | |
| 半宽 | 卡占半行。字少的卡半宽,相邻两张半宽的并一行;放不下就全宽。页面量出来的,不是谁定的 | `canHalf`、`fitsHalf`、`rowsFor` | 小卡、短卡 |
| 尾巴 | 板书第一个 `## ` 起的部分,孩子看不到。给家长的话、「## 记忆」「## 记账」都在这 | `parentText` | |
| 旁注 | 家长板书页在节与节之间插的只读块,不是卡 | | 卡 |
| 录像 | 家长端按时间重看孩子的一个话题(听写也有,`/parent/dictation/reel`:按笔迹的时刻一笔一笔重画):上半是孩子的屏幕(孩子端同一份页面开在 iframe 里,照当时的数据画)、下半是录像栏。录的是数据,不是屏幕 | `ui/kid/reel.ts`、`/threads/<话题>/reel`、`/reel`、`MODE.reel` | 回放(那是 `cotutor replay`)、再听、录屏 |
| 课包 | 用 drawtell 做出的逐笔讲解动画,在 `bundles/<id>/`;家长在 workspace 里做,当小课堂放 | `bundle` | 动画文件 |
| 气口 | 课包里一步画完的停顿;小课堂放的时候不停 | | |
| 你说我画 | 孩子编一个故事,语文老师用画家的口吻问到说清楚,应用画成一张连环画;出题版叫「我来出题」,画出来是一道看图说话题 | `paint`(卡)、`src/scenes/paint/` | AI 画画、文生图 |
| 画家 | 你说我画里老师追问时借的那个读者:只知道孩子说出来的话。不是一位老师,没有老师文件 | | 画图老师 |
| 分幅 | 一幅一句,只写看得见的;画图卡的编号行 | `panels` | 分镜、提示词 |
| 画图卡 | `paint` 卡:老师写分幅,应用画成图;出题版带题干与词语宝库 | `paint` | image 卡(现成的图)、canvas 卡(孩子画) |
| 拍给我看卡 | `photo` 卡:老师请孩子拍一张照片发来;下沿是「等你拍…」带拍照、相册,拍来的照片落回这里 | `photo` | 拍照卡、上传卡、image 卡(给孩子看的图) |
| 画板卡 | `canvas` 卡:老师出题,孩子在上面画;点开铺满,交过就锁 | `canvas` | 画图卡(那是应用画的) |
| 纸 | 孩子在实时老师页左栏点「画板」打开的那张:没题、没底,一个话题一张,一直能改 | `paper`、`src/board/paper.ts`、`S.paper` | 草稿、白板、画板卡 |
| 画卡 | 孩子从纸上交给老师的画在板上那张:图、几笔、「接着画」;放在回答它的那一节前面 | `drawing`、`c-draw` | 画的卡(那是小课堂里画的一处) |
| 边画边聊 | 画板开着时嘴看着画说话:孩子按头像说的只给嘴,嘴也会照规矩主动说一句;交画那一轮说过的一起给脑 | `chat`、`live.draw`、`src/board/canvas-chat.ts` | 实时点评 |

## 老师看到的

| 词 | 是什么 | 代码里 | 别说成 |
|---|---|---|---|
| 上下文包 | 应用放在每条消息前的一块 YAML,后面接几段原文。老师能看到的,只有它和自己 Read 的文件 | `src/schema/context-pack.ts` | prompt |
| 插槽 | activity 文件里交给工具人的那段的 `{{名字}}`(如画家的 `{{分幅}}`),应用填。给老师的字不插值 | `fillSlots` | 变量 |

## 实时老师

| 词 | 是什么 | 代码里 | 别说成 |
|---|---|---|---|
| 实时 | realtime 模型负责听说,Qwen Code 运行脑模型写卡与讲稿的协作方式 | `live`(cotutor.json、消息) | 实时模式、语音模式 |
| 嘴 | 实时那头:百炼 realtime 模型,出声。只接住孩子的话、把给它的词照说,不讲新内容;画板开着时例外,看着画说一两句(边画边聊) | `src/runtime/live/call.ts` | 语音老师、副老师 |
| 脑 | 实时时的老师命令行(老师文件、技能、vault 照旧),写卡和讲稿,讲稿交给嘴照念 | | 主老师 |
| 连接 | 一条 realtime WebSocket,孩子端一个老师页一条;「会话」留给命令行的 session | `RealtimeSession` | 会话 |
| 接住 | 一轮开始脑还没写时嘴先说的那很短的一句。只用于三种情况:拍照「我看一看图片」、转写空的「没听清,再说一遍吧」、口语课开课「好,我们先热热身!」;别的嘴不先说 | `catchCue`、`caught` | 回应、确认、垫话 |
| 照念 | 嘴把脑写好的讲稿一字不改地念出来,写好一句交一句 | `readCue` | 朗读、复述 |
| 节头(实时) | 实时的板上一件事的开头:脑写的一张只有一行 `# 标题` 的文字卡,一行摘要。脑觉得是新的一件事才写;没写,这一轮的卡接着上一节 | `heading`、`BoardEntry.head` / `cont` | 标题、小节标题、孩子的话 |
| 一直听 | 实时老师页上不用按住说话的那种说法:麦一直开着,孩子张嘴老师就听,说完了老师接;老师说话时也在听(全双工),孩子插嘴老师先小声、认出是孩子在说就停。口语课用;别的老师照 `live.listen`(缺省按住说),孩子端没有开关。和「按住说」相对 | `listen: 'open'`、`liveGate` | 常开麦、免按、电话模式 |
| 收下 / 放过 | 一直听时服务端切出来、转写回来的一句,算孩子对老师说的(收下 = 按下 + 松手)还是不算(放过:空的、老师没问时的语气词、老师自己的回声) | `judge`、`{t:'skip'}` | 过滤、丢弃 |
| 热身 | 口语课在英语老师实时页上的头一段:老师用中文带着孩子跟读,一拍一拍的小游戏(回声、小声大声、搭积木、你先说),顺带摸底 | `[[echo]]`、`[[say]]`、`src/scenes/talk/warmup.ts` | 跟读练习、预热 |
| 摸底 | 热身里应用每拍记的:跟没跟、开口快不快、说出了哪些词、自己说不说得出。只看转写,不说明发音;交给老师定打电话多难,老师在尾巴里写给家长 | `live.warmup`、`{t:'echo'}` | 测评、打分 |
| 打电话 | 口语课的第二段:响铃以后老师只说英文、一问一答聊口语单上的词,孩子确实跟不上才夹中文 | `[[call]]`、`live.phone` | 聊天、对话 |
| `[[echo 词]]` / `[[say 词]]` / `[[call]]` | 热身的三个记号,写在讲稿那句末尾:跟我说(念完等孩子跟)、你先说(念完等孩子自己说)、进打电话(念完响铃)。不锚卡,记在句子上 | `BoardLine.echo`、`call` | 指令、标签 |
