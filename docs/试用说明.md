# cotutor 试用说明(R3 版,2026-09-09)

> 给手动试用写的操作稿:从零建一个孩子的 workspace,到家长端聊三轮、孩子端在 iPad 上按住说话。每步都写了「看到什么算对」和「不对时看哪里」。设计与拍板见《产品规划.md》,这里只讲怎么跑。

## 0. 准备

| 要什么 | 怎么确认 | 备注 |
|---|---|---|
| Node ≥ 22.18 | `node -v` | bin 直跑 src,不用构建 |
| `claude` 或 `qwen` 至少一个 | `claude --version` / `qwen --version` | 本机 claude 2.1.220 不认全局 settings 里的模型,**预设模板要加 `--model sonnet`**(第 2 步会改) |
| voxtell(配音,可选) | `node ~/Projects/github-tarslab/voxtell/bin/voxtell.js doctor` | 没发 npm,用本地检出;不配就用浏览器的声 |
| mkcert(iPad 上录音要,可选) | `mkcert -CAROOT` 能打出目录 | 没有:`brew install mkcert && mkcert -install` |
| 仓库依赖 | `cd ~/Projects/github-tarslab/cotutor && pnpm i && pnpm test` | 15 个测试文件全绿再往下 |

下文的 `cotutor` 都指 `node ~/Projects/github-tarslab/cotutor/bin/cotutor.js`;嫌长就 `alias cotutor='node ~/Projects/github-tarslab/cotutor/bin/cotutor.js'`。

**在 Claude Code 会话里试**要先 `unset CLAUDECODE CLAUDE_CODE_ENTRYPOINT CLAUDE_CODE_SESSION_ID CLAUDE_CODE_CHILD_SESSION CLAUDE_PID CLAUDE_EFFORT`,否则老师起不来(嵌套会话被拒)。在普通终端里不用管。

## 1. 建 workspace

```sh
cotutor init ming --name 小明 --port 5180
```

看到什么算对:`~/cotutor/ming/` 下有 `cotutor.json`、`CLAUDE.md`、`QWEN.md`、`agents/<五位老师>/`、`ledger/`、`conversations/`,`.claude/agents/` 里五个链指向仓库的 `agents/*.md`。重跑一次全是 `exists` / `kept`,不会覆盖你改过的东西。

顺手 `cd ~/cotutor/ming && git init && git add -A && git commit -m init`:老师记忆、账本、政策都是不可再生状态,改坏了靠 git 回退。

## 2. 改 cotutor.json

用编辑器打开 `~/cotutor/ming/cotutor.json`,改四处:

1. **模型**:`agents.claude.run` 与 `agents.claude.resume` 两个数组末尾各加 `"--model", "sonnet"`。
2. **音色**(想听声音才改):`teachers.math-teacher` 里加 `"voice": "qwen-audio-3.0-tts-plus-longhongxinxu"`(`voxtell voices --grep 女` 能查别的);`tts.say` 的前两项改成 `"node", "/Users/ae86/Projects/github-tarslab/voxtell/bin/voxtell.js"`(voxtell 不在 PATH 时)。
3. **vault**(有 Obsidian 仓库才改):`paths.vault` 指到孩子的 vault 根,`paths.timetable` 写课程表文件名(如 `"课程表.md"`)。不配就相对 workspace 根,课程表放 `~/cotutor/ming/timetable.md` 也行。
4. 其余不动。`_note` 里有每个字段的说明。

课程表格式(表头 星期 / 时间 / 学科,孩子列可选):

```markdown
| 星期 | 时间 | 学科 |
|---|---|---|
| 一 | 19:00–19:40 | 语文 |
| 二 | 19:00–20:00 | 数学 |
| 六 | 09:30–10:10 | 英语 |
```

想让「今天」立刻有高亮时段,临时加一行 `| <今天周几> | 00:00–23:59 | 数学 |`。

## 3. 体检

```sh
cotutor doctor
```

必需项(✗)全过才能往下;`!` 是建议。这几项现在应该是:`cotutor.json` ✓、五位老师的 `.claude` 链 ✓、`timetable` ✓(写了几个时段)或「没有课程表」、`https` !(还没签证书)、`tts` ✓ 或 !、`agents.claude` ✓。每条不过的都带修复命令。

## 4. 起服务,先在 Mac 上试

```sh
cotutor serve
```

打印两个地址(本机名与局域网 IP),孩子端 `/`,家长端 `/parent`。没证书时走 HTTP,会提醒一句 iPad 录音要 HTTPS,Mac 上不影响。

### 4.1 家长端 `/parent`

浏览器开 `http://localhost:5180/parent`:

1. 左栏是开着的老师(含孩子看不到的规划老师),点「数学老师」。
2. 底部选身份「家长」、预设「claude(缺省)」,输入「我家孩子二年级,42-17 这种退位减法总错,该怎么讲?」,⌘+Enter 发。
3. 看到什么算对:发出去的话在上面,下面出现「老师在想……」,十几秒后出现老师的话(主线说话)、末尾「本轮结束 · N 轮 · $x」,再下面一行绿色「孩子看到:……」——那就是孩子端会看到的那一句(最后一段、按 60 字截)。
4. 再发两条:「那用数轴讲怎么讲?一句话说给孩子听」「妈妈说的数轴我不懂」(身份切成「孩子(模拟)」)。页脚「会话 xxxxxxxx(claude)」三轮都是同一个 id,回复接得上前文,就是 resume 通了。
5. 预设切「qwen」再发一条:会新开会话(id 变),再发一条又 resume 上;切回 claude 也一样。
6. 若老师回复里带「## 待裁量」段,会渲染成黄卡 + 选项按钮;点一个按钮 = 以家长身份回一句「待裁量「…」:选「…」」。
7. 老师用了工具会折成「用了 N 步工具」,子代理的话折成「子代理 · N 条」;出错是红条,下面附 err.log 尾巴。

顶部「助教团」标签:每位老师一张卡,改显示名 / 头像 / 音色 / 开关 / 孩子端不露 / 政策覆盖(留空 = 继承),点「保存」写回 cotutor.json;把「朗读老师」的「开启」勾掉保存,回到「对话」标签它就从左栏消失了,孩子端也没了。全局卡能改标题、缺省预设、政策缺省。在编辑器里直接改 cotutor.json 也行,服务每个请求都看文件时间,改坏了顶栏会红字提示、仍用上一份。

### 4.2 孩子端 `/`(先在 Mac 的 Safari 或 Chrome 看)

开 `http://localhost:5180/`:

1. 顶部一条「一周小路」:课程表里有课的日子一站,今天最大写着「今天」,环的颜色是学科色;下面是今天的时段(正在进行的有橙色边)。没课程表就只有今天一站。
2. 一排老师头像(不含规划老师)。点「数学老师」进聊天窗。
3. 底部:橙色话筒(Chrome / Safari 有 `webkitSpeechRecognition` 才显示;Firefox 没有就只剩输入框)、输入框、↑。
4. 打字「25加17等于多少」回车。看到什么算对:自己的话在右边蓝泡,左边黄泡「老师在想」三个点,约 10 秒后变成老师的话,自动播声音(配了 voice 是 voxtell 的声,否则是浏览器的合成声;首次可能要先点一下页面让浏览器放行音频)。泡泡左边的 ▶ 可重播。
5. 回 `/parent` 看数学老师今天:刚才那条是「孩子 · …」,带完整转录、费用、配音文件名。孩子端那边永远看不到这些。
6. 试话筒:按住不放说一句,松手自动发送;识别中输入框里能看到实时文字,顶上有「在听……」。
7. 把 `cotutor serve` 停掉(Ctrl+C),孩子端 5 秒内所有头像变灰、聊天窗关掉、出现「老师们休息中」,没有任何报错;重新起服务又恢复。
8. 每日上限:助教团页把数学老师的「每日消息上限」改成 1 保存,孩子端再发一条后头像灰、聊天窗底部变成「今天聊够啦」。家长端不受影响。记得改回来。
9. 右下角「家长 · 长按」按住 0.8 秒进家长端。

## 5. iPad 真机(R0 第 2 项也在这一步)

1. Mac 上签证书:`cotutor cert`。它用 mkcert 把本机名、`.local` 名、局域网 IP、localhost 都签进 `~/cotutor/ming/certs/`,并打印根证书位置(`mkcert -CAROOT` 下的 `rootCA.pem`)。
2. 把 `rootCA.pem` 隔空投送到 iPad → 设置 › 已下载描述文件 › 安装 → 设置 › 通用 › 关于本机 › 证书信任设置 › 打开那条。这是 iPad 信任自签证书的唯一办法,一台 iPad 做一次。
3. 重启 `cotutor serve`,这次打印的是 `https://…`。
4. iPad Safari 开 `https://192.168.1.5:5180/`(用 serve 打印的那个 IP;Mac 与 iPad 同一 Wi-Fi)。锁屏图标正常、没有证书警告就对了。加到主屏幕会去掉地址栏。
5. 点数学老师,**按住话筒说一句**:第一次 Safari 会问是否允许麦克风。看识别出来的字准不准、松手有没有发出去、几秒后有没有听到回答——这三个观察写回《产品规划.md》R0 第 2 项。
6. 若识别根本不出字:说明 iPad 这版 Safari 的语音识别不可用,先用打字,voxtell transcribe 要提前做(产品规划里写的备选路)。

## 6. 终端里发一条(不开页面)

```sh
cd ~/cotutor/ming
cotutor send math-teacher "42-17 怎么讲?"           # 家长身份
cotutor send math-teacher "为什么要借位" --from kid  # 孩子身份,算进每日上限
cotutor send math-teacher "再讲一遍" --preset qwen  # 换预设
```

打印孩子看到的那句、待裁量 / 转交段(若有)、会话 id 与费用。和页面走的是同一条路,只是同步等它说完。

## 8. 不对时看哪里

| 现象 | 看 | 多半是 |
|---|---|---|
| 家长端发出去一直「老师在想」然后红条 | 红条下的 err.log 尾巴;或 `conversations/<老师>/<日期>.<job>.err.log` | 没加 `--model sonnet`(API Error 400 版本不够);在 Claude Code 里没 unset `CLAUDECODE` |
| 回复出来了但没有声音 | err.log 里「cotutor tts: 没合成(…)」 | `tts.say` 指的 voxtell 不在 PATH;老师没配 voice(这时用浏览器的声,不算错) |
| 孩子端没有话筒 | 浏览器 | 没有 `webkitSpeechRecognition`(Firefox),或 iPad 上用了 http |
| iPad 打不开 https | 证书信任设置 | 根证书没装或没打开信任;IP 变了要重签 `cotutor cert` |
| 老师头像全灰 | `cotutor serve` 还在跑吗;`/api/health` | 后端不通;或每日上限到了(只灰那一位) |
| 顶栏红字「cotutor.json 改坏了」 | `cotutor doctor` | JSON 少个逗号;服务仍用上一份 |
| 课程表没画出来 | `cotutor doctor` 的 timetable 项 | 表头缺列、时间格式不对,都带行号 |

费用参考:数学老师问答一轮 $0.01–0.18(首轮带上下文包贵一点),配音按字算。
