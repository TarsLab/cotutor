# 二年级教学包

面向中国大陆小学二年级。默认采用短句、一次一个问题、具体情境与逐步提示。年级不代表孩子已经学过某项知识;教材版本、学期和进度由孩子档案与学科入口文件提供,英语难度还要看实际表现。

普通聊天使用 `agents/<老师>.md`;activity 使用自己完整的「老师怎么带」,不继承老师正文。共同守则和板书协议仍由应用提供。

安装: `cotutor init ming --grade 2`。文件拷进 workspace 后属于家长;upgrade 只换未修改的。老师 ID 与现有 activity 名称保持稳定,看图说话的按钮可显示为「看图写话」。

三科提供预习、批改、复习;语文另有看图说话、写话、听写与表达活动;英语另有口语课、听写;小课堂继续使用提前做好的课包,看完再问。典型题型的完整示例见 `examples/数学平均分.md`。

验证:所有 activity 及例子必须通过静态检查;真实模型的评估结果见 [验证记录](VALIDATION.md),命令见仓库 `docs/年级教学包.md`。静态通过不表示教学效果已经验证。
