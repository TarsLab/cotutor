# 典型题型:平均分

这是一份可选的小课堂样例,供家长看过后使用。适合能数到 6、会比较一样多的孩子,无需先学除法。不把二年级当成已经学过平均分。

- 题目:6 个圆片平均放进 3 个盘子,每盘几个?
- 做法:一轮每盘放一个,放两轮,再合起来核对总数。
- 目标:理解「平均」表示每盘一样多。
- 源文件: `2026-10-27-pingjunfen.ts` 与同名讲法说明。
- 课包: `2026-10-27-pingjunfen/`,含画面、讲稿和配音。

## 安装与首页

把课包目录复制到试用 workspace 的 `bundles/2026-10-27-pingjunfen/`。仅复制课包不改变已有课程或首页。

在数学老师的首页卡中加入:

```tutor
math-tutor
小课堂 2026-10-27-pingjunfen 平均分:每盘一样多
```

跑 `cotutor home check`,家长看过内容后再发布首页。孩子看完会进入数学老师原有的「小课堂」activity。

## 看完怎么聊

孩子说「为什么每盘放一样多」:回看课里解释「平均分」的一段,请他看三个盘子的数量。孩子说懂了就结束。

孩子主动说「我想自己试一道」:用 8 个圆片、4 个盘子,请他自己分。不会时提示先每盘放一个;不要先给出每盘数量。做完核对各盘一样多且总数为 8,然后结束。

孩子不想练:直接结束。不在看懂之后强制加题。

## 开发者重建

在仓库根运行(配音调用服务,会产生费用;配音缓存在解析到的那个 workspace 的 `.cotutor/tts/`):

```sh
node bin/cotutor.js chalk build grades/grade-2/examples/2026-10-27-pingjunfen.ts --out grades/grade-2/examples/2026-10-27-pingjunfen
node bin/cotutor.js chalk bake 2026-10-27-pingjunfen --bundles grades/grade-2/examples
node bin/cotutor.js chalk dub 2026-10-27-pingjunfen --bundles grades/grade-2/examples --voice qwen-audio-3.0-tts-plus-longcanzhuyue
```

检查数量、笔顺、文字与讲稿是否一致;配音变化后再确认每步时长。不能只凭构建成功宣称教学效果通过。
