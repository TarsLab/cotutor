# 讲解知识

讲法先落成**说明文件**(`scenes/<id>.md`,格式见 [references/说明文件.md](references/说明文件.md)),再写坐标。
草稿画法(**表征**:点阵、线段图、数轴、小棒、分解式……)是有限集,一表征一文件在 `models/`;
库里有现成骨架就照骨架讲——数学正确性与笔顺跟着骨架走,比自由发挥稳;没有就按知识点 + 范例 + 画布词汇自己设计,
说明文件标 `表征: ★新`,不停下来问。

## 查什么读哪

| 想… | 读 |
|---|---|

| 圈的几何余量、数量上限、画得下画不下 | drawtell-scene 的「数量与画面」 |

## 画布词汇表(动作优先从这里选)

添画 · 划掉(=减)· 圈起来(=聚焦)· 连箭头 · 分行(=分类)· 虚线 · 涂色 · 擦掉(橡皮)

引擎里的对应写法(第一批真题验证过):

- **涂色** = 元素加 `backgroundColor` + `fillStyle: 'hachure'`(斜线填充),能画能播;标记"第几个人"、"多出的一段"都用它
- **圈起来**:椭圆或**矩形**都算圈。椭圆两端收窄,圈一排对象时要靠高度换余量;
  要圈"一排里的前 k 个"而右边紧挨着第 k+1 个、或圈的东西本身是排/捆时,矩形圈一次到位(且与"捆 = 矩形"同形)
- **擦掉** = 一条沿旧笔迹走的粗线(`strokeWidth` ≥ 12)加 `customData: { tool: 'eraser' }`:引擎用纸色盖住旧笔迹,
  画这一笔时笔尖换成橡皮。只在白板上擦得干净(背景图上盖住的是图);擦掉的东西后面还要用就再画一遍(新 id)
- **虚线** `strokeStyle: 'dashed'`;短于 ~50px 只剩两段,像冒号——一一对应的连线要够长、两头都到
- 涂色会盖住同位置在先画的线条(按顺序叠放),先画的虚线别指望从涂色块里透出来

## 两种段落:草稿与作答

草稿段 = 图,灵活、个性化,用图形表达思路;作答段 = 偏书本答案(算式、答、结论,需要作图的题作图也算)。
竖向交替,一步可以只有草稿、只有作答或先草稿后作答——是引导不是分区,细则在 `references/说明文件.md`。

## 标准小件

两个反复用到的**标准小件**(没有名字,靠基本元素手搭,写法见种子/工作区场景):

- **分解式**:数下面分出两个数(如 5 → 3、2):两条短 line + 两个 text;凑十/破十都要
- **括号留空后来填**:"( )" 拆成两个 text(左括号、右括号)留出空位,答案填进去时才不会触发 check 的 text-overlap

## 讲法设计原则

- 先写说明文件,再写坐标。缺省 3–6 步(数列分行这类可到 7)——步多了孩子跟不上,少了一步塞两件事;
  每步一个想法、一句讲稿,可有草稿、作答两拍
- 讲稿短句、面向孩子、讲到什么画什么;讲稿说"从右边起"就真的从右往左落笔——批内笔顺跟着讲稿的方向走
- 数学正确性优先于画面好看;讲法以"孩子看完能在纸上照着画"为目标(paper-strict 的初衷)
- 画面本身也会教错东西:楼画成一格一格的、"1 楼"标在格子里,孩子就会把"到 3 楼"数成 3 层——
  先想"这张图会不会被读成别的意思",再想好看

## 用色(政策,单一真相)

主笔迹 `#1e1e1e`,强调红 `#e03131`,划掉橙 `#e8590c`;红用在讲稿强调处、橙 = 划掉,不出现无来由的颜色。
搬移箭头、"新添的"对象用什么色还没定(家长政策),同一批课包里保持一致。

## 讲稿套路(各模型通用)

- 每步一句,短句,直接对孩子说;先说动作再说含义("划掉 5 个——送出去的就不是他的了")
- 数数环节让孩子跟着数("1、2……9"),这是接力交互的钩子
- 最后一段通常是作答:算式、答写在作答段;草稿里圈出答案可选(缺省圈,家长口径可改)
- 涉及"我 / 某人自己"的排队类,必有一句"别忘了他自己 / 他被数了两次"
- 应用题按册子习惯把算式写进作答段;算式是单独一步还是并进末步,同一批课包里保持一致(家长定)
- 讲稿超过一行(~38 个汉字)字幕会折行,尽量控制在一行内;换行会把"数字 + 量词"拆开
- 一升二读不了字幕,讲稿就是孩子听到的全部;每句 TTS 约 3 字/秒,一步 10 秒左右为宜。
  dub 报"拉伸超过 5 倍"说明这步讲稿太长或画得太少——回讲法层修(讲稿拆步、多画几笔),别指望时钟

## 表征怎么进库(当前做法)

生成时遇到库里没有合适表征的题:**不停**,按知识点 + 画布词汇 + 邻近范例自己设计草稿,说明文件 `表征: ★新`,
给家长看时点明。家长认可(验收通过,或纸上手绘验证)后再进库:`models/<名>.md`(适用知识点 / 画法骨架 / 已验收范例)
+ `models-index.md` 一行;文件名就是表征名。
第一批真题(一升二暑假每日一练 12 题)一次就进了 8 个——表征库主要靠真题批量长出来,不靠预先设计。
