# 表征库索引

一种草稿画法一文件(`models/<名>.md`:适用知识点 / 画法骨架 / 已验收范例);文件名即表征名。
挑表征的顺序:同知识点已验收的范例(说明文件 + 课包)→ 题面 → 本表。库里没有合适的:自己设计,说明文件标 `表征: ★新`,
不停下来问(准入见 SKILL.md「表征怎么进库」)。
