# 命令与文件(机器生成,别改)

## 分析用的命令(在 workspace 根跑;每条就是 cotutor <命令> --help 的内容)

```
这些命令都认 --workspace <目录>(在 workspace 根跑可以不写)和 --sandbox(在试用副本里跑,不进孩子的记录)。

cotutor show — 看一轮:问了什么、上下文包、讲稿与卡、读了什么

用法:
  cotutor show <老师> <job> [<日期>] [--evals] [--json]

选项:
  --evals  看回放的那轮(evals/ 里的)
  --json   机器可读的输出

说明:
  - 日期缺省今天;--json 和家长端「看原文」是同一份

例子:
  cotutor show math-tutor 1620-1 2026-09-12 --json

cotutor pack — 干跑上下文包:不起模型,看老师会拿到什么

用法:
  cotutor pack <老师> [<消息>] [--activity <名> [--param '名=值;名=值']] [--from kid|system] [--at <ISO时间>] [--json]

选项:
  --activity <名>        像孩子点了首页的 activity 按钮,新开话题
  --param '名=值;名=值'  activity 的参数(按钮下面那几行)
  --from kid|system      谁说的(缺省 kid;system 不算孩子说的)
  --at <ISO时间>         当作这个时间
  --json                 机器可读的输出

说明:
  - 每段来自哪个文件、一共几条、按政策带了几条;改了档案、日记、计划立刻看效果

例子:
  cotutor pack math-tutor "讲讲退位"

cotutor replay — 同一问按现在的提示词再跑一遍,并排对照

用法:
  cotutor replay <老师> <job> [<日期>] [--runtime <名>] [--json]

选项:
  --runtime <名>  换个运行时
  --json          机器可读的输出

说明:
  - 落 evals/,不进孩子的对话、不配音

注意:
  - 花钱

例子:
  cotutor replay math-tutor 1620-1 2026-09-12

cotutor compare — 再看一次回放的对照

用法:
  cotutor compare <老师> [<evalJob>] [<日期>] [--json]

选项:
  --json  机器可读的输出

说明:
  - 不给 evalJob 就列这天回放过哪些

例子:
  cotutor compare math-tutor

cotutor trace — 回放一轮的事件

用法:
  cotutor trace <老师> <job> [<日期>] [--lane <道>] [--json]

选项:
  --lane <道>  只看这几道的事件,逗号分开,如 main,tts
  --json       机器可读的输出

说明:
  - 读 <日期>.<job>.events.jsonl;日期缺省今天

例子:
  cotutor trace math-tutor 1620-1 --lane main

cotutor doctor — 体检;--fix 修掉能自动修的

用法:
  cotutor doctor [--json]
  cotutor doctor --fix
  cotutor doctor --live

选项:
  --fix   修掉能自动修的(幂等,不碰孩子的数据,不用人输东西),要人来的留着
  --live  真连一次百炼的嘴、真配一句音
  --json  机器可读的输出

说明:
  - --json 里没过的项带 cmd(能直接跑)或 human(要人来)
  - 有必需项没过,退出码 1

注意:
  - --live 花一分钱

例子:
  cotutor doctor --fix
  cotutor doctor --json

cotutor send — 终端里给老师发一条

用法:
  cotutor send <老师> [<消息>] [--new] [--photo <图,图>] [--quiet] [--json]
  cotutor send <老师> --activity <名> [--param '名=值;名=值']

选项:
  --new                  开新话题
  --photo <图,图>        带作业照片(jpg / png,最多 9 张);有照片时消息可以空
  --activity <名>        像孩子点了首页的 activity 按钮,新开话题
  --param '名=值;名=值'  activity 的参数(按钮下面那几行)
  --from kid|system      谁说的(缺省 kid;system 不算孩子说的)
  --runtime <名>         换个运行时
  --lane <道>            只看这几道的事件,逗号分开,如 main,tts
  --quiet                只要结果,不打印过程
  --json                 机器可读的输出

说明:
  - 孩子的话照实时写(同孩子端),只是没有嘴;事件落 events.jsonl,事后 cotutor trace 看

注意:
  - 花钱
  - 写进孩子的对话记录(试一下用 --sandbox)

例子:
  cotutor send math-tutor "这一步为什么要借位"

cotutor rate — 给一个话题打星(1–5)

用法:
  cotutor rate <老师> <话题> <1-5> [--date <日期>] [--json]

选项:
  --date <日期>  哪天(YYYY-MM-DD,缺省今天)
  --json         机器可读的输出

说明:
  - 和家长端同一条路;到 vault.keepScore 星的话题,记账时摘要才进日记

例子:
  cotutor rate math-tutor 1620-1 4

cotutor bookkeep — 记账:把这天的话题写进日记

用法:
  cotutor bookkeep <老师> [--date <日期>] [--thread <话题>] [--quiet] [--json]

选项:
  --date <日期>    哪天(YYYY-MM-DD,缺省今天)
  --thread <话题>  只记这个话题
  --quiet          不打印过程
  --json           机器可读的输出

说明:
  - 每个还没记过的话题起一轮记账,应用写进笔记文件夹的日记

注意:
  - 花钱
  - 写孩子的笔记文件夹

例子:
  cotutor bookkeep math-tutor
```

## 一轮的文件(conversations/ 下;回放的在 evals/ 下,同一套名字)

job 形如 1620-1(时分-当天序号)。

| 文件 | 是什么 |
|---|---|
| `conversations/<老师>/<日期>.json` | 一天的索引:每条消息物化了 text / kidText / section(卡与讲稿)/ tools(读了什么)/ timing / tokens(这轮老师用的 token:输入 / 输出)/ warnings / bookkeeping;顶层 sessions / ratings / booked(老数据里还有 costUsd,是 claude 时代的美元,不用管) |
| `conversations/<老师>/<日期>.<job>.run.json` | 这轮发给老师的:prompt(上下文包 + 消息)、argv(完整命令行)、resume / session、sources(当时的老师文件正文与 hash、技能 SKILL.md 的 hash) |
| `conversations/<老师>/<日期>.<job>.log` | 老师进程的 stdout 原样(stream-json):每次 tool_use 的完整参数、tool_result 的内容、文本、result(token、轮数)。最大最全,别整个读,按 job 与关键字 grep |
| `conversations/<老师>/<日期>.<job>.err.log` | stderr |
| `conversations/<老师>/<日期>.<job>.events.jsonl` | 这轮的事件流,一行一条 {t, lane, kind, …}:main 老师 / tts 配音 / ready 就绪 / index / ledger;cotutor trace 读它 |
| `conversations/<老师>/<日期>.<job>.cards/<n>.json` | 第 n 张卡的状态(孩子在卡上做的):{at, turn, state} |
| `conversations/<老师>/<日期>.<job>.cards/<n>/<k>.mp3` | 卡的资产(点读段配音) |

上下文包里每一行是什么、路径后面的状态怎么看,见 `.agents/skills/cotutor-tutor/references/上下文包.md`;截断的上限是哪个政策旋钮,见 cotutor-tune 的 references/字段.md。
