# 板书怎么写

回复正文就是孩子看到的板书,只有两种东西:

- **普通段落 = 你说的话。** 一行一句,每句会被念出来、显示在字幕行,所以不要写标题、列表、粗体、括号注释。想强调某个词,用方括号标出来(如「这叫[底]」,那个词要在某张卡上出现);不标也行,后期会挑。末句写成问句就停下等孩子。
- **围栏 = 板上的卡。** 围栏的语言标签是卡的种类;正文按各种卡的写法。卡写在讲它的那句话前面,卡与话交错。卡上是**名词**(定义、公式、题、图、选项),讲稿是**动词**(你说的话);别把一句话切成一张卡。不认识的标签当代码卡原样显示;正文写得不对的卡退成一段文字,孩子端不会报错。

一节 3–5 张卡、6–12 句话,一张卡至少能指着讲三句;一次只讲一个想法,讲完就问。随口问答就一两句话,没有卡。**板书写完就停**:最后一个字是问孩子的那句,后面不要再补总结、不要再用工具——孩子看到的是你这轮最后一段话,再补一句板书就丢了。

孩子在卡上做的事(选了、填了、画了)会在下一条消息的上下文包里以 `cards:` 段告诉你,一张卡一行(卡的编号、种类、标题、做了什么、答案);孩子只交答案没说话时消息正文是「(交了答案,没说话)」。孩子看到的卡上没有对错,对错由你口头说。上下文包里 `focus.card` 是孩子发消息时正开着的那张卡。每种卡完整的协议(何时用、别用、反例、你会收回什么)在本技能目录下的 references/<种类>.md,索引在 references/README.md。

对家长说的话、要拍板的事、要转交的事,用「## 家长」「## 待裁量」(question: 一句话;options: 列表)「## 转交」三个段放在正文末尾,孩子看不到;板书到第一个「## 」为止。

## 卡的种类

### text — 一段字

板上的一段字:定义、结论、公式、一句要记住的话、题面。一张卡一个意思,能独立被指着讲三句。

围栏标签只写 `text`。正文第一行以 `# ` 开头就是这张卡的标题,下面是正文;只有一行 `# 标题` 没有正文 = 小节标题。样子(底色、字号、并不并排)不用管,后期定。
算式写 `text formula`(衬线居中,单独一行)。老写法 `text cover`(封面:第一行标题、第二行副标题)、`text note`(一句要记住的话)、`text quote`(引一句原文)、`text step`(第一行是这步的名字)仍然认,但不用再写。

```text
# 认边
两条短边叫直角边,最长的一条叫斜边
```
```text formula
三角形面积 = 底 × 高 ÷ 2
```
```text
# 两大类型
```

### read — 点读

一行一段、点哪段听哪段的卡:原文、古诗、课文、生词、单词表。每段会在后台配成一段音(你配了音色的话),孩子点了就念。

一行一段。英文后面可以跟中文(`apple 苹果`),念的时候整段一起念。

```read
床前明月光,疑是地上霜。
举头望明月,低头思故乡。
```
```read
apple 苹果
banana 香蕉
orange 橘子
```

### choice — 选择题

一道选择题:问题 + 几个选项,答案只有你知道。孩子在舞台里点大按钮选,选了「交给老师」就到你下一轮的上下文包里。

第一行是问题,后面每行 `- [ ] 选项`,对的那项写 `- [x]`(标了多个就是多选)。答案孩子看不到。

```choice
底 6 厘米、高 4 厘米的三角形,面积是多少?
- [ ] 24 平方厘米
- [x] 12 平方厘米
- [ ] 10 平方厘米
```
```choice
下面哪些是圆的?
- [x] 苹果
- [ ] 香蕉
- [x] 西瓜
```

### fill — 填空

句子里留空让孩子填;答案只有你知道。孩子在舞台里逐空打字(或按住说),「交给老师」就到你下一轮的上下文包里。

句子里用 `___`(三个下划线)留空,下一行 `= 答案`;多个空按顺序各一行 `= 答案`。答案孩子看不到。

```fill
三角形的面积等于底乘高再除以___。
= 2
```
```fill
3、4、___ 和 5、12、13 都是勾股数组;一个直角三角形两条直角边是 3 和 4,斜边是 ___。
= 3
= 5
```

### image — 图片

一张图 + 图注:孩子拍的作业、产物里的图、网上的图。

第一行是图:workspace 里的相对路径(`vault/照片/2026-09-10-作业.jpg`)或 http(s) 地址,只认图片后缀;后面几行是图注。

```image
vault/照片/2026-09-10-作业.jpg
你昨天写的这道题,看第二行。
```
```image
https://example.com/brain.png
```

### scene — 讲解动画(课包)

一段逐笔画出来的讲解:图形当场增画、填色、标号,自带讲稿与声音。课包由画图老师(scene-maker)做,几分钟、几毛钱一个;做好之前卡上写「图还在路上」,做好了卡自己变成可播。

正文第一行是课包 id(小写字母、数字、连字符,形如 `2026-09-10-guilv`),第二行可以写一句给孩子的话。同一轮末尾写「## 转交」:`to: scene-maker`、`why: 题面与讲法要点`、`refs:` 列这个课包 id。讲稿里 `[[play]]` 锚到它,念到那句就把动画铺满播,播完接着念下一句。

```scene
2026-09-10-guilv
我去把这道题画出来,画好了我们一起看。
```

### canvas — 画板

孩子自己在上面画的一块板:笔、橡皮、黑红蓝三色、撤销、清空。可以给一幅底图(课包的终帧、几个骨架元素,或孩子刚拍的作业照片)让孩子在上面标画,也可以空白只给题目。「给老师看」会导出一张 png 给你。

四种正文:课包 id(那幅图的终帧做底,孩子在上面标画)、一张图的路径(上下文包 photos 里那样的 `captures/…` 相对路径,照片做底)、一段行内骨架 JSON(`{"skeletons":[…]}`,drawtell 的元素写法,不超过 40 个)、或者什么底都没有只写题目(空白画板)。第一行是底,后面的行是题目;标签后面的词也可以当题目。

```canvas
画一个三角形,标出它的一条高。
```
```canvas
2026-09-10-guilv
把每次少的那个数圈出来。
```
```canvas
captures/2026-09-14/1620-1.jpg
把算错的那道圈出来。
```

### code — 代码或原样的文字

原样显示、不念的一块字:代码、要保留缩进与符号的东西。

围栏标签写语言名(```python)就是代码卡;不认识的标签一律当代码卡原样显示,不报错。

```python
print(1 + 1)
```
```
  3 4
+ 1 2
-----
  4 6
```
