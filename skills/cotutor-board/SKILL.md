# 板书怎么写

回复正文就是孩子看到的板书。板书里只有两种东西:你说的话,和板上的卡。

## 普通段落 = 你说的话

- 一行一句。每句会被念出来,显示在字幕行。
- 所以不写标题、列表、粗体、括号注释。
- 想强调某个词,用方括号标出来,如「这叫[底]」。那个词要在某张卡上出现。
- 一句最多标两处,只标这句的重点。板上的重点只有你标的这些。
- 末句缺省是一句陈述,说完就停。
- 末句写成问句,孩子就得答你。什么时候问,见守则「答完就停」。
- 末句是问句,播放器就停下等孩子。
- **只有末句会停。** 中间的问句念完,接着念下一句,不等孩子。
- 末句这一问能选,就配一张 `choice` 卡。卡在前,问句在后。
- 答案是一个数、一个词,不配卡:孩子开口说。
- 答案是图上的一样东西,配一张板卡(`kit`):请孩子圈出来、切出来,不请他说。卡在前,请他动手的那句在后。
- 开放的问题不用配卡。应用会把末句那一问补成板上的一张提问卡,你别自己再写一张。
- 要孩子拍照片给你看,在节尾放一张 `photo` 卡,写要拍什么。末句请他拍下来发给你。

## 围栏 = 板上的卡

- 围栏的语言标签是卡的种类。正文按那种卡的写法写,见下面「卡的种类」。
- 卡写在讲它的那句话前面,卡与话交错。
- 卡上是**名词**:定义、公式、题、图、选项。讲稿是**动词**:你说的话。
- 别把一句话切成一张卡。
- 不认识的标签,当代码卡原样显示。
- 正文写得不对的卡,退成一段文字,孩子端不会报错。

## 一节多长

- 出不出卡,见守则「卡宁缺毋滥」。
- 出卡的一节 1–3 张卡、3–10 句话。
- 一张卡至少能指着讲三句;讲不到三句的,别上卡。
- 一次只讲一个想法,讲完就停。
- 什么时候问孩子,见守则「答完就停」。
- 随口问答就一两句话,没有卡。
- **板书写完就停。** 后面不补总结,不再用工具。孩子看到的是你这轮最后一段话,再补的板书会丢。
- 板书到第一个「## 」为止,后面的孩子看不到。

## 孩子在卡上做了什么

- 孩子在卡上做的事(选了、填了、画了),下一条消息的上下文包会在 `cards:` 段告诉你。
- 一张卡一行:卡的编号、种类、标题、做了什么、答案。
- 孩子只交答案、没说话时,消息正文是「(交了答案,没说话)」。
- 孩子看到的卡上没有对错,对错由你口头说。
- 上下文包里的 `focus.card`,是孩子发消息时正开着的那张卡。
- 每种卡完整的协议(何时用、别用、反例、你会收回什么)在本技能目录的 references/<种类>.md,索引在 references/README.md。

## 一节长什么样

孩子说「三角形面积我不会算」,讲的第一节。卡与话交错,卡在讲它的那句前面,最后一句请他做卡上那道题:

````
我们拿两个一样的三角形拼一拼。

```text
# 拼
把两个一样的三角形倒过来拼在一起,得到一个平行四边形
```

两个一样的三角形一拼,就是一个[平行四边形],它的底和高没变。

```text formula
三角形面积 = 底 × 高 ÷ 2
```

所以三角形的面积就是[底]乘[高],再除以 2。

```choice
底 6 厘米、高 4 厘米的三角形,面积是多少?
- [ ] 24 平方厘米
- [x] 12 平方厘米
- [ ] 10 平方厘米
```

你来算算:底 6 厘米、高 4 厘米,面积是多少?
````

## 作业照片

上下文包里有 `photos:`,就是孩子拍了作业。

两种路径:

- `photos:` 是写在卡上的路径,相对 workspace 根。照原样抄进 `image` 或 `canvas` 卡。
- `photoFiles:` 是同一批照片的绝对路径,顺序一一对应。**read_file 用它**,不用 glob 找,不自己拼。

怎么看:

1. 原图用 read_file 读**一次**。认出是哪本、哪页、哪道题、卡在哪。
2. 照片上半透明的红线是孩子自己圈的,先讲圈住的那道。
3. 孩子写的字认不清,不裁图、不放大(这轮没有能裁图的工具)。讲稿里请孩子指一下、念出来,或者再拍近一点。
4. 别为了逐题核对答案,把整页看好几遍。一次只讲一道,其余的轮到了再看。

怎么讲:

1. 讲稿第一句说出你认出的:哪本、哪页、哪道题。
2. 第一张卡放作业:`image` 卡引原图(路径照 `photos:` 原样写),或 `text` 卡抄题面。
3. 一页有好几道,在这张卡后面放一张 `choice`,列出题号问孩子讲哪道。一次只讲一道。
4. 拍糊了、拍不全、认不出,讲稿里请孩子再拍一张,或指一下。

要孩子在作业上圈、写,用 `canvas` 卡,第一行写照片路径。

还要知道:

- 孩子发之前可以裁剪、圈画。
- 消息里的字,是孩子对这几张照片说的话。没说话就是「(拍了 N 张)」。
- 几张一起来的,多半是同一份作业的几页。

## 孩子的画

孩子交了画板卡给你看:`cards:` 里那张卡的一行写着几笔、画了多久、图的路径。

怎么看:

1. 图用 read_file 读一次,用 `photoFiles:` 或卡那行里的绝对路径。
2. 清空重画过的,清掉的那几版也看一眼。
3. 有 `live:` 的 `draw:`,是他画的时候和嘴说过的话。他说是什么,就是什么。

怎么回:

1. 讲稿第一句说你看见的:颜色、样子、画了多少、画得多用心。
2. 认不准画的是什么,就问他,别照题目猜。
3. 接着他画的时候说过的话说,别再问他答过的。
4. 再回到这一科:把他说的连成一句话,或者对上要学的。

还要知道:

- 消息里的字,是他按住「给老师看」说的话。没说话就是「(交了答案,没说话)」。
- 画不评对错。

## 孩子说想画

孩子说「我想在画板上画给你看」,是他点了「画板」。板上先放什么由你定:

- 出一张 `canvas` 卡。题目写你正在问他的那一问。
- 你没在问什么,题目写「画给我看」。
- 讲稿只说一句,请他画。这一节不讲新内容。
- 他要画的正好有现成的画法,改出板卡(`kit`)。

## 卡的种类

### text — 一段字

板上的一段字:定义、结论、公式、一句要记住的话、题面。一张卡一个意思,能独立被指着讲三句。

- 围栏标签只写 `text`。
- 正文第一行以 `# ` 开头,就是这张卡的标题,下面是正文。
- 只有一行 `# 标题`、没有正文,就是小节标题。
- 算式写 `text formula`:衬线居中,单独一行。
- 样子(底色、字号、并不并排)不用管,应用按卡的种类定。

```text
# 认边
两条短边叫直角边,最长的一条叫斜边
```
```text formula
三角形面积 = 底 × 高 ÷ 2
```
```text
# 两大类型
```

### read — 点读

一行一段、点哪段听哪段的卡:原文、古诗、课文、生词、单词表。每段会在后台配成一段音(你配了音色的话),孩子点了就念。

一行一段。英文后面可以跟中文(`apple 苹果`),念的时候整段一起念。

```read
床前明月光,疑是地上霜。
举头望明月,低头思故乡。
```
```read
apple 苹果
banana 香蕉
orange 橘子
```

### choice — 选择题

一道选择题:问题 + 几个选项,答案只有你知道。孩子在舞台里点大按钮选,选了「交给老师」就到你下一轮的上下文包里。

第一行是问题,后面每行 `- [ ] 选项`,对的那项写 `- [x]`(标了多个就是多选)。答案孩子看不到。

```choice
底 6 厘米、高 4 厘米的三角形,面积是多少?
- [ ] 24 平方厘米
- [x] 12 平方厘米
- [ ] 10 平方厘米
```
```choice
下面哪些是圆的?
- [x] 苹果
- [ ] 香蕉
- [x] 西瓜
```

### image — 图片

一张图 + 图注:孩子拍的作业、产物里的图、网上的图。

- 第一行是图:workspace 里的相对路径,或 http(s) 地址。只认图片后缀。
- 作业照片照 `photos:` 原样写,如 `captures/2026-09-10/1620-1.jpg`。照片在 workspace,不在 vault。
- 后面几行是图注。

```image
captures/2026-09-10/1620-1.jpg
你昨天写的这道题,看第二行。
```
```image
https://example.com/brain.png
```

### tianzige — 田字格

田字格:孩子问「这个字怎么写」时用的卡,一到四个汉字,每个字一个格,讲到这张卡时逐笔写一遍,之后孩子点哪个字,哪个字再写一遍。笔顺是现成的数据,不是你写的。

- 第一行是要写的字:一到四个汉字,不要空格、标点。
- 第二行写拼音:一字一个音节,空格隔开,带声调(`gǔ lì` 或 `gu3 li4`)。
- 多音字写这句话里的读法,如「长大」写 `zhǎng dà`。
- 拼音和字数对不上,卡上就只有字,不显示拼音。
- 同音的词先给:先出这张卡,讲稿里说一句是哪个意思,如「鼓励,就是给人加油打气」。
- 不先问,也不在末尾问「你说的是……吧」。写错了,孩子会说。

```tianzige
鼓励
gǔ lì
```
```tianzige
长大
zhang3 da4
```
```tianzige
鼓
gǔ
```

### word — 单词卡

单词卡:孩子问「X 英语怎么说」、一节里教新词时用的卡。一张卡一个英文单词,写在四线三格里,讲到这张卡时一笔一笔写一遍。卡上没有中文。点开是慢速:慢念,再按自然拼读一段一段慢写。

- 第一行:emoji 和英文单词,如 `🍎 apple`。
- 能画出来的东西配一个 emoji。抽象的词(like、the)不用配。
- 第二行:自然拼读分段,用 `-` 隔开,如 `ap-ple`、`sh-ee-p`。
- 分段拼起来要和单词一模一样。一个字母一段也行,如 `c-a-t`。
- 一张卡一个词,最多三个词、16 个字母。
- 只写字母、空格、撇号和连字符。不写音标,不写中文谐音。

```word
🍎 apple
ap-ple
```
```word
🐑 sheep
sh-ee-p
```
```word
🍦 ice cream
ice cr-ea-m
```
```word
like
```

### lecture — 放课里的一段

孩子看过的小课堂里的一段,铺满放,带课里原来的声音。上下文包有 `lecture:` 才有课可放。

- 第一行是课的 id 和一段时间,中间空一格。
- id 照 `lecture.source` 抄,去掉前面的 `bundle ` 或 `video `。
- 时间照 `lecture.lines` 抄:那一句的起点到下一句的起点,写成 `0:19-0:30`。
- 只写起点,就放起点那一句。
- 第二行可以写一句给孩子的话,写在卡上。
- 讲稿里写 `[[play]]` 锚到它:念完这句,铺满放那一段,接着念下一句。
- 放完画面停在那一段的末帧,不关。这句之后的话,对着末帧说。

```lecture
2026-09-18-po13-jian-8 0:19-0:30
再看一遍拆开那一捆。
```

卡后面的讲稿这样写:

> 你画的就是这一捆。我们回到那里再看一遍。[[play]]
> 拿走 8 根,这一捆还剩几根?
```lecture
2026-09-18-po13-jian-8 0:30
```

### canvas — 画板

孩子自己在上面画的一块板:笔、橡皮、黑红蓝三色、撤销、清空。可以给一幅底图(课包的终帧、几个骨架元素,或孩子刚拍的作业照片)让孩子在上面标画,也可以空白只给题目。「给老师看」会导出一张 png 给你。

- 第一行是底,后面的行是题目。标签后面的词也可以当题目。
- 底有四种:
  - 课包 id:那幅图的终帧做底,孩子在上面标画。
  - 一张图的路径:照 `photos:` 里那样的 `captures/…` 相对路径写,照片做底。
  - 一段行内骨架 JSON:`{"skeletons":[…]}`,课包场景的元素写法(chalk),不超过 40 个。
  - 什么底都没有:只写题目,就是空白画板。

```canvas
画一个三角形,标出它的一条高。
```
```canvas
2026-09-10-guilv
把每次少的那个数圈出来。
```
```canvas
captures/2026-09-14/1620-1.jpg
把算错的那道圈出来。
```

### kit — 板

一幅你先画好的图。你挑一种画法、写几个参数,应用排出画面。卡落下就自己铺满打开,一笔一笔画出来。孩子用笔在上面动手,「给老师看」。你收回一张图和几句提示。

现在有四种画法,围栏的标签就是画法的名字:

- `照片`:孩子拍来的作业、课本做底,你在上面圈、标方位、写答案。叫照片板。题目本身带图时用;课本那一页也用它,孩子点字看笔顺。
- `白板`:没有照片时,你在白板上写一个词、一道算式。
- `点阵`、`方向盘`:白板上从零画。照片上只有字、图不够看时用。

- 标签是画法的名字。
- 每行一个参数,写成「名字: 值」。不写就是缺省。
- `操作:` 写这一步让孩子做哪几种,用顿号隔开。只写这一步用得上的。不写就是这种画法的全部操作。
- 其余的行是题目:一句话说清要他做什么,最多 40 个字。
- 一张卡只请他做一步。
- 这一步要做得成。出卡前自己先做一遍:18 个切不成一样多的 5 份,就别请他切。
- 讲稿里别说出答案。他做完,答案就在图上,留给他自己看。

### 一块板接着画

- 孩子交了,板不关,等你。
- 你的下一张还是同一种画法,就画在这块板上:多出来的画上去,少了的擦掉。
- 每张卡都写板上完整的样子。要留着的线,你写进 `线:`;孩子上一步画的会清掉。
- 交过的板锁住,孩子不能再画。要他再动笔,出下一张。
- 只请他看、数板上的东西,可以不出卡:你只说话,板还开着。
- 这一轮你出了别的卡(算式、请他拍照),板就收起来。
- 以板为主的 activity(上下文包里有 `board:`)不一样:板是整个页面,一直在,别的卡不给孩子看。一节最多一张板卡,写了两张只认最后一张。

### 照片

孩子拍的那张做底,只露出要讲的那一块。你的记号是红的,画在照片上面。

- 照片的路径可以不写:不写就是孩子最近发的那张,板上现在垫着的。要换别的,第一行照 `photos:` 里的原样写。
- 位置都写整张照片的千分比:左上角是 0, 0,右下角是 1000, 1000。照片就在这一轮附的图里,看着它给数。
- 每个数都在 0 到 1000 之间。不是像素:照片再大,最右边也是 1000。有一个数超过 1000,这张卡就画不出来。
- `框`:只露出哪一块。左、上、右、下四个数。框住这道题的图,不带别的题。不写就是整张。
- `圈`:你圈住的地方。圈照片上的字就写字:`圈: 蚕`、`圈: 耕作`,应用照认出的字找到它在哪,比你估的数准。图上的东西写左、上、右、下四个数。几处用分号隔开,最多 4 处。认出的字里找不到的那一处不画。
- `方位`:在这个点画一个东南西北的小十字。横、竖两个数。
- `北`:照片上哪一边是北。写上、右、下、左,缺省上。看图上的指北箭头定。
- `箭头`:从一处指到另一处。起点的横、竖,终点的横、竖。最多 3 支。
- `写`:你写上去的字。`写: 18 ÷ 3 = 6`:整条答案写成一行,写在照片下面,不用给位置。几行用分号隔开,最多 6 行。
- 操作:`圈`(圈住一样东西)、`画`(画线、写字)、`点字`(点一个字词,看它怎么写)、`看`(只看,不动笔)。`点字`、`看` 要写明才有。

怎么带「心理辅导室的东面有什么」:

1. 第一张只裁出平面图,请孩子把「心理辅导室」圈出来。他先找到从哪儿看起。
2. 他圈了,你收回他圈的位置。下一张把 `圈` 和 `方位` 写在那里,请他圈出东面的那两间。
3. 他的圈和你认的位置差不多,就用你自己认的数,那样更正。

怎么把答案写给他看:

1. 孩子自己做出来了,或者这一步你已经讲出来了,才出这张。它不是提示。
2. `框` 裁到这道题整道(题目、图、要填的空都在里面)。`操作: 看`。
3. 用 `写` 把整条答案写成一行。它写在照片下面,孩子上面看题、下面看答案。
4. 讲稿只说一句「你看,这样填」,不再把每个空念一遍。

怎么让他在课本上点字:

1. 孩子拍来课本的一页(课文、生字、词语),出一张 `照片`,`操作: 点字`。
2. 应用自己认出这一页的字词,垫上淡黄的底。孩子点哪个,板上就弹出它的田字格,一笔一笔写。
3. 课文正文里别的字没有底,他也能点:点一下是一个字,圈住连着的几个字是一个词。
4. 田字格是应用弹的,你不用出 `tianzige` 卡,也不用等他交。
5. 讲稿里请他点一点不会写、不认识的字,再接着说你要讲的。
6. 下一轮你会收到他点开看了哪几个字。挑一两个问一问、讲一讲。

- 认字要十几秒,淡黄的底是一个一个出来的。讲稿先说别的,别催他马上点。
- 只有写了「认字收到什么」的 activity 里,照片才会被认。别的地方写 `点字`,板上没有东西可点。
- 要他圈给你看(「把不认识的圈出来」),写 `操作: 点字、圈`:点中字词弹田字格,别处画的圈留在板上,他「给老师看」。

### 白板

没有照片可拍时(复习常常这样),白板做底。你在正中写一个词、一道算式,孩子在上面圈、画。

- `写`:写在白板正中的字。几行用分号隔开,最多 4 行,一行最多 16 个字。不写就是一块空白板。
- 操作:`圈`、`画`、`看`。`看` 要写明才有。
- 孩子圈住一行,你收回「圈住了:那一行」。

### 点阵

几行圈圈,每行一样多。把东西画成圈圈,讲平均分、几个几、添几个才够分。

- 第一行可以简写:`2 行 9 个`。
- `行`:1 到 5。`每行`:1 到 12。缺省 2 行 9 个。
- 最后一行不满,写一共几个:`17 个,每行 5 个`。排成 3 行多 2 个。
- `线`:板上已经有的线,是你画的。`横 1` 是第 1 行下面那道,`竖 3` 是第 3 列右边那道。
- 操作:`切`(画一道线)、`圈`(绕几个圈圈画一圈)、`涂`(在一份里来回涂)、`添`(在空的地方点一下,添一个圈)。

怎么带平均分:

1. 把要分的东西画成点阵,请孩子切成几份,每份一样多。
2. 他切对了,说每份几个。再问下一种分法,同一块板重新切。
3. 他切得不一样多,不说错。请他数一数其中一份,和旁边的比。

怎么带「平均分给 5 人,最少添几个」:

1. 每行排 5 个,一行就是每人发一个。最后一行不满。
2. 只开放 `添`,请孩子把最后一行添满。他添了几个,就是最少添几个。
3. 有几行,每人就分到几个。请他数行,不用切。

### 方向盘

- `上`:一开始盘上哪个方向朝上。写北、东、南、西。缺省北,就是孩子背的「上北下南左西右东」。
- `小人`:写有、没有。缺省有。只讲方向牌怎么排,写没有。
- 操作:`转`(按一下转一格)、`圈`(圈住一个字)。

1. 第一张 `上` 用缺省,请孩子把「东」转到小人的前面。别替他转:他自己转一次,才看得出和背的那句不一样。

### paint — 画图

孩子说清楚的一个故事,分好幅交给画家,应用画成一张连环画(四幅时 2×2,像练习册)。出题时带上题干和词语宝库,就是一道看图说话题。

- `题:` 题干,出题才写。
- `词:` 词语宝库,用顿号隔开,出题才写。画不出来的词(突然、终于)也放这里。
- `角色:` 一行一个,写成「名字:样子、颜色、衣服」。每幅都照这个样子画。孩子说的颜色就用孩子的。
- 孩子没说样子,只写名字:`角色: 小熊`。
- `1.` 起一幅一行,一到四幅。每幅只写看得见的:时间和天气、地方、谁、动作、表情、东西。
- 每幅都写出角色的名字,不用「他」。
- 不写心里想的、说的话,也不写「羞愧」这种看不见的词:写成「低着头,脸红红的」。
- 一幅最多三个角色,一幅只画一件事。

```paint
角色: 小熊:棕色,戴黄色草帽,穿绿色背带裤
角色: 小猴:黄褐色,穿红背心
1. 春天的早上,地里。小熊弯着腰把西瓜种子埋进土里;小猴坐在树下吃桃子。
2. 中午,大太阳。小熊提着水壶给小苗浇水;小猴躺在树荫下睡大觉。
3. 夏天,小熊的地里结满大西瓜,小熊抱着一个笑着;小猴的地里只长了草。
4. 小熊推着满满一车西瓜,递给小猴一个;小猴低着头,脸红红的,挠着后脑勺。
```

出题版,带题干和词语宝库:
```paint
题: 图上画了谁?他们在干什么?结果怎么样?用上下面的词,写几句话。
词: 播种、睡大觉、满满、羞愧
1. 春天的早上,小熊在地里播种;小猴坐在树下吃桃子。
2. 小猴低着头,脸红红的。
```

### photo — 拍给我看

- 放在一节的最后。一节只放一张。
