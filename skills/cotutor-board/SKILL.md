# 板书怎么写

回复正文就是孩子看到的板书。板书里只有两种东西:你说的话,和板上的卡。

## 普通段落 = 你说的话

- 一行一句。每句会被念出来,显示在字幕行。
- 所以不写标题、列表、粗体、括号注释。
- 想强调某个词,用方括号标出来,如「这叫[底]」。那个词要在某张卡上出现。不标也行,后期会挑。
- 末句写成问句,就停下等孩子。
- **只有末句会停。** 中间的问句念完,接着念下一句,不等孩子。
- 末句这一问能选,就配一张 `choice` 卡;能填,就配一张 `fill` 卡。卡在前,问句在后。
- 开放的问题不用配卡。应用会把末句那一问补成板上的一张提问卡,你别自己再写一张。

## 围栏 = 板上的卡

- 围栏的语言标签是卡的种类。正文按那种卡的写法写,见下面「卡的种类」。
- 卡写在讲它的那句话前面,卡与话交错。
- 卡上是**名词**:定义、公式、题、图、选项。讲稿是**动词**:你说的话。
- 别把一句话切成一张卡。
- 不认识的标签,当代码卡原样显示。
- 正文写得不对的卡,退成一段文字,孩子端不会报错。

## 一节多长

- 一节 3–5 张卡、6–12 句话。
- 一张卡至少能指着讲三句。
- 一次只讲一个想法,讲完就问。
- 随口问答就一两句话,没有卡。
- **板书写完就停。** 最后一个字是问孩子的那句,后面不补总结,不再用工具。孩子看到的是你这轮最后一段话,再补的板书会丢。
- 板书到第一个「## 」为止,后面的孩子看不到。

## 孩子在卡上做了什么

- 孩子在卡上做的事(选了、填了、画了),下一条消息的上下文包会在 `cards:` 段告诉你。
- 一张卡一行:卡的编号、种类、标题、做了什么、答案。
- 孩子只交答案、没说话时,消息正文是「(交了答案,没说话)」。
- 孩子看到的卡上没有对错,对错由你口头说。
- 上下文包里的 `focus.card`,是孩子发消息时正开着的那张卡。
- 每种卡完整的协议(何时用、别用、反例、你会收回什么)在本技能目录的 references/<种类>.md,索引在 references/README.md。

## 一节长什么样

讲三角形面积的第一节。卡与话交错,卡在讲它的那句前面,最后一句问孩子:

````
我们拿两个一样的三角形拼一拼。

```text
# 拼
把两个一样的三角形倒过来拼在一起,得到一个平行四边形
```

两个一样的三角形一拼,就是一个[平行四边形],它的底和高没变。

```text formula
三角形面积 = 底 × 高 ÷ 2
```

所以三角形的面积就是[底]乘[高],再除以 2。

```choice
底 6 厘米、高 4 厘米的三角形,面积是多少?
- [ ] 24 平方厘米
- [x] 12 平方厘米
- [ ] 10 平方厘米
```

你来算算:底 6 厘米、高 4 厘米,面积是多少?
````

## 作业照片

上下文包里有 `photos:`,就是孩子拍了作业。

两种路径:

- `photos:` 是写在卡上的路径,相对 workspace 根。照原样抄进 `image` 或 `canvas` 卡。
- `photoFiles:` 是同一批照片的绝对路径,顺序一一对应。**Read 用它**,不用 find,不自己拼。

怎么看:

1. 原图 Read **一次**。认出是哪本、哪页、哪道题、卡在哪。
2. 照片上半透明的红线是孩子自己圈的,先讲圈住的那道。
3. 孩子写的字认不清,只放大**一次**:只裁孩子圈住的那块;没圈,就裁你要讲的那道题。裁出来的图存到 `/tmp`,别写进 captures/。
4. 放大了还认不清,别再裁了。讲稿里请孩子指一下、念出来,或者再拍近一点。
5. 别为了逐题核对答案,把整页一块块裁开看。一次只讲一道,其余的轮到了再看。

怎么讲:

1. 讲稿第一句说出你认出的:哪本、哪页、哪道题。
2. 第一张卡放作业:`image` 卡引原图(路径照 `photos:` 原样写),或 `text` 卡抄题面。
3. 一页有好几道,在这张卡后面放一张 `choice`,列出题号问孩子讲哪道。一次只讲一道。
4. 要孩子在作业上圈、写,用 `canvas` 卡,第一行写照片路径。
5. 拍糊了、拍不全、认不出,讲稿里请孩子再拍一张,或指一下。

还要知道:

- 孩子发之前可以裁剪、圈画。
- 消息里的字,是孩子对这几张照片说的话。没说话就是「(拍了 N 张)」。
- 几张一起来的,多半是同一份作业的几页。

## 卡的种类

### text — 一段字

板上的一段字:定义、结论、公式、一句要记住的话、题面。一张卡一个意思,能独立被指着讲三句。

- 围栏标签只写 `text`。
- 正文第一行以 `# ` 开头,就是这张卡的标题,下面是正文。
- 只有一行 `# 标题`、没有正文,就是小节标题。
- 算式写 `text formula`:衬线居中,单独一行。
- 样子(底色、字号、并不并排)不用管,后期定。

```text
# 认边
两条短边叫直角边,最长的一条叫斜边
```
```text formula
三角形面积 = 底 × 高 ÷ 2
```
```text
# 两大类型
```

### read — 点读

一行一段、点哪段听哪段的卡:原文、古诗、课文、生词、单词表。每段会在后台配成一段音(你配了音色的话),孩子点了就念。

一行一段。英文后面可以跟中文(`apple 苹果`),念的时候整段一起念。

```read
床前明月光,疑是地上霜。
举头望明月,低头思故乡。
```
```read
apple 苹果
banana 香蕉
orange 橘子
```

### choice — 选择题

一道选择题:问题 + 几个选项,答案只有你知道。孩子在舞台里点大按钮选,选了「交给老师」就到你下一轮的上下文包里。

第一行是问题,后面每行 `- [ ] 选项`,对的那项写 `- [x]`(标了多个就是多选)。答案孩子看不到。

```choice
底 6 厘米、高 4 厘米的三角形,面积是多少?
- [ ] 24 平方厘米
- [x] 12 平方厘米
- [ ] 10 平方厘米
```
```choice
下面哪些是圆的?
- [x] 苹果
- [ ] 香蕉
- [x] 西瓜
```

### fill — 填空

句子里留空让孩子填;答案只有你知道。孩子在舞台里逐空打字(或按住说),「交给老师」就到你下一轮的上下文包里。

句子里用 `___`(三个下划线)留空,下一行 `= 答案`;多个空按顺序各一行 `= 答案`。答案孩子看不到。

```fill
三角形的面积等于底乘高再除以___。
= 2
```
```fill
3、4、___ 和 5、12、13 都是勾股数组;一个直角三角形两条直角边是 3 和 4,斜边是 ___。
= 3
= 5
```

### image — 图片

一张图 + 图注:孩子拍的作业、产物里的图、网上的图。

- 第一行是图:workspace 里的相对路径,或 http(s) 地址。只认图片后缀。
- 作业照片照 `photos:` 原样写,如 `captures/2026-09-10/1620-1.jpg`。照片在 workspace,不在 vault。
- 后面几行是图注。

```image
captures/2026-09-10/1620-1.jpg
你昨天写的这道题,看第二行。
```
```image
https://example.com/brain.png
```

### tianzige — 田字格

田字格:孩子问「这个字怎么写」时用的卡,一到四个汉字,每个字一个格,讲到这张卡时逐笔写一遍,之后孩子点哪个字,哪个字再写一遍。笔顺是现成的数据,不是你写的。

- 正文就是要写的字:一到四个汉字。
- 不要空格、标点、拼音。
- 同音的词先给再确认:先出这张卡,讲稿里再问一句「你说的是加油打气的那个鼓励吧」。不要先问再给。

```tianzige
鼓励
```
```tianzige
鼓
```

### scene — 讲解动画(课包)

一段逐笔画出来的讲解:图形当场增画、填色、标号,自带讲稿与声音。课包由画图老师(scene-maker)做,几分钟、几毛钱一个;做好之前卡上写「图还在路上」,做好了卡自己变成可播。

- 第一行是课包 id:小写字母、数字、连字符,形如 `2026-09-10-guilv`。
- 第二行可以写一句给孩子的话。
- 新课包再写一行 `题面:`(完整题目)和一行 `讲法:`(讲法要点、孩子的口径)。画图老师主要看这两行,孩子看不到。
- 要再放一次做好的课包,只写 id,不写这两行。
- 讲稿里写 `[[play]]` 锚到它:念到那句,就把动画铺满播,播完接着念下一句。

```scene
2026-09-10-guilv
我去把这道题画出来,画好了我们一起看。
题面:找规律填数 75、70、65、__、55
讲法:每次少 5;先圈出相邻两个数,再一格一格往后推
```

### canvas — 画板

孩子自己在上面画的一块板:笔、橡皮、黑红蓝三色、撤销、清空。可以给一幅底图(课包的终帧、几个骨架元素,或孩子刚拍的作业照片)让孩子在上面标画,也可以空白只给题目。「给老师看」会导出一张 png 给你。

- 第一行是底,后面的行是题目。标签后面的词也可以当题目。
- 底有四种:
  - 课包 id:那幅图的终帧做底,孩子在上面标画。
  - 一张图的路径:照 `photos:` 里那样的 `captures/…` 相对路径写,照片做底。
  - 一段行内骨架 JSON:`{"skeletons":[…]}`,drawtell 的元素写法,不超过 40 个。
  - 什么底都没有:只写题目,就是空白画板。

```canvas
画一个三角形,标出它的一条高。
```
```canvas
2026-09-10-guilv
把每次少的那个数圈出来。
```
```canvas
captures/2026-09-14/1620-1.jpg
把算错的那道圈出来。
```

### code — 代码或原样的文字

原样显示、不念的一块字:代码、要保留缩进与符号的东西。

- 围栏标签写语言名(```python),就是代码卡。
- 不认识的标签,一律当代码卡原样显示,不报错。

```python
print(1 + 1)
```
```
  3 4
+ 1 2
-----
  4 6
```
