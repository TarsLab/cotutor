# 卡的种类(索引)

每种卡一份协议:是什么、什么时候用 / 别用、写法、例子、反例、孩子看到什么、你会收回什么、状态的形状。讲解前只读需要的那一两张;总表在 ../SKILL.md。机器文件,init / upgrade 刷新。

- **text**(text.md)—— 板上的一段字:定义、结论、公式、一句要记住的话、题面。一张卡一个意思,能独立被指着讲三句。
  - 用在:给一个概念下定义、放一个公式、写一句要记住的话、写题面(没有选项、不用孩子填)。
  - 用在:小节标题——只写一行 `# 标题`,板上出一行无底的字,不算卡。
- **read**(read.md)—— 一行一段、点哪段听哪段的卡:原文、古诗、课文、生词、单词表。每段会在后台配成一段音(你配了音色的话),孩子点了就念。
  - 用在:要孩子反复听、跟着读的东西——古诗、课文原句、单词(英文后面可以跟中文)。
  - 用在:超过两行的原文。`text` 卡是给你讲的,这张是给孩子读的。
- **choice**(choice.md)—— 一道选择题:问题 + 几个选项,答案只有你知道。孩子在舞台里点大按钮选,选了「交给老师」就到你下一轮的上下文包里。
  - 用在:一节讲完,要孩子回答一个能选的问题;放在这节**末尾**,末句讲稿就是这个问题,停下等孩子。
  - 用在:选项都短(数字、几个字)最好——短选项会横排成一行胶囊。
- **fill**(fill.md)—— 句子里留空让孩子填;答案只有你知道。孩子在舞台里逐空打字(或按住说),「交给老师」就到你下一轮的上下文包里。
  - 用在:答案是一个词、一个数,不适合给选项(给了选项就是猜)。
  - 用在:放在一节末尾,末句讲稿就是这道题。
- **image**(image.md)—— 一张图 + 图注:孩子拍的作业、产物里的图、网上的图。
  - 用在:讲孩子拍来的作业(上下文包 `photos:` 里的路径),指着图讲。
  - 用在:一张现成的插图能说清的概念。
- **tianzige**(tianzige.md)—— 田字格:孩子问「这个字怎么写」时用的卡,一到四个汉字,每个字一个格,讲到这张卡时逐笔写一遍,之后孩子点哪个字,哪个字再写一遍。笔顺是现成的数据,不是你写的。
  - 用在:孩子问「X 怎么写」「X 的笔顺」;讲生字、讲词语时要孩子看清怎么落笔。
  - 用在:一个词就写一张,`鼓励` 两个字放一张,孩子看得到它们是一个词。
- **scene**(scene.md)—— 一段逐笔画出来的讲解:图形当场增画、填色、标号,自带讲稿与声音。课包由画图老师(scene-maker)做,几分钟、几毛钱一个;做好之前卡上写「图还在路上」,做好了卡自己变成可播。
  - 用在:要画图才讲得清的题(几何、找规律、数形结合);讲作业题。
  - 用在:一天最多起两个(policy `scenes.dailyMax`),所以一节最多一张,放在最需要图的那一步。
- **canvas**(canvas.md)—— 孩子自己在上面画的一块板:笔、橡皮、黑红蓝三色、撤销、清空。可以给一幅底图(课包的终帧、几个骨架元素,或孩子刚拍的作业照片)让孩子在上面标画,也可以空白只给题目。「给老师看」会导出一张 png 给你。
  - 用在:「画一画」「标出来」「圈出来」这类要孩子动手的题:画高、标直角、圈出错的那步。
  - 用在:一节末尾,末句讲稿就是这个要求。
  - 用在:上下文包里有 photos 时,把那张照片做底图,让孩子在自己的作业上圈出错的那道、把答案写上去。
- **code**(code.md)—— 原样显示、不念的一块字:代码、要保留缩进与符号的东西。
  - 用在:教编程时的代码;要孩子一字不差看的东西(竖式、表格)。
