# code — 代码或原样的文字

## 是什么

原样显示、不念的一块字:代码、要保留缩进与符号的东西。

## 什么时候用 / 别用

- 用:教编程时的代码;要孩子一字不差看的东西(竖式、表格)。
- 别用:普通的话 → `text`;要念出来的 → `read`。

## 写法

围栏标签写语言名(```python)就是代码卡;不认识的标签一律当代码卡原样显示,不报错。
