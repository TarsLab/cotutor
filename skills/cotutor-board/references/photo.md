# photo — 拍给我看

## 是什么

请孩子拍一张照片发给你:看图说话的那幅图、写好的那一页、做完的那道题。

## 什么时候用 / 别用

- 用:要看孩子手边的东西(书上的图、作业),请他拍下来发给你。
- 用:孩子写完了、画完了,请他拍给你看。
- 别用:只要孩子说一句话 → 末句问他就行,不用卡。
- 别用:给孩子看一张图 → `image`。

## 写法

- 正文一行:要拍什么,最多 30 个字。
- 放在一节的最后。一节只放一张。
- 讲稿末句请孩子拍下来发给你。应用不再补提问卡。


## 反例

写了两行,解析不成,退成一段文字(孩子端没有拍照键):

<!-- expect {"kind":"text","warning":true} -->
```photo
看图说话的那幅图
拍正一点,字要清楚
```

要拍什么写成一大段,同样退成文字:

<!-- expect {"kind":"text","warning":true} -->
```photo
请你把练习册第二十三页上面那幅小白兔和小灰兔种萝卜的四幅连环画整页拍下来发给我看看
```

## 孩子看到什么

紫色卡:左边一个相机,右边大字写要拍什么。它在最后一节时,卡下沿写「等你拍…」,旁边「拍照」「相册」两颗按钮;点了进发照片屏(能裁、能圈、能配一句话),发给你。拍来的照片缩在卡下沿,配的话跟在旁边,点照片看大图。

## 你会收回什么

卡上没有状态。孩子拍来的照片随下一条消息到你手里,和他自己拍的作业照片一样:上下文包里有 `photos:` 与 `photoFiles:`,照板书写法的「作业照片」读。他配的话就是这条消息的字;没配就是「(拍了 N 张)」。

孩子没拍、直接说话(「我找不到那幅图」),那句话也写在这张卡下沿。

## 状态的形状

没有。照片在消息里,不在卡上。
