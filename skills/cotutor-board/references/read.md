# read — 点读

## 是什么

一行一段、点哪段听哪段的卡:原文、古诗、课文、生词、单词表。每段会在后台配成一段音(你配了音色的话),孩子点了就念。

## 什么时候用 / 别用

- 用:要孩子反复听、跟着读的东西——古诗、课文原句、单词(英文后面可以跟中文)。
- 用:超过两行的原文。`text` 卡是给你讲的,这张是给孩子读的。
- 别用:你自己的解释、结论 → `text`。
- 别用:一段里塞两句;一段就是孩子一次点的量。

## 写法

一行一段。英文后面可以跟中文(`apple 苹果`),念的时候整段一起念。

## 例子

<!-- expect {"kind":"read","props":{"segments":["床前明月光,疑是地上霜。","举头望明月,低头思故乡。"]}} -->
```read
床前明月光,疑是地上霜。
举头望明月,低头思故乡。
```

<!-- expect {"kind":"read","props":{"segments":["apple 苹果","banana 香蕉","orange 橘子"]}} -->
```read
apple 苹果
banana 香蕉
orange 橘子
```

## 反例

空的点读卡解析不成,会退成一段文字:

<!-- expect {"kind":"text","warning":true} -->
```read
```

## 孩子看到什么

米色卡,每段一条白底的行;点一条就念那条(你配了音色就是你的声,配音还没生成好时先用浏览器的声),念的时候那条亮起来。讲稿的 `[词]` 落在段上是荧光笔。

## 你会收回什么

没有——点读不记状态(点了哪段不告诉你)。

## 状态的形状

没有。
