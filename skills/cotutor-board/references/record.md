# record — 录音卡

## 是什么

一句要读的话。孩子点开卡,先听示范音,再按住录;交给老师后,koubo 会给你一条判(过 / 可救 / 重录)和原因。

## 什么时候用 / 别用

- 用:练发音,要孩子把一句话读出来。
- 用:一节放几张,一张一句,孩子一张一张录。
- 别用:要孩子回答问题 → `choice` 或 `fill`。
- 别用:只给孩子听 → `read`。

## 写法

- 正文一句,最多 30 个字。要读几句就放几张卡。
- 容易读错的字用【】括出来,孩子看到的是红字。
- 标签后写 `focus=sh_s`,只查这一组;不写就按混淆表全查。几组用逗号隔开。
- 拼音题在标签后写 `pinyin`:第一行是带调号数字的拼音,第二行是给孩子看的字。

## 例子

<!-- expect {"kind":"record","props":{"text":"老师上山看树","risk":[3,5],"mode":"sentence","focus":["sh_s"]}} -->
```record focus=sh_s
老师上【山】看【树】
```

<!-- expect {"kind":"record","props":{"text":"shi2 si4 shi4 shi2 si4","show":"十四是十四","risk":[0,2,3],"mode":"pinyin"}} -->
```record pinyin
shi2 si4 shi4 shi2 si4
【十】四【是】【十】四
```

<!-- expect {"kind":"record","props":{"text":"四是四,十是十,十四是十四","mode":"sentence"}} -->
```record
四是四,十是十,十四是十四
```

## 反例

超过 30 个字,解析不成,退成一段文字(孩子端没有录音键):

<!-- expect {"kind":"text","warning":true} -->
```record
各位观众朋友大家好,欢迎收看今天的节目,今天我们聊一聊闽南语母语的朋友学普通话时最容易混的几组声母
```

两句写在一张卡里,同样退成文字:

<!-- expect {"kind":"text","warning":true} -->
```record
老师上山看树
四是四,十是十
```

拼音行没写调号数字,同样退成文字:

<!-- expect {"kind":"text","warning":true} -->
```record pinyin
shi si shi si
```

## 孩子看到什么

紫色卡:大字的句子,风险字标红;拼音题的字下面有带调号的拼音。卡上有「听」(示范音,你的声音),和「没录」或「我的 · 7.1 秒」。点卡开舞台:先听,再按住大圆键录,松手就停;录好了能回放、能按住再录。这一节还有没录的,底部是「下一句」;都录了才是「交给老师」。交了之后这一节的录音卡锁住,只能回放。卡上永远没有分数、没有判。

## 你会收回什么

交给老师后,下一条消息的上下文包 `cards:` 段里,每张录了的卡一行:

- `<job>/<n> record「老师上山看树」 已录 7.1 秒;判 重录:句准确度 36 < 80;山 的 sh 19 < 65,读成 s;树 的 sh 20 < 65;take=20260926-162203-b7a1c2`
- `<job>/<n> record「十四是十四」 已录 2.4 秒;判 过;take=…`
- `<job>/<n> record「四是四,十是十,十四是十四」 已录 5.0 秒;没评上(timeout)`
- `<job>/<n> record「…」 已录 5.0 秒;还没评完`

判和原因是 koubo 给的事实,你听不到声音,别自己评。「读成 s」只是提示,说的时候用「可能」。没评上、还没评完,就请孩子再录一次。
