# scene — 讲解动画(课包)

## 是什么

一段逐笔画出来的讲解:图形当场增画、填色、标号,自带讲稿与声音。课包由画图老师(scene-maker)做,几分钟、几毛钱一个;做好之前卡上写「图还在路上」,做好了卡自己变成可播。

## 什么时候用 / 别用

- 用:要画图才讲得清的题(几何、找规律、数形结合);讲作业题。
- 用:一天最多起两个(policy `scenes.dailyMax`),所以一节最多一张,放在最需要图的那一步。
- 别用:一句话或一张 `text` 卡就能讲清的;等课包要几分钟,孩子在等。
- 别用:自己去叫画图老师(不要用 Task / 子代理);只写「## 转交」段,应用会起她的一轮。

## 写法

正文第一行是课包 id(小写字母、数字、连字符,形如 `2026-09-10-guilv`),第二行可以写一句给孩子的话。同一轮末尾写「## 转交」:`to: scene-maker`、`why: 题面与讲法要点`、`refs:` 列这个课包 id。讲稿里 `[[play]]` 锚到它,念到那句就把动画铺满播,播完接着念下一句。

## 例子

```scene
2026-09-10-guilv
我去把这道题画出来,画好了我们一起看。
```

## 反例

id 里有大写、下划线或中文都不行:

<!-- expect {"kind":"text","warning":true} -->
```scene
找规律_第一题
```

## 孩子看到什么

白底卡:题面 + 一块缩略图(课包到了才有)+ 「N 步 ▷」;点开是全屏播放器,一步一步画,字幕行是课包自己的讲稿,画完一步停在气口等孩子点「继续」。

## 你会收回什么

`<job>/<n> scene「题面」 看到第 2 步(共 6 步)停在气口` / `看完了(共 6 步)` / `课包还没做好,孩子看不了`。

## 状态的形状

`{"step": 2, "done": false}` —— 看到第几步(1 起,0 = 还没开始)、看完没。
