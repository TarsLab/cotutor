# 排首页

你在一个 cotutor workspace 的根目录(有 cotutor.json)。

孩子端打开就是首页:

- 最上面每位老师一张老师卡,卡上几个按钮。孩子点哪个,就带着哪个意思进那位老师。
- 下面是几张给孩子看的卡:一段字、几个字的田字格、一张图、一段点读。

首页由你和家长商量,**家长批准后发布**。孩子只看得到发布的那份。

## 铁律

- **发布要家长在这次对话里明说**(「发吧」「可以发布」)。草稿随便改;cotutor home publish 只在明说之后跑。
- 不写 vault。总结要留下来,走记账(第二步),由应用落进日记。
- 不改 conversations/、ledger/、cotutor.json、老师文件。
- home/published.json 与 home/history/ 是机器件,不手改。
- 孩子看得到的字(按钮、卡)不评判:不写对错、分数、名次、「真棒」「聪明」「最…」。
- .claude/agents/ 里的老师是给 cotutor 起 claude -p 用的。不要当子代理派,也不要替老师回答孩子。

## 一、看今天

1. `cotutor home show`:现在发布的是哪份、每个按钮被点了几次。先知道上次推荐的,孩子选了什么。
2. 有脸的老师逐位读 conversations/<老师>/<今天>.json。有脸的老师 = cotutor.json 里键以 -tutor 结尾、enabled、不 hidden 的。要看的:
   - 话题(thread)。
   - 孩子的话(from: kid)。带 via、且 button 是数字的那条,是按钮上的字,不是孩子说的。
   - 每轮的 kidText 与 section.cards。
   - parentText:老师写给家长的。
   - remembered。
3. 细看一轮,用 `cotutor show <老师> <job>`。卡的 id(`<job>/<n>`)在「卡」那一行。
4. 孩子在卡上做的:conversations/<老师>/<日期>.<job>.cards/<n>.json。

总结在对话里说,不落文件。每位老师两三行:学了什么、停在哪、哪里卡住。引孩子的原话,或卡上做的。

## 二、记账

要留下来的,走记账:

1. 家长给值得记的话题打星:`cotutor rate <老师> <话题> <1-5>`。到 vault.keepScore 的,摘要才进日记。
2. 再跑 `cotutor bookkeep <老师>`。

- 记账每个话题起老师一轮;记完,每位有记忆的老师再整理一轮记忆,结果直接落进记忆文件。**花钱,先问。**
- 家长说不记,就跳过。
- 记完读当天日记核对一眼。日记在哪,见 cotutor-vault 技能。

## 三、商量下次

先在对话里列提案,不写文件。

材料:

- 今天停在哪。
- 日记最近的「- 观察:」。
- 本周计划里各位老师那段、课程表。
- 这科这学期的入口文件与教材:下一课是什么。
- 上次首页被点了什么。

### 老师卡

每位老师一张。不写的,应用会补一张只有「新话题」的。

- 按钮最多 4 个。「新话题」应用自己加,不写。
- 孩子看的字最多 16 个,孩子的口吻:「我要预习小蝌蚪找妈妈」「接着写看图写话」「再练两道退位减法」。
- 每个按钮下一行「讲法:」,写给老师:从哪开始、重点是什么、讲到哪收。孩子看不到。
- 「接着」要指到那一天的那个话题:日期 + 话题 id。老师会拿到那个话题最后一节的讲稿与卡。今天的话题,就是接着聊。
- 没什么要推荐的老师,不写按钮。

草稿里可能已经有家长在家长端「交给孩子」写进来的「接着」行。它指的是家长今天和老师备好的话题,孩子按了只打开、看到的就是家长挑好的那几张卡。

- 别删它。
- 别改它的日期与话题。
- 字可以和家长商量着改。

### 其余的卡

按需,一两张就够:

- 要孩子今晚先看一眼的一句话:`text`。
- 要再写一遍的字:`tianzige`。
- 一张图:`image`。
- 一段要读的:`read`。

每条提案带一句「为什么」。家长改、删、加,直到点头。

## 四、写草稿、检查、预览

1. 家长点头后,写 home/draft.md,整份覆盖。
   - 写法见 references/首页语法.md,老师卡的细则在 references/tutor.md。
   - 最后写「## 为什么这么排」,把第三步每条的「为什么」放进去。这段给家长,孩子看不到。
2. `cotutor home check`。「要改」的改到没有;「提醒」的跟家长说一声。
3. 服务开着,就请家长打开工作台「首页」页(/dev#home)看预览,手机、平板两种尺寸。
   - 预览里点按钮不会真发,会显示发给谁、讲法是什么。
4. 家长要改就改草稿,再 check。

## 五、发布

家长明说之后:`cotutor home publish`。

- 它再检查一遍、留历史,打印发布的 id。
- 孩子端刷新就是新首页,不用重起服务。
- 发完告诉家长:发了哪几张卡、哪几条提醒还在。

回到以前的某份:`cotutor home publish --from home/history/<id>.md`,同样先问。

## 报告怎么写

1. 总结先行:每位老师两三行。
2. 再是下次的提案:按卡列,带为什么。
3. 最后是做了什么:记没记账、花了多少、草稿写没写、check 结果、发没发布。
