# tutor — 老师卡

## 是什么

老师卡:首页上一位老师一张,卡上几个按钮,孩子点哪个就带着哪个意思进这位老师——新开一个话题、接着以前的某个话题、说一句开场话让老师照家长备好的讲法讲起来,或者先看一堂做好的小课堂。只用在首页。

## 什么时候用 / 别用

- 用:排首页时,给每位要推荐下一步的老师写一张:预习下一课、接着没讲完的、再练一练。
- 用:同一位老师有两三件事,写在同一张卡上,一行一个按钮。
- 别用:在板书里写老师卡 → 板书里退成一段文字;老师之间不互相推荐。
- 别用:没什么要推荐的老师不必写 → 应用会补一张只有「新话题」的。
- 别用:同一位老师写两张 → 只认第一张,检查会让你合并。

## 写法

围栏标签 `tutor <老师的键>`(cotutor.json tutors 里的英文名,如 `chinese-tutor`)。正文一行一个按钮,孩子看到的字就是这一行,最多 16 个字,孩子的口吻;最多 4 个按钮。

- 普通的一行 = **开场按钮**:孩子点了,这行字就作为孩子的第一句发给老师,新开一个话题。
- `接着 <日期> <话题> <孩子看到的字>` = **接着按钮**:接着那天的那个话题(话题 = 那个话题第一条消息的 job,如 `1930-1`,`cotutor show` 与对话索引里都有)。今天的话题就是接着聊;以前的新开一个会话,老师会拿到那个话题最后一节的讲稿与卡。
- `小课堂 <课包或视频的 id> <孩子看到的字>` = **小课堂按钮**:孩子点了先铺满看这一课(课包 `bundles/<id>/`,或视频 `lectures/<id>/`),看完才能开口;开口那句新开一个话题,老师拿到课的每句原话与孩子看的情况。
- `activity <名> [孩子看到的字]` = **activity 按钮**:进这位老师的一个 activity(`agents/<老师>/activities/<名>.md`,如你说我画)。字不写就是 activity 的名字。孩子点了和开场按钮一样,新开一个话题,老师照那个 activity 文件带。
- activity 按钮下面 `名: 值` 的行是这个 activity 的参数(家长填的),一行一个。有哪些参数、什么类型、能不能空,看那个文件的「## 家长填的」;检查会对。孩子看不到。
- `讲法: …` 挂在上一个按钮下面,写给老师的:从哪开始、重点是什么、讲到哪收。可以写多行。孩子看不到。
- `留到: <日期>` 挂在上一个按钮下面:这个按钮留到那天(含那天),过了孩子就看不到。不写就一直留着。
- `新话题` 不用写,应用永远放第一个。

## 反例

按钮的字太长(要跟老师说的话写进了按钮)解析不成,整张卡退成一段文字,检查报「要改」:

<!-- expect {"kind":"text","warning":true} -->
```tutor math-tutor
再练两道退位减法,先让他说怎么想,跨十那一步慢一点
```

`接着` 没写日期和话题:

<!-- expect {"kind":"text","warning":true} -->
```tutor chinese-tutor
接着 小蝌蚪找妈妈
```

`小课堂` 后面只写了课名,没写课包 id:

<!-- expect {"kind":"text","warning":true} -->
```tutor math-tutor
小课堂 13减8怎么拆
```

课包 id 写错(或课包还没做),解析得过,首页检查报「要改」:`bundles/<id>/` 不在或读不出来。

`留到:` 后面写的不是日期:

<!-- expect {"kind":"text","warning":true} -->
```tutor chinese-tutor
我要看图说话
留到: 明天
```

`activity` 后面没写名字:

<!-- expect {"kind":"text","warning":true} -->
```tutor chinese-tutor
activity
```

activity 的名字写错、参数写错或少了要填的,解析得过,首页检查报「要改」(对的是那个 activity 文件)。

`讲法:` 前面没有按钮:

<!-- expect {"kind":"text","warning":true} -->
```tutor chinese-tutor
讲法: 先读课文
我要预习小蝌蚪找妈妈
```

## 孩子看到什么

首页最上面,一位老师一张卡:头像、名字,下面竖着一排按钮——「✨ 新话题」,今天聊过的再加一个「↻ 接着刚才的…」,然后是你写的(开场按钮与 activity 按钮带 ▶,接着按钮带 ↻,小课堂按钮浅橙底、写着课长与「看完再问老师」)。点开场或接着按钮,老师页打开、按钮上的字立刻发出去,老师接着就讲;点新话题是空白的老师页,等孩子开口。今天的条数用完、或服务不通,整张卡变灰。讲法孩子永远看不到。

## 你会收回什么

没有卡上的状态。孩子点了哪个按钮,记在那条消息的 `via` 上(`cotutor home show` 汇总);老师那边,开场与接着按钮的那条消息的上下文包里有 `home:`(按钮的字与讲法),接着以前话题的还有 `continue:`,小课堂看完开口那条还有 `lecture:`(课的每句原话与看的情况);activity 按钮起的话题,每条都有 `activity:`(哪个 activity、家长填的参数、应用算的),第一条还有 `<cotutor-activity>`(那个文件「老师怎么带」一节)。

## 状态的形状

没有。
