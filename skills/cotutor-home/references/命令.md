# 命令(机器生成,别改)

在 workspace 根跑;每条就是 cotutor <命令> --help 的内容。

```
这些命令都认 --workspace <目录>(在 workspace 根跑可以不写)和 --sandbox(在试用副本里跑,不进孩子的记录)。

cotutor home — 检查和发布孩子端首页

用法:
  cotutor home check [--published] [--json]
  cotutor home publish [--force] [--from <文件>] [--json]
  cotutor home show [--json]

选项:
  --published    [check] 查已发布的那份(缺省查草稿 home/draft.md)
  --force        [publish] 有要改的卡,丢掉它们照发
  --from <文件>  [publish] 发另一份(比如历史里的)
  --json         机器可读的输出

说明:
  - check 不花钱:孩子会看到哪几张卡、每位老师的按钮、要改的(带行号)
  - publish 先检查,留历史 home/history/,写 home/published.json;孩子端刷新就是新的
  - show:现在发布的是哪份、每个按钮被点了几次

例子:
  cotutor home check
  cotutor home publish

cotutor show — 看一轮:问了什么、上下文包、讲稿与卡、读了什么

用法:
  cotutor show <老师> <job> [<日期>] [--evals] [--json]

选项:
  --evals  看回放的那轮(evals/ 里的)
  --json   机器可读的输出

说明:
  - 日期缺省今天;--json 和家长端「看原文」是同一份

例子:
  cotutor show math-tutor 1620-1 2026-09-12 --json

cotutor rate — 给一个话题打星(1–5)

用法:
  cotutor rate <老师> <话题> <1-5> [--date <日期>] [--json]

选项:
  --date <日期>  哪天(YYYY-MM-DD,缺省今天)
  --json         机器可读的输出

说明:
  - 和家长端同一条路;到 vault.keepScore 星的话题,记账时摘要才进日记

例子:
  cotutor rate math-tutor 1620-1 4

cotutor bookkeep — 记账:把这天的话题写进日记

用法:
  cotutor bookkeep <老师> [--date <日期>] [--thread <话题>] [--quiet] [--json]

选项:
  --date <日期>    哪天(YYYY-MM-DD,缺省今天)
  --thread <话题>  只记这个话题
  --quiet          不打印过程
  --json           机器可读的输出

说明:
  - 每个还没记过的话题起一轮记账,应用写进笔记文件夹的日记

注意:
  - 花钱
  - 写孩子的笔记文件夹

例子:
  cotutor bookkeep math-tutor
```

## 文件

| 文件 | 是什么 |
|---|---|
| `home/draft.md` | 草稿:你写、家长可改;孩子端不读 |
| `home/published.json` | 已发布的那份(publish 生成,机器件,别手改);孩子端只读它 |
| `home/history/<id>.md` | 每次发布的原文 |
| `conversations/<老师>/<日期>.json` | 一天的对话索引;消息的 `via` = 从首页哪个按钮进来的(`{home, button, label}`),`continues` = 接着哪天哪个话题 |
