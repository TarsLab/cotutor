# 首页怎么写(机器生成,别改)

首页文件是 workspace 的 home/draft.md,和板书同一个解析器:

- **frontmatter**(可选):只认 `for: YYYY-MM-DD`(这份是给哪天用的)。
- **围栏 = 卡**:标签第一个词是种类,其余是修饰。卡按文件顺序铺;老师卡永远排在最上面。
- **第一个 `## ` 起是给家长的**(「## 为什么这么排」),孩子看不到。
- 围栏外的普通行首页不显示(检查会提醒),要给孩子看的写进卡里。

应用保证的:每位孩子端露出的老师都有一张老师卡(没写就补一张只有「新话题」的);「新话题」永远是第一个按钮;今天和这位老师聊过,第二个按钮是应用加的「接着刚才的」;引用坏了(话题找不到)的按钮不出现。

老师卡的按钮最多 4 个,每个最多 16 个字。

## 首页专属的卡

### tutor — 老师卡

老师卡:首页上一位老师一张,卡上几个按钮,孩子点哪个就带着哪个意思进这位老师——新开一个话题、接着以前的某个话题、或者说一句开场话让老师照家长备好的讲法讲起来。只用在首页。

围栏标签 `tutor <老师的键>`(cotutor.json tutors 里的英文名,如 `chinese-tutor`)。正文一行一个按钮,孩子看到的字就是这一行,最多 16 个字,孩子的口吻;最多 4 个按钮。

- 普通的一行 = **开场按钮**:孩子点了,这行字就作为孩子的第一句发给老师,新开一个话题。
- `接着 <日期> <话题> <孩子看到的字>` = **接着按钮**:接着那天的那个话题(话题 = 那个话题第一条消息的 job,如 `1930-1`,`cotutor show` 与对话索引里都有)。今天的话题就是接着聊;以前的新开一个会话,老师会拿到那个话题最后一节的讲稿与卡。
- `讲法: …` 挂在上一个按钮下面,写给老师的:从哪开始、重点是什么、讲到哪收。可以写多行。孩子看不到。
- `新话题` 不用写,应用永远放第一个。

```tutor chinese-tutor
我要预习小蝌蚪找妈妈
讲法: 第 22 课。先带他把 1–3 自然段读顺,重点字 塘、脑、袋
接着 2026-09-16 1930-1 接着写看图写话
讲法: 上次第二句卡住了,先把他写的两句念给他听
```

只要「新话题」的老师,正文空着(也可以不写这张卡):
```tutor reading-tutor
```

## 和板书共用的卡

- `text`:板上的一段字:定义、结论、公式、一句要记住的话、题面。一张卡一个意思,能独立被指着讲三句。 写法见 ../../cotutor-board/references/text.md(首页上没有讲稿,那里说「讲到这张卡时」的动作不会发生;孩子点了照样能用)。
- `read`:一行一段、点哪段听哪段的卡:原文、古诗、课文、生词、单词表。每段会在后台配成一段音(你配了音色的话),孩子点了就念。 写法见 ../../cotutor-board/references/read.md(首页上没有讲稿,那里说「讲到这张卡时」的动作不会发生;孩子点了照样能用)。
- `image`:一张图 + 图注:孩子拍的作业、产物里的图、网上的图。 写法见 ../../cotutor-board/references/image.md(首页上没有讲稿,那里说「讲到这张卡时」的动作不会发生;孩子点了照样能用)。
- `tianzige`:田字格:孩子问「这个字怎么写」时用的卡,一到四个汉字,每个字一个格,讲到这张卡时逐笔写一遍,之后孩子点哪个字,哪个字再写一遍。笔顺是现成的数据,不是你写的。 写法见 ../../cotutor-board/references/tianzige.md(首页上没有讲稿,那里说「讲到这张卡时」的动作不会发生;孩子点了照样能用)。

只能用在板书里的卡(选择题、填空、画板、讲解动画、代码)首页放不了——它们做完要交给某位老师。

````markdown

for: 2026-09-18

```tutor chinese-tutor
我要预习小蝌蚪找妈妈
讲法: 第 22 课。先带他把 1–3 自然段读顺,重点字 塘、脑、袋;读完问他小蝌蚪先遇到了谁
接着 2026-09-16 1930-1 接着写看图写话
讲法: 上次第二句卡住了,先把他写的两句念给他听再往下
```

```tutor math-tutor
再练两道退位减法
讲法: 出 52−7、80−3,先让他说怎么想,跨十那一步慢一点
```

```tianzige
塘脑袋
```

## 为什么这么排

- 语文:16 号小蝌蚪只读到第 1 段;看图写话第二句卡住,日记观察「句子接不上时会停很久」。
- 数学:近两周观察里两次跨十停顿,计划里写了周五小测。
- 朗读老师今天没有要接的,只留新话题。
````
