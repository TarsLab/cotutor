# 改课本的分块

你在一个 cotutor workspace 的根目录(有 cotutor.json)。

孩子在 iPad 上看课本 PDF。应用不认图,课本页上哪是一道题、哪格能写,全靠分块:一页一份 JSON。
cotutor 已经照规则给每页出了一份(块、段、能写的格),但规则看不懂题意:表格叫什么、口诀一句一句、答案是什么,它都不知道。
你在规则出的那份上改,改好存回 vault。老师照你写的叫法找题、看答案,孩子点哪块念哪块。

## 铁律

- **框不估。** 能写的格从候选(`p078.candidates.json`)里取,id 就写候选的编号。候选里没有的格(横线、圈画区),写脚本量页图,量好写 `"src": "measured"`。
- **不直接写 vault。** 只改 pull 出来的目录,改好用 `cotutor textbook push` 存回去。
- **叫法照书上印的号。** 书上没号的从上往下数。一课里不重名。
- **念法照印的念。** 不加书上没印的话。空着的地方念「几」或「什么」。
- **答案只给老师。** 写在 `teacher` 里;没把握的写 `note`,不硬写。
- 课本 PDF、`agents/`、`cotutor.json` 都不改。
- 装东西(poppler、Python 包)先问家长。

## 一、先说多久

1. `cotutor textbook list <册>`:看每一课在 PDF 的哪几页,哪几课已经改过(标着 vault)。
2. 跟家长说清:改哪几课、一共几页、大概多久(一页一两分钟)。
3. 家长点头再动手。

一个单元十几页,一次只取一两课,改完 push 一次,再取下一课。

## 二、取出来

```
cotutor textbook pull 数学 --lesson 7～9的乘法口诀
```

- 给页也行:`--pages 78`(PDF 的页,不是印的页码)。落在哪一课,就把那一课的页都取全。
- 缺省放 `.cotutor/zones-work/<册名>-p<头>-<尾>/`,每页三个文件:

| 文件 | 是什么 | 你做什么 |
|---|---|---|
| `p078.json` | 这一页现在用的分块(规则出的,或以前改好的) | 改它 |
| `p078.candidates.json` | 候选:文字层的行 `L0…`、能写的格 `0…`、表格 `T0…`,千分比的框 | 照它取框,别改 |
| `p078.png` | 页图(200dpi,和框同一套坐标) | 看 |

- 页图没出来:要 poppler 的 `pdftoppm` 或 Python 的 PyMuPDF。先问家长装哪个。
- `pull.json` 记着哪一册、哪几课,check、push 要它,别删。

## 三、一页一页改

先看页图,再读这一页的规范(`references/数学.md`、`语文.md`、`科学.md`),再改 `p078.json`。字段在 `references/格式.md`。

1. **块对不对。** 规则出的块、段、栏目、例题、题多半对;叫法不对的改 `label`。
2. **补规则不会的。** 小题、一组口诀、插图里要圈要数的东西,照规范加小块(`children`)、物件(`objects`)。
3. **能写的格。** 规则已经把候选的格挂好了;挂错块的挪过去,id 不改。候选里漏的格,量了加上。
4. **念法。** 孩子会单独点的块写 `say`。
5. **给老师的话。** `teacher` 写练什么、卡住怎么引、答案。

几条要点:

- 块的 `id` 一页里不重;一段、一道题跨两页,两页上各写一块,用同一个 id。
- 字行 `rows` 照候选 `L…` 的框抄。表格、插图这种块写 `"rows": []`。
- 小块要在大块的框里。框不够大就把大块撑大。
- 候选里的格不是孩子要写的(装饰的框、图里的格),把它的编号写进这一页的 `ignore`。

## 四、检查、看图

1. `cotutor textbook check <目录>`:列出全部要改的。改到「都对得上」。
2. `cotutor textbook preview <目录>`:每页出 `p078.preview.png`。块一层一色(外到里 红、紫、粉、棕),作答区橙,没人认领的候选红粗框。
3. 一页一页看预览:块框住整道题、小块在大块里、格子框住格子、红框都处理了。
4. 再读一遍答案:每道题算一遍,题面和答案对得上。

## 五、存回去

```
cotutor textbook push <目录>
```

- check 干净才写。写进 vault 的 `教材/.zones/<指纹>/`,一课的页一起写。
- 存的时候作答区的框吸到候选上,字行吸到文字层的行上。
- 孩子端下一轮起就照这一份。

## 改一课

家长说「第 3 题叫错了」「这格没认出来」:先 `pull` 那一课(草稿就是上次 push 的那份),改、check、push。

## 报告怎么写

1. 改了哪几课、几页、用了多久。
2. 每课改了什么:补了哪些块和格、改了哪些叫法、写了几道题的答案。
3. check 的结果;没把握的答案(写成 note 的)列出来,请家长看一眼。
