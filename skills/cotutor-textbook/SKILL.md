# 给一本课本出分块

你在一个 cotutor workspace 的根目录(有 cotutor.json)。

孩子在 iPad 上看课本 PDF。应用不认图:一页上哪是一段、哪是一道题、哪格能写,全靠分块,一页一份 JSON。
你把一整本课本从头分好,一课一课存进 vault。以后家长在工作台上调。

从孩子的角度分:**一块就是孩子会单独点着说「念给我听」,或者老师会说「看这里」的东西。** 分到这里就停,不要更细。

## 铁律

- **框不估。** 字行写行号(`L4`,一行里隔开的一截 `L4.2`),应用换成框;块的 `box` 不写,应用照字行、小块、作答区撑出来。
  文字层里没有的(插图、横线、圈画区),写脚本量页图,量好写 `box`;作答区再加 `"src": "measured"`。
- **能写的格照抄候选。** id、框、`cell`、`ch`、`m` 都照页面数据里「能写的格」那张表抄。
- **页名、种类不改。** 照 book.md 写;觉得不对写进报告。
- **id 照页名起头。** 块 `4-1`、`4-2`,小块 `4-2.1`;一整本不重。
- **叫法照书上印的号。** 书上没号的从上往下数(「课后第 2 题」「第 3 段」)。一课里不重名:泡泡、注释这种一课里有好几个的,照规范接上开头几个字。
- **念法照印的念。** 不加书上没印的话。空着的地方念「几」或「什么」。
- **不写答案,不写给老师的话**(`teacher` 不写)。
- 不直接写 vault,只改 prep 出来的目录,用 `cotutor textbook push` 存。
- 课本 PDF、`agents/`、`cotutor.json` 都不改。
- 要装东西(poppler、Python 包)先停下,说要装什么。

## 一、摊开

```
cotutor textbook prep 数学
```

放在 `.cotutor/zones-work/<册名>/`:

| 文件 | 是什么 | 你做什么 |
|---|---|---|
| `book.md` | 页名和 PDF 页的对照、警告、目录上的课、样式表 | 先读 |
| `styles.json` | 每种样式(字体 × 字号)在这本书里是什么 | 填 |
| `004.md` | 印的第 4 页的页面数据:一行一条(行号、离页顶、缩进、样式、离上一行的空、字),能写的格 | 读 |
| `004.data.json` | 同一份,给脚本读 | 量图时用 |
| `004.png` | 页图(200dpi,框是千分比,和它一套) | 看 |
| `004.json` | 这一页的分块,空着 | 写 |
| `progress.json` | 哪几课存过了 | 别动 |

- 页图没出来:要 poppler 的 `pdftoppm` 或 Python 的 PyMuPDF,停下说要装哪个。
- 断了接着做:再跑一遍 prep(写过的不动),照 book.md 里「课」那张表,没打勾的接着做。

## 二、先过一遍整本

1. 读 `book.md`:多少页、哪些是封面目录、有没有警告、有几课。
2. 挑几页不同的(一课的头一页、课后题、园地或练一练)看页图和页面数据,对着样式表认:哪种样式是正文、哪种是题的指令、哪种是泡泡、注释。
3. 写进 `styles.json`:`{"楷 18": "课文正文", "宋 16": "习题的指令", ...}`。后面每页照它认。

## 三、一课一课分

照 `book.md` 里「课」的先后,一课一组。一课里每一页:

1. 看页图,读页面数据,读这一科的规范(`references/语文.md`、`数学.md`、`科学.md`)。
2. **找块。** 「空」那一列大(一行半以上)多半换了内容;样式变了多半换了种类;两条都没有的多半还是同一块。
3. **接上一页。** 页面数据开头写着上一页最后一行。这一页第一块接着它(没收句、同一段、同一道题、同一个栏目),写 `"cont": "<上一页那块的 id>"`,叫法和种类跟它一样。
4. **字行。** 每块的 `rows` 写它的行号,照读的先后。有字的行都要归到一块里:不归哪块读的(插图里的字、表里的字),落在插图、表格那块的框里也算。
5. **能写的格。** 挂到它所在的那块的 `regions`。候选里不是孩子写的(装饰框、图里的格),把 id 写进这一页的 `ignore`。
6. **念法。** 孩子会单独点的块写 `say`。

写完一课,**check 过了马上 push 这一课,再做下一课**(订阅的额度会突然用完,没 push 的要下次接着做):

```
cotutor textbook check <目录> --lesson <课名>
cotutor textbook preview <目录> --lesson <课名>
cotutor textbook push <目录> --lesson <课名>
```

- `check` 列全要改的,改到「都对得上」。
- `preview` 每页出 `004.preview.png`:块一层一色(外到里 红、紫、粉、棕),作答区橙,没人认领的候选红粗框。一页一页看:块框住整块,小块在大块里,红框都处理了。
- `push` 只写 check 干净的课。写完孩子下一轮就照它。
- 不要等几课都写完再一起 push。

封面、目录、版权这些页不分块,`zones` 空着就行。最后不带 `--lesson` 跑一次 `push`,把它们和剩下写齐的课一起存。

## 多久

一页半分钟左右:2026-11-26 Codex 分人教统编语文二上第一单元,15 页 8 分钟;数学《1.乘法的初步认识》把图里的乘客、樱桃、圆点一个一个量成物件(5 页 265 个),一页两分多钟。一本一百多页的课本一个多小时。
订阅的额度可能中途用完(同一天同时跑两本,8 分钟就用完了):一次只跑一本;断了再跑一遍 prep(写过的不动),照 book.md 里没打勾的课接着做。

## 报告

照手上的结果写,不用为写报告再查一遍(check 和预览前面已经过了)。

1. 分了哪几课、几页、用了多久;没分完的列出来。
2. 样式表(`styles.json`)。
3. book.md 里的警告;觉得页名、种类不对的页。
4. 拿不准的地方:哪一页、哪一块、为什么,请家长在工作台看一眼。
