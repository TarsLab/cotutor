# 命令(机器生成,别改)

在 workspace 根跑;每条就是 cotutor <命令> --help 的内容。

```
这些命令都认 --workspace <目录>(在 workspace 根跑可以不写)和 --sandbox(在试用副本里跑,不进孩子的记录)。

cotutor textbook — 课本的分块:摊开给编程助手整册出、检查、预览、存回 vault

用法:
  cotutor textbook list [<册>] [--json]
  cotutor textbook prep <册> [--lesson <课名>] [--out <目录>] [--json]
  cotutor textbook check <目录> [--lesson <课名>] [--json]
  cotutor textbook preview <目录> [--lesson <课名>] [--json]
  cotutor textbook push <目录> [--lesson <课名>] [--json]

选项:
  --lesson <课名>  [prep、check、preview、push] 照目录中这一项的 PDF 页段选页
  --out <目录>     [prep] 摊开到哪(缺省 .cotutor/zones-work/<册名>/)
  --json           机器可读的输出

说明:
  - <册> 是 vault 教材/ 里课本 PDF 的文件名或其中一段(如 数学);分块的协议在技能 cotutor-textbook 的 references/格式.md
  - list 列每一课在 PDF 的哪几页、现在用规则出的还是 vault 里改好的
  - prep 出 book.md(页名、目录、样式表),每页出 004.md(页面数据:行号、离页顶、样式、离上一行的空、字;能写的格)、004.png、空着的 004.json
  - 页图 200dpi,要 poppler 的 pdftoppm 或 python3 的 PyMuPDF;prep 重跑只补缺的,不动写过的
  - check 不花钱,一次列全要改的,都对了退出码 0;preview 出 004.preview.png(块一层一色,作答区橙,没人认领的候选红)
  - push 一课一课写:页都写了、check 干净的才写进 vault 的 教材/.zones/<指纹>/,行号换成框、框吸到候选上;孩子端下一轮起照它

注意:
  - push 写 vault 的 教材/.zones/

例子:
  cotutor textbook list 数学
  cotutor textbook prep 数学
  cotutor textbook check .cotutor/zones-work/数学二年级上册-人教版 --lesson 分类与整理
  cotutor textbook push .cotutor/zones-work/数学二年级上册-人教版 --lesson 分类与整理
```
