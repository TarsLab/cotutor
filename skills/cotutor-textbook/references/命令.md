# 命令(机器生成,别改)

在 workspace 根跑;每条就是 cotutor <命令> --help 的内容。

```
这些命令都认 --workspace <目录>(在 workspace 根跑可以不写)和 --sandbox(在试用副本里跑,不进孩子的记录)。

cotutor textbook — 课本的分块:取出来给编程助手改、检查、预览、存回 vault

用法:
  cotutor textbook list [<册>] [--json]
  cotutor textbook pull <册> (--pages <PDF 页> | --lesson <课名>) [--out <目录>] [--json]
  cotutor textbook check <目录> [--json]
  cotutor textbook preview <目录> [--json]
  cotutor textbook push <目录> [--json]

选项:
  --pages <PDF 页>  [pull] PDF 的第几页(不是印的页码),如 78 或 76-83;落在哪几课就把那几课的页都取全
  --lesson <课名>   [pull] 取这一课(写单元就是整个单元)
  --out <目录>      [pull] 放哪(缺省 .cotutor/zones-work/<册名>-p<头>-<尾>/)
  --json            机器可读的输出

说明:
  - <册> 是 vault 教材/ 里课本 PDF 的文件名或其中一段(如 数学);分块的形状在技能 cotutor-textbook 的 references/格式.md
  - list 列每一课在 PDF 的哪几页、现在用规则出的还是 vault 里改好的
  - pull 每页出:p078.json(现在用的分块,当草稿改)、p078.candidates.json(文字层的行 L0…、能写的格 0…、表格 T0…)、p078.png(200dpi 页图,要 poppler 的 pdftoppm 或 python3 的 PyMuPDF)
  - check 不花钱,一次列全要改的,都对了退出码 0;preview 出 p078.preview.png(块一层一色,作答区橙,没人认领的候选红)
  - push 先过 check,把框吸到候选上,一课的页一起写进 vault 的 教材/.zones/<指纹>/;孩子端下一轮起照它

注意:
  - push 写 vault 的 教材/.zones/

例子:
  cotutor textbook list 数学
  cotutor textbook pull 数学 --pages 78-79
  cotutor textbook check .cotutor/zones-work/数学二年级上册-人教版-p78-85
  cotutor textbook push .cotutor/zones-work/数学二年级上册-人教版-p78-85
```
