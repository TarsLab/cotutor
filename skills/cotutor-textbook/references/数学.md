# 数学课本怎么分

照人教版数学二年级上册定的;别的版本照着套。

## 一页上有哪些块

| 块 | `kind` | 叫法(`label`) |
|---|---|---|
| 单元页的大字、小节、课题 | `title` | 印的字:「6的乘法口诀」 |
| 例题 | `example` | 「例 1」「例 2」 |
| 做一做、练一练、整理和复习、你知道吗 | `column` | 栏目名;一课里有好几个「做一做」,叫「例 1 的做一做」「例 2 的做一做」 |
| 栏目下面的一道题 | `problem`(栏目的小块) | 「练一练第 3 题」「例 1 的做一做第 2 题」 |
| 一道题里的(1)(2) | `sub` | 「练一练第 3 题第(1)小题」 |
| 一排算式、一组口诀 | `group` | 「7 的乘法口诀」「第 2 题的算式」 |
| 一句口诀、一个算式 | `sub`(一组的小块) | 印的字:「二七」「7×3」;别的题里也有「7×3」不要紧,同一组里不重名就行 |
| 表格 | `table` | 「例 1 的表格」「第 5 题的表格」 |
| 插图 | `figure` | 只在要圈、要数时加 |

- 一组一块,一句一个小块:老师会说「看 7 的乘法口诀」,也会说「二七是多少」。
- 插图里要圈要数的东西写成 `objects`,插图本身不用单独一块。
- 不写「右边第 3 个算式」这种只有标的人懂的叫法。

## 孩子做什么

| 孩子做的 | 作答区 |
|---|---|
| 括号里填数、算式方框里填数、表格空格 | `write`(候选里的 `blank`、`table`) |
| 圈一圈 | `circle` + 要圈的东西写进 `objects` |
| 连一连 | `link` + 两头的 `objects` 带 `side` |
| 画一画 | `draw` |
| 对的打勾 | `tick`;候选里的小方框规则当成了 `blank`,确实是打勾的改成 `tick`,id 不变 |

## 念法

- 照印的念:「例 1。前面学习了……」。
- 空着的括号、方框念「几」:「二七,几」「7 乘 3 等于几」。
- 运算符照读:× 念「乘」,÷ 念「除以」,= 念「等于」。

## 给老师

- `goal` 写这道题练什么:「用 7 的乘法口诀算」「几个几是多少」。
- `hint` 写卡住了怎么引:「先数一份有几个」。
- 每个空一条答案;几种写法都算对的都列(「十四」「14」)。
