# 数学课本怎么分

照人教版数学二年级上册定的;别的版本照着套。

## 一页上有哪些块

| 块 | `kind` | 叫法(`label`) |
|---|---|---|
| 单元名、小节、课题 | `title` | 印的字:「6的乘法口诀」 |
| 例题 | `example` | 「例 1」「例 2」;`rows` 放题干 |
| 例题、题里的一问 | `sub` | 「第 1 问」,从上往下数;印了(1)(2)的照印的「第(1)小题」 |
| 做一做、练一练、整理和复习、你知道吗 | `column` | 栏目名;一课里有好几个「做一做」,叫「例 1 的做一做」「例 2 的做一做」 |
| 栏目下面的一道题 | `problem`(栏目的小块) | 「练一练第 3 题」「例 1 的做一做第 2 题」 |
| 一排算式、一组口诀 | `group` | 「7 的乘法口诀」「第 2 题的算式」 |
| 一句口诀、一个算式 | `sub`(一组的小块) | 印的字:「二七」「7×3」;同一组里不重名就行 |
| 人物说的话 | `bubble` | 「泡泡:」接开头几个字:「泡泡:我按形状分」;挂在它说的那一问下面,说在两问中间的挂前一问 |
| 表格 | `table` | 「例 1 的表格」「第 5 题的表格」 |
| 插图 | `figure` | 要看图答的题加:「气球」「分好的气球」 |

- 一题里有几问的,一问一块:孩子会一问一问地点,老师会说「看第 2 问」。
- 一组一块,一句一个小块:老师会说「看 7 的乘法口诀」,也会说「二七是多少」。
- 图里的数、字(「3 个」)不单独成块,落在那张图的框里。
- 插图只在题要看图、要圈要数时加,一道题一张;填空旁边、题号旁边的小图标(一片叶子、一个气球)不单独成块,算在那一问里。
- 插图里要圈要数的东西写成 `objects`。
- 不写「右边第 3 个算式」这种只有标的人懂的叫法。

## 孩子做什么

| 孩子做的 | 作答区 |
|---|---|
| 括号里填数、算式方框里填数、表格空格 | `write`(候选里的 `blank`、`table`) |
| 圈一圈 | `circle` + 要圈的东西写进 `objects` |
| 连一连 | `link` + 两头的 `objects` 带 `side` |
| 画一画 | `draw` |
| 对的打勾 | `tick`;候选里的小方框当成了 `blank`,确实是打勾的改成 `tick`,id 不变 |

## 念法

- 照印的念:「例 1。把下面的气球分类。」
- 空着的括号、方框念「几」:「二七,几」「7 乘 3 等于几」。
- 运算符照读:× 念「乘」,÷ 念「除以」,= 念「等于」。
