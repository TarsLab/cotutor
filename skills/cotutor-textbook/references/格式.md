# 分块文件的格式

协议版本 3。一页一份,文件名照页名:印的第 4 页是 `004.json`,封面是 `封面.json`。prep 已经写好了空的,你填 `zones`。
JSON Schema 在 `分块.schema.json`(同一份形状,能拿来校验)。

## 坐标

- 框都是这一页的千分比 `[左, 上, 右, 下]`:横的按页宽、竖的按页高,都是 0–1000。
- 页面数据里能写的格、表格,`004.data.json` 里每一行的 `box`,和页图 `004.png` 是同一套坐标。
- 字行不写框,写行号(下面)。

## 一页

| 字段 | 是什么 |
|---|---|
| `v` | 协议版本,写 `3` |
| `page` | PDF 的第几页(prep 写好了,不改) |
| `name` | 页名:印的页码,或「封面」「目录-1」这种(prep 写好了,不改) |
| `kind` | 页的种类:封面、扉页、版权、目录、单元页、正文、附录、后记、封底、空白(prep 写好了,不改) |
| `zones` | 这一页的块(一棵树) |
| `regions` | 不在哪一块里的作答区(块外面的格),少用 |
| `ignore` | 候选里不是孩子要写的格,列 id;check 不再说漏了 |

## 一块

| 字段 | 是什么 |
|---|---|
| `id` | 块 `<页名>-<第几>`(这一页最外一层从上往下数:`4-1`、`4-2`),小块 `<外面那块>.<第几>`(`4-2.1`)。一整本不重 |
| `kind` | 是什么(下面) |
| `label` | 老师和孩子怎么叫它:「课后第 2 题」「例 2」「练一练第 3 题」「第 3 段」。一课里不重名;小题(`sub`)只在同一块里不重名,老师写「练一练第 1 题的 7×2」找得到 |
| `rows` | 这一块的字行,照读的先后:行号 `"L4"`;一行里隔开的几截,写其中一截 `"L4.2"`。插图、表格写 `[]` 或不写 |
| `box` | 框住整块。有字行、小块、作答区的不写,应用撑出来;插图这种量好了写 |
| `cont` | 接着上一页的哪一块(那一块的 id)。这一截和它是同一块,叫法、种类跟它一样 |
| `style` | 这一块的样式,push 时应用算,不写 |
| `say` | 孩子点它念什么,照印的念 |
| `regions` | 块里孩子作答的地方(下面) |
| `objects` | 块里能指的东西:要圈的星星、要连的词(下面) |
| `teacher` | 只给老师的话,家长在工作台写;初始化不写 |
| `children` | 套在里面的小块 |

`kind`:

| `kind` | 是什么 |
|---|---|
| `title` | 课题、单元名、小节名、诗题 |
| `para` | 自然段;诗的一节,一行一句的诗一句一块 |
| `problem` | 一道题。`rows` 只放题的指令(「读一读,记一记。」),下面的内容是它的小块 |
| `sub` | 一道题里的一问、(1)(2)、一句口诀、一个算式 |
| `group` | 一组:一行词、一排算式、一组口诀、一首诗、认字栏、写字栏 |
| `column` | 栏目:做一做、练一练、识字加油站、日积月累、探索与实践 1 |
| `example` | 例题 |
| `table` | 表格 |
| `figure` | 插图 |
| `bubble` | 泡泡:学习伙伴的话、图里人物说的话。点了念 |
| `note` | 注释:页下注、题注(「① 本文选自……」)。点了不念 |
| `other` | 实在归不进上面的。少用 |

- 栏目下面的题、段写成它的 `children`。读回来的时候,题记着它在哪个栏目下。
- 整课朗读(孩子点段首的钮)念这一课的第一个 `title` 和所有 `para`,照先后一次合成;所以只有要朗读的正文、诗写 `para`,别的字不写 `para`。`title`、`para` 不写 `say`。
- 题号、段号、例几,应用从 `label` 里读:「第 3 段」「例 2」「练一练第 3 题」照这个样子写。
- 小块的框要在大块的框里。

## 作答区 `regions`

| 字段 | 是什么 |
|---|---|
| `id` | 候选里的格照抄候选的 id(`"4-格12"`);自己量的照页名起头起个名字(`"4-量1"`) |
| `kind` | `write` 写、`tick` 打勾、`circle` 圈、`draw` 画、`link` 连线、`underline` 画线、`trace` 描写 |
| `label` | 给老师看的名字:「例 2 的表格第 2 行第 3 格」「二六的括号」 |
| `box` | 候选的格抄候选的框;自己量的写量出来的 |
| `src` | 自己写脚本量的框写 `"measured"`;候选里的不写 |
| `cell` | 候选的格是哪种(照抄):`model` 范字、`trace` 描红、`empty` 空格、`blank` 填空、`table` 表格的空格 |
| `ch` | 格里印的字(范字、描红) |
| `m` | 这一格照着写的那个字 |
| `tian` | 田字格写 `true` |
| `fourLine` | 四线三格的四条线,从上往下的 y(课本少用) |
| `model` | 描写的字母与笔顺(`glyph`、`strokes`;课本少用,练习册用) |
| `say` | 写起来太长的,写 `true`:老师可以请他说着答 |

## 物件 `objects`

只在有 `circle`、`link` 作答区的块里写:孩子圈了、连了,应用照物件认出是哪几个。光是给孩子看的图不写。

| 字段 | 是什么 |
|---|---|
| `id` | 一页里不重 |
| `label` | 是什么:「星星」「蒲公英」 |
| `box` | 框住它 |
| `center` | 画出来的中心 `[x, y]`,在框里 |
| `region` | 在哪个作答区里被圈、被连;只是图就不写 |
| `side` | 连线的哪一头:`left`、`right`。连线题两列各写成物件,左列 `left`、右列 `right`,`region` 都写那个 `link` 作答区;作答区的框框住两列 |
| `group` | 画面上本来就分好的组:第几盘、第几排 |

## 给老师 `teacher`(工作台写,初始化不写)

| 字段 | 是什么 |
|---|---|
| `goal` | 这一块练什么 |
| `hint` | 孩子卡住了怎么引 |
| `answers` | 答案,一条一个空:`at` 这条答案占的作答区 id,`ok` 都算对的写法,`links` 连线的答案(`[左端物件, 右端物件]`),`note` 没有唯一答案时怎么看 |
| `note` | 没有固定答案、没把握的,写怎么看 |

## 一页的例子

下面是编的一页(不是哪本书上的):印的第 40 页,数学。上一页的「练一练」接到这一页。

```json
{
  "v": 3,
  "page": 45,
  "name": "40",
  "kind": "正文",
  "zones": [
    { "id": "40-1", "kind": "column", "label": "练一练", "cont": "39-4", "rows": [],
      "children": [
        { "id": "40-1.1", "kind": "problem", "label": "练一练第 5 题", "cont": "39-4.3", "rows": ["L0"] }
      ] },
    { "id": "40-2", "kind": "title", "label": "6的乘法口诀", "rows": ["L1"] },
    {
      "id": "40-3", "kind": "example", "label": "例 2", "rows": ["L2"],
      "say": "例 2。每盒彩笔有 6 支,3 盒一共有几支?",
      "children": [
        { "id": "40-3.1", "kind": "bubble", "label": "泡泡:1 盒有 6 支", "rows": ["L3"], "say": "1 盒有 6 支。" },
        {
          "id": "40-3.2", "kind": "table", "label": "例 2 的表格", "box": [150, 140, 700, 220], "rows": [],
          "say": "盒数,1、2、3。支数,6、几、几。",
          "regions": [
            { "id": "40-格12", "kind": "write", "label": "例 2 的表格第 2 行第 3 格", "box": [380, 180, 500, 215], "cell": "table" },
            { "id": "40-格13", "kind": "write", "label": "例 2 的表格第 2 行第 4 格", "box": [500, 180, 620, 215], "cell": "table" }
          ]
        },
        {
          "id": "40-3.3", "kind": "group", "label": "例 2 的口诀",
          "children": [
            { "id": "40-3.3.1", "kind": "sub", "label": "一六", "rows": ["L4.1"], "say": "一六得六。" },
            {
              "id": "40-3.3.2", "kind": "sub", "label": "二六", "rows": ["L4.2"], "say": "二六,几?",
              "regions": [{ "id": "40-格14", "kind": "write", "label": "二六的括号", "box": [800, 182, 880, 208], "cell": "blank" }]
            }
          ]
        }
      ]
    },
    {
      "id": "40-4", "kind": "column", "label": "做一做", "rows": ["L5"],
      "children": [
        {
          "id": "40-4.1", "kind": "problem", "label": "做一做第 1 题", "rows": ["L6"],
          "say": "6 个圈一圈。",
          "children": [
            {
              "id": "40-4.1.1", "kind": "figure", "label": "星星", "box": [120, 680, 880, 920],
              "regions": [{ "id": "40-量1", "kind": "circle", "label": "每 6 个圈一圈", "box": [120, 680, 880, 920], "src": "measured" }],
              "objects": [
                { "id": "星1", "label": "星星", "box": [140, 700, 180, 740], "center": [160, 720], "region": "40-量1", "group": 1 },
                { "id": "星2", "label": "星星", "box": [200, 700, 240, 740], "center": [220, 720], "region": "40-量1", "group": 1 }
              ]
            }
          ]
        },
        {
          "id": "40-4.2", "kind": "problem", "label": "做一做第 2 题", "rows": ["L7"],
          "regions": [{ "id": "40-格20", "kind": "tick", "label": "「是」前面的方框", "box": [420, 942, 436, 958] }]
        }
      ]
    },
    { "id": "40-5", "kind": "note", "label": "注①:简牍是", "rows": ["L8"] }
  ],
  "ignore": ["40-格22"]
}
```

- `40-1` 和它的第 5 题接着上一页:写 `cont`,叫法跟上一页一样。这一页上只有第 5 题的最后一行,栏目自己没有字,`rows` 空着。
- 「一六得六  二六十二」印在一行里、中间空开,页面数据里是 `L4.1`、`L4.2` 两截,一句一个小块。
- 插图里的星星没有文字层,框是量的。
