# 分块文件的格式

一页一份 `p<PDF 页,补成三位>.json`。

## 坐标

- 框都是这一页的千分比 `[左, 上, 右, 下]`:横的按页宽、竖的按页高,都是 0–1000。
- 同样大的方格,竖向的千分数比横向的小(页是竖的)。
- 候选 `p078.candidates.json` 和页图 `p078.png` 用的是同一套坐标。

## 一页

| 字段 | 是什么 |
|---|---|
| `page` | PDF 的第几页(不是印的页码) |
| `zones` | 这一页的块(一棵树) |
| `regions` | 不在哪一块里的作答区(块外面的格),少用 |
| `ignore` | 候选里不是孩子要写的格,列编号;check 不再说漏了 |

## 一块

| 字段 | 是什么 |
|---|---|
| `id` | 一页里不重;字母、数字、汉字、连字符。一段、一道题跨两页,两页上用同一个 id |
| `kind` | `title` 课题、`column` 栏目、`example` 例题、`problem` 题、`sub` 小题、`group` 一组、`para` 自然段、`table` 表格、`figure` 插图、`other` 别的字 |
| `label` | 老师和孩子怎么叫它:「例 2」「练一练第 3 题」「第 3 段」。一课里不重名 |
| `box` | 框住整块:字、图、要写的格都在里面 |
| `rows` | 这一块的字行,照读的先后,每行抄候选 `L…` 的框。表格、插图写 `[]` |
| `say` | 孩子点它念什么,照印的念 |
| `regions` | 块里孩子作答的地方(下面) |
| `objects` | 块里能指的东西:要圈的星星、要连的词(下面) |
| `teacher` | 只给老师的话(下面) |
| `children` | 套在里面的小块 |

- `column` 下面的题、段写成它的 `children`。读回来的时候,题记着它在哪个栏目下。
- 题号、段号、例几,应用从 `label` 里读:「第 3 段」「例 2」「练一练第 3 题」照这个样子写。
- 小块的框要在大块的框里。

## 作答区 `regions`

| 字段 | 是什么 |
|---|---|
| `id` | 候选里的格写候选的编号(`"12"`);自己量的起个名字 |
| `kind` | `write` 写、`tick` 打勾、`circle` 圈、`draw` 画、`link` 连线、`underline` 画线、`trace` 描写 |
| `label` | 给老师看的名字:「例 2 的表格第 2 行第 3 格」「二六的括号」 |
| `box` | 候选的格抄候选的框;自己量的写量出来的 |
| `src` | 自己写脚本量的框写 `"measured"`;候选里的不写 |
| `cell` | 候选的格是哪种(规则写的,照抄):`model` 范字、`trace` 描红、`empty` 空格、`blank` 填空、`table` 表格的空格 |
| `ch` | 格里印的字(范字、描红) |
| `m` | 这一格照着写的那个字 |
| `tian` | 田字格写 `true` |
| `fourLine` | 四线三格的四条线,从上往下的 y(课本少用) |
| `model` | 描写的字母与笔顺(`glyph`、`strokes`;课本少用,练习册用) |
| `say` | 写起来太长的,写 `true`:老师可以请他说着答 |

## 物件 `objects`

| 字段 | 是什么 |
|---|---|
| `id` | 一页里不重 |
| `label` | 是什么:「星星」「蒲公英」 |
| `box` | 框住它 |
| `center` | 画出来的中心 `[x, y]`,在框里 |
| `region` | 在哪个作答区里被圈、被连;只是图就不写 |
| `side` | 连线的哪一头:`left`、`right` |
| `group` | 画面上本来就分好的组:第几盘、第几排 |

## 给老师 `teacher`

| 字段 | 是什么 |
|---|---|
| `goal` | 这一块练什么 |
| `hint` | 孩子卡住了怎么引 |
| `answers` | 答案,一条一个空(下面) |
| `note` | 没有固定答案、没把握的,写怎么看 |

一条答案:

| 字段 | 是什么 |
|---|---|
| `at` | 这条答案占的作答区 id,按书写的顺序 |
| `ok` | 都算对的写法(「十二」「12」) |
| `links` | 连线的答案:`[左端物件, 右端物件]` |
| `note` | 没有唯一答案时怎么看 |

`ok`、`links`、`note` 至少写一个。

## 一页的例子

下面是编的一页(不是哪本书上的),每种常见的写法都有一处。

```json
{
  "page": 40,
  "zones": [
    { "id": "40-1", "kind": "title", "label": "6的乘法口诀", "box": [380, 60, 620, 80], "rows": [[380, 60, 620, 80]] },
    {
      "id": "例2", "kind": "example", "label": "例 2", "box": [80, 100, 920, 560],
      "rows": [[120, 105, 880, 125]],
      "say": "例 2。每盒彩笔有 6 支,3 盒一共有几支?",
      "teacher": { "goal": "几盒就是几个 6", "hint": "先数 1 盒有几支,再一盒一盒加上去" },
      "children": [
        {
          "id": "例2-表", "kind": "table", "label": "例 2 的表格", "box": [150, 140, 700, 220], "rows": [],
          "say": "盒数,1、2、3。支数,6、几、几。",
          "regions": [
            { "id": "12", "kind": "write", "label": "例 2 的表格第 2 行第 3 格", "box": [380, 180, 500, 215], "cell": "table" },
            { "id": "13", "kind": "write", "label": "例 2 的表格第 2 行第 4 格", "box": [500, 180, 620, 215], "cell": "table" }
          ],
          "teacher": { "goal": "2 盒、3 盒各几支", "answers": [{ "at": ["12"], "ok": ["12"] }, { "at": ["13"], "ok": ["18"] }] }
        },
        {
          "id": "例2-口诀", "kind": "group", "label": "例 2 的口诀", "box": [720, 140, 900, 420], "rows": [],
          "children": [
            {
              "id": "例2-口诀-2", "kind": "sub", "label": "二六", "box": [730, 180, 890, 210],
              "rows": [[730, 182, 790, 206]],
              "say": "二六,几?",
              "regions": [{ "id": "14", "kind": "write", "label": "二六的括号", "box": [800, 182, 880, 208], "cell": "blank" }],
              "teacher": { "goal": "二六十二", "answers": [{ "at": ["14"], "ok": ["十二", "12"] }] }
            }
          ]
        }
      ]
    },
    {
      "id": "练一练", "kind": "column", "label": "练一练", "box": [80, 600, 920, 980], "rows": [[90, 605, 170, 625]],
      "children": [
        {
          "id": "练一练-3", "kind": "problem", "label": "练一练第 3 题", "box": [100, 640, 900, 930],
          "rows": [[110, 645, 600, 665]],
          "say": "第 3 题。6 个圈一圈。",
          "regions": [{ "id": "圈", "kind": "circle", "label": "每 6 个圈一圈", "box": [120, 680, 880, 920], "src": "measured" }],
          "objects": [
            { "id": "星1", "label": "星星", "box": [140, 700, 180, 740], "center": [160, 720], "region": "圈", "group": 1 },
            { "id": "星2", "label": "星星", "box": [200, 700, 240, 740], "center": [220, 720], "region": "圈", "group": 1 }
          ],
          "teacher": { "goal": "6 个一份地数", "answers": [{ "at": ["圈"], "note": "6 个一圈就对,从哪儿圈起都行" }] }
        },
        {
          "id": "练一练-4", "kind": "problem", "label": "练一练第 4 题", "box": [100, 935, 900, 975],
          "rows": [[110, 940, 400, 960]],
          "regions": [{ "id": "20", "kind": "tick", "label": "「是」前面的方框", "box": [420, 942, 436, 958] }],
          "teacher": { "goal": "6 个 6 是不是 36", "answers": [{ "at": ["20"], "ok": ["√"] }] }
        }
      ]
    }
  ],
  "ignore": ["22"]
}
```
