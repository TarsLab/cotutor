# 科学课本怎么分

照广东版科学二年级上册定的;教科版的聚焦、探索、研讨、拓展照着套。

## 一页上有哪些块

| 块 | `kind` | 叫法(`label`) |
|---|---|---|
| 课题 | `title` | 课名 |
| 栏目 | `column` | 印的名字带序号:「探索与实践 1」「讨论与发现」「思考与练习」 |
| 栏目里的一段 | `para`(栏目的小块) | 「第 3 段」,整课连着数 |
| 记录表 | `table`(栏目的小块) | 「探索与实践 1 的记录表」 |
| 安全提示 | `other` | 「安全提示」 |
| 思考与练习的一道题 | `problem` | 「思考与练习第 2 题」 |
| 插图 | `figure` | 只在要看图回答时加 |

## 孩子做什么

| 孩子做的 | 作答区 |
|---|---|
| 记录表打勾、思考与练习的小方框 | `tick`(候选里的 `tick`) |
| 记录表填字 | `write`(候选里的 `table`) |
| 说一说 | 不加作答区;块写 `say`,老师请他说 |

## 念法

- 段照印的念。
- 记录表念表头和每一行的名字,空着的格念「打勾」或「填什么」:「能不能看见空气,能,还是不能」。

## 给老师

- 观察、实验的结果写进 `answers` 或 `note`:「瘪的袋子扎破后没有东西出来」。
- 孩子家里做不了的实验,`hint` 写怎么用图讲。
