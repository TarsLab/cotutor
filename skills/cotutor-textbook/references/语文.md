# 语文课本怎么分

照人教统编语文二年级上册定的。

## 一页上有哪些块

| 块 | `kind` | 叫法(`label`) |
|---|---|---|
| 课题 | `title` | 课名 |
| 课文的自然段 | `para` | 「第 3 段」 |
| 诗的一节 | `para` | 「第 2 节」;一行一段的诗,一句一块 |
| 认字栏、写字栏 | `other` | 「认字」「写字」 |
| 写字栏里的一个字 | `sub` | 「写字:处」 |
| 课后题 | `problem` | 「课后第 2 题」:书上没号,从上往下数 |
| 语文园地的栏目 | `column` | 印的名字:「识字加油站」「日积月累」 |
| 插图 | `figure` | 只在课后题要看图时加 |

- 自然段的号整课连着数,跨页的段两页上用同一个 id。
- 课后题、认字栏、日积月累都分成块:孩子点了能听。

## 孩子做什么

| 孩子做的 | 作答区 |
|---|---|
| 田字格写字、描红 | `write` + `tian`(候选里的 `empty`、`trace`) |
| 括号填词、句末填标点 | `write`(候选里的 `blank`) |
| 朗读、照样子说 | 不加作答区;块写 `say`,老师请他说 |
| 连线 | `link` + 两头的 `objects` 带 `side` |

- 范字格(候选里的 `model`)规则已经挂好,不用动。

## 念法

- 课文的段不用写 `say`:应用整课一次合成朗读。
- 认字栏一个字一个字念,字和字之间顿一下:「观、沿、渴」。
- 课后题照印的念,不念「◇」这类记号,不念页下的注。
- 括号里空着的念「什么」:「一(什么)鱼塘」。

## 给老师

- 课后题的 `goal` 写练什么:「读好问句的语气」。
- 没有标准答案的(说一说、想一想)写 `note`:「说出青蛙和小鸟看到的天不一样就行」。
