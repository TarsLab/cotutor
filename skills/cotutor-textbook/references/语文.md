# 语文课本怎么分

照人教统编语文二年级上册定的;别的版本照着套。

## 一页上有哪些块

| 块 | `kind` | 叫法(`label`) | 孩子点了 |
|---|---|---|---|
| 课题(连课号) | `title` | 课名 | 点读那套,不写 `say` |
| 课文的自然段 | `para` | 「第 3 段」,整课连着数 | 点读那套,不写 `say` |
| 诗的一节;一行一句的诗 | `para` | 「第 2 节」;一句一块「第 2 句」 | 点读那套 |
| 认字栏 | `group` | 「认字」 | 一个字一个字念 |
| 写字栏 | `group` | 「写字」 | 不念,格子挂在它上面 |
| 课后题、园地里的题 | `problem` + 内容的小块 | 「课后第 2 题」,书上没号,从上往下数 | 题念指令,内容念内容 |
| 题的内容:一行词、几句话 | `group` | 「第 1 行」「句子」 | 念 |
| 园地的栏目(识字加油站、字词句运用、书写提示、日积月累、我的发现……) | `column` | 印的名字 | 不念,点到里面的块 |
| 栏目里的诗(日积月累的古诗) | `group`:诗题 `title` + 一句一块 `para` | 「《梅花》」「第 2 句」 | 念整首、念一句 |
| 泡泡(学习伙伴的话) | `bubble` | 「泡泡」 | 念 |
| 页下注、题注(「① 本文选自……」) | `note` | 「注①」 | 不念 |
| 插图 | `figure` | 只在题要看图时加:「四张图」 | 不念 |

- 课后题的指令句(「读一读,记一记。」「分角色朗读课文。」)多是命令的口气、和下面内容的样式不一样:指令是题的 `rows`,内容是它的小块。
- 内容拆到哪:一行自己是一组(一行一个字族:脑袋、口袋、袋子、袋鼠)的,一行一块;一行里并排几个短语的,不拆。
- 自然段的号整课连着数;跨页的段,下一页那一截写 `cont`。
- 着重号(页面数据里〈〉括着的字)不用单独标,念法照常念。

## 孩子做什么

| 孩子做的 | 作答区 |
|---|---|
| 田字格写字、描红 | `write` + `tian`(候选里的 `empty`、`trace`) |
| 括号填词、句末填标点 | `write`(候选里的 `blank`) |
| 朗读、照样子说 | 不加作答区;块写 `say` |
| 连线 | `link` + 两头的 `objects` 带 `side` |

- 范字格(候选里的 `model`)也照抄挂上:孩子点了能看笔顺。

## 念法

- 课文的段、课题不写 `say`:应用整课一次合成朗读。
- 认字栏一个字一个字念,字和字之间顿一下:「观、沿、渴」。
- 题照印的念,不念「◇」这类记号,不念注释。
- 一行里隔开的词之间顿一下:「灌溉田地、发动机器」。
- 括号里空着的念「什么」:「一(什么)鱼塘」。
