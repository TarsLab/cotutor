# 能改的字段(机器生成,别改)

## 老师文件 agents/<name>.md

frontmatter 只写这几个键:`name`、`description`。`name` 必须等于文件名,也是 cotutor.json 里 tutors 的键,**不能改**。`description` 是工作台里看到的一句介绍。正文就是系统提示。

旧版文件里的 `maxTurns`、`permissionMode`、`memory` 现在不起作用,可以删。

## cotutor.json 的 tutors.<name>(人设、开关、运行时)

| 字段 | 必需 | 缺省 | 说明 |
|---|---|---|---|
| `display` | 必需 |  | 显示名:孩子端头像下的字,计划文件的 H2 标题 |
| `subject` | 可选 |  | 学科:与课程表的学科列、观察的 subject、vault 入口文件的 subject 属性对齐即归到这位老师 |
| `avatar` | 可选 |  | 头像:一个 emoji,或 workspace 根以内的图片相对路径(如 avatars/math-tutor.png;figshot pick --workspace 会写这个);不写 = 语文、数学、英语用出厂头像,其余显示学科首字 |
| `color` | 可选 |  | 学科色 #rrggbb:头像的环、牌的边、新话题气泡(白字压在上面,要够深,doctor 会查)、听写页的按钮;不写 = 语文粉、数学蓝、英语绿,其余按先后自动分、不撞色 |
| `voice` | 可选 |  | 卡的配音用的音色 id(百炼 Qwen-Audio-TTS,如 qwen-audio-3.0-tts-plus-longcanzhuyue;家长端首页「样子与声音」里挑;点读、单词卡、听写念词的声音)。不写 = 语文、数学、英语老师用出厂的那个,别的老师没有配音。老师开口的嘴在 live.voices |
| `enabled` | 可选 | true | 开关:false 时两端都不见 |
| `hidden` | 可选 | false | 孩子端不露(只和系统、家长打交道的工具人) |
| `cards` | 可选 |  | 这位老师的板书写法里讲哪几种卡(text / read / choice / image / tianzige / word / lecture / canvas / kit / paint / photo / code);不写 = 全部,text 总是带着。只裁递给老师的写法,写了清单外的卡照常显示 |
| `runtime` | 可选 |  | 这位老师用的运行时(runtimes 里的键;不配用 default)——要换模型的老师配自己的 |
| `extras` | 可选 |  | 老师卡上的常驻入口:dictation 听写(含拍照听写)、talk 口语课(要 talk.enabled);不写按学科给缺省:语文有听写,其余没有;[] = 都不要 |
| `tiles.preview` | 可选 |  |  |
| `tiles.check` | 可选 |  |  |
| `tiles.review` | 可选 |  |  |

`policy` 是下面这张表的子集,写了的覆盖 policyDefaults,没写的继承。

## 政策(policyDefaults,或 tutors.<name>.policy 按老师覆盖)

| 字段 | 必需 | 出厂缺省 | 说明 |
|---|---|---|---|
| `replyMaxChars` | 必需 | 60 | 老师说给孩子听的每一句的字数上限(板书讲稿一行一句,按句截);超出在句末截断 |
| `contextPack.recent` | 必需 | 10 | 上下文包带最近几条观察(最近 14 天日记里本学科的「- 观察:」行,取最新的) |
| `contextPack.planLines` | 必需 | 10 | 上下文包带本周计划里这位老师的前几行 |
| `contextPack.entryChars` | 必需 | 4000 | 档案与这位老师的入口文件(vault 里 cotutor: subject 那篇)原文各最多带多少字;超出截断并在上下文包里注明 |
| `effort` | 必需 | low | 老师动笔前想多久:low = 不想、开口快(缺省,孩子等 10–15 秒);medium = 想一点(算题的老师);high = 不限,最慢最细。带工具的那轮至少想一点 |
| `tools` | 必需 | off | 孩子说的话,老师带不带工具:off = 不带,只凭上下文包答,开口快(缺省);on = 带只读工具(查教材、读 vault,慢)。带照片的那条、记账,总是带只读工具(read_file / glob / grep_search) |
| `board` | 必需 | auto | 板书:auto = 讲题讲概念时老师出卡(缺省);off = 只说话不出卡 |
| `stall.ms` | 必需 | 30000 | 老师那头多少毫秒没有动静就停,这轮记没成(缺省 30000;0 = 不看) |

## 相关命令(每条就是 cotutor <命令> --help 的内容)

```
这些命令都认 --workspace <目录>(在 workspace 根跑可以不写)和 --sandbox(在试用副本里跑,不进孩子的记录)。

cotutor add — 加一位自家的老师

用法:
  cotutor add <老师名> --display <显示名> [--subject <学科>] [--avatar <emoji|图片>] [--description <一句话>] [--hidden] [--json]

选项:
  --display <显示名>      孩子看到的名字(必填)
  --subject <学科>        学科
  --avatar <emoji|图片>   emoji,或 workspace 里图片的相对路径
  --description <一句话>  写进老师文件的一句介绍
  --hidden                孩子端不露(只和系统、家长打交道的工具人)
  --json                  机器可读的输出

说明:
  - 名字以 -tutor 结尾的是有脸的老师,其余是工具人
  - 出老师文件、写进 cotutor.json、建它的家;服务不用重启

例子:
  cotutor add science-tutor --display 科学老师 --subject 科学 --avatar 🔬

cotutor add-theme — 加一个自家的主题

用法:
  cotutor add-theme <主题名> [--from <主题>] [--json]

选项:
  --from <主题>  从哪个主题拷(缺省 default)
  --json         机器可读的输出

说明:
  - 拷到 themes/<主题名>/;cotutor.json 的 kid.theme 改成它就换过去

例子:
  cotutor add-theme dark

cotutor refresh — 换新这个孩子的出厂文件(不升级程序)

用法:
  cotutor refresh [--json]
  cotutor refresh --config [--dry-run] [--json]

选项:
  --config   改的是 cotutor.json:只补缺的、删不再用的出厂段,改过的值不动
  --dry-run  和 --config 一起:只看要改什么
  --json     机器可读的输出

说明:
  - 出厂的老师、activity、技能、主题:没改过的换新,改过的保留并报 diff;换之前自动备份一份
  - 升级程序用 cotutor update,它会对每个孩子跑这条;这条只在程序已经换过(手动 npm i -g、从仓库跑)时单独用
  - 改过的想回出厂的:cotutor reset

例子:
  cotutor refresh
  cotutor refresh --config --dry-run

cotutor reset — 把改过的出厂老师或 activity 换回出厂的

用法:
  cotutor reset <老师>|<老师>/<activity>... [--json]

选项:
  --json  机器可读的输出

说明:
  - 只动点名的这几份;你那份存成旁边的 .bak,换之前还自动备份一份
  - 自家加的老师、activity 没有出厂那份,换不了

注意:
  - 盖掉家长改过的老师文件:家长明确说要回出厂的才跑

例子:
  cotutor reset math-tutor
  cotutor reset chinese-tutor/你说我画

cotutor doctor — 体检;--fix 修掉能自动修的

用法:
  cotutor doctor [--json]
  cotutor doctor --fix
  cotutor doctor --live

选项:
  --fix   修掉能自动修的(幂等,不碰孩子的数据,不用人输东西),要人来的留着
  --live  真连一次百炼的嘴、真配一句音
  --json  机器可读的输出

说明:
  - --json 里没过的项带 cmd(能直接跑)或 human(要人来)
  - 有必需项没过,退出码 1

注意:
  - --live 花一分钱

例子:
  cotutor doctor --fix
  cotutor doctor --json

cotutor pack — 干跑上下文包:不起模型,看老师会拿到什么

用法:
  cotutor pack <老师> [<消息>] [--activity <名> [--param '名=值;名=值']] [--from kid|system] [--at <ISO时间>] [--json]

选项:
  --activity <名>        像孩子点了首页的 activity 按钮,新开话题
  --param '名=值;名=值'  activity 的参数(按钮下面那几行)
  --from kid|system      谁说的(缺省 kid;system 不算孩子说的)
  --at <ISO时间>         当作这个时间
  --json                 机器可读的输出

说明:
  - 每段来自哪个文件、一共几条、按政策带了几条;改了档案、日记、计划立刻看效果

例子:
  cotutor pack math-tutor "讲讲退位"

cotutor replay — 同一问按现在的提示词再跑一遍,并排对照

用法:
  cotutor replay <老师> <job> [<日期>] [--runtime <名>] [--json]

选项:
  --runtime <名>  换个运行时
  --json          机器可读的输出

说明:
  - 落 evals/,不进孩子的对话、不配音

注意:
  - 花钱

例子:
  cotutor replay math-tutor 1620-1 2026-09-12

cotutor compare — 再看一次回放的对照

用法:
  cotutor compare <老师> [<evalJob>] [<日期>] [--json]

选项:
  --json  机器可读的输出

说明:
  - 不给 evalJob 就列这天回放过哪些

例子:
  cotutor compare math-tutor

cotutor show — 看一轮:问了什么、上下文包、讲稿与卡、读了什么

用法:
  cotutor show <老师> <job> [<日期>] [--evals] [--json]

选项:
  --evals  看回放的那轮(evals/ 里的)
  --json   机器可读的输出

说明:
  - 日期缺省今天;--json 和家长端「看原文」是同一份

例子:
  cotutor show math-tutor 1620-1 2026-09-12 --json
```
