# 上下文包每一行是什么

消息前面 `cotutor:` 开头的那段 YAML,是应用替你备好的。它后面接几段原文,再是 `---`,再是消息本身。

怎么用这些行,见守则(`<cotutor-rules>`);vault 里的东西什么时候读,见 cotutor-vault 技能。

## 每一行

| 行 | 是什么 | 什么时候有 |
|---|---|---|
| `at` | 本地时间,分钟精度,如 `2026-09-08T16:20` | 每条 |
| `slot` | 课程表命中的时段,如「数学 16:00-17:00」 | 命中时 |
| `focus` | `focus.card` 是孩子发消息时正开着的那张卡(`<job>/<n>`) | 开着卡时 |
| `rules` | 老师守则在哪,后面跟状态 | 有脸的老师 |
| `boardGuide` | 板书写法在哪:「已在你的系统提示里」,或一个路径加状态 | 板书没关时 |
| `semester` | 当前学期,如「二年级上」。应用按档案算好的,你不用再推 | 算得出时 |
| `profile` | 档案的路径(相对 vault 根),后面跟状态 | 每条 |
| `entry` | 你这一科这学期入口文件的路径,后面跟状态 | 有脸的老师 |
| `memory` | 你的记忆文件的路径,后面跟状态;「还没有」= 你还没记过东西 | 每条 |
| `refs` | 参考资料的绝对路径:这科这学期的教材,加档案与入口文件里链到的笔记。**只给路径**,用到才读 | 有资料、这轮带工具时 |
| `plan` | 本周计划里你的行 | 计划里有你时 |
| `recent` | 最近 14 天日记里本学科的「- 观察:」行,取最新的几条 | 有观察时 |
| `board` | `off` = 只说话,不出卡 | 家长关了板书时 |
| `cards` | 上一轮之后孩子在卡上做的,一张卡一行:编号、种类、标题、做了什么、答案 | 孩子动过卡时 |
| `lecture` | 孩子刚看完的小课堂:`title` 课名,`source` 哪一课(`bundle <id>` 是课包,`video <id>` 是视频),`length` 课长,`lines` 每句的起点与原话(「0:18 …」),`watched` 他怎么看的(看完没、停过几次、圈了几处),`marks` 他圈的每一处:那一刻在讲哪句、圈住了什么;视频的圈是截图,在 `photos` 里第几张 | 看完后的第一条;问过以后再看一遍又圈了的那条 |
| `home` | 孩子从首页的按钮进来:`button` 是按钮上的字,`brief` 是家长备好的讲法 | 只在按钮发来的那条 |
| `continue` | 接着以前某天的某个话题:`from` 哪天哪个话题,`title` 话题名,`said` / `cards` 那个话题最后一节的讲稿与卡(卡带孩子做的与答案),`index` 那天的对话索引 | 只在新话题的第一条 |
| `photos` | 这条带的作业照片,相对 workspace 根。写在卡上用 | 孩子拍了照片时 |
| `photoFiles` | 同一批照片的绝对路径,顺序一一对应。**Read 用它** | 同上 |
| `vault` | 家长的 Obsidian 仓库在哪:`root` 是绝对路径,`diary` / `plans` / `timetable` / `reference` 相对 `root` | 配了 vault、这轮带工具时 |

## 路径后面的状态

`rules`、`boardGuide`、`profile`、`entry`、`memory` 的路径后面可能跟一段括号:

| 写着 | 意思 | 你怎么做 |
|---|---|---|
| 只有路径 | 原文就在后面的原文段里 | 看原文段 |
| 「未变」 | 这个话题前面已经给过原文,内容没改 | 往前看,别再 Read |
| 「截到 N」 | 原文太长,只带了前面 N 字 | 用带来的这些;这轮带工具才 Read 全文 |
| 「只带最近 N」 | 记忆太长,截掉的是前面旧的 | 同上 |
| 「缺:…」 | 没有这篇,冒号后面写着为什么 | 照常教,别编 |

## 原文段

YAML 后面、`---` 前面,整篇原文照登:

| 标签 | 是什么 |
|---|---|
| `<cotutor-rules>` | 老师守则 |
| `<cotutor-board>` | 板书写法(没进系统提示时才有) |
| `<vault-note role="profile">` | 档案 |
| `<vault-note role="entry">` | 你这一科这学期的入口文件 |
| `<vault-note role="memory">` | 你的记忆 |

- 守则与笔记只在话题第一条带,或者话题里原文改过了才再带。
- 家长写的字是真相。

## 拼 vault 里的路径

- 路径拼法:`<vault.root>/<相对路径>`。
- `root` 可能含空格。
- 别猜缺省名,别去读 cotutor.json。
