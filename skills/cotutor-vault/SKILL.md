# 家长的 Obsidian 仓库怎么读、记账怎么回

## 这个仓库是什么

家长在 Obsidian 里看和改的那个目录(下面叫 vault),是关于孩子的**长期记忆**。对话、板书、照片都在 workspace,不在这里。

家长写的笔记**按 frontmatter 的 `cotutor:` 属性认**,不认文件名和目录。家长会改名、挪位置。

| `cotutor:` | 是什么 | 你怎么拿到 |
|---|---|---|
| `profile` | 孩子的档案,一个 vault 一篇 | 每个话题第一条,原文在 `<vault-note role="profile">` |
| `subject` | 你这一科这学期的**入口文件**(`subject` 与 `semester` 属性对上的那篇):学到哪、常问什么、家长的讲法偏好。正文里的 `[[链接]]` 指向更多资料 | 每个话题第一条,原文在 `<vault-note role="entry">` |
| `textbook` | 一册教材。可以没有,可以多本 | 路径在上下文包 `refs:` 里,自己 Read |
| `memory` | 你自己的记忆(`agent:` 是你的名字),一个老师一篇,缺省在 `记忆/<显示名>.md` | 每个话题第一条,原文在 `<vault-note role="memory">` |

另外两样按目录找:

- 日记:`vault.diary`,一天一篇,记账时应用追加。
- 周计划:`vault.plans`,家长写。

上下文包里每一行是什么、路径后面的状态怎么看,见 `../../.claude/skills/cotutor-tutor/references/上下文包.md`。

**家长写的字是真相。** 你不写 vault 里的任何文件。记账、记忆都是回一段文本,应用替你落盘。

## 什么时候读什么

| 时机 | 做什么 |
|---|---|
| 随口问答 | 只用上下文包,不读文件 |
| 讲解之前 | 入口文件里提到的、和这次有关的 `refs`,读一篇。有教材就 Grep 这次的字、词、课题,只读命中的那一节 |
| 想知道以前讲过什么 | Grep 日记目录(`<root>/<diary>/`),看命中那几段的摘要与 `骨架:` 行 |
| 孩子最近问过什么 | 在日记目录 Grep `孩子问`,加 `-A3` |

## 记忆的细节

「## 记忆」段的格式、记什么,见守则的「## 记忆」。这里是应用怎么处理、还有哪些不记。

例子:

```markdown
## 记忆
- 讲跨十用「先凑成十」他马上懂,用「借一」听不懂
- 家长说周末不讲新课,只复习
```

应用怎么处理:

- 一轮超过两条,多的应用丢掉,并提醒家长。
- 缺省是新增:应用给每条加日期,追加到你的记忆文件末尾。
- 文件不在就建:`记忆/<显示名>.md`,带 `cotutor: memory`、`agent:`。
- `- 改:原话 → 新的` 改那一行,`- 删:原话` 删那一行。原话照记忆文件里那行抄,日期可以不抄。
- 谁写的行都能改。找不到那一行的,应用不动,并提醒家长。
- 家长在 Obsidian 里改、删、分小节都行。下个话题你看到的就是改过的。
- 家长点记账之后,应用会另起一轮,让你整理整篇记忆:合并重复的,改掉过时的,整理完不超过 30 条。那一轮不受两条的上限,消息里会写怎么回。

另外不记:

- 照片路径。
- 对孩子的评判。
- 家长改掉或删掉的,别再记回去。
- 画图老师只记手艺,不记孩子。

## 记账任务:回什么

什么时候是记账:上下文包 `from: system`,消息说「给刚才这个话题记账(话题 xxx,家长打了 n 星)」。这轮 resume 的是那个话题的会话,你记得聊了什么。

- 只回一段「## 记账」,别的一个字都不写,**不用工具**。
- 字段、消息原样、解析器认什么、应用替你补什么,都在本目录的 `references/记账.md`。
- summary、steps 只在消息里要了才写(打分够时)。没要的写了,应用也丢。
- textbook 从消息里列的教材目录挑一条,**原样抄**。都不是就不写这行,别自己编一个目录里没有的。
- 话题里有作业照片:摘要里把你认出的册子、页、题号、题面写成文字,**不写路径**。日记不存图。
- 孩子的问题永远值得记,但那是应用抄的,不用你写。

observations 写不写,先过**写入前三问**,过不了的别写:

1. 一年后,家长还想翻到它吗?
2. 你或别的老师下次讲同类东西,需要它吗?
3. 能不能被机械取出来(固定行头)?

## 谁能写 vault

封闭清单,只有这两处:

| 写什么 | 怎么写 | 谁 |
|---|---|---|
| 日记 | 只追加,文件不在就建 | 应用,按你的「## 记账」段 |
| 记忆 | 增、改、删(任何一行),文件不在就建 | 应用,按你的「## 记忆」段 |

永不:

- 写 `#标签`。
- 写图片或照片路径。
- 改家长写过的字。
- 删文件。
- 写档案、入口文件、教材、计划、课程表、参考。

## 常见错法

| 错法 | 为什么错 |
|---|---|
| 问答里去 Grep 日记、读 refs | 白花一轮,问答只用上下文包 |
| 见到「未变」又去 Read 档案、入口文件 | 原文就在这个话题前面 |
| 把整本教材 Read 进来 | 先 Grep,只读命中的那一节 |
| 把 `captures/…` 路径写进记账 | 日记里只留你认出的文字 |
| textbook 自己编一个「册#节」 | 教材目录里没有的,链不到任何东西 |
| 打分不够还写 summary | 应用会丢,白写 |
| 自己去 vault 里写文件、建目录 | 那是家长的地盘,机器只写上面两处 |
