# 家长的 Obsidian 仓库怎么读、记账怎么回

## 这个仓库是什么

家长在 Obsidian 里看和改的那个目录(下面叫 vault)是关于孩子的**长期记忆**;对话、板书、照片都在 workspace,不在这里。家长写的笔记**按 frontmatter 的 `cotutor:` 属性认,不认文件名和目录**(家长会改名、挪位置):

| `cotutor:` | 是什么 | 你怎么拿到 |
|---|---|---|
| `profile` | 孩子的档案,一个 vault 一篇 | 每个话题第一条,原文在上下文包后面的 `<vault-note role="profile">` |
| `subject` | 你这一科这学期的**入口文件**(`subject` 与 `semester` 属性对上的那篇):学到哪、常问什么、家长的讲法偏好,正文里 `[[链接]]` 指向更多资料 | 每个话题第一条,原文在 `<vault-note role="entry">` |
| `textbook` | 一册教材,可以没有、可以多本 | 路径在上下文包 `refs:` 里,自己 Read |
| `memory` | 你自己的记忆(`agent:` 是你的名字),一个 agent 一篇,缺省在 `记忆/<显示名>.md` | 每个话题第一条,原文在 `<vault-note role="memory">`;你写「## 记忆」段,应用增、改、删 |

另外两样按目录找:日记(`vault.diary`,一天一篇,记账时应用追加)与周计划(`vault.plans`,家长写)。

硬规则:**家长写的字是真相**。你不写 vault 里的任何文件——记账、记忆都是回一段文本,应用替你落盘。

## 上下文包里的这几行

- `semester:` 当前学期(如「二年级上」),应用按档案算好的;你不用再推。
- `profile:` / `entry:` 两篇的路径(相对 `vault.root`)。后面跟「未变」= 这个话题前面已经给过原文,内容没改,往前看;跟「截到 N」= 原文太长被截了,要全文自己 Read;是「缺:…」= 没有这篇,照常教,别编。
- `memory:` 你的记忆文件路径,状态写法同上,只是太长时截的是前面旧的、带的是最近的(「只带最近 N」);「还没有」= 你还没记过东西。
- `refs:` 参考资料的绝对路径:这科这学期的教材 + 档案与入口文件里链到的笔记。**只给路径**,用到才读。
- `plan:` 本周计划里你的行;`recent:` 最近 14 天日记里本学科的「- 观察:」行。
- `home:` 孩子从首页的按钮进来(家长排的首页):`button` 是按钮上的字,`brief` 是家长备好的讲法,照着开场、别念出来。只在按钮发来的那条出现。
- `continue:` 接着以前某天的某个话题(新会话):`from` 是哪天哪个话题,`title` 是话题名,`said` / `cards` 是那个话题最后一节的讲稿与卡(卡带孩子做的与答案),`index` 是那天的对话索引,要更多自己 Read。只在这个话题的第一条出现。

## 什么时候读什么

| 时机 | 做什么 |
|---|---|
| 随口问答 | 只用上下文包,不读文件 |
| 讲解之前 | 入口文件里提到的、和这次有关的 `refs` 读一篇;有教材就 Grep 这次的字 / 词 / 课题,只读命中的那一节 |
| 想知道以前讲过什么 | Grep 日记目录(`<root>/<diary>/`),看命中那几段的摘要与 `骨架:` 行 |
| 孩子最近问过什么 | Grep `孩子问` 加 `-A3` 在日记目录 |

路径拼法:`<vault.root>/<相对路径>`,root 可能含空格;别猜缺省名、别去读 cotutor.json。

## 记忆:什么时候记、怎么写

任何一轮都能记。在回复最后(板书之后、同一段里)写:

```markdown
## 记忆
- 讲跨十用「先凑成十」他马上懂,用「借一」听不懂
- 家长说周末不讲新课,只复习
```

- 一行一条,一轮最多两条,多的应用丢掉并提醒家长。孩子看不到这段。
- 缺省是新增:应用给每条加日期,追加到你的记忆文件末尾;文件不在就建(`记忆/<显示名>.md`,带 `cotutor: memory`、`agent:`)。
- 以前记的不对了、过时了:`- 改:原话 → 新的` 改那一行,`- 删:原话` 删那一行。原话照记忆文件里那行抄(日期可以不抄),谁写的行都能改;找不到那行的,应用不动并提醒家长。
- 家长在 Obsidian 里改、删、分小节都行,下个话题你看到的就是改过的。
- 家长点记账之后,应用会另起一轮让你整理整篇记忆(合并重复的、改掉过时的,整理完不超过 30 条);那一轮不受两条的上限,消息里会写怎么回。
- 记什么:这个孩子怎么教管用、哪种说法他听不懂、家长交代的做法(画图老师只记手艺)。
- 不记:档案、入口文件、记忆里已经有的;只关今天的事;照片路径;对孩子的评判。家长改掉或删掉的,别再记回去。

## 记账任务:回什么

触发:上下文包 `from: system`,消息说「给刚才这个话题记账(话题 xxx,家长打了 n 星)」,这轮 resume 的是那个话题的会话,你记得聊了什么。

- 只回一段「## 记账」,别的一个字都不写,**不用工具**;字段、消息原样、解析器认什么、应用替你补什么,都在本目录 `references/记账.md`。
- summary / steps 只在消息里要了才写(打分够);没要的写了应用也丢。
- textbook 从消息里列的教材目录挑一条**原样抄**;都不是就不写这行,别自己编一个目录里没有的。
- 话题里有作业照片:摘要把你认出的册子 / 页 / 题号 / 题面写成文字,**不写路径**——日记不存图。
- observations 写不写,过**写入前三问**:一年后家长还想翻到它吗;你或别的老师下次讲同类东西需要它吗;能不能被机械取出来(固定行头)。过不了的别写。孩子的问题永远值得记,但那是应用抄的,不用你写。

## 谁能写 vault(封闭清单)

| 写什么 | 怎么写 | 谁 |
|---|---|---|
| 日记 | 只追加,文件不在就建 | 应用,按你的「## 记账」段 |
| 记忆 | 增、改、删(任何一行),文件不在就建 | 应用,按你的「## 记忆」段 |

永不:写 `#标签`、写图片或照片路径、改家长写过的字、删文件、写档案 / 入口文件 / 教材 / 计划 / 课程表 / 参考。

## 常见错法

- 问答里去 Grep 日记或读 refs:白花一轮,问答只用上下文包。
- 见到「未变」又去 Read 档案 / 入口文件:原文就在这个话题前面。
- 把整本教材 Read 进来:先 Grep,只读命中的那一节。
- 把 `captures/…` 路径写进记账:日记里只留你认出的文字。
- textbook 自己编一个「册#节」:教材目录里没有的链不到任何东西。
- 打分不够还写 summary:应用会丢,别白写。
- 自己去 vault 里写文件或建目录:那是家长的地盘,机器写它只有上面两处。
