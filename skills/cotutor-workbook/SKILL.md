# 出练习册

你在一个 cotutor workspace 的根目录(有 cotutor.json)。

练习册是照教材一个单元(或一课)编的几页习题。孩子点首页上的按钮,舞台铺这一册,他用 Apple Pencil 直接在页上写、圈、画。
应用不认字:哪里是一道题、哪一格能写、圈里该有几个,全靠 workbook.json 里排版时记下的框。框准,孩子落的笔才归得到题,老师才说得对。

## 铁律

- **框是画的时候记下的,不是事后量的。** 一个排版脚本同时画页图、记框、出 workbook.json。不要先画图再去估坐标,也不要拿现成的图片(扫描、截图、教材页)来标。
- **页上不印答案。** 答案只写进 workbook.json 的 `teacher`,只给老师。
- **不照搬教材的图和题。** 照这一单元练什么重新编题、自己画简单的插图(圆点、方块、简笔的东西)。教材 PDF 只用来看学什么、用什么说法。
- **孩子看得到的字不评判:** 不写分数、对错框、「你真棒」。
- 改 vault 先问。练习册放在家长的 vault 里,写之前说清放哪、几个文件。
- 不改 agents/、cotutor.json、home/:挂首页走 cotutor-home,改 activity 走 cotutor-tune。
- 装东西(Python 包、字体)先问家长。

## 一、商量出什么

在对话里列提案,家长点头再动手:

- 哪一科、哪一册、哪一单元或哪一课。看 vault 的 `教材/` 里的课本 PDF、这一科的入口文件、日记里最近的「- 观察:」、本周计划。
- 几页:两到四页 A4 竖版,一页三五道题。孩子在 iPad 上一次做一页左右。
- 每道题练什么、什么题型(下面「题型」)。从易到难排,题号整册连着编。
- 一册的文件夹名(`<名>`):短,用中文或字母都行,不带斜杠、不以点开头,如 `表内乘法一`、`植物妈妈有办法`。首页按钮填的就是它。

## 二、排版脚本

一个脚本出一册,放在这一册的文件夹里(如 `generate.py`),以后改题、改图都改脚本重跑。

- 输出:`01.png`、`02.png`…(每页一张)、`workbook.json`,可选打印版 `<名>.pdf`(和 PNG 同一份排版)。
- 页图:A4 竖版的比例,宽 2600 左右(放大 2 倍画:逻辑 1300×1839,出 2600×3678),白底。
- 每画一样东西就记下它的框:按页图的宽、高各换成 0–1000 的千分比(`[左, 上, 右, 下]`,横的按宽、竖的按高,所以同样大的方格,竖向的千分数比横向的小)。
- 字的框用字体量出来的(Pillow 的 `textbbox`、浏览器的 `getBoundingClientRect`),不要按字号估。
- 写完图算 sha256、记宽高,一起进 workbook.json。重画了图,json 一定要一起重出。
- 工具不限。现成的样子:Python + Pillow 画 PNG、ReportLab 出 PDF;macOS 的系统字体 Songti(宋体)、Kaiti(楷体,写字、识字用)、Hiragino Sans GB(数字、算式)。Pillow 没装要先问家长(`python3 -m pip install --user pillow reportlab`)。

### 页上怎么排

- 页眉一行:年级册次、单元名;题号用一个色块圆圈,题面跟在后面。
- 能写的格子要够大,孩子用笔写:填数字、填字的空格宽至少 45、高至少 40(都按页宽的千分比算);田字格 65–70 见方;四线三格一行高 35 以上。
- 格子画成浅底色带边框,一眼看得出能写。格子之间留空,别挨着(孩子的笔会出界,落进旁边那格就归错了)。
- 圈的东西(积木、读音、词)之间留出空当,一圈能只圈住想圈的几个。
- 题与题之间一条淡虚线。页脚页码。

## 三、写 workbook.json

字段、每种题型怎么记、一份完整的例子都在 references/格式.md。要点:

- 文字层 `lines`:页上印的每一行字,照原样。老师「看第几行」、孩子点字都照它。
- `terms`:孩子能点的字词(生字 `char`、词语 `word`,点了弹田字格或念),只给老师圈的写 `other`。
- 每道题:题号、题框(把题面和作答区都框进去)、完整的题面、作答区 `regions`、能指的东西 `objects`、给老师的 `teacher`(练什么、卡住了怎么引、答案)。
- id 写成 `q<题号>-<名字>`,整册不重。
- 答案挂在作答区上;几种写法都算对的都列;没有唯一答案的写 `note` 说怎么看。

### 题型

| 孩子做的 | 作答区 `kind` | 应用读得出他做了什么 |
|---|---|---|
| 填数、填字、写算式、写拼音 | `write` | 哪一格写了几笔;写成什么老师看图 |
| 田字格里写字 | `write` + `tian: true` | 同上;点开是田字格 |
| 圈出(选读音、每几个圈一组) | `circle` + 每个能圈的东西一个 `objects` | 每一圈围住了几个、是什么 |
| 照题画(画几个圆、画示意图) | `draw` | 框里画了几个合拢的形状 |
| 连线 | `link` + 两列端点(`side`) | 暂时只看图 |
| 在短文里画出句子 | `underline` | 暂时只看图 |
| 描字母 | `trace` + `fourLine` + `model` | 暂时只看图 |

- 数学多用 `write`、`circle`、`draw`:老师拿得到孩子做了什么的句子。连线、画线、描写老师只能看图,一页别太多。
- 写话、编题这种长的,作答区加 `say: true`:老师可以请他说着答。
- 描写区的 `model.strokes` 是那个字母的参考笔顺,照 `cotutor workbook glyph <字母>` 给的换到页上(说明在 references/格式.md)。

## 四、检查

1. `cotutor workbook check <名>`:形状、题号和 id、框、答案的引用、页图的宽高和 sha256。「要改」改到没有。
2. 自己看图:脚本多出一张把所有框描成红线的预览图(放临时目录,不放进 vault),逐页看一遍:题框框住整道题、格子框住格子、圈的东西框住那个东西、文字层压着字。
3. 再看一遍答案:每道题算一遍、读一遍;题面和答案对得上。

## 五、挂上去、试一下

- 现在出厂只有数学老师有「做练习册」这个 activity(`agents/math-tutor/activities/做练习册.md`)。语文、英语的册子要用,得先给那位老师加一个 `base: workbook` 的 activity(cotutor-tune 的活,跟家长说一声,别自己加)。
- 挂首页是 cotutor-home 的活:老师卡上一个按钮 `activity 做练习册 <孩子看到的字>`,下面一行 `练习册: <名>`。发布要家长明说。
- 想先试,在试用 workspace 里挂:命令都带 `--sandbox`(`cotutor home check --sandbox`、`cotutor home publish --sandbox`、`cotutor serve --sandbox`),不动孩子真的首页;试用 workspace 读的是同一个 vault 的练习册。孩子端点进去开口才起老师,花钱。

## 改一册

家长说「第 5 题答案错了」「第 2 页的格子太小」:改脚本、重跑、再 check。只改答案、提示也走脚本,别手改 json(下次重跑就丢了)。孩子做过的那几页,笔迹存在那节课里,题的位置挪了,以前的笔迹会对不上题:动版式前跟家长说一声。

## 报告怎么写

1. 出了什么:放在哪、几页几题、每页练什么。
2. check 的结果,自己看图看出的、改了的。
3. 还要家长做的:挂首页、要不要给别的老师加 activity。
