# 命令(机器生成,别改)

在 workspace 根跑;每条就是 cotutor <命令> --help 的内容。

```
这些命令都认 --workspace <目录>(在 workspace 根跑可以不写)和 --sandbox(在试用副本里跑,不进孩子的记录)。

cotutor workbook — 检查练习册;描写格子的字母笔顺

用法:
  cotutor workbook check [<名>] [--json]
  cotutor workbook glyph <字母>

选项:
  --json  [check] 机器可读的输出

说明:
  - 练习册放在 vault 的 练习册/<名>/(cotutor.json 的 paths.workbooks 能改),<名> 是文件夹名
  - check 不花钱:不给名字查每一册;列出全部要改的(形状、块与 id、叫法重名、框、答案引用、页图在不在、宽高与 sha256),都对了退出码 0
  - glyph 打印这几个字母的笔顺(JSON):x 高 = 1、基线 0、向下为正,guides 是四线三格的四条线;描写区的 model.strokes 照它换到页上

例子:
  cotutor workbook check
  cotutor workbook check 表内乘法一
  cotutor workbook glyph Aa
```
