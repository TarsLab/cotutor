# workbook.json 的格式

一册一个文件夹,放在 vault 的 `练习册/<名>/`(cotutor.json 的 `paths.workbooks` 能改到别处):

```
练习册/植物妈妈有办法/
  workbook.json        这里写的格式
  01.png 02.png …      每页一张图,和 workbook.json 由同一个脚本出
  植物妈妈有办法·练习册.pdf   打印版(可选,应用不读)
  generate.py          出这一册的脚本(应用不读,改题重跑它)
```

应用只读 workbook.json 和它写到的 PNG;文件夹里别的文件不管。写完跑 `cotutor workbook check <名>`。

## 坐标

- 每页自己的千分比:框 `[左, 上, 右, 下]`,点 `[x, y]`。x 按页图的宽、y 按页图的高,都是 0–1000 的数(可以带小数)。
- 页图不是正方形:A4 竖版高是宽的 1.414 倍,同样大小的方格,竖向的千分数是横向的 1/1.414。一个 68 宽的田字格,框是 `[130, 115, 198, 163]`(高 48)。
- 换算:`千分 = round(1000 × 像素 / 页图的宽或高)`,像素是最后出的那张 PNG 上的(放大画的,先乘倍数)。

## 一册

| 字段 | 是什么 |
|---|---|
| `version` | 写 `2` |
| `id` | 这一册的 id,字母、数字、汉字、连字符,一般就用文件夹名 |
| `title` | 册名,孩子在顶栏看得到:「《植物妈妈有办法》练习册」 |
| `subject` | `语文`、`数学`、`英语` 之一 |
| `grade` | 年级 1–6 |
| `term` | `上` 或 `下` |
| `source` | 照教材哪儿编的:`edition` 教材版本、`unit` 单元、`lesson` 课(可选)、`printed` 课本上印的页码 `[从, 到]`、`pdf` 课本 PDF 的第几页 `[从, 到]`(可选)、`note` 别的说明(可选) |
| `print` | 打印版 PDF 的文件名(可选) |
| `pages` | 每页一项,按页序 |

## 一页

| 字段 | 是什么 |
|---|---|
| `image` | 页图:`file` 文件名(只能是同一个文件夹里的 `.png`)、`w` `h` 像素宽高、`sha256` 文件的 sha256(小写十六进制) |
| `lines` | 文字层:页上印的每一行字,`text` 照原样、`box` 框住这一行。题面、选项、短文、表头都算;页眉页码可以不记 |
| `terms` | 孩子能点、老师能圈的字词:`text`、`box`、`kind`(`char` 一个字,点了弹田字格看笔顺;`word` 一个词,点了念;`other` 只给老师圈,比如题面里的「加点的字」)、`say` 老师怎么念(和字面不同才写,如多音字) |
| `zones` | 这一页的块:一道题一块,至少一块(下面) |

数学的册子点字不弹田字格,`terms` 写题面里要强调的几个词(`other`)就够了。

## 块 `zones`

和课本的分块是同一种写法(cotutor-textbook 技能改的也是它):一块是页上的一个框,能套小块。孩子点一下落到最里面那一块,老师说「看 第 3 题」照叫法找。

| 字段 | 是什么 |
|---|---|
| `id` | 一页里不重(和作答区、物件共用一套 id),写成 `q<题号>`、小题 `q<题号>-<名字>` |
| `kind` | 一道题 `problem`;题里的小题 `sub`(一个词、一个算式、一句口诀);一排算式、一组口诀 `group`(里面一句一个 `sub`);别的:`title` 页上的大标题、`column` 栏目、`table` 表格、`figure` 插图、`para` 一段短文、`example` 例题、`other` |
| `label` | 老师和孩子怎么叫它:题写「第 3 题」(题号整册连着编);小题照印着的叫(「bàn fǎ」「3×4」「二七」)。一册里不重名;小题只在同一道题里不重名 |
| `box` | 框:题框住题号、题面、图、所有作答区;小块在它外面那块的框里 |
| `say` | 孩子点了念什么:题照印的题面念,空着的地方念「几」「什么」(「3 个 4,几乘几?」)。不加没印的话,不念答案 |
| `regions` | 这一块里孩子作答的地方(下面),没有就不写 |
| `objects` | 这一块里能指的东西(下面),没有就不写 |
| `teacher` | 只给老师的:`goal` 练什么(题一定要写)、`hint` 孩子卡住了怎么引、`answers` 这一块里作答区的答案(下面)、`note` 别的要老师知道的(没把握的答案写这里,不硬写) |
| `children` | 套在里面的小块,写法一样 |

- 字和行不写进块:页上的 `lines` 落在哪块的框里就归哪块(几块都框住的归最里面那块),老师看到的题面就是这几行。
- 题里有(1)(2)、几个词、几个算式要分开写的,一个一个写成 `sub`:老师会说「看 第 1 题的 bàn fǎ」,孩子点一个听一个。不用单独指的不分。
- 答案挂在作答区所在的那一块上:作答区在小题里,答案也写在小题的 `teacher.answers`;题的 `teacher` 写练什么、卡住怎么引。只有答案的小题,老师那里一行说完。
- 老师拿到的:每页的块(叫法、印着的字)第一次看到时给一次;练什么、怎么引、答案是孩子眼前那几块的,每轮照他看的地方给。

## 作答区 `regions`

孩子在哪儿作答。他落的笔照作答区的框归到哪一格(一笔有四分之三在框里就算这一格)。

| 字段 | 是什么 |
|---|---|
| `id` | 一页里不重,写成 `q<题号>-<名字>`:`q1-1`、`q3-link`、`q5-乘号左边` |
| `kind` | `write` 写、`circle` 圈、`draw` 画、`link` 连线、`underline` 画线、`trace` 描写、`tick` 打勾(小方框,孩子用笔画勾) |
| `label` | 给老师看的名字,在这一块里叫什么:「乘号左边」「第 1 格」「写话第 1 行」。应用说给老师时前面接上块的叫法(「第 1 题的乘号左边」),名字里已经有就不接 |
| `box` | 框,要在它那一块的框里 |
| `tian` | `true`:这一格是田字格,一格一个字 |
| `fourLine` | 四线三格的四条线,从上往下的 y `[第一线, 第二线, 第三线, 第四线]` |
| `model` | 照着写的字母:`glyph` 那个字母,`strokes` 参考笔顺(一笔一串点 `[x, y]`,页上的千分比)。描写区必须有;临写的格子可以带 |
| `say` | `true`:这一格写起来长(写话、编题),老师可以请他说着答 |

- 一格一个作答区:两个字的词是两个田字格,一个算式「□×□=□」是三格。答案再把它们串起来。
- 圈的作答区框住所有能圈的东西;要圈的东西各写一个 `objects`,`region` 指这个作答区。
- 连线的作答区框住两列端点;端点各写一个 `objects`,带 `side: "left"` 或 `"right"`。左右两头都要有。
- 描写的字母:`cotutor workbook glyph Aa` 打印笔顺。坐标是字母自己的:x 高 = 1,`u` 从字的左边起往右,`v` 基线是 0、往下为正(第一线 -2、第二线 -1、第三线 0、第四线 1)。四线三格一格高 `h` 像素(第一线到第二线),字母放在 `x0`,基线在 `y0`:页上一点 = `(x0 + u × h, y0 + v × h)`,再换千分比。`fourLine` 是 `y0 - 2h`、`y0 - h`、`y0`、`y0 + h` 换成千分比。画在图上的灰字母也用这份笔顺画,孩子照着描的就是老师看的。

## 东西 `objects`

写在作答区所在的那一块上。

| 字段 | 是什么 |
|---|---|
| `id` | 一页里不重(和块、作答区共用),写成 `q<题号>-<名字>` |
| `label` | 是什么:「积木」「jiàng」「蒲公英」「靠风」 |
| `box` | 框住它画出来的样子 |
| `center` | 画出来的中心(立体的积木中心不在框的正中),要在框里 |
| `region` | 它在哪个作答区里被圈、被连;只用来数的图(数一数有几个风车)不写 |
| `side` | 连线的哪一头:`left` 或 `right`,只有连线的端点写 |
| `group` | 画面上本来就分好的组,第几组(第几盘草莓),从 1 起 |

## 答案 `teacher.answers`

一条答案占这一块里的一个或几个作答区。三种写法至少有一种:

| 字段 | 是什么 |
|---|---|
| `at` | 这条答案占的作答区 id,按书写的顺序 |
| `ok` | 都算对的写法,每种是 `at` 那几格连起来写的样子:`at` 是乘号左、乘号右、积三格,`ok` 写 `["3×4=12", "4×3=12"]` |
| `links` | 连线:`[[左端, 右端], …]`,都是物件的 id,挂在连线的作答区上 |
| `note` | 没有唯一答案时怎么看:「每组圈 4 个,圈法可以不同」「说清哪种植物、种子怎么走的就行」 |

答案只给老师参考,孩子端不判对错,老师也不念出来。

## check 报的那些

| 报的 | 怎么改 |
|---|---|
| 某个字段「Too big」「Invalid」 | 框出了 0–1000、`kind` 写错、少了必填的字段:照上面的表补 |
| version「expected 2」 | 写的是旧的格式(一页的 `questions`):照这一篇改成 `zones`,一道题一块 |
| 框不是左上到右下 | 左和右、上和下写反了 |
| 出了「…」的框 / 作答区出了块框 | 外面那块的框画大一点,把小块、作答区都包进去 |
| id 重复 | 一页里块、作答区、东西共用一套 id,加上题号前缀 |
| 有几块都叫「第 3 题」 | 题号整册连着编;小题同一道题里不重名 |
| 题要写 teacher.goal | 每道题写这道题练什么 |
| 中心不在框里 | `center` 照画出来的中心算 |
| 作答区「…」不在这一块里 | 东西的 `region`、答案的 `at` 只能指同一块里的作答区:答案写到作答区所在的那一块(常是小题)上 |
| 连线的端点要写 side / 左右两头都要有端点 | 连线的东西都带 `side`,两列都有 |
| 描写区要带 model | 描写区写 `model`(`cotutor workbook glyph` 取笔顺) |
| 图是 W×H,workbook.json 写的 … / sha256 不一样 | 图重画了,json 没跟着重出:重跑脚本 |
| 没有一块写了 say(提醒) | 题写上 `say`,不认字的孩子点题能听 |
